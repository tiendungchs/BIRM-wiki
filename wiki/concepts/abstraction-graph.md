# Abstraction Graph

**An abstraction graph is the sparse, lit subgraph of the world's derivation graph that a bounded agent holds: typed schemas with free variables as nodes, "derived from" with a premise set and a fidelity as the edge, ordered by generality, each node carrying a grain and a horizon on the world side and, on the agent side, an access cost, a precision, a suppression flag and a provenance pointer. It is what the meta-graph's vocabulary becomes when it is given depth and a budget, and the centre of this page is what holding one requires of an agent's architecture.**

> **Epistemic status — (brainstorm) throughout.** Assembled from a two-day brainstorming session (14–15 October 2026) and from wiki material, following the pattern of [[wiki/concepts/reasoning.md]]; no new source was ingested. Every empirical statement is cited to the page that carries it. The derivation graph is the world's hidden rule structure. The abstraction graph is an `L0` description of how an ideal bounded agent would internalise and compress that structure — what its competence looks like as if it held such a subgraph — and not a claim that any agent, the brain included, materialises it or recovers the hidden structure exactly. The one measured biological graph estimate shows what to expect instead: on the core framing's state graph the brain holds a predictive metric, not the topology (Garvert et al. 2017, [[wiki/concepts/latent-graph-discovery.md]]), whatever serves prediction rather than the structure itself, and the same should be expected one level up. The page's `L1` content is the requirements table below: fourteen constraints a decomposition must meet to hold the graph, each naming a component kind (a binder, a variable-length loop, a suppressor, an AND-OR controller) without committing to a realisation. The one `L1` decomposition assumed outright is a cache and a deriver, with the cache's contents chosen under a budget ([[wiki/concepts/amortized-inference.md]]). Where the page adopts one side of a `LIVE` tension it says so at the point of use (`T392` Position A, `T131` Position B). A precedent audit (22 October 2026) added the **Precedents not ingested** section: where an idea on this page has a close source outside the wiki, that section names it once; the body does not cite it, since nothing uningested counts as evidence here.

## Limits

**Derivation order of this page: setup → limits → features of the graph → consequences → requirements → Correspondence.** The setup lives on [[wiki/concepts/latent-graph-discovery.md]] (§ The Setup): an agent in a world, with a goal, perceiving a sliver of the state at a time; the five limits of the first group are stated there and repeated here. The page reasons from the problem side toward the brain: the features below are predictions about how an ideal bounded agent would internalise, compress and retrieve its world's structure, and the brain is read against them last. Every feature on this page carries a **follows from** cell naming the limit or the earlier feature that forces it; a feature that cites nothing is marked **posited**. The list is closed: no limit is added below this section, and the brain adds none.

**Direction `(brainstorm)`.** The agent whose features are predicted is the *ideal* bounded agent, the optimum of the front under Scoring: a small, deep, lit set `R` that derives almost all of its domain within budget (Understanding), sparsely lit across depths at fixed memory and not all-deep. That optimum is the direction the frontier moves toward, and it is what keeps the page finite: reasoning from the limits alone grows a feature list without bound, and a feature the ideal agent does not need is not added. The human whose competence the target resembles is the expert with a deep understanding of a domain, not the one who learned it by heart. The shortcuts the human record also shows, chunking and segmentation on [[wiki/concepts/relational-reinterpretation.md]], the degenerate corners under Scoring, are the brain's approximations of the front and not features of the target; nothing in the wiki models them, and the page does not ask it to. The brain is read against the features last, as Correspondence, for the same reason.

| Limit | Group | What it denies the agent | Degenerate agent it excludes |
|---|---|---|---|
| **Partial perception** | setup | reading the state: an observation is a coarse-graining of it, so structure is inferred, never read off | — |
| **Time** | setup | unbounded deliberation per step: the world moves while the agent perceives and derives | — |
| **Energy** | setup | free observation, derivation and action | — |
| **Finite experience** | setup | the full graph: only the visited part is evidenced, the rest is extrapolated | — |
| **A goal** | setup | indifference: the goal sets the query distribution, so which structure is worth holding is decided by what will be asked | — |
| **Memory** | definitional | holding every situation met | the **lookup table**: unbounded memory, answers by match, needs no schema for anything already met |
| **Compute** | definitional | deriving from the base at every query | the **simulator**: the generator-agent of the next section, unbounded derivation per query, needs no cache |

The second group is a choice of this page, not a consequence of the setup. Both could be argued from energy and time as rates; the page does not argue them, and states them outright so that the two degenerate agents are excluded by definition. The two agents are the two corners of the front under Scoring: the lookup table is the all-shallow-lit corner and the simulator the base-only corner, and the question the page answers — how an ideal bounded agent internalises and compresses its world's structure — has an answer other than a corner only once both limits hold.

## Two graphs

| Object | Definition | Held by | Follows from |
|---|---|---|---|
| **Derivation graph** (world side) | The closure of the world's axioms and building blocks under derivation: every schema derivable from them, every coarse-graining of their variables, and each coarse-graining's *true* error `ε` — zero exactly when the coarse-graining is computationally closed ([[wiki/concepts/computational-closure.md]]) | In full, only by the **generator-agent**: the world's own simulator, which predicts the whole next state exactly at unbounded cost — the agent the compute limit excludes. The formal ceiling of this page, as [[wiki/entities/aixi.md]] is the core framing's | the setup: a world with a hidden rule structure. That the structure is held as a closure under derivation is the formalisation chosen — **posited** |
| **Abstraction graph** (agent side) | A lit subgraph of the derivation graph with the per-node attributes below and an *estimated* `ε` on each lossy edge. Per agent: shaped by what it has met and what it can afford | Any bounded agent. An efficient agent predicts the *relevant part* of the next state with bounded error at a small fraction of the generator's cost, using lossy schemas over coarse variables | finite experience (only met structure is lit), memory (only what can be held is lit), partial perception (`ε` is estimated, never read) |

**Relation to the core framing.** [[wiki/concepts/latent-graph-discovery.md]]'s nodes are world states and its edges are transitions. The abstraction graph's nodes are that framing's *node types and edge labels*. So it sits over the core framing's vocabulary, which that page holds as a flat alphabet (hardness source 2) and which [[wiki/concepts/reasoning.md]] shows every operation-definition takes as given. It fills the open problem "multi-level hierarchy — making W itself a discoverable graph" and gap `G9`. The state graph is unchanged: it is the world.

**Where the state graph is held is not assumed.** The requirements table names a brain candidate per row and takes no side on which tissue holds the instance graph the candidates operate on: `T28` (map or index, `LEANING` toward a map where no cortical structure applies and an index once one does), `T107` (hippocampal formation or cortical controller, `LIVE`), `T203` (abstract format hippocampal or shared, `LIVE`). The solution-side pages read against this table do take a side, and say so: [[wiki/entities/medial-prefrontal-cortex.md]]'s reading in the core framing assumes the subgraphs are hippocampal and the ventral tier selects among them (`T107` Position A), and [[wiki/concepts/schema-assimilation.md]]'s `cue → PFC selects schema → HPC retrieves the path` assumes the same. The rows below survive either answer; what moves with it is which row's brain candidate is a store and which is a reader.

**The base is finite, world-side.** Every learnable world has a finite base, because learnable means compressible ([[wiki/concepts/universal-induction.md]], read in reverse). Where the world contains other agents, their abstraction graphs are part of its base, so a theory of mind is a coarse model of another agent's lit set — which is where the edge-driver-latent benchmarks sit ([[wiki/entities/bib.md]], [[wiki/entities/agent-benchmark.md]]). Stochastic generators qualify; determinism is not assumed.

**Disambiguation.** On the compositional-generalisation pages ([[wiki/entities/cfq.md]], [[wiki/entities/scan.md]]) "derivation" names the per-instance parse tree, an instance-graph object. Here it names the relation between schemas.

## Nodes and edges

| Element | Definition | Consequence | Follows from |
|---|---|---|---|
| **Node** | A typed proposition schema with free variables | A **concept** is a schema with a unary head (`fork(P, A, B)`); a **rule** has at least one free variable and a precondition; a **fact** has none. Facts are the shallow end: the most specific nodes, with nothing derived from them | finite experience + a goal: one lifetime meets each situation at most once while the queries range over unmet ones, so anything held that transfers must range over situations — a free variable. The type system splits in two. Its **minimal sorts**, an *individual* sort and a *relation* sort carrying an arity, follow from Width below: a variable that ranges over schemas as well as over individuals cannot be stated without them. The **rich type lattice** (piece against square in the chess case) is **posited**; the candidate ground is the cache objective, a precondition shared by many schemas folded into the variable as a cached precondition, and the page does not argue it |
| **Edge** | "Derived from": a *premise set* → one conclusion (AND); a node may have several alternative derivations (OR) | The graph is an AND-OR graph. A derivation of `X` is an AND-tree rooted at `X`; its **premises** are the nodes where expansion stops. "Go down as far as needed" = expand toward deeper premises until every premise is lit | the derivation graph: closure under derivation gives the premise set (AND); two chains reaching one schema give the alternatives (OR) |
| **Fidelity** | **Exact**: instantiate a variable, add a precondition, chain two schemas, unfold a definition. **Lossy**: replace variables by a coarse-graining of them; the conclusion then holds with closure error `ε` at that grain. `ε` is the edge's error on the coarse variable's *own* dynamics only; what the coarse-graining discards about the fine state is the node's grain attribute, not part of `ε` (the split is made under Tests and open problems) | Deduction, which the reasoning census says no wiki definition covers, lives on exact edges. Induction and discovery are not a third edge kind: they light a deep node from many shallow lit facts, its edges to those facts staying exact instantiations, with the uncertainty carried as the new node's precision (below), not as `ε`. **Exact is a formal kind, not a neural one.** The one lesion series that tests deduction and analogy together separates items by how many mutually irreducible structures a step must hold at once (indeterminate against determinate syllogisms), not by validity (Mole et al. 2025, [[wiki/entities/lateral-frontoparietal-network.md]], [[wiki/concepts/reasoning.md]]); the quantity the anatomy sees is row 14 of the requirements table, which cuts across exact and lossy | exact: the derivation graph's own edges. Lossy: partial perception (the agent's variables are coarse-grainings to begin with) + compute (an exact chain may exceed the per-query budget, so a coarse variable with a known error is the cheaper node) |
| **Direction** | General → specific throughout. Convention: deep is *down*, so derivation runs upward from premises to conclusion and expansion runs downward from a conclusion to its premises; induction lights a node further down | Specialisation is instantiation. Inheritance: a rule applies to a concept and to all its specialisations, never to its generalisations | the edge: instantiation specialises. "Deep is down" is notation, not a feature |
| **Length** | A derivation runs until every premise is lit, so its length is set by the query and by the current lit set, not fixed in advance | Chaining at inference time is variable-length; no bound on the number of steps per query can be set before the query arrives. The feature the variable-length-chaining row of the requirements table cites | the edge (expansion stops at lit premises) + the abstraction graph (which premises are lit is per agent) + a goal (the queries vary) |
| **Width** | An AND edge with `k` premises needs `k` nodes co-held while the conclusion is formed. Since a node is a schema and a variable may range over schemas — a relation is itself an object of the graph — second-order schemas exist (a relation between relations), and one needs its first-order premises held apart from each other while it is formed | Holding is `k`-wide, not only long: a bound on co-held mutually irreducible structures is a second budget on derivation, independent of length. The feature the width row of the requirements table cites | the edge (a premise set, not a single premise) + a goal whose queries span domains: an inference that transfers across domains must be stated over relations, not over the individuals of one domain ([[wiki/concepts/relational-reinterpretation.md]], P7), so a variable must be able to range over relations. The node is cited for relations as objects only; the sorts run the other way, from this row to the Node row |

**Worked case (chess).** `fork(P, A, B) ⟺ attacks(P, A) ∧ attacks(P, B) ∧ A ≠ B` is a concept derived *exactly* from the base predicates; unfold it and the movement rules are back. "Knight forks king and queen, queen unprotected → queen lost in two plies" is derivable from the movement rules plus "the king must leave check" by a long exact chain, and is one step once `fork` is lit. So a concept is a *named sub-derivation* that shortens every derivation through it — [[wiki/entities/dreamcoder.md]]'s library — which is why one can understand without articulating: the long chain exists whether or not the lemma is named. `material = Σ piece values` is a *chosen* coarse-graining of the piece-position variables, a lossy edge with no exact chain behind it; "material advantage of two or more → likely win" is not derivable from the axioms by any exact chain, holds at the grain of `material` with some `ε`, and is the kind of node an efficient agent's graph is mostly made of.

## Three axes, not one

| Axis | Property of | Measures | Ordering comes from | Follows from |
|---|---|---|---|---|
| **Generality** (deep / shallow) | a *schema* | how many situations its preconditions admit | derivation: specialising makes a schema shallower | the node + the edge: instantiation specialises |
| **Grain** (coarse / fine) | a *variable* | how much of the state the many-one map discards: the unprocessed information `Δ = I(←X;→X) − I(←Z;→Z)` of [[wiki/concepts/computational-closure.md]], small for an irrelevant merge and large for a relevant level | the coarse-graining lattice ([[wiki/concepts/computational-closure.md]]) | partial perception: the observation is already a coarse-graining, and every lossy edge adds one |
| **Horizon** (long / short) | a *prediction* | how many generator steps ahead the conclusion is about | the generator | time + a goal: the world moves, and the queries ask about steps ahead |

Only generality orders the graph; grain and horizon are node attributes. Chess separates all three: the knight-move rule is deep, fine and one-ply; the material heuristic is deep, coarse and long; a memorised opening line is shallow, fine and medium; "opposite-coloured bishops draw" is mid-depth, coarse and long.

**Two caveats on the grain axis.** Its floor is the causal-state partition, the coarsest partition that loses nothing about the future, with an asymmetry: a predictor may over-split it at zero loss but never over-merge ([[wiki/concepts/causal-states.md]]). And the axis assumes a coarse variable is a partition. Some systems have finite linear dimension and no finite node set ([[wiki/concepts/predictive-state-representations.md]]); for those the coarse variable is a vector of test predictions and its grain is a rank, not a cell count.

Two correlations are statable as conjectures with a mechanism, and neither is a definition:

- **Long horizon selects coarse grain** — the "abstraction level = prediction horizon" claim of [[wiki/concepts/abstract-structural-codes.md]] is a *selection* claim on one attribute, not an identity between axes: train a representation to stay predictable far ahead and it discards what cannot be predicted far ahead. Against it: sufficiency for the *whole* future needs a finer partition as the horizon grows ([[wiki/concepts/causal-states.md]], the fixed-horizon remark). The two reconcile because the predictable information shrinks with horizon while the distinctions needed to keep all of it grow, so the conjecture is about what a bounded representation keeps, not about the sufficient partition.
- **Deep reaches coarse at bounded length** — at a bounded number of derivation steps a deep exact schema reaches only what is near it, so the cheap predictions from a deep-lit store are the coarse invariants. This is a budget consequence, which is why it looks like a definition from inside.

## Agent-side attributes

| Attribute | Meaning | Biological register | Follows from |
|---|---|---|---|
| **Access cost** | What it costs to read the node now; a function of which store serves the read | Per store, table below | memory + energy: a held node is paid for per store, and a read is paid for |
| **Precision** | How far the node is trusted. Below one everywhere on the agent side: only the derivation graph holds truths. An exact derivation inherits its premises' precision; a lossy one adds `ε`. Updated by evidence, with the step scaled by expected information gained ([[wiki/concepts/synaptic-plasticity.md]]) | A register separate from strength, on a slower timescale ([[wiki/concepts/precision-weighting.md]]); accessibility declines while precision does not (`T392`) | partial perception + finite experience: structure is inferred, never read, so no agent-side node reaches the derivation graph's certainty; a lossy edge adds its `ε` |
| **Suppressed** | A competing node is winning. Refutation never deletes | Extinction adds a second, context-limited association; weights become unreachable and reacquisition is fast; abandonment has its own channel ([[wiki/entities/lateral-habenula.md]]) | partial perception: the refuting evidence is itself a sliver, so the node may hold in a context the agent did not see, and deleting it would lose that. "Never deletes" and "context-gated" are the derived parts |
| **Provenance** | The derivation that lit the node, or one of three terminal values: observed, told, innate. The registry already asks for this: `G71`, a generated inference is never tagged as one | The hippocampus reinstates the *intermediary* of a composed edge at choice time (Barron et al. 2020, [[wiki/concepts/offline-replay.md]]) | precision + suppression: when a premise loses precision or is suppressed the change must reach its dependents, which needs the derivation that lit each node to be recoverable |

Derived states are computed, not stored: **conjectured** = low precision; **refuted** = suppressed; **forgotten** = access cost has risen. This adopts Position A of `T392`, a `LIVE` row: forgetting is loss of address, not of the trace. The gate-out column of the store table below lists Position B's mechanisms (decay, addressed erase, an index "designed to be lost"), and under A each of those raises access cost rather than deleting; **derivable-but-unlit** and **unreachable** fall out of the AND-OR expansion. **Innate** = installed with high precision at low access cost, a strong default and not a constraint — defeasible at the conceptual level through symbol systems ([[wiki/concepts/core-knowledge.md]], `T11`).

**Two registers per node, moved by different events.** Precision moves on evidence: a confirmation or a contradiction of what the node predicts. Access cost moves on use and on budget: a read lowers it, disuse and eviction raise it. Neither event implies the other, so the two cannot be one quantity: a node may be trusted and hard to reach (forgotten, not doubted) or cheap to reach and distrusted (a suppressed habit still fires first). Follows from the two attributes' definitions above. This is the feature the access-cost-and-precision row of the requirements table cites; that the brain carries the two on different timescales (`T392` Position A, [[wiki/concepts/precision-weighting.md]]) is its Correspondence, not its ground.

**The stores run in parallel, not as a ladder** (the `L1` evidence; every row second-hand from the page named).

The closest the wiki comes to the ladder, "a chain of three or more stores with successively stricter gates", is listed as unexplored on [[wiki/concepts/recall-gated-consolidation.md]].

## What gets lit

**The cache objective.** Light the nodes that maximise `frequency × value × derivation cost saved / memory`. Reward has one role: it weights the query. Follows from memory (the denominator), compute (the derivation cost saved) and a goal (frequency and value are properties of the query distribution). The nearest measured form is replay priority as gain × need (Mattar & Daw 2018, [[wiki/concepts/simulation-based-planning.md]]): need is the frequency term, gain is value × derivation cost saved, and the memory denominator is absent because replay prices compute, not storage. The objective is a memo-table policy in the sense of [[wiki/concepts/computational-reuse.md]], whose three design issues map onto this page one to one: *generalisation* (how an entry serves a query it was not computed for) is the free variable, *persistence* is access cost, *decomposition* (whole answer or sub-solution) is concept against fact. The four measured gates are each a one-sided approximation:

| Gate | Approximates | Page |
|---|---|---|
| Recurrence: write to the slow store iff the fast store already recalls it | frequency | [[wiki/concepts/recall-gated-consolidation.md]] |
| Stop promoting at minimum held-out error | frequency, through generalisation | [[wiki/concepts/generalization-optimized-consolidation.md]] |
| Execution frequency, no reward term | frequency | [[wiki/concepts/value-free-habit.md]] |
| Reward × confidence as the recall factor; offline composition only for the rewarded chain | value | [[wiki/concepts/recall-gated-consolidation.md]], [[wiki/concepts/offline-replay.md]] |

**Concept formation, in series.** Closure bounds the `ε` a coarse concept *can* have ([[wiki/concepts/computational-closure.md]]: lumpable ⟹ zero; [[wiki/concepts/emergent-macrostates.md]]: a level is worth keeping when its predictive efficiency beats the finer level's). The cache objective decides whether to *pay* for it at that `ε`, which is [[wiki/entities/dreamcoder.md]]'s compression step. Hence what gets internalised is chosen by convenience, not cleanliness: near-synonyms survive because the cache objective, not closure, decides, and some coarse concepts cannot be made reliable however convenient.

**Plasticity falls out of the node kind.** Ground facts (no free variables) are written in one shot; a schema with free variables needs many instances. That is the one-shot node rule against the many-shot edge rule on [[wiki/concepts/synaptic-plasticity.md]], where "requiring many exposures *is* the spuriousness filter".

**Budgets.** All priced by the opportunity-cost rate `λ` of [[wiki/concepts/resource-rationality.md]]. `λ` has units: as the inverse temperature `β` of [[wiki/concepts/thermodynamic-bounded-rationality.md]] it is a sample count, and that page gives the outer-loop objection (the cost–benefit is learned, not run) its mechanism: the agent does not reason about its constraint, it derives until the resource runs out. The alternative to a price is an aspiration level, a stopping rule for derivation that drifts with how hard success is to reach ([[wiki/concepts/satisficing.md]]). This page prices every budget by `λ` and inherits the outer-loop objection with it; the aspiration level is the `G107` answer that needs no exchange rate, and it is not used here.

| Budget | Where it enters | Follows from |
|---|---|---|
| Perception | The observation is a coarse-graining of the true state: the core framing's observation-map bit, with [[wiki/concepts/emergent-macrostates.md]]'s `f : Γ → Ξ` as the map | partial perception |
| Memory | Number of lit nodes × per-store hold cost | memory |
| Compute | Derivation steps per query; the exchange rate against accuracy is hand-set in every architecture that varies its own compute (`G107`) | compute |
| Time | The world moves while the agent derives | time |
| Energy / action | Folded into `λ` | energy |
| Ingraining | The per-store hold cost of lowering a node's access cost | memory + the access-cost attribute |
| Experience selection | Observation is free per unit and time-bounded, so which experience to seek is a priced choice ([[wiki/concepts/epistemic-value.md]], [[wiki/concepts/information-sampling-vs-search.md]], `G129`) | finite experience + time + a goal |

## Scoring, and the two levels

- **The front.** An abstraction graph is a point on an accuracy-versus-compute front against the derivation graph: the error it incurs on the queries it faces per unit derivation it runs. This is bounded optimality (Russell & Subramanian 1995, [[wiki/concepts/resource-rationality.md]]): optimise over programs for a machine, not over actions, and the lit set is the program. Deep-lit (general, slow) and shallow-lit (fast, brittle) are two corners; at fixed memory the optimum is sparsely lit across depths. Nothing in the wiki scores a vocabulary this way.
- **The meta-graph, agent-side.** The lit schemas general enough to apply to every instance of a family. This is a second definition beside the core framing's world-side `θ_shared`, not a replacement; the difference between the two is the measurable quantity (what the agent is missing, or has over-specialised). Where no common lit ancestor exists the agent must light one, which is the core framing's discovery case. The stronger reading, meta-graph = the *lowest* common lit ancestor, is a conjecture; under instantiation as the ordering, the lowest common ancestor of two schemas is their least general generalisation, a computable operation (Precedents), which would make the conjecture testable.
- **Mapping onto W / M.** Schemas ↔ slow stores ↔ meta-graph; ground facts ↔ fast stores ↔ instance-graph. The named exception: ground facts consolidate (a capital city is a ground fact in the slow store), which is the price of relevance as the criterion. **The exception is biology's main measured case, not a corner.** What consolidates into the medial prefrontal controller is exactly a ground-fact mapping, context + event → response, with the vocabulary of codes already in the controller at acquisition (Euston et al. 2012, [[wiki/entities/medial-prefrontal-cortex.md]]); the specific associate then leaves the ventromedial template for ventrolateral prefrontal and anterior temporal cortex at three months ([[wiki/concepts/schema-assimilation.md]]). So the slow store is reached in two stages through a way-station, which the store table carries as its own row, and the clean "schemas slow, facts fast" split is the limit the measured trajectory tends to, not the trajectory.

## Understanding

**An agent understands a domain `D` to the extent that a small, deep, lit set `R` derives almost all of `D` within budget**, scored by `|R|`, the depth of `R`, and coverage of `D` against the derivation graph, estimated on the facts the agent knows.

| In words | In the graph |
|---|---|
| "The correct root cause(s)" | A small `R` of deep lit schemas: one for life (self-replication), three for economics and governance (human nature, game theory, every decision is a compromise) |
| "With enough context and time, explain almost everything about it" | Derivations from `R` to almost every fact of `D`, runnable within budget, with the instance's ground facts as context |
| "Correct framing", "like choosing the loss function" | Framing = choosing `R`. A candidate `R` fails in one of three ways, separated in the table below: it is inconsistent, ungrounded, or incomplete. Only the first is a refutation |
| "It all clicks" | A compression event: connecting one node lights many derivations at once — the [[wiki/concepts/simplicity-principle.md]] (posit the hidden cause when the data compress better with it) and the richness protocol of [[wiki/concepts/causal-model-building.md]] (one representation answers classify, generate, explain). A competing account: abrupt learning is a model-class property, an unbounded-capacity class with a wide prior stalls and then collapses onto the truth with no uniform `N`, and no compression event is needed ([[wiki/concepts/predictive-information.md]]) |
| "Almost": the boundary cases | Targets whose derivation runs through a coarse concept with large `ε` at that target's grain. "Makes copies of itself" is exact for a cell and lossy for a virus, since the copying needs host machinery. The residue is derived from the fidelity attribute, not stipulated |

Three qualifications, all from the attributes above:

- **Nothing is absolute.** `R` has a precision like every other node, and it is not derived bottom-up — no one derives the whole domain of life. It is *reinforced*: each new fact of `D` that `R` derives raises it, each contradiction lowers it, by a step scaled to surprise. "Forming a theory" is lighting a deep node at low precision.
- **Dissonance has a size.** The cost of revising `R` is the number of lit nodes whose provenance pointer runs back through `R`: its dependent cone. That is computable from the pointers and gives a prediction (P7 below).
- **Three ways a root set fails**, each a different graph event with a different repair; the row above folded them into one word.

| Failure | Graph event | Example | Repair | Effect on `R` |
|---|---|---|---|---|
| **Inconsistent** | two AND-trees from `R` conclude `X` and `¬X`, or a derivation from `R` concludes the negation of a lit fact whose precision is higher than `R`'s | — | suppress the member of `R` the two derivations share | precision lowered by a contradiction step: a refutation |
| **Ungrounded** | expansion of a target toward premises never bottoms out: every premise needs a deeper one, so the candidate is not a root | an immortal, adaptable being needs regulation of its regulation, and of that | replace the member by a deeper node at which the chain terminates | `R` was not wrong but not deep enough: a depth failure |
| **Incomplete** | a known fact of `D` has no derivation from `R` within budget | any attribute of life other than replication fails to derive the others, so each is rejected as a root | add a member, or accept the lower coverage | the coverage score, not a refutation |

- **Understanding is not compression.** `G26` says a short description need not expose structure ([[wiki/concepts/universal-induction.md]]); formally, `C_μ` is not a description length, and a description-length state estimator grows structure the ε-machine does not have ([[wiki/concepts/causal-states.md]]). What separates the two here is that the derivations from `R` must be *runnable by the agent*, which is the "with enough context and time" clause.

What this buys the rest of the wiki: a success criterion for framing, which [[wiki/concepts/reasoning.md]] records that R6 lacks (a framing is correct when its `R` covers `D`), and a use for the R7 perturbation tests ([[wiki/entities/gsm8k.md]], [[wiki/entities/math-perturb.md]]): a content swap tests whether the derivation, not the fact, is what is lit. It addresses only `G73`'s weaker demand — selecting among frames the agent already holds — and not the construction of one.

## Tests and open problems

**Tests attached to rows.**

| Test | Row | Instrument |
|---|---|---|
| P1: at fixed memory, error on novel queries trades against derivation steps along a front bounded by the generator | scoring | ponder-step counts against accuracy ([[wiki/concepts/adaptive-computation-time.md]], [[wiki/entities/universal-transformer.md]]) |
| P4: ground facts light in one shot; a schema with `k` free variables needs many instances, at `½ log₂N` bits per effective free variable ([[wiki/concepts/predictive-information.md]]), so rising with `k` | 11 | the one-shot / many-shot plasticity split; sample-complexity curves across PGM-style regimes |
| P5: an agent whose lit set holds the family's common ancestors shows the `O(V)` saving; a shallow-lit agent shows `O(E)` | 13 | nodes-visited against edges-taken curves ([[wiki/entities/tolman-eichenbaum-machine.md]]) |
| P6: perturbation invariance holds for nodes lit by derivation and fails for nodes lit by observation or testimony | 9 | R7 tests with provenance recorded ([[wiki/entities/gsm8k.md]], [[wiki/entities/math-perturb.md]]) |

**Open problems.**

- **P2, no instrument.** The probability a hypothesis is entertained should decay with its derivation distance from the lit set: confirmation bias as a budget effect, since searching from lit nodes is cheaper than from the trunk.
- **P3, no direct instrument.** At bounded derivation length, deep schemas yield only coarse predictions; closure's per-level predictive-information shares are the nearest quantity.
- **P7, no instrument.** Resistance to revising a belief grows with the size of its dependent cone.
- **No model tracks `ε` per coarse concept** (row 4), and `ε` is now one quantity, not two. The earlier draft folded two things into it; they live on two different elements of the graph:

| Quantity | Lives on | Formal object | Zero when |
|---|---|---|---|
| **`ε`, closure error** | the lossy *edge* | the micro past's extra information about the coarse future, `I(←X; →Z \| ←Z)` ([[wiki/concepts/computational-closure.md]], information closure) | the coarse-graining is closed: the coarse schema predicts its own next value as well as the micro state would |
| **grain, discarded detail** | the *node* (three-axes table) | the unprocessed information `Δ = I(←X;→X) − I(←Z;→Z)` | nothing about the fine future is lost: an irrelevant merge |

  The paired-rollout test ([[wiki/concepts/exact-coarse-graining.md]]) reads both at once: evolve two micro states the concept maps to one code. The difference **decays**: `ε = 0`, `Δ` small (irrelevant merge). It **persists while the codes stay equal**: `ε = 0`, `Δ` large (a relevant level: the coarse dynamics are closed and the fine detail is gone). The codes **diverge**: `ε > 0`. The fourth cell, `ε > 0` with `Δ = 0`, is empty, since no discarded detail means the coarse past carries all the predictive information, which is closure. So row 4's register is one number per lossy edge, and the grain attribute per node is already carried. The `ε = 0` case coincides with the interpretability literature's notion of a valid causal abstraction (interventions commute between a coarse and a fine model), which is absent from the wiki and is an acquisition target (Precedents).
- **Whether the generality ordering is computable by the agent.** "Down" is implicit in provenance pointers; choosing a *deep* `R` for framing needs an estimate of depth, and coverage is the only candidate here.
- **The precision propagation rule is stated qualitatively** (inherits, plus `ε`) and no formula is committed to. The candidates are known calculi rather than open theory (certainty factors, belief functions, probabilistic logic programming; Precedents), so this is a choice, and it waits on which store carries precision (row 5).
- **Elegance is deliberately not defined.** "A short derivation from a deep premise" is a pair (premise depth, tree size) that could be reported per derivation; it is left out as a human preference the requirements do not need, following the bounded-optimality remark that the best procedure may be neither elegant nor illuminating ([[wiki/concepts/resource-rationality.md]]).

## How this page is used

The direction of derivation is: the world's structure plus the agent's limits ⇒ the graph ⇒ the requirements table ⇒ brain candidates per row ⇒ reference models as worked examples. It is run from both ends at once — from the problem (the world, the benchmarks) and from the solution (the brain) — looking for a path between them, which is the `L0 → L1 → L2` ladder of the schema with the realisation found last. The wiki's computational models are references for how a row was approximated, each reproducing a few properties of one region with many compromises, and not components to be assembled; the programme is to understand the connections and mechanisms of the regions a row names and replicate each as closely as possible.
