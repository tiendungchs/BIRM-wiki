# Representation Probing

**Test whether a trained network *contains* a hypothesised structure by fitting a deliberately weak decoder from its internal activations to that structure — and, if the decoder succeeds, ask separately whether the network itself uses what the decoder found.**

Every other evaluation instrument in the wiki scores a system from outside: behaviour on shifted tasks ([[wiki/concepts/shortcut-learning.md]]), code length on a stream ([[wiki/concepts/prediction-compression-equivalence.md]]), skill per unit of prior and experience ([[wiki/concepts/skill-acquisition-efficiency.md]]), outputs per bit of description ([[wiki/concepts/intelligence-density.md]]). Probing is the wiki's first instrument that looks **inside**, and therefore the first that can, in principle, answer gap G17's question directly rather than by proxy. It comes with a matching set of ways to be wrong.

---

## The instruments

| Instrument | Object fitted | What it reads out |
|---|---|---|
| **Linear probe** | `p ∈ R^d` per property, on activations `R_l(t)` at layer `l`, token `t`; predict `[R_l(t) · p] > θ` | Whether property `y` is *linearly* decodable from that site. Restricting to a linear (or thresholded-linear) decoder is the whole point: a strong decoder proves only that the information survived, not that it is in usable form |
| **Direct logit attribution** | `C_{l,h} = E_{(p,c)~D} [ R_{l,h}(p) · (E(c) − r(c)) ]` — head output dotted into the correct-token direction | Which component *writes* toward the answer, per sub-task. Correlational and additive: it decomposes the logit, not the computation |
| **Logit / tuned lens** | Affine translator `L_l : R^d → R^d` with `L_l(R_l(t)) ≈ R_{l_final}(t)`, then the model's own unembedding | The layerwise trajectory of the model's belief in vocabulary terms — where information enters and how it is refined |
| **Intervention (the standard the above do not meet)** | Edit the activation along the probe direction, ablate the head, patch it from another input | Whether the represented content is **causally load-bearing**. Only this licenses "the model uses X" |
| **Similarity-matrix regression against a graph kernel** | Pairwise representational similarity `RSM_ij` regressed on a kernel of the task graph — adjacency `A`, shortest path, Euclidean embedding, or a weighted path sum (`e^A`, `(I − γA)⁻¹`) | *Which metric* over the graph the site carries, not merely whether the graph is decodable. Needs no labels beyond the graph itself and no fitted decoder, so it cannot be won by decoder capacity; the competing kernels are the hypothesis set. The form used to read a predictive map out of human entorhinal cortex (Garvert et al. 2017) |
| **Cross-condition generalization (CCGP) + parallelism score** | A linear decoder for variable `A` trained on one value of variable `B`, tested on the other; and the cosine between `A`'s coding vectors at each value of `B` | Whether the site holds `A` in a **generalizable format**, not whether it holds `A` at all. The two come apart in data: human hippocampal stimulus and context decoding were statistically unchanged between sessions where participants could and could not perform inference, while CCGP and PS both rose (Courellis et al. 2024). Needs the full condition grid enumerated in advance and a choice of which conditions to hold out; and, like every probe here, it is correlational — it is just correlated with behaviour at single-trial resolution |
| **Representational-network community detection** | Per-site representational similarity matrices over the same condition set → similarity *between those matrices* across sites → community detection (Leiden) on the resulting graph | A partition of the **substrate**, not of the conditions: which sites agree about how the condition set is structured. Yields per-community "cuts" — one community may collapse two conditions the next one separates — so it measures *where in a system a distinction exists at all*. Applied to 360 cortical parcels over four working-memory operations, only the frontoparietal control network separated all four (DeRosa et al. 2024, [[wiki/concepts/working-memory.md]]). Assumes the condition set is the right basis, and is blind to any distinction no site represents |
| **Multi-term reverse inference** | Posterior `P(domain\|activation at site)` under a balanced prior, computed head-to-head between two candidate domains: `P(T₁) = hit(T₁) / [hit(T₁) + hit(T₂)]` over a corpus of studies tagged by domain | *Which* of several named functions an activation at that site is evidence for — the direction of inference a selectivity claim actually needs. Immune to how many studies each domain contributed (a rate ratio, not a count), so it recovers structure that a forward map with low statistical power misses. Requires a tagged corpus and a fixed candidate set: a function nobody tagged cannot win, and every result is "relative to these `k` domains" (Lieberman & Meyer 2018) |
| **Idle-state coupling strength** | Mean off-diagonal of the unit-by-unit correlation matrix of one module, recorded while the system is given no task — one scalar, no fit | A *capacity* estimate rather than a content estimate, and the only entry here that needs no labels, no decoder and no task. In humans it tracks conflict-task performance at ages 4–5 (`r = +0.70` with accuracy) and 18–22 (`r = −0.45` with reaction time) and rises between those ages (0.57 → 0.75), and it is near-invariant to what the subject is looking at while idle (crosshair vs. animation, `r_z = 0.90`), so it reads out the weights rather than the stimulus (Eng et al. 2025, [[wiki/concepts/control-unity-and-diversity.md]]). Correlational, coarse, and it measures only *within*-module coupling — the topological predictors it summarises (modularity, global efficiency) also require the between-module term |
| **Statistical counterfactual probing (input-side, label-free)** | No fit at all: clamp one input variable in a *generative* model, sample `R × T` responses, and cluster the pairwise response-correlation matrix `A[u,v] = φ[u]ᵀφ[v]` over response descriptors `φ` | A **partition the experimenter never named** — which structures in the input are causally bound together according to the model. Meets this page's own intervention standard by construction (the probe *is* an intervention), and needs no decoder, so decoder capacity cannot manufacture the result. Its requirement is architectural rather than statistical: the model must be addressable at a point, which rules out globally-conditioned diffusion. Validated only against human annotations of the same structure, so it inherits a weaker version of the circularity — no label is needed to *produce* the answer, but one is still needed to *score* it (Venkatesh et al. 2025, [[wiki/entities/spelkenet.md]]) |
| **Sparse autoencoder / `k`-sparse classifier** | Overcomplete dictionary with a sparsity penalty on the activation space | Candidate features when the hypothesis set is *not* known in advance — the one instrument here that does not require the answer up front |
| **Manifold inference** | A low-dimensional surface fitted to the activity itself (from temporal transition probabilities, not just the state cloud), then task variables regressed onto its coordinates | The *shape* of the representation before any hypothesis is named, plus an intrinsic-dimension count. Names nothing, so it cannot beg the discovery question the way a probe does — and it is what makes population-level claims measurable ([[wiki/concepts/population-geometry.md]]) |
| **Centered kernel alignment (CKA)** | `CKA(x,y) = ‖yᵀx‖²_F / (‖xᵀx‖_F ‖yᵀy‖_F)` on centred activation matrices `x ∈ R^{n×m}`, `y ∈ R^{n×p}` — the RV-coefficient, a normalised Hilbert–Schmidt independence criterion | Whether two *layers* carry the same representation, within or across models, with no shared units, no fitted decoder and no labels. Cheaper than the rotation row above and does not presuppose a group, but it is over-sensitive to architectural differences (convolutional vs. linear), so only *variations* in similarity are interpretable, never absolute values across layer types. Its failure mode is the reason to keep it in the list: two agents with opposite behaviour matched on every layer except a Gaussian variance head, and that difference was legible only after the head's activations were split by action (Champion et al. 2023, [[wiki/entities/deep-active-inference-agent.md]]) |
| **Cross-system alignment over a symmetry group** | One rotation `R ∈ SO(d)` between two systems' `d`-dimensional embeddings; score = fraction of decoding variance the rotation transfers | Whether two systems learned the *same* structure, with no shared units, no per-system probe and no cell-to-cell matching. Works model↔model, model↔brain and brain↔brain with one procedure (Nieh et al. 2021: 69–75% shared between mice). It presupposes the group, so a permutation, reparameterisation or nonlinear warp reads out as absent structure |

**Worked example.** Ivanitskiy et al. 2023 run the first four on maze-solving transformers: `n_layers × m × m × 4` wall probes on the residual stream of a single token reconstruct an entire maze at 0.83–0.99 per-wall accuracy from layer 2, direct logit attribution isolates an *adjacency head* attending to in-context path-length-1 neighbours, and the tuned lens shows valid-neighbour probability rising from the same layer. See [[wiki/entities/maze-solving-transformers.md]].

## What a successful probe does and does not establish

| Claim | Licensed? |
|---|---|
| "The information is present at this site" | **Yes**, up to probe capacity |
| "It is present in linearly readable form" | **Yes**, if the probe is linear and the site/token is fixed in advance |
| "It is present in a form that will *transfer* to a new setting" | **Yes**, if the probe is tested on held-out conditions rather than held-out trials (CCGP). This is the one row where a purely internal measurement predicts an out-of-distribution behaviour, which is why it is worth more than decoding accuracy |
| "It is present by layer `l`" | **Yes** — and the layer index is informative: a world model appearing at layer 2 of 11 has 9 layers left to be used by |
| "This site's *function* is X, because tasks of type X activate it" | **No — this is affirming the consequent**, and it is the single most common inference in the neuroimaging literature the wiki cites. `P(activity \| task X)` is high says nothing about `P(task X \| activity)`; the second needs a prior over what else activates the site. The machine analogue is identical: "this head fires on induction sequences" is not "this head does induction" until the alternatives have been scored on the same activations |
| "The model uses it" | **No.** Requires intervention. Probe accuracy and task accuracy can move together across training and still share a common cause |
| "The model discovered it" | **No.** The probe is trained on ground-truth labels, so it can only confirm a structure the experimenter could already write down |
| "The structure the model has is *this* structure" | **No.** Probing tests containment of a *named* hypothesis; a different, better structure the experimenter did not think of reads out as a failed probe |

**The circularity.** A probe needs labels, and labels are the answer. So probing converts "did this system recover the latent graph?" into "does this system contain the graph I already have?" — which is exactly the move gap G17 forbids for *discovery* claims and permits for *re-representation* claims. It is a strong instrument for the second question and structurally unable to answer the first. The only listed escapes are unsupervised dictionary learning over the activation space, which returns features without names and hands the identification problem back to the experimenter, and the input-side counterfactual row above, which returns a *grouping* without names by clustering the model's own responses to interventions rather than fitting anything to its activations.

## The decoded-but-unused failure

The finding that makes this a concept page rather than a methods note. In the maze setting, both implications fail:

- **Representation ⇏ competence.** A model whose residual stream reconstructs the maze at ≥0.93 for most cells still emits paths that cross walls (13–16% of rollouts in distribution; 62% for the smaller model out of distribution), while reaching the target ≈100% of the time.
- **Competence ⇏ representation.** A model trained on corridor mazes solves them without ever acquiring a linearly decodable maze representation — the world model shows up when the task distribution contains forks.

| Consequence | Statement |
|---|---|
| **Discovery and use are separately failable** | The wiki's framing splits into estimate-the-graph and route-on-it; here the estimate is verified good and the routing is bad, so a single end-to-end score cannot be attributed to either half |
| **"Emergent world model" claims need the second half** | The literature's headline result is the probe; the behavioural consequence is what the architecture argument actually needs |
| **Probe accuracy is a poor optimisation target** | Maximising decodability optimises for the instrument. Nothing forces the network's own downstream reads to use the direction the probe found |
| **(brainstorm) The right measurement is a gap, not a level** | Report *decodable structure minus behaviourally expressed structure*. On the maze task that is ~0.95 probe accuracy against 84% topology-valid rollouts. A large positive gap localises the deficit in the *use* half (gaps G5, G15) and says the discovery machinery needs no further work — which is the opposite of the conclusion an end-to-end score would suggest |

**The reversible version of the second row, with the control the maze result lacks.** In monkey posterior medial prefrontal cortex, the number of neurons representing a forelimb task drops significantly (`p < 0.01`) when the task is retrained so that only one response tactic is valid, and **returns to its original size** when both tactics are restored — same animals, same penetrations, same actions, 99–100% accuracy throughout, and no change in the two neighbouring areas recorded as controls (Matsuzaka et al. 2012, `raw/matsuzaka-2012-dmpfc-response-tactic-selection.md`). Earlier recordings had reported no forelimb-task representation in this region at all, because their tasks required a single tactic. Two consequences:

- **A null probe is a statement about the task distribution, not about the site.** The maze result says the training distribution decides whether a structure forms; this says the *testing* distribution decides whether an existing one is expressed, on tissue that demonstrably has it. Both failure modes produce the same empty probe.
- **The same laboratory supplies the *downstream* version, and it is the harder case.** In the same animals under a mixed-tactic task, pre-SMA shows no significant cue-position signal by a per-factor variance partition, although pre-SMA neurons are spatially tuned in reaching tasks that require no tactic choice; the authors' reading is that the upstream area handles the binding and the downstream area is never given the argument (Awan et al. 2020, `raw/awan-2020-tactic-based-sensorimotor-transformations.md`). So a component's null is contingent not only on its own demand but on **whether another component is currently doing the job** — which for a machine probe sweep means an empty result at layer `k` is uninterpretable without knowing what layer `k−1` was doing on those inputs.
- **The measure is worth importing on its own.** Coefficient of partial determination per factor in a sliding window — the fraction of firing-rate variance a factor explains beyond the rest of the model, permutation-tested against a pre-trial baseline — gives a *time-resolved, mutually-controlled* selectivity curve rather than a single decoding accuracy, and it makes "this factor is absent here" a statement with an effect size attached. No probing study in the wiki partitions variance across the competing task factors; they decode one variable at a time and cannot say whether an above-chance read is that variable or a correlate.
- **The reversibility is the diagnostic to copy.** "Representation absent" and "representation present but undemanded" are separated by restoring the demand and re-probing — a control no machine interpretability study in the wiki runs, and one that costs nothing beyond a second evaluation distribution. **(brainstorm)** The machine form is a probe sweep run under matched task distributions that differ only in whether a decision at the probed level is live; a direction that appears and disappears with the demand is a *control* variable, and one that persists is a stored one.

## Forward selectivity is the wrong direction, and the fix is a battle royale

> **Provenance.** Lieberman & Meyer 2018 (`raw/lieberman-2018-mpfc-social-self-affective.md`), applied to human medial prefrontal cortex — see [[wiki/entities/medial-prefrontal-cortex.md]] for what it found. The method is the transferable part.

| Direction | What is computed | What it licenses |
|---|---|---|
| **Forward inference** — the default everywhere | `P(activity at v \| task ∈ D)`: which voxels/units a domain's tasks reliably drive, against a null | *Where* to look. Accumulates with study count, so it is a statement about statistical power as much as about the region |
| **Single-term reverse inference** | `P(D \| activity at v)` with the prior set to 0.5 against *all other* tagged studies | Whether the site is more diagnostic of `D` than of the field's background. Several domains can pass at once, which is why it under-determines function |
| **Multi-term reverse inference** | `P(D₁ \| activity at v)` against one rival `D₂`, both sampled to equal `n`, averaged over 500 matched resamples; threshold 0.60 (i.e. the winner is ≥50% more likely than the loser) | Which of *two* named functions the site prefers. This is what a selectivity claim means |
| **Battle royale** — the conjunction | A site must clear 0.60 against **every** rival domain simultaneously | A domain-selective site, with a stated candidate set. The `p`-value is the product across the pairwise tests |

**Two results from running it that a probe designer should carry:**

1. **The two directions can disagree outright, and forward inference is the one that fails.** A ventral cluster is the most social-selective tissue in the entire region under reverse inference, and appears in *no* meta-analysis and not in the authors' own forward map. The cause is signal dropout: that location contributes roughly a quarter as many studies as the dorsal social cluster, and forward inference needs accumulated counts while a rate ratio does not. **Machine analogue, and it is exact:** any unit whose activations are rare, quantization-clipped, or under-sampled by the probe corpus is invisible to a forward selectivity sweep and recoverable by a ratio-based one. Sweeps that rank units by mean activation under condition `D` are forward-inference instruments.
2. **Selectivity is a minority phenomenon even where it is real.** 17% of the region's voxels win a battle royale; 88% win only the weak `>0.5` version (chance 6%); one subdivision is 99% accounted for by weak wins and another only 75%. The honest summary of a partition result is *two* numbers — a strong-criterion fraction and a weak-criterion fraction — because reporting either alone supports the opposite architectural conclusion (modular vs. shared).

**The residual is informative, not noise.** The tissue that clears the *single-term* threshold for all five domains and wins none of them is where this method's most interesting claim came from: a shared representation every domain reads. A forward-inference sweep cannot find such a site — it is active in every condition, so it survives no contrast — and a battle-royale sweep only finds it as a hole in the map. **(brainstorm) That is a named search target the wiki's interpretability instruments do not have: run the conjunction of single-term wins with the conjunction of head-to-head wins and look at the set difference.** In a transformer that is the set of components diagnostic of many task families and preferred by none — the candidate shared-workspace units, invisible to both ablation-by-task and probing-by-task.

### The candidate-set problem

Every reverse-inference verdict is relative to the `k` domains entered. The source states this as its own limiting caveat (it dropped four candidate domains for want of data, and its conclusions are explicitly "relative to the other domains considered"). For a machine probe the consequence is sharper than for a brain: **a head-to-head battery cannot discover a function, only rank the ones written down** — the same circularity this page's opening states for linear probes, arriving now through the comparison set rather than through the labels. Sparse dictionary learning remains the only listed escape.

## Applying it to build a reasoning model

| Use | How |
|---|---|
| **Locate the graph estimate** | Probe every layer × token for adjacency; the layer where accuracy peaks is where the estimate is complete, and everything after it is the navigation stack |
| **Verify the `g`/`x` split** | Two probe families — one for structural position, one for content — trained at the same site. The factorization gap G1 tracks is measurable as *whether a content probe generalises across structural positions and vice versa*, which no behavioural test isolates |
| **Test path-consistency (G3)** | Probe the same structural position after distinct routes and compare the decoded codes; commutativity becomes a measurable residual rather than an aspiration |
| **Curriculum diagnosis** | Probe across training checkpoints and across task distributions; the maze result says the branching factor of the training distribution decides whether a graph estimate forms at all |
| **Intervention as the acceptance test** | Before crediting an architecture with a world model, edit the probe direction and check that behaviour changes in the predicted way |

## Open problems

- **No probe certifies discovery.** Labels are required, so the instrument is confined to re-representation claims (gap G17 stands). The two additions above narrow the hole without closing it: manifold inference finds a *shape* without labels, and group alignment compares two systems without either one's ground truth — but both still need the experimenter to name the task variables before the shape means anything.
- **Decodability is the wrong summary statistic, and there is now a case where it is *flat* while everything that mattered moved.** In human hippocampus across inference-absent vs inference-present sessions, stimulus decoding went 0.73 → 0.76 (n.s.) and context 0.63 → 0.67 (n.s.), while CCGP and PS for both rose significantly and error trials lost the format (Courellis et al. 2024). Any study reporting only decoding accuracy would have concluded that nothing changed.
- **Which cells enter the probe is a free parameter, and it can reverse the ranking.** Lai et al. 2026 compare two prefrontal projection classes on how well each separates social from non-social stimuli: over *all* recorded cells the amygdala-projecting pathway wins; over a subensemble defined by an unrelated manipulation in an earlier session (cells excited by entry into an anxiogenic zone) the accumbens-projecting pathway wins, both at `P < 0.001`. Neither analysis is wrong and no principle picks between them, so any "region X encodes Y better than Z" claim must state the cell-selection rule alongside the decoder ([[wiki/empirical-tensions.md]] T116).
- **Layer-similarity metrics can be flat where the behaviour is not.** A representationally near-identical pair of agents can differ completely in policy: the reward-maximising and expected-free-energy-minimising critical hidden Markov models match across the encoder, transition and most critic layers, and the entire difference sits in the *variance* head of a Gaussian output layer — a site no standard pipeline inspects, and one that only reads out when conditioned on the action. Aggregate similarity is a summary statistic with the same weakness as decodability (Champion et al. 2023).
- **A probe ranks representations, not the choices that produced them — and the confound is usually the training corpus.** Three world models probed for the same physical quantities on the same environment differ simultaneously in objective, parameter count (15M vs 300M+) and pretraining data (none vs ~124M images); the best-probing model is the one with the largest corpus, and its own authors attribute the advantage there rather than to the modelling choice. Probe tables in this literature are therefore uninterpretable as objective comparisons unless the corpus is held fixed ([[wiki/entities/lewm.md]]) — the same attribution failure [[wiki/concepts/objective-identifiability.md]] states for behavioural scores.
- **Probe capacity has no principled setting.** Linear is a convention; the boundary between "the model represents it" and "the probe computed it" moves with the decoder class.
- **Intervention is rare.** Most published probes, including the maze work, stop before the causal step and report a correlation.
- **Site selection is manual.** Which token, which layer, which stream — chosen by the experimenter, and a negative result is uninformative if the choice was wrong.
- **Nothing connects probe geometry to the loss.** No training signal rewards a network for making its internal structure decodable, so decodability is a lucky by-product (gap G30).

- **[[wiki/concepts/objective-identifiability.md]]** — extends the decoded-but-unused problem to two more instruments: a grid score and a linear regression onto neural data are both decodability measures, and the second is confounded by the model's intrinsic dimensionality (participation ratio), so "best matches area X" can be won by being higher-dimensional than the competitors.
- **[[wiki/concepts/prediction-compression-equivalence.md]]** — the outside-in counterpart: code length says how much structure was exploited without saying what it is, probing names a structure without saying it was used. The pair brackets gap G26 from both sides.
- **[[wiki/concepts/simulation-based-planning.md]]** — supplies the diagnostic that planning failures are not always model failures: if the map probes clean, the deficit is in search, valuation or control (G15).
- **[[wiki/concepts/energy-based-models.md]]** — a probe is a linear read of a latent; where the latent is designed to be low-capacity and discrete, decodability is stipulated rather than discovered, which is the same claim arrived at by construction instead of by measurement.
- **[[wiki/concepts/pattern-separation-completion.md]]** — imposes the same discipline from neuroscience: an internal code's dissimilarity is uninterpretable without the upstream input's, so a separation claim requires recording the source region, just as a probe requires a control for what was already in the input.
- **[[wiki/concepts/pattern-separation-completion.md]]** — also supplies the wiki's one *label-free* internal instrument: the lure bias score `(1st − Lure)/(1st − Repeat)` reads a site's separation/completion position off mean activity using three stimulus conditions as its own anchors, so unlike every probe on this page it needs no ground-truth target and cannot beg the discovery question — at the cost of being blind wherever mean activity is constant across conditions (Bakker et al. 2008).
- **[[wiki/concepts/successor-representation.md]]** — supplies the strongest kernel for the similarity-regression row and a non-obvious prediction to test with it: the biological target is the *traffic-weighted* path sum, so a model whose representational distances match adjacency exactly should score worse against brain data than one whose distances are warped by how often each edge is used.
- **[[wiki/concepts/population-geometry.md]]** — supplies the format instruments (CCGP, parallelism score, shattering dimensionality) that make "present in usable form" a measurement rather than a convention about decoder capacity, plus the wiki's clearest case of decodability staying flat while format moved; and the same inside-the-system ambition run without naming a hypothesis first: fit the manifold, then ask what lies on it, and compare two systems by the rotation between their geometries rather than by two separately trained probes. It also bounds this page's dimensionality confound with a number — a linear PC count can exceed the true latent dimension by 7–8×.
- **[[wiki/concepts/distributed-reference-frames.md]]** — the neuroscience form of this page's discipline: a grid score is a decodability instrument, and the source that argues grids are everywhere also states that its standard autocorrelation detector generates false positives without spike-shuffle controls ([[wiki/empirical-tensions.md]] T37).
- **[[wiki/concepts/inhibitory-control-of-coding.md]]** — a taxonomy instrument this page does not have, with the validation discipline it says the literature lacks: fit a weak classifier of unit *class* on intrinsic activity statistics (rate, irregularity, autocorrelation timescale, waveform) using a small causally-labelled subset, then confirm it against properties withheld from the fit (oscillation phase, spatial tuning, expected class fractions) — the classifier cannot have manufactured a correlation with a feature it never saw.
- **[[wiki/concepts/control-unity-and-diversity.md]]** — the source and the caveat for the idle-state-coupling row: one scalar taken from a module's task-free covariance ranks human control ability at two ages and is invariant to what the idle input is, but it summarises only the within-module term of a predictor (modularity, global efficiency) whose content is topological (Eng et al. 2025).
- **[[wiki/entities/fcann.md]]** — a label-free *structural* probe to add to the instrument list: compare a network's attractor states with the eigenvectors of its own coupling matrix (alignment ⇒ approximately orthogonal storage), and compare its convergence time against a degree- and symmetry-preserving permutation of those couplings (383 vs 3543 iterations in the human connectome) — neither needs activity labels or a decoder.
- **[[wiki/concepts/working-memory.md]]** — the source of this page's community-detection row and the case where it pays: clustering 360 cortical parcels by their representational geometry shows four subsystems making four *different* cuts over the same four working-memory operations, so "is this distinction represented?" has no system-wide answer — only sensory cortex's occupancy bit, and the control network's full 4-way code (DeRosa et al. 2024).
- **[[wiki/concepts/arbitrary-sensorimotor-mapping.md]]** — the confound this page's causal interventions share with lesion work, plus the control it lacks: ablating ventral/orbital prefrontal cortex removes both a candidate rule store *and* the only route by which object identity reaches premotor cortex, so an ablation localizes a computation only when the ablated part is off the input path — biology separates the two with crossed-hemisphere disconnection, and no machine analogue exists (Murray et al. 2000).
- **[[wiki/entities/medial-prefrontal-cortex.md]]** — the worked application of this page's reverse-inference instrument and the source of its numbers: five candidate functions run head-to-head across three subdivisions of the human medial wall, yielding a content partition, a 17%-vs-88% selectivity spread, and one shared cluster that no contrast-based method could have found.
- **[[wiki/entities/medial-prefrontal-cortex.md]]** — also supplies this page's cell-selection caution as a measured inversion, and the complementary null: two projection-defined prefrontal populations are identical in mean firing rate under every condition tested and differ only in population geometry, so a rate-level probe would have reported one homogeneous region (Lai et al. 2026).
- **[[wiki/concepts/policy-abstraction-hierarchy.md]]** — the reason a probe can come back empty from tissue that holds the representation: a control level is instantiated only while its output varies, so removing the choice — and nothing else — empties the population that codes the task, reversibly, which turns "representation absent" into a claim about the evaluation distribution ([[wiki/empirical-tensions.md]] T111, Matsuzaka et al. 2012). The same laboratory adds the downstream form of that confound and the instrument for detecting it: a caudal area's *sensory* signal is absent precisely when the rostral area is doing the binding, measured as a per-factor coefficient of partial determination in a sliding window rather than as one-variable-at-a-time decoding (Awan et al. 2020).
- **[[wiki/concepts/inter-areal-synchrony.md]]** — a probe the wiki does not otherwise have, and it needs no classifier: band-limited coupling between a unit and each candidate source module identifies which pathway is currently driving it, and in the biology exactly those coupled units carry the task variable (phase-locked prefrontal cells predict the upcoming choice; non-locked ones do not).
- **[[wiki/concepts/controller-knowledge-vs-process.md]]** — the question that needs this instrument: every localization claim in the lesion/activation literature is forward-inference, while a stored-content partition is a reverse-inference statement and needs candidate functions compared head-to-head on the same activations.
- **[[wiki/entities/deep-active-inference-agent.md]]** — the source of this page's centered-kernel-alignment row and the wiki's clearest case of a probe coming back empty where the whole behavioural difference lies: two agents with opposite policies match on every layer except a Gaussian *variance* head, and the collapse is legible only after that unit's activations are split by action (Champion et al. 2023).
- **[[wiki/concepts/subjective-value.md]]** — the strongest probe protocol the wiki holds, and it comes from psychophysics rather than machine learning: fit a parametric function to behaviour, fit the *same* form to internal activity, and require both covariation across agents and a mean difference of zero. The offset half is what a correlation-only probe cannot do — it is what falsified the claim that these regions carry a more impulsive component of value than the behaviour they produce.
- **[[wiki/entities/kan-ode.md]]** — the limiting case of every instrument above: when the network's activations *are* learned univariate functions, structure is read off the parameters by symbolic regression instead of fitted from activations by a decoder, so decoder capacity cannot manufacture the result. It inherits this page's central caveat in a new form — the extracted equation is compared to ground truth but never re-integrated and scored against the model it replaced, so "decoded but unused" is untested one level up (Koenig et al. 2024).
- **[[wiki/concepts/counterfactual-probing.md]]** — the input-side counterpart of everything on this page, and the second escape from its circularity: intervene on a generative model's input and cluster the response distribution, which returns an unnamed partition, meets the intervention standard by construction, and shifts the requirement from decoder capacity to the model's conditioning interface.
- **[[wiki/entities/spelkenet.md]]** — the worked instance of that row, including the negative control this page keeps asking for: the *deterministic* version of the same probe (CWM) blurs multi-modal responses and merges objects, so the instrument's validity depends on a property of the probed model, not only of the probe.
- **[[wiki/entities/lewm.md]]** — the corpus confound measured, plus a label-free read-out this page's table lacks: a decoder fitted *after* training to a single 192-d embedding recovers the scene it was never trained to reconstruct, and a paired violation-of-expectation contrast (physical vs visual perturbation of the same trajectory) reads out *what kind* of regularity the latent encodes without any probe being fitted at all.
- **[[wiki/entities/v-jepa-2.md]]** — a probe built for a latent world model and used only as an instrument: a feedforward decoder fit by pixel loss to the *encoder's* features, then applied off-the-shelf to the *predictor's* autoregressive rollouts, which renders a model's imagination in a space it was never trained to reconstruct. It inherits this page's confound in the sharpest possible form — the decoder was fit on real features, so a blurry or wrong rollout image cannot be attributed between "the predictor drifted" and "the decoder was never shown features like these" — and it is used qualitatively throughout (Assran et al. 2025).
