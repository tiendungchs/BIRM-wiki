# Abstract Structural Codes

**A code that represents an item's *position in a relational structure*, invariant to the objects, individuals or scene elements that fill the structure — the wiki's `g`, as opposed to the content code `x`.**

If far transfer means reusing structure across domains that share no surface features, then something must represent the structure separately from what fills it. This page tracks the candidates and the evidence, which is currently thin (Hassabis et al. 2017).

---

## The requirement

| Requirement | Statement |
|---|---|
| **Content invariance** | The code must not change when the objects populating the domain change |
| **Relational content** | It must code relations among patterns of input, not the inputs |
| **Path consistency** | The same structural position must be reached by any route to it (gap G3) |
| **Decomposability** | It should decompose a state space in a way that exposes subgoals, so hierarchical planning has something to plan over |

Requirement 4 is what makes structural codes an efficiency claim and not just a representational one.

**And a capacity argument for the same role.** If `g` is the address, then *freezing* it is what makes the address book large: a random fixed projection from `M` grid modules into a hippocampal layer turns all `∏_i K_i` grid states into stable attractors with `N_h` growing only linearly in `M` — exponentially many addresses, convex and equal-sized basins, no spurious states. Any content leaking into `g` destroys this: statistically matched but content-shuffled scaffold states with bidirectionally *learned* weights lose the exponential scaling entirely (Chandra et al. 2023, [[wiki/entities/vector-hash.md]]). So content-invariance stops being a stipulation about transfer and becomes a precondition for capacity.

**A derivation of requirements 1–3 from a single role.** Whittington et al. 2020 argue that if `g` is used as the *address* of a fast memory, then only two constraints are needed and both are forced: **distinctness** (different states must get different codes or their memories collide) and **path-invariance** (the same state must get the same code from any direction or the memory cannot be retrieved). Content-invariance then follows for free, because the address must not depend on what happens to be stored at it. This converts three stipulated requirements into consequences of one architectural decision — bind content into a separately-addressed store — and it is the wiki's only account of *why* `g` should have these properties rather than a list saying that it must.

## Grid codes as the leading biological candidate

| Fact | Source status |
|---|---|
| Entorhinal cells encode allocentric space with a periodic "grid" code, receptive fields tiling the local space in a hexagonal pattern | Established |
| Grid codes decompose state spaces efficiently, in a way that could support subgoal discovery and hierarchical planning | Theoretical argument |
| Functional neuroimaging shows grid-*like* codes in humans performing an **abstract categorization** task — periodic coding as a general hallmark of knowledge organization, not a spatial specialization | One report, explicitly flagged as requiring much further work. Read first-hand (Constantinescu et al. 2016) it survives the checks that matter for a code claim — sixfold only, no four-/five-/seven-/eightfold control periodicity; grid angle stable within a day and across a week; entorhinal and ventromedial-prefrontal angles aligned to each other; `R² < 0.02` with every stimulus and behavioural confound — but the space was a hand-designed continuous 2D plane and the measurement is BOLD |
| The same grid-*like* code measured as a **graded, developing quantity** rather than as present/absent — and mediating a cognitive ability | 203 participants aged 8–25 inferring on a 5×5 conceptual map (attack × defence rank). Entorhinal six-fold modulation rises with age (`r` = 0.16) and with inference accuracy (`r` = 0.31), is six-fold only (four-, five-, seven-, eight-fold null), survives an entorhinal signal-to-noise control, and **statistically mediates** the age→inference relation (`β_ab` = 0.04, CI [0.01, 0.08]). Three independent detectors (hexagonal modulation, cross-run angle consistency, angular-difference RSA) converge on the same entorhinal cluster (Qu et al. 2026) |
| A *learned latent* variable held invariant to the content filling it, in human single units | Hippocampal populations code an uncued context so that a decoder trained on one pair of stimuli transfers to the others, and a stimulus decoder transfers across contexts — the two variables occupying roughly orthogonal subspaces. Present only in sessions where participants perform inference, absent on error trials, and absent in the upstream visual region (VTC), whose stimulus code is abstract but never becomes context-structured (Courellis et al. 2024, [[wiki/concepts/population-geometry.md]]). This is the closest the wiki has to `g`/`x` separation measured *as* separation, but the "structure" is one binary latent, not a relational space |
| Direct evidence for object-invariant relational codes in the mammalian brain | **Absent** — the paper states we currently lack it. The nearest cellular-resolution result runs the *other* way: in mouse dorsal CA1, ~90% of cells informative about a learned abstract variable code it **conjunctively** with position, and the two variables separate only at the population level, as independent gradients on a ~5-dimensional manifold (Nieh et al. 2021, [[wiki/concepts/population-geometry.md]]) — so the invariance, where it exists, is a property of the geometry rather than of any cell |
| The `g`/`x` invariance split is measurable cell by cell: object-vector cells in the structural layer generalise over object identity within and across environments, while landmark cells in the conjunctive layer stay object-specific — same architecture, same training, opposite invariance, matching recordings | Model plus supporting recordings (Whittington et al. 2018) |
| The split is also measurable *within one cell, across two dimensions at once*: on two sensorially different versions of a reward-every-4-laps task, hippocampal cells remap spatially while **retaining their lap preference**, because lap identity is carried by the structural input and space by the sensory conjunction. Predicted by the model, then confirmed in mouse recordings (Whittington et al. 2020, data from Sun et al. 2020) | Model prediction confirmed in data |

The tension between the grid-like neuroimaging rows and the "direct evidence … **Absent**" row is recorded as T4 in [[wiki/empirical-tensions.md]]: the same review both advances periodic conceptual coding and states that codes of this kind have no direct evidence.

## The code as a developing quantity

Every other row above treats `g` as present or absent in an adult. Qu et al. 2026 (n = 203, ages 8–25, cross-sectional fMRI) treats its *strength* as the dependent variable, which turns three of this page's stipulations into measurements.

| Claim | Measurement | Why it matters for a builder |
|---|---|---|
| **`g` is what buys inference, not memory** | Premise knowledge was **performance-matched** across ages (all subjects trained to ≥80% on the 1-rank pairs before scanning), yet age still predicts inference accuracy (`r` = 0.56; `r` = 0.54 adjusting for memory) and entorhinal grid strength mediates it | The usual confound — older subjects know the edges better — is removed by design. What develops is the *code over* the edges, not the edge list |
| **The schema drives the map, not the reverse** | Medial prefrontal cortex carries a Euclidean **distance code** between inferred pairs, stronger for 2-D distance than for either 1-D rank (`t₂₀₂` = 2.69). That distance code is significantly stronger on trials whose trajectory is **grid-aligned** (within 15° of the subject's entorhinal `φ`) than on misaligned ones, and in a parallel mediation only the entorhinal path survives | The wiki's `g` → readout ordering, measured as a *directional* claim for the first time: the same downstream quantity is computed better in `g`'s coordinate frame. Extends Park et al. 2021's aligned-value effect from a value head to a metric head |
| **The wiring matures with the code** | Entorhinal grey-matter volume *increases* with age (`r` = 0.36) against the whole-cortex decline, medial prefrontal volume decreases (`r` = −0.68), and entorhinal↔medial-prefrontal white-matter fractional anisotropy shows the strongest age effect of any tract pair (`r` = 0.48) — with the **cingulum**, not the fornix, carrying the mediation onto assimilation performance (`β_ab` = 0.07) | The two regions holding one shared orientation (Constantinescu et al. 2016, G43) turn out to be connected by a tract that matures late. **(brainstorm)** If registration between concurrent frames is what a late-maturing bundle buys, then the machine analogue of G43 is not an arbitration rule but a *learned alignment channel* between two `g` modules, trained after both are individually competent |

**And the code predicts fluid intelligence.** Canonical correlation between five cognitive-map measures (entorhinal grid strength, prefrontal distance code, both grey-matter volumes, structural connectivity) and standardised IQ subtests yields two significant variates (`r` = 0.64, `p` < 0.001; `r` = 0.39, `p` = 0.009 under a permutation framework). Grid strength (`β` = 0.55) and distance code (`β` = 0.52) both load on **Raven's Standard Progressive Matrices** — the reasoning test, not the working-memory or coding subtests. Raven's score also mediates the age→inference effect (`β_ab` = 0.15) and predicts *fewer training sessions needed* (`r` = −0.34).

**(brainstorm) This is the wiki's only quantitative link between a candidate `g` and the ability the wiki is trying to build.** It runs the right way for the design bet: the neural quantity that tracks matrix-reasoning score is a *structural code strength*, not a memory capacity or a processing speed. The obvious model-side test is the same regression — sweep a family of trained agents, measure grid score or an equivalent structural-code statistic per agent, and check whether it predicts held-out abstract-reasoning accuracy better than parameter count or training loss ([[wiki/entities/arc-agi.md]], [[wiki/concepts/skill-acquisition-efficiency.md]]). If it does not, the correlation is about human brains rather than about `g`.

**Two limits.** The design is cross-sectional, so every mediation is correlational and no temporal precedence is established; and the space is again a hand-designed 2-D Euclidean plane, so the non-embeddable slice (G11) and the graph-structured case are untouched — the authors name graphs as the next target themselves.

## Mapping to the core framing

| Structural-code property | Latent-graph element |
|---|---|
| Position in a relational structure | `g` — position in the meta-graph |
| Content filling the structure | `x` — node content |
| Conjunction of the two | `p = f(g, x)` — content anchored to graph position |
| Periodic tiling / multi-scale grids | A hierarchy of resolutions over one space: coarse scales are the jumpy level for planning, fine scales the step level |
| Transfer of an abstract schema to a new domain | Reuse of `g` with a new `x` binding — instantiation as binding, not learning |

**(brainstorm)** A periodic code is attractive for path consistency for a mechanical reason: positions are updated by *adding* a displacement to a phase, and addition commutes, so any route accumulating the same total displacement lands on the same code. Path consistency would then be a property of the update rule rather than something a loss must enforce — which is the only concrete proposal the wiki has so far for gap G3.

## Abstraction as long-range predictability

The wiki's first *training signal* for abstraction, as opposed to an architectural stipulation of one ([[wiki/entities/h-jepa.md]]):

> A representation is abstract because it is what stays predictable at long range. Detail is discarded not to save capacity but because it cannot be predicted far ahead.

| Consequence | Statement |
|---|---|
| **Abstraction level = prediction horizon** | Low-level codes carry detail and predict a short way; high-level codes drop detail and predict far. The two are one axis, not two |
| **The level structure is emergent** | Stack predictors, pool over time between levels, and the hierarchy of abstraction falls out of the objective rather than being designed |
| **The trade-off is explicit** | Two criteria pull against each other: maximise the representation's information about its input, *and* make it predictable from the previous representation. Where the balance lands decides what is abstracted away |
| **Driving example** | Given wheel and pedal commands, a driver predicts the trajectory accurately for seconds; over an hour only the abstract route survives (arrival time, the path as drawn on a map), and alternative routes are a discrete latent |

**The horizon is now a measured knob, not only an argument.** mm-TEM writes its relational memory every `m_b` steps and must therefore predict `m_b` steps ahead unaided; the emergent grid period scales with `m_b` — longer horizon, coarser code — end-to-end, with nothing multiscale supplied (Li et al. 2026, [[wiki/entities/mm-tem-hippoformer.md]]). So "abstraction level = prediction horizon" holds *inside* the structural code and not only between stacked levels of a hierarchy, and it comes with a knob that can be set rather than a level that must be designed. Two limits: the effect is fixed at training time (changing `m_b` afterwards leaves the scale untouched), and the same paper finds models with low grid scores and high long-horizon accuracy, so a longer horizon does not force a *periodic* code — only a coarser one ([[wiki/empirical-tensions.md]] T44).

**(brainstorm)** This is a candidate objective for gap G30, arriving from an unexpected direction. It does not directly reward path-consistency, but it does reward *content invariance* for a reason: content that varies unpredictably across instances of the same structure is exactly the content a long-horizon predictor is penalised for keeping. So `g` would be what survives a predictability filter, and `x` what the filter discards — measurable from trajectories alone, with no labels and no environment partition. What it still does not supply is commutativity: nothing in the criterion prefers a code that assigns the same value to a position reached by two different routes (gap G3).

**The counterweight.** What gets kept is decided *implicitly* by the encoder's and predictor's inductive biases, and the source concedes it does not know how to set them, offering only auxiliary prediction heads on task-relevant derived variables. So the objective selects *among* representations the architecture can express, which puts the burden back on the architecture lever (gap G16).

## Open problems

- **Is periodic coding general or spatial?** One neuroimaging report on abstract categorization (morphed birds, a neck × leg feature plane) is still the whole case for a *periodic* abstract code: sixfold modulation of the BOLD signal by trajectory angle in bird space, in entorhinal cortex, ventromedial prefrontal cortex, orbitofrontal, posterior cingulate, retrosplenial, lateral parietal and temporoparietal cortex — the same network as virtual spatial navigation, and the default-mode network (Constantinescu et al. 2016, now read first-hand). The nearest independent evidence is *not* periodic: a social power × affiliation space is coded as hippocampal angle plus posterior-cingulate magnitude, i.e. a vector, not a hexagonal tiling — so "maps outside space" is better supported than "grids outside space" ([[wiki/concepts/cognitive-map.md]]).
  - **What the primary source does and does not buy.** Read directly, the report is stronger than "one fMRI result" on four counts and weaker on two others.

    | Strength | Detail |
    |---|---|
    | **Symmetry is specific** | The effect holds for sixfold and for *no* control periodicity between four- and eightfold (all `P > 0.15`) in both ventromedial prefrontal and entorhinal cortex — so it is not generic direction tuning |
    | **The frame persists** | The estimated grid angle `φ` cross-validates across sessions half an hour apart *and* across sessions more than a week apart (vmPFC, `t20 = 3.65`) — a stable reference frame over the concept space, not a task-transient alignment |
    | **Two regions share one angle** | Entorhinal and ventromedial prefrontal grid angles are aligned to each other (`t21 = 2.18`), which is a *coordination* result, not a second instance |
    | **It is not a stimulus confound** | `sin(6θ)`/`cos(6θ)` share `R² < 0.02` with start/end neck and leg lengths, response accuracy, and whether the morph passed through a rewarded outcome; trajectory angles were sampled evenly; the waveform differs per subject and scan |
    | **It tracks competence** | Hexagonal modulation strength (`r = 0.432`) and cross-session angle consistency (`r = 0.431`) both correlate with task accuracy across subjects, and with *current* performance rather than learning speed |

    | Limit | Detail |
    |---|---|
    | **Two continuous dimensions, hand-designed** | The "space" was neck length × leg length. The authors close by stating it is unknown how such a code behaves in conceptual problems not easily mapped onto a continuous 2D plane — which is exactly the non-embeddable slice this page's "what supplies the metric?" bullet names |
    | **Reuse vs. re-derivation is untested** | Whether conceptual tasks are solved by mapping abstract dimensions onto a *preexisting* spatial map, or by a new organisation formed for the problem, is posed as the open question and left open — the difference between reusing `g` and discovering one |
    | **BOLD, not cells** | The authors' own caution; and no single-unit grid code in a conceptual space has since been recorded ([[wiki/empirical-tensions.md]] T37) |

    **(brainstorm) The strongest single fact here is the third row of the first table, and it is not about periodicity.** Two anatomically separate regions holding the *same* orientation for a code over a space neither of them was built for is the wiki's only observation of concurrent structural codes being *registered to one another* — a candidate answer to G43 that costs nothing at inference: don't arbitrate between frames, share their orientation so their outputs are already commensurate. That is the representational analogue of a shared coordinate convention, and it is cheap to test in a model with two `g` modules (correlate their learned bases; force alignment with a penalty and see whether readout mixing gets easier).

    **And the task's construction is itself the finding.** Subjects never saw a 2D space: stimuli were single morphing birds, dimensions had to be extracted from one-dimensional visual features, "movement" was the *ratio of rates of change* of legs to neck, and 0 of 28 subjects reported conceiving of the relationships as a spatial map. So the plane was inferred from experience and never perceived — the map was constructed, and the code appeared without the map being available to report.
  - **The evidence base has since widened and its detector has been undercut in the same source.** Chen et al. 2022 add: grid-like fMRI modulation over a *discrete* social-hierarchy decision space (Park et al. 2021) and over angular positions of newly learned words in a "word space" (Viganò et al. 2021); grid-like coding of *gaze* in monkey entorhinal cortex with no locomotion (Killian et al. 2012); and grid, place and head-direction cells recorded in rat primary somatosensory and secondary visual cortex that survive whisker trimming and darkness (Long & Zhang 2021; Long et al. 2021a). Against that: grid identification is "a relatively arbitrary threshold phenomenon", spatial autocorrelation generates false positives without spike-shuffle controls, BOLD is not spiking, and **no single-unit grid code in a conceptual space has ever been recorded** ([[wiki/empirical-tensions.md]] T37, [[wiki/concepts/distributed-reference-frames.md]]). So the row above gets more instances and no better instrument.
  - **And one of those instances is now in the wiki at first hand, where it does more than add a domain.** Park et al. 2021 is the only demonstration of a grid-like code over displacements that were **never executed**: subjects inferred direct vectors between people in a 4×4 social hierarchy they had themselves assembled from two 1-D rank orders learned on *separate days*, and entorhinal and medial prefrontal cortex showed six-fold modulation of those inferred angles (four-, five-, seven-, eight-fold all null), including for pairs seen for the first time. Three things this buys `g` that the concept-space result did not:
    - **`g` supports composition of a joint space from marginals.** The plane was never sampled jointly — only its two axes, days apart, with no task demanding their combination — and the resulting code is 2-D Euclidean rather than two number lines. Whatever builds `g` here is not consuming transitions in the space it builds, which is what every model on this page assumes ([[wiki/entities/tolman-eichenbaum-machine.md]], [[wiki/concepts/successor-representation.md]]).
    - **`g` is queried, not just traversed.** The vector is a hypothesised move evaluated at decision time, so the periodic code is being read for planning rather than tracking — the first evidence on this page that `g` is usable off-policy.
    - **A readout downstream of `g` is *gated* by alignment to `g`.** The decision value in medial prefrontal cortex and temporoparietal junction is uncorrelated with the hexadirectional regressor yet significantly stronger for grid-aligned vectors, and across subjects entorhinal grid modulation predicts temporoparietal value coding (`r` = 0.58). **(brainstorm)** That is the cheapest available operationalisation of "the readout is in the code's coordinate frame": a model with a structural `g` and a value head should show head accuracy varying with the query direction's alignment to `g`'s basis, which is directly testable and, if it holds, makes alignment a *diagnostic* that a head is genuinely reading `g` rather than a correlated feature of `x`.
  - **And the one matched-domain control is a null.** Kumaran & Maguire 2005 equate relational demand and search depth across a spatial and a social version of the same chain-search task over the same 14 people, and find hippocampal engagement only in the spatial version — with the domain × task interaction significant in the hippocampus alone. This does not test for a *periodic* code (no hexadirectional analysis), but it undercuts the weaker claim the row above retreats to: "maps outside space" also fails when the non-spatial task is properly matched ([[wiki/empirical-tensions.md]] T45, [[wiki/concepts/cognitive-map.md]]).
  - **And what a grid code *is* has moved.** Grid firing is argued to support a learned topology of ordered experience rather than a rigid coordinate frame tied to physical measurement (Rueckemann et al. 2021, via Chen et al. 2022) — which is what makes the code portable to domains with no continuum, and which puts it on the topological side of [[wiki/empirical-tensions.md]] T27.
- **Content-invariance now has a number, and the number is not decoding accuracy.** CCGP and the parallelism score make requirement 1 a measurement: train the structural readout at one content value, test at another (Bernardi et al. 2020, [[wiki/concepts/population-geometry.md]]). Two calibrations from the source: the *same* variable in the *same* region can pass the test in one 900 ms window and fail it in the next (monkey DLPFC codes the latent context at ≈ 0.9 decoding with CCGP at chance right after stimulus onset, and abstractly again before the next stimulus), so requirement 1 is a property of a code at an epoch, not of a module; and a clustering-based test — conditions of one context grouping together — gives the *wrong answer*, finding the format only in hippocampus while CCGP and PS find it in prefrontal areas too. Content-invariance is parallel displacement, not proximity. In the one dataset where both are reported against a behavioural contrast, decoding accuracy for *both* `g` (context) and `x` (stimulus) was statistically unchanged while CCGP and PS rose — so a model evaluated on decodability would show nothing (Courellis et al. 2024). Two consequences: content-invariance is cheap to measure in any model with an enumerable condition grid, and it is not implied by the variable being present.
- **At which level is `g` separate from `x`?** This page's requirements are written as constraints on a *code*, and the wiki has been reading them as constraints on cells. The one dataset that measures both levels at once says they disagree: cell-level conjunction (~90%) with population-level factorisation (two independent gradients on one manifold) in the same 917 neurons (Nieh et al. 2021, [[wiki/concepts/population-geometry.md]]). If factorisation is a geometric property, then content-invariance should be *tested* by transferring a decoder across positions in the geometry, not by looking for invariant units — and a model whose units are entangled has not thereby failed the requirement.
- **The metric may not be needed at all.** The hippocampal-entorhinal system also codes spaces defined only by transitions between discrete items, with no underlying continuum — which weakens the row above and reopens what "distance" means when the only data are observed transitions (Epstein et al. 2017).
- **Format vs. precision.** Core number keeps a ratio-limited *format* fixed for life while its precision improves from a Weber ratio of 2.0 to 1.15–1.3 (Spelke & Kinzler 2007). If structural codes work the same way, what a model must install is the format and what it must train is the resolution — nothing here says which parts of a grid code are which.
- **What supplies the metric?** Grid codes presuppose a space with a distance; the non-embeddable symbolic slice (modular arithmetic, syntactic recursion) offers none.
- **How is the structure discovered?** Nothing here says how the code arises for a *new* domain, which is the discovery half of LGD.
  - **One concrete proposal: don't discover it, reweight it.** Grid, band, border and object-vector cells are one family of **basis functions for transition statistics**, and which basis a network develops is set by the *transition distribution* it is trained on — dwell near boundaries and border cells appear, bias toward particular stimuli and object-vector cells appear, walk an unbiased 2D graph and grids and bands appear (Whittington et al. 2018, [[wiki/entities/tolman-eichenbaum-machine.md]]). A new domain would then need only an on-line reweighting of an already-learned basis set, inferred from observed transitions or from performance — inference over coefficients rather than gradient learning of a code. Untested: nothing in that paper actually performs the reweighting, and no procedure is given for guessing the initial structure.
- **The cheapest known way to install a content-invariant direction is to ask for it at the output.** A two-hidden-layer network trained on MNIST digits 1–8 to emit **parity** and **magnitude** simultaneously develops CCGP and PS above the random-geometry null for exactly those two dichotomies out of 35, in its last hidden layer, while shattering dimensionality stays at 0.96 — every other dichotomy remains decodable and none is abstract (Bernardi et al. 2020). The input carries no structure aligned to either variable, so the abstraction is created, and it is created by *naming the factors at the output*, not by any regulariser on the code. Requirement 1 therefore has a supervised construction whenever the factors are known in advance; what it does not have is the unsupervised one, and the paper's own hidden-variable case (a deep Q-learning agent making the *unobserved* context abstract in a fraction of runs) shows the harder version is reachable but unreliable.
- **There is still no objective that trains toward these requirements — but one loss now has the right *shape*.** The four requirements above are stated as properties of a code and every model on this page acquires them incidentally, from an architecture or a transition distribution (gap **G30**). DINOv3's **Gram anchoring** is the first term in the wiki that penalises *relations between elements* directly and nothing else: `L_Gram = ‖X_S X_Sᵀ − X_G X_Gᵀ‖_F²` over ℓ₂-normalised token codes, invariant to any transformation preserving inner products, computable with no labels ([[wiki/entities/dinov3.md]]). What it demonstrates is the behaviour requirement 1 asks for and no page here has measured in a trained system: an image-level content objective was steadily eroding the relational structure over 800k iterations while its own metric improved monotonically, and a term on the relations alone restored the structure **without costing the content code**. What it is *not*: it says nothing about path consistency (requirement 3), it constrains relations *within a single input* rather than across episodes, and its target must be supplied by a reference network rather than derived — so it is a shape to steal, not a candidate `g`-objective.

- **Transfer mechanisms are unknown on both sides.** How humans or animals achieve far transfer of abstract structure is stated as an open question in neuroscience, and it is the one place the transfer channel currently has nothing to send.

## Connections

- **[[wiki/entities/dinov3.md]]** — the nearest thing the wiki holds to a trainable objective for the relational half of the `g`/`x` split: a label-free penalty on the token-similarity matrix, invariant to any inner-product-preserving transformation, measured to hold relational structure in place against a content objective that was destroying it — though it carries no path-consistency term and needs a reference network to supply its target (G30).


- **[[wiki/entities/rolls-treves-hippocampal-model.md]]** — the dissenting use of the same code: grid firing is argued to be the wrong format for episodic binding, and a competitive-learning stage in dentate gyrus converts it into place-like conjunctions — with simulations showing untrained sparse projection is *not* enough, Hebbian training in the perforant path is required.

- **[[wiki/concepts/latent-graph-discovery.md]]** — supplies the biological candidate for `g`, the structural half of the factorized code, and the only concrete proposal for making it path-consistent.
- **[[wiki/concepts/simulation-based-planning.md]]** — the state-space decomposition claimed for grid codes is exactly what jumpy, multi-scale planning needs to plan over.
- **[[wiki/concepts/complementary-learning-systems.md]]** — the hippocampal-entorhinal system is one anatomy: the sparse instance store and the structural code are neighbours, which is why binding content to position is cheap there.
- **[[wiki/concepts/neuroscience-ai-transfer.md]]** — a *representation* being imported (state-space decomposition by periodic codes) rather than an algorithm, matching the pattern of every successful transfer so far.
- **[[wiki/concepts/meta-learning.md]]** — a content-invariant structural code is what would make the outer loop's learned regularity reusable in a domain with entirely new objects.
- **[[wiki/concepts/skill-acquisition-efficiency.md]]** — the only place a candidate `g` has been scored against that page's quantity: grid-code strength predicts matrix-reasoning ability and training sessions to criterion across 203 developing humans, so the structural-code bet and the conversion-rate definition of intelligence coincide at least once outside a model.
- **[[wiki/concepts/shortcut-learning.md]]** — a shortcut is a rule that reads content `x` where the intended rule reads structure `g`; a content-invariant code is the *architecture* lever that makes the structural rule the cheaper one to learn. It also carries the sharpest test in the wiki of *which* rule is in use — partitioning trials by whether a marginal statistic suffices — and the finding that a subject's grid-code strength predicts which side of that partition their competence lives on (Qu et al. 2026).
- **[[wiki/concepts/core-knowledge.md]]** — shows what `g` looks like when it is installed rather than trained: a code whose domain is fixed in advance is content-invariant by construction, at the cost of covering only its own domain. It also supplies the two sharpest behavioural measurements of the split — the number system's cross-modal comparisons, as accurate as within-modality, i.e. one code shared across `x` types; and the reorientation literature's dissociation of a content-blind geometric channel from an associative landmark-to-object channel (Spelke & Kinzler 2007).
- **[[wiki/concepts/predictive-coding-free-energy.md]]** — a second candidate for `g`, learned rather than periodic: *spatial predictive encodings* that map one frame of reference onto another posture-dependently, acquired from multimodal correlation and localised to posterior parietal cortex. It is content-invariant by role rather than by geometry, and it carries no commutativity guarantee, so it answers the requirement grid codes answer for gap G3 less cleanly (Butz 2016).
- **[[wiki/concepts/event-segmentation.md]]** — an event schema is content-invariant in the same sense `g` is: "reaching to contact" is defined by a relative distance reaching zero, whatever object fills the slot.
- **[[wiki/concepts/compositionality.md]]** — a part-and-relation description is content-invariant by construction: the same relation vocabulary applies to pen strokes, wheels and ice floes, so compositional structure is one way of realising `g` without a metric embedding.
- **[[wiki/concepts/three-component-framework.md]]** — locates this page in the *architecture* slot and names what the other two slots lack: no objective function is maximized by a path-consistent `g` and no learning rule ascends toward one (gap G30).
- **[[wiki/entities/h-jepa.md]]** — supplies the first candidate objective for `g`: content that cannot be predicted at long range is penalized out of the representation, so abstraction becomes a consequence of a predictability/completeness trade-off rather than a design decision.
- **[[wiki/concepts/subgraph-matching.md]]** — the most degenerate `g` that still pays: a one-hot anchor marking *which node the embedding is about* is what lifts a message-passing encoder above the Weisfeiler-Lehman limit on `d`-regular graphs (Ying et al. 2020).
- **[[wiki/entities/maze-solving-transformers.md]]** — emergent metric structure with nothing metric supplied: embedding distance tracks lattice Manhattan distance at short range although every input token is orthogonal and adjacency order is randomised, and the lattice-wide geometry lands in the *weights* while per-instance connectivity can only live in activations (Ivanitskiy et al. 2023).
- **[[wiki/concepts/representation-probing.md]]** — makes this page's requirements measurable: content-invariance is a cross-position probe transfer test and path-consistency (gap G3) is a residual between codes decoded after distinct routes.
- **[[wiki/concepts/pattern-separation-completion.md]]** — the other de-aliasing route in the same anatomy: `g` distinguishes repeated content by *position*, pattern separation distinguishes it by orthogonalizing the code itself, with no metric and no commutativity requirement.
- **[[wiki/concepts/cognitive-map.md]]** — supplies two further instances of grid-like coding outside physical space (hexadirectional entorhinal and ventromedial-prefrontal modulation over morphed-bird concept space; hippocampal angle / posterior-cingulate magnitude coding of a social power × affiliation space), and the matching negative: no anchoring analogue — no cell has been reported coding the boundary of a concept (Epstein et al. 2017); it also carries the domain-matched null (Kumaran & Maguire 2005) that limits how far any of those instances licenses an amodal code.
- **[[wiki/concepts/path-integration.md]]** — turns this page's central speculation into a mechanism: `g` commutes because it is built by accumulating action displacements, so gap G3 is answered by the update rule — provided the domain's actions compose at all, a precondition this page did not state.
- **[[wiki/concepts/successor-representation.md]]** — an independent derivation of the same code: grid-like patterns as eigenvectors of a diffusion process over the state graph, with no periodicity or action algebra assumed, and eigenvalue reweighting as the knob that turns one basis into exploration, planning or replay.
- **[[wiki/entities/tolman-eichenbaum-machine.md]]** — the demonstration that `g` can be *learned* from next-observation prediction across an environment family, and reused across worlds by rebinding rather than retraining (Whittington et al. 2022); its 2018 precursor adds the two things this page most lacked — a mechanism for the multi-scale row above (frequency bands wired low→high so fine-scale statistics are reused across the whole space, keeping weight count independent of arena size) and a route to a `g` for a *new* domain (reweight learned transition-statistic bases rather than learn a code).
- **[[wiki/concepts/distributed-reference-frames.md]]** — answers this page's generality question with "replicated, not general": the same periodic primitive run separately in every cortical area over its own input space, which converts `g` from one code into many concurrent codes needing arbitration — and it supplies the false-positive caveat that qualifies every abstract-grid row here.
- **[[wiki/concepts/objective-identifiability.md]]** — removes one leg of this page's support: hexagonal codes in trained networks are produced by a centre–surround supervised target rather than by the structural task (grids appear in almost none of >11,000 path-integrating networks and vanish under heterogeneous place-cell-like readouts), so `g`'s periodicity rests on recordings plus attractor theory, not on emergence experiments.
- **[[wiki/entities/vector-hash.md]]** — the strongest functional reason to keep `g` frozen and content-free: it is the address space, exponentially large precisely because it is prestructured, and its *metric ordering* additionally buys strong generalization — return weights learned over a small contiguous region of the code stabilise the entire code. It is also the counter-case to this page's discovery question, since it installs `g` outright and makes no attempt to learn one.
- **[[wiki/entities/tem-transformer.md]]** — the cheapest available export route for `g` out of navigation: if a position encoding is produced by a learned action-keyed recurrent operator rather than by a clock, the same equations carry grammar or task structure, and grid and band codes arise in it from a one-hot next-stimulus target with no centre–surround readout anywhere in the loss.
- **[[wiki/entities/mm-tem-hippoformer.md]]** — turns this page's "abstraction level = prediction horizon" row into a measured knob inside `g` itself: one integer (how many steps between memory writes) fixes how far ahead the model must predict and thereby how coarse the emergent periodic code is, end-to-end and with nothing multiscale imposed — and it reports the counterexample that keeps the row honest, models with low grid scores and high long-horizon accuracy that solve the task with a non-periodic code.
- **[[wiki/concepts/population-geometry.md]]** — turns requirement 1 into an instrument (cross-condition decoder transfer) and supplies the only case where `g` and `x` are seen becoming mutually invariant *in the same population as a function of learning*; it also relocates this page's factorisation requirement one level up: the cells carrying a learned abstract variable in mouse CA1 are overwhelmingly conjunctive, and `g`/`x` separation appears only as independent gradients on the population manifold — which also makes content-invariance a cross-position decoder-transfer test rather than a search for invariant units.
- **[[wiki/entities/fly-central-complex.md]]** — the cheapest existence proof that a code can be structural rather than sensory: one bump survives a many-featured scene unchanged, a 270° arena is rescaled onto the ring's full 360°, and the code's binding to the world is a single offset that can be re-assigned without the code changing.
- **[[wiki/concepts/cognitive-control.md]]** — a content-invariant code with no metric and no space: an abstract *match / non-match* rule generalises across sensory modality and to stimuli never seen, so `g` can be a relation over a task rather than a position in a plane — and its category result adds a property the grid candidates here lack, a learned partition of the stimulus space that is *overwritten* when the animal is retrained on an orthogonal boundary, leaving no trace of the old one in the same cells (Miller et al. 2002).
- **[[wiki/entities/spacetime-attractor.md]]** — names this page's product as the blocking piece of a hierarchical planner: stacking spacetime attractors makes plan length exponential in hierarchy depth, but only if some mechanism supplies the abstract state space the upper attractor plans over, which that model assumes and does not build (Jensen et al. 2026).
- **[[wiki/entities/neuromatch.md]]** — the cheapest structural code in the wiki: a single anchor one-hot — one distinguished node identity — is what lifts a graph-matching encoder above the Weisfeiler-Lehman ceiling, so structure is paid for in architecture rather than learned.
- **[[wiki/concepts/temporal-abstraction-options.md]]** — the consumer for this page's decomposability requirement: subgoals are what an option library is compiled from, so a structural code helps hierarchy only to the extent that its partition boundaries coincide with the transition graph's access points — and a code whose partitions are metric rather than topological would supply the wrong ones (Botvinick, Niv & Barto 2009).
- **[[wiki/entities/hami.md]]** — factorisation obtained without a structural code at all: two encoders quantised independently make an unseen (event, context) pairing representable the moment both components have been seen alone, which shows how far compositional generalisation gets on separate quantisation — and where it stops, since an unseen *rule* over those pairings is not representable (Poursiami et al. 2025).
- **[[wiki/concepts/language-of-thought.md]]** — the competing answer to what a concept is stored as: a typed expression supports variable binding and this page's code does not, while the code supports transfer and path consistency that a syntax says nothing about.
- **[[wiki/entities/othellogpt.md]]** — a content-invariant re-referencing that gradient descent chose unasked: board squares are coded relative to whoever is to move ({Mine, Yours}) rather than absolutely ({Black, White}), which makes one code serve both players, de-aliases the same square across plies, and is invisible to any probe written in the domain's own vocabulary. The transferable rule: the frame a model adopts is the one its *loss* is invariant under ([[wiki/concepts/linear-representation-hypothesis.md]]).
- **[[wiki/entities/transformer.md]]** — a `g`/`x` arrangement this page does not list, and the one that the whole attention literature runs on: the structural address is **added into the content vector** in the same `d_model` space, in linear superposition rather than conjunction or separate slots, and each head recovers whichever component it needs through its own learned `W^Q`/`W^K` projection before scoring — with the specific basis empirically irrelevant (learned positional embeddings 25.7 BLEU vs sinusoidal 25.8), so what carries the work is that displacement acts *linearly* on the code, not what the code is (Vaswani et al. 2017).
- **[[wiki/concepts/vector-symbolic-binding.md]]** — supplies the operator this page's `g`/`x` split never had: role vectors are `g`, tokens are `x`, circular convolution binds them at fixed width, its approximate inverse reads them apart, and superposition holds many bindings at once — with `g` random and content-free, exactly the condition the capacity argument demands.
