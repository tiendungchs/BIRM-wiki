# Function → Structure Inference — Why a Correlation Graph Cannot Recover the Wiring, Even With a Perfect Forward Model

**Structural connectivity predicts functional connectivity; functional connectivity does not recover structural connectivity. The failure is quantitative and it is *not* an instrument defect: in a simulation where the structural matrix **is** the exact coupling matrix that generated the dynamics, thresholding the resulting correlation matrix at 80% true-positive rate still leaves ≈72% of the inferred edges false. Two independent causes compound — correlations have sources other than direct edges (distance, two-step paths, shared drive), and in a sparse graph the base rate of a true edge is ≈3%, so any fixed false-positive rate is multiplied by the ~30× more numerous non-edges. This is the wiki's sharpest bound on the discovery half of [[wiki/concepts/latent-graph-discovery.md]], and it is a bound on the *problem*, not on the estimator.**

> **Provenance.** Honey, Sporns, Cammoun, Gigandet, Thiran, Meuli & Hagmann 2009, *Predicting human resting-state functional connectivity from structural connectivity*, PNAS 106(6):2035–2040, doi:10.1073/pnas.0811168106 (`raw/honey-2009-structural-to-functional-connectivity.md`). Same five participants and same two-granularity parcellation (998 ROIs ≈1.5 cm²; 66 landmark regions) as [[wiki/concepts/connectome-hubs-and-cores.md]], with resting fMRI added on two separate days (20 min, 15 min). Structural connectivity (SC) from diffusion-spectrum-imaging streamline counts; resting functional connectivity (rsFC) from pairwise Pearson correlations of regional BOLD. The same SC then supplies the couplings of a 998-node conductance-based neural-mass model simulated at 0.2 ms for 16 min, from which simulated BOLD and simulated rsFC are extracted — **the model is the control that separates "the measurement is bad" from "the inverse problem is ill-posed"**.

---

## The forward direction: strong, and a function of granularity

| Data | SC → rsFC correlation | Excluding absent / inconsistent SC edges |
|---|---|---|
| 66 regions, participant-averaged | `r = 0.66` | `r = 0.82` |
| 998 ROIs, participant-averaged | `r = 0.36` | `r = 0.53` |
| 998 ROIs, individual participants | `r = 0.39–0.48` | — |
| 998 nodes, **simulated** rsFC, individuals | — | `r = 0.32–0.44` |
| 998 nodes, simulated, participant-averaged | `r = 0.46` | `r = 0.52` |

Two things to read off:

- **The headline structure–function correlation halves when the nodes get smaller** (0.66 → 0.36). Averaging into 66 units removes noise *and* absorbs within-unit relational content into the node — exactly the conservation statement of [[wiki/concepts/node-definition-problem.md]]. Any number of the form "structure explains X% of function" is quoted in units of a parcellation.
- **The model reproduces the empirical relationship at its own resolution** (`0.46` vs `0.36` averaged) using topological coupling only — no spatial term, no subcortex, no local specialisation. Whatever the 998-node structure–function relationship is, it does not require ingredients beyond cortico-cortical topology.

## The reverse direction: the arithmetic

Thresholding rsFC to declare an edge, sweeping the threshold, gives a receiver-operating characteristic:

| | Area under ROC curve | At the threshold detecting 80% of true edges |
|---|---|---|
| **Empirical** rsFC → SC | **0.79** | false-positive rate **> 40%** |
| **Simulated** rsFC → SC (coupling matrix known exactly) | **0.95** | — |

The AUC looks respectable and is misleading, because AUC is base-rate-free and the graph is not. With prevalence `p ≈ 1/31` (structurally unconnected pairs are ≈30× as numerous at 998 ROIs):

```
precision = TPR·p / ( TPR·p + FPR·(1−p) )
          ≈ 0.8·0.032 / ( 0.8·0.032 + 0.40·0.968 )  ≈  0.06     (empirical)
```

**≈6% of inferred structural connections would be genuine.** In the model — where the correlations were *generated by* the very matrix being recovered, with no scanner, no head motion, no vasculature and no registration error — the same operating point yields **≈28%**. Sparsity alone destroys most of the achievable precision; the instrument only accounts for the gap between 28% and 6%.

**The transferable statement.** For any sparse latent graph, a discovery method that reports a per-pair score and thresholds it is fighting a prevalence term that scales as `(1−p)/p`. At 3% density this is a factor of ~30 working against every candidate edge, and it is a property of the graph, not of the score. Improving the classifier from AUC 0.79 to 0.95 — a jump larger than any the wiki's discovery methods have demonstrated — buys 6% → 28%, still unusable as an edge list.

## Where the unexplained correlation comes from

Three named sources, each measured, and together they say the residual is *structured*, not noise.

| Source | Measurement | Consequence for a discovery method |
|---|---|---|
| **Distance** | rsFC ∝ 1 / fibre distance, `r = 0.67` (66 regions). Partial correlation SC↔rsFC controlling fibre distance: `r = 0.47`. Bivariate `rsFC ~ SC + 1/d`: **69%** of variance at 66 regions, **30%** at 998 ROIs; **29%** in the model | A metric prior on the node set predicts edges on its own. Any "discovered" graph over spatially (or otherwise metrically) embedded nodes is confounded with the embedding unless distance is regressed out first |
| **Indirect two-step paths** | `IndirectSC_ij = Σ_k w_ik w_kj` over pairs whose shortest path is exactly 2 edges → `r = 0.29` with rsFC (998 ROIs, averaged); not accounted for by Euclidean distance; significant in every individual. Strongest for interhemispheric visual cortex | A correlation matrix is closer to a *communicability* / path-weighted object than to an adjacency matrix — the same object the entorhinal graph estimate turns out to be ([[wiki/concepts/successor-representation.md]]). Recovering adjacency means deconvolving the path sum |
| **Non-stationarity** | See table below | The target of the estimate moves inside the estimation window |

**The distance result has a specific sting.** The model contains **no spatial term** — coupling is topological only — and it nonetheless reproduces the empirical distance fall-off. So the distance effect needs no vascular, cardiac, respiratory or preprocessing explanation: cortico-cortical topology (which is itself distance-biased) suffices. The corollary is unwelcome for discovery: the confound cannot be removed by better imaging, because it is partly real.

The model also captures the *indirect* structure, which is the check that it is doing network computation rather than passing the input matrix through: simulated vs empirical rsFC at 998 ROIs is `r = 0.46` on directly connected pairs and `r = 0.37` on indirectly connected ones. (At 66 regions the split is `0.70` direct / `0.23` indirect — the coarse graph gets the direct edges better and the indirect ones worse.)

## Reliability: the target moves, and the model says so too

| Comparison | rsFC reliability (correlation of two rsFC estimates) |
|---|---|
| Empirical, across sessions days apart, 998 ROIs | `r = 0.38–0.69` |
| Empirical, two 10-min windows *within* one scan | `r = 0.39–0.61` |
| **Simulated**, two consecutive 8-min windows within one run | `r = 0.69–0.80` |

The simulation has no scanner artefacts and a literally constant coupling matrix, and still fails to reproduce its own functional connectivity across an 8-minute window. Both empirical and simulated BOLD show very long-range temporal autocorrelation, so a window of 200+ time points contains far fewer independent samples than it appears to — **the effective sample size of a functional connectome is not its number of frames**. The authors' conclusion, and the one the wiki should carry: rsFC values "may not reflect a static underlying entity".

**The anatomy sets the reliability, not just the strength.** ROI pairs *with* SC show significantly less rsFC variability, within and across sessions, than pairs without. The paper is explicit that it cannot separate "more persistent because stronger" from "stronger because more persistent" — but either way the mediator is the tract. Densely interconnected subsystems such as the default mode network are therefore the *persistent* functional networks, and persistence is an anatomical property.

This is primary evidence for [[wiki/empirical-tensions.md]] T240 (is a resting-state network an object or a window artefact), which the wiki previously carried only from a review.

## The default-mode case, and a failure with a named cause

Simulated rsFC matches empirical rsFC best in posterior medial cortex — precuneus, posterior cingulate — and medial orbitofrontal cortex, i.e. precisely the structural core of [[wiki/concepts/connectome-hubs-and-cores.md]]. Seeding the default mode network reproduces its medial axis (strong interhemispheric and along-the-medial-wall SC between precuneus/posterior cingulate and medial prefrontal cortex) and **largely fails to include lateral parietal cortex**.

The failure is traced, not hand-waved: lateral↔medial posterior parietal connections exist in macaque tracer data but run perpendicular to the superior longitudinal fasciculus, which streamline tractography does not follow. So a model faithfully inheriting a biased structural input reproduces the bias — a clean instance of a forward model being right about the wrong graph. Any pipeline of the form (measure graph) → (simulate) → (score against data) has this failure mode and no internal test for it.

## Relevance to a reasoning model

- **Do not build edge discovery as per-pair scoring plus a threshold.** The base-rate term makes it hopeless at biological sparsity even with a perfect score. What survives: (i) estimate the graph as *parameters of a generative model* with an explicit sparsity prior or evidence-based pruning ([[wiki/concepts/effective-connectivity.md]]); (ii) accept a path-weighted metric instead of an adjacency matrix, which is what the brain's own estimate looks like ([[wiki/concepts/successor-representation.md]]); or (iii) get the prevalence up by conditioning on a candidate set before scoring.
- **Report precision at a stated prevalence, never AUC alone.** AUC 0.95 and 28% precision are the same experiment. The wiki's graph-discovery evaluations ([[wiki/entities/hag-reservoir.md]], [[wiki/entities/fcann.md]], attention-as-adjacency readings) inherit this: a plausible-looking recovered adjacency matrix over a sparse ground truth is mostly false positives at any usable recall.
- **Correlation matrices are transitively closed and adjacency matrices are not.** The `Σ_k w_ik w_kj` term is the concrete form of the leak. A learner reading co-activation as evidence of connection will build the two-step closure of its graph, which is the *opposite* of the biological finding that composition is selective, offline and value-gated ([[wiki/concepts/offline-replay.md]]).
- **A metric prior on the nodes is a confound and a resource.** 1/distance alone explains a large share of the correlation structure. If the node set has any geometry — retinotopy, embedding similarity, layer index — an edge estimator must be scored against a distance-only baseline before its topology claim means anything. **(brainstorm)** Conversely, a discovery method could *initialise* from the metric and spend its evidence budget only on the residual, which is the 30% (998 ROIs) that distance and direct wiring jointly fail to explain.
- **Estimation window is a first-class hyperparameter with no principled setting.** Two 8-minute windows of a stationary simulated system disagree at `r ≈ 0.7`. Any architecture that estimates a graph from long-run co-statistics ([[wiki/entities/fcann.md]], co-fluctuation thresholding) is estimating a window-average of a moving object, and nothing in the wiki sets the window ([[wiki/architectural-gaps.md]] `G67`).
- **Structural connectivity should be a prior, not a target.** The one direction that *does* work — SC present ⇒ rsFC strong and reliable — is exactly the usage the whole-brain modelling literature makes of it: hand the anatomy to the model as fixed couplings and fit the few remaining parameters ([[wiki/entities/virtual-brain-twin.md]]). The result on this page is the justification for that division of labour.

## Open problems

- **The deconvolution is never attempted.** The paper measures that indirect paths and distance contribute; it does not invert the mapping. A method that takes a correlation matrix and returns a *posterior over adjacency matrices* given a path-sum forward model and a sparsity prior is the obvious missing tool, and does not appear anywhere in the wiki.
- **Which of the two reliability accounts is true.** Genuine reconfiguration of neuronal interactions versus low-frequency signal components of unknown origin — the paper cannot separate them, and the answer decides whether short-window functional connectivity is a signal to be tracked or a variance to be averaged away.
- **Fibre density is not synaptic efficacy.** The couplings are streamline counts, resampled to a Gaussian (mean 0.5, sd 0.1) purely because the raw exponential distribution spans orders of magnitude that physiological efficacies are assumed not to. The monotone-but-otherwise-arbitrary map from tract to weight is unvalidated, and every number on this page is downstream of it.
- **Cortex only, and no thalamus.** The model has cortico-cortical couplings alone. The authors name thalamus and basal ganglia as required additions; the wiki's thalamocortical sources make the thalamus a *switch* between cortical routing states, which would appear here as exactly the kind of shared drive that creates correlation without an edge.
- **`n` = 5, all male, all right-handed, mean age 29.4 ± 3.4.** Same cohort limitation as the structural-core page.
- **No task.** Everything is resting state. Whether the structure→function relationship holds, tightens or loosens under task demands is untouched here (and is the question [[wiki/concepts/connectome-state-transformation.md]] takes up).

- **[[wiki/concepts/effective-connectivity.md]]** — the constructive response to this page's negative result: stop thresholding statistics and estimate edges as parameters of an inverted generative model, where sparsity comes from model evidence rather than from a cutoff on a correlation.
- **[[wiki/concepts/dynamic-repertoire.md]]** — this page supplies that page's claim-1 evidence in primary form: the low test–retest reliability of functional connectivity is reproduced by a model with a fixed coupling matrix, converting an apparent measurement defect into a prediction of the theory.
- **[[wiki/concepts/node-definition-problem.md]]** — the reason "structure explains X% of function" has no parcellation-free value: the same data give `r = 0.66` at 66 nodes and `r = 0.36` at 998, because coarsening absorbs within-unit relations into the node.
- **[[wiki/concepts/successor-representation.md]]** — what a correlation matrix actually approximates: the two-step path sum `Σ_k w_ik w_kj` predicts functional connectivity between unconnected pairs, so the observable is a path-weighted (communicability-like) object, which is the same class of estimate the entorhinal graph code turns out to be.
- **[[wiki/entities/virtual-brain-twin.md]]** — the pipeline this page justifies and bounds: structural connectivity is handed to the model as fixed couplings (the direction that works), and both inherit the lateral-parietal tractography blind spot demonstrated here.
- **[[wiki/entities/fcann.md]]** — the wiki architecture most directly cautioned: its couplings come from regional BOLD co-statistics over long windows, which this page shows is both a window-average of a moving target and an object contaminated by distance and two-step paths.
- **[[wiki/entities/medial-prefrontal-cortex.md]]** — the anatomical half of the default-mode result: strong structural connectivity along the medial wall to precuneus/posterior cingulate is what the model reproduces, and the lateral parietal component is what it misses.
- **[[wiki/concepts/inter-areal-synchrony.md]]** — the general form of this page's warning at a different frequency band: a coherence or correlation between two nodes licenses no inference about a connection between them, and here the false-positive rate is measured.
- **[[wiki/concepts/metastability.md]]** — the dynamical reading of the reliability result: a functional connectome estimated over a window is a time-average over coalitions that form and dissolve, so its instability is the signal `σ_R` measures rather than noise to be suppressed.
- **[[wiki/concepts/connectome-state-transformation.md]]** — the task-state continuation of this resting-state analysis, and the source of the qualification this page's open problems name: what is stable across states may be the *map between* functional connectomes rather than any one of them.
- **[[wiki/concepts/excitation-inhibition-balance.md]]** — the constructive form of the deconvolution this page lists as never attempted: instead of thresholding correlations to declare edges, hold the tractography skeleton fixed and invert the correlation matrix into a per-edge excitation/feedforward-inhibition mixture, which never asks whether an edge exists and so never pays the base-rate penalty — and inherits this page's lateral-parietal tractography blind spot unchanged.
- **[[wiki/concepts/anatomical-harmonic-modes.md]]** — the structure→function direction used at its cheapest: anatomy enters as a two-parameter exponential distance law plus an outlier set rather than as a measured matrix, and the raw structural connectome performing *worse* than the fitted law is this page's tractography-noise result restated as a modelling recommendation (Vohryzek et al. 2024).
- **[[wiki/concepts/cortical-traveling-waves.md]]** — the forward direction used against a harder target than a connectivity matrix: structure predicts a *spatiotemporal* property of the dynamics, and the claim is carried by six ablations (shuffled weights, distance-matched surrogate, zero delay, constant delay, instrength normalisation, different node model) rather than by the headline correlation — a control ladder that correlation-matching benchmarks do not apply (Koller et al. 2024).
- **[[wiki/concepts/default-self-model.md]]** — the same reverse inference one level up, on function rather than wiring: a *psychological* default mode is read off the fact that medial prefrontal cortex is metabolically expensive at rest and co-active during self-judgment, with no test that the resting signal computes the task-defined thing.
- **[[wiki/entities/default-mode-network.md]]** — the wiki's largest system named for a function its own design cannot identify: passive tasks move mental content and attentional breadth together, so a simulation engine and an environmental sentinel predict the same deactivation map — and the count is worse than two: the field carries **ten** function hypotheses over that one map, of which only the sentinel is a genuine rival to construction, so the number of surviving explanations is a property of how few distinguishing designs exist rather than of how much evidence there is (Azarias et al. 2025).
