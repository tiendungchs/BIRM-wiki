# T84 — Should the fraction of units written per memory be fixed, or should it track load and statistics?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** An engram study varies the number of stored memories — the only variable the capacity theories say should move the coding level, and the one no engram experiment manipulates.

## Position A

**Fixed set-point.** Within a region the engram fraction is conserved across memories — 10–20% in lateral amygdala, 2–6% in dentate gyrus — and neither raising shock intensity nor switching valence from fear to reward changes it; the budget is defended by feedback inhibition, since blocking interneurons enlarges the trace (`raw/talk-nd-memory-engram.txt`, **(tentative)** — talk only, no paper read)

## Position B

**Load- and statistics-dependent.** Every capacity-derived optimum in the wiki makes the coding level a function of something that changes: `p = (2MT)^(−1/3)`, which *falls as the store fills* ([[wiki/entities/sparse-distributed-memory.md]]); `f* ∝ λ`, tracking the recurrence rate of the memory being written ([[wiki/concepts/recall-gated-consolidation.md]]); `a` as a per-context control variable whose optimum depends on the number of contexts ([[wiki/entities/context-modular-memory-network.md]])

## Where it bites

Decides whether a machine store needs an adaptive sparsity controller at all, or whether one inhibitory gain per store — set once, never scheduled — is the right design. It also decides how to read overlap: with `k` fixed, every edge written by co-allocation is capacity spent, so a constant budget is what bounds runaway linking ([[wiki/concepts/engram.md]])

## Status

`LIVE` — the two may not be measuring the same thing: the theory optima are asymptotic (best `a` for a *store* of given size and load), the biological constant is per-*episode* and measured over a handful of memories, and no engram study varies the number of stored memories, which is the only variable the theory says should move it
