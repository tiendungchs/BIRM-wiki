# T198 — Does locality buy resistance to catastrophic forgetting?

**Status:** `LIVE`  
**Level:** `L3`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Clamped predictive coding and backpropagation are run on the same task sequence and backward transfer measured — cheap, unrun, and the interesting quantity is whether forgetting tracks approximation tightness.

## Position A

**Yes.** Backpropagation moves every weight in service of one global output loss, which is the mechanism by which prior structure is overwritten; predictive coding's weights each descend only their own layer's residual, so learning a new example cannot recruit the whole network — locality is offered as a forgetting-resistance argument in itself (talk-nd-brain-learning-algorithm, **(tentative)**)

## Position B

**Not established, and in tension with the framework's own headline result.** A clamped predictive-coding network's error nodes settle on the backpropagated `δ_l` to a close approximation (Whittington & Bogacz 2017, 2019) — if the approximation is close, the weight trajectory is close, and the forgetting behaviour should be close too. No continual-learning benchmark comparing the two is cited

## Where it bites

Decides whether a builder gets continual learning free by choosing a local objective, or still has to pay for it with gating, replay or code separation ([[wiki/concepts/continual-learning.md]])
