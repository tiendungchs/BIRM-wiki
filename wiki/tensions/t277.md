# T277 — Is the single-neuron receptive field still the right unit of description above the thalamus?

**Status:** `LIVE`  
**Level:** `L4`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The residual statistic is reported: monotone in the prediction means a missing term, uncorrelated means a missing mechanism. Neither side has measured it.

## Position A

**Yes — the standard model is incomplete, not wrong.** Every V1 nonlinearity found so far has been absorbed by bolting a stage onto a two-stage box: an output nonlinearity fixes the tuning-bandwidth and direction-selectivity errors, half-squaring plus divisive normalization fixes saturation and nonspecific suppression, and adding gain control fixed the equivalent problem one stage earlier in the LGN. The decisive point is that **the composite has never been built**: nobody has assembled a V1 model containing the known dynamical nonlinearities (synaptic depression, surround suppression, contrast adaptation, a refractory spike generator) and tested it on natural video, so "V1 is poorly understood" and "the standard model has never been assembled" are not currently distinguishable (Tolhurst and Mante, in Carandini et al. 2005, [[wiki/entities/early-visual-system.md]])

## Position B

**No — the failure is qualitative and the unit is wrong.** The residual changes *type* between stages: in LGN the linear model predicts nearly every response event and errs in gain, which a scalar mechanism corrects; in V1 under time-varying natural input the model misses events entirely and invents others, which no pointwise nonlinearity or modulatory term repairs. The accounting says why — ~60–80% of a layer-4 V1 cell's response variance is contributed by other V1 neurons or by non-geniculate input, ~40% of explainable variance is the ceiling reached to date, and up to 85% of V1 function is unaccounted for once biased neuron sampling is priced in. The stated conclusion is that describing any one neuron will require including the simultaneously recorded others (Olshausen & Field 2005; David & Gallant 2005, same review)

## Where it bites

Whether a per-unit description of a sensory or hidden layer is a target that further refinement reaches, or one it provably does not — which decides whether [[wiki/concepts/representation-probing.md]]'s per-unit instruments have a depth ceiling and whether [[wiki/concepts/population-geometry.md]]'s premise is forced rather than chosen. Also prices [[wiki/concepts/neuroscience-ai-transfer.md]]'s convolutional row: under B the biology being copied is a recurrent network whose feedforward drive is a minority shareholder

## Status

`LIVE` — and unusually cheap to move, because the two positions differ in a measurable signature rather than in interpretation: **a residual that is a monotone function of the prediction is a missing term (A); a residual uncorrelated with the prediction is a missing mechanism (B)**. Neither side has reported that statistic, and the same test runs unchanged on an artificial network — fit the best per-component description at each layer and plot residual–prediction correlation against depth ([[wiki/concepts/predictive-adequacy.md]]). **A third response exists and it declines the question**: DiCarlo, Zoccolan & Rust 2012 concede the per-unit target outright above V1 — encoding models for inferior temporal neurons are poor and directly recovering one may be "practically impossible with current methods" — and replace the criterion with a *decoding* one that rises monotonically over the same stages the per-unit score falls across ([[wiki/entities/ventral-visual-stream.md]], [[wiki/concepts/manifold-untangling.md]]). That does not settle A vs B, because a population being linearly readable is compatible with either; it does show the disagreement is only forced if per-unit description is the only thing on offer
