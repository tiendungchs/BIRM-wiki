# T272 — Does failure to decode a content from prefrontal cortex mean the content is not there?

**Status:** `LEANING`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**Yes — it is a key challenge to the theory.** COGITATE reports that stimulus category and orientation could not be decoded from prefrontal cortex while they could from posterior areas, and reads the posterior success as positive evidence for the integrated-information account's posterior hot zone

## Position B

**No — it is a read-out artefact.** Naccache et al. 2025: visual and ventrotemporal cortex have mesoscopic columnar organisation (neighbouring cells share selectivity) so the code survives the averaging kernel of fMRI/MEG/iEEG, while prefrontal cortex has no strong columnar organisation and codes by **mixed selectivity** (Wang 2022), which coarse instruments cancel. The counter-cut: posterior decoding succeeds even for **non-conscious** stimuli (Dehaene et al. 2001; Salti et al. 2015; King et al. 2016), so the positive evidence may index non-conscious processing

## Where it bites

Every negative interpretability result, biological or artificial. A probe on a pooled signal measures code geometry × unit arrangement × averaging kernel, and only the first is about content, so a coarse-scale null licenses nothing while a hit still licenses the content claim. In a machine the confound is optional — it is reintroduced by probing pooled layers or comparing regions with unmatched code clustering ([[wiki/concepts/population-geometry.md]], [[wiki/concepts/ignition.md]])

## Status

`LEANING B` on the mechanism, which is a fact about instruments rather than a claim about consciousness, and which costs the framework as much as it saves — it removes prefrontal decoding from the evidence for the workspace at the same time. **The named resolving measurement was already run, and it is positive** — Kapoor et al. 2022: 987 macaque ventrolateral prefrontal units, no-report binocular rivalry, the current percept decodable at up to 95% on single transitions, while on the *same* array sites with opposite motion preference sit ~0.4 mm apart with no patch structure. Both halves of B's mechanism therefore hold in one dataset: the code is spatially unclustered **and** the content is present, so they vary independently and a coarse null over this exact tissue would have been wrong. Two gaps remain before the row can close on COGITATE's own claim: different features (motion direction, not category/orientation) and different species/paradigm, so what is established is that a prefrontal coarse null is *uninformative*, not that COGITATE's specific contents were present

**The primary record adds a discriminating fact that neither position had** (Ferrante et al. 2025): the prefrontal null is **dimension-selective** — category generalised across task at ~70% (iEEG) and ~60% (fMRI) in the *same* tissue, instrument and kernel where identity was absent for every category and orientation supported the null (`BF₀₁ = 5.11–8.65` iEEG; 34–55% of prefrontal voxels substantial-to-very-strong for the null). A geometry×kernel argument is variable-agnostic and predicts a uniform cancellation, so B cannot carry the whole null. Settled form: **a coarse null licenses nothing on its own, but a coarse null that is selective across variables is evidence about content** — here, that prefrontal cortex carries abstract category and not low-level detail, which narrows the workspace's advertised scope rather than excusing it.
