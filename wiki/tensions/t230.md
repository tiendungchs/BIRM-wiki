# T230 — When the rewrite machinery is itself rewritable, is there anything left to learn?

**Status:** `LIVE`  
**Level:** `L0`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The same self-amending environment is run with the proposal distribution held fixed and known: recovered performance locates the generator in the agents rather than the rules.

## Position A

**No — and the wiki already says so.** [[wiki/concepts/latent-graph-discovery.md]]'s treatment of hardness source 6 states that a rewrite process with *no compressible generator* is unsolvable in principle, for any learner, because there is nothing to learn. [[wiki/entities/nomic.md]] is the limit case: proposals are free natural-language text (unbounded vocabulary), the amendment and precedence rules are themselves amendable (no meta-stationarity), and the scoring rule and winning threshold are ordinary mutable rules, so even the reward is inside the rewritten object. There is no stationary kernel over `rule_config` to infer, and the two-tier W/M assignment — generator to slow **W**, active edge set to fast **M** — has nothing to put in W.

## Position B

**Yes, and the generator is simply not in the rules.** The game has been played since 1982 and games terminate with winners, so *something* makes the rewrite stream predictable enough to act on. Suber locates it outside the rule text: game rules derive authority from the players' agreement rather than by inference from prior rules, so Hart's **acceptance** model applies where Ross's inference model does not — the compressible structure is the population of proposers and the ratification threshold they will clear, not the rule system. The rule set then *bounds* what that population can do to the episode: at most 25 concurrent mutable rules, one rule-change per turn, no retroactive effect, an initial set deliberately built so that no single rule-change can destroy continuity, and the objective's *form* entrenched against amendment. On this reading the learnable object is a model of the other agents plus a set of hard bounds, which is ordinary [[wiki/concepts/contextual-inference.md]] over a non-stationary but *rate-limited* latent.

## Where it bites

Decides whether hardness source 6 has a solvable interior or only a solvable boundary. If A holds, G9 is not an architecture problem — a self-amending system is unlearnable from the inside and the only question is what to entrench, which makes the interesting work the *design* of the immutable tier. If B holds, the generator was never supposed to be in the environment: it is in the other agents, and G9 collapses into multi-agent modelling under rate limits, which relocates it beside [[wiki/entities/autotom.md]] rather than beside [[wiki/concepts/meta-optimized-plasticity.md]]. Nothing decides it today, because the domain has never been implemented and no system, human or machine, has been measured on it — the wiki's only self-amending domain is also its only domain with **zero** data

## Status

`LIVE`, and it is a tension about the *object of learning* rather than about a result. The cheap discriminator is B's own claim: run the same self-amending environment with the proposal distribution held fixed and known, and see whether performance is recovered — if it is, the generator was in the agents
