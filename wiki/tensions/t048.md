# T48 — Where is an inferred, never-experienced association computed — inside the medial temporal lobe or downstream?

**Status:** `LIVE`  
**Level:** `L1`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A single-day version of Barron's design is run, testing whether the outcome code sits in hippocampus before multi-day consolidation moves it out.

## Position A

**Inside.** The retrieved-context account has hippocampal reinstatement of an item's stored context pull back everything else that shared it, so transitive and backward associations fall out of medial-temporal machinery alone; hippocampal lesion abolishes exactly those and spares forward association (Howard et al. 2005, [[wiki/entities/temporal-context-model.md]]); recurrent-loop models likewise recirculate within the medial temporal lobe until the inferred item is reinstated

## Position B

**Downstream.** With the intermediary `Y` and the outcome `Z` dissociated by a many-to-one cue mapping, human and mouse hippocampus during the inference cue represents `Y` and shows *no* evidence for `Z` (nor for `Y`'s value), while `Z` is decodable in medial prefrontal cortex and midbrain — including for neutral outcomes. The hippocampus is causally necessary (optogenetic dorsal-CA1 silencing at the cue abolishes the inference) but supplies the *link*, not the answer (Barron et al. 2020)

## Where it bites

Decides the shape of the memory module in an architecture. If A, a fast store that iterates on its own output can return composed answers and the reasoner is one module. If B, the store returns a one-hop retrieval and composition must be completed by a separate downstream valuator — which also means a system whose memory recirculates until convergence is modelling the wrong anatomy

## Status

`LIVE` — the two are not strictly incompatible: Barron's ripple result shows the composed `X→Z` link itself being written *in* hippocampus offline, so the disagreement may be about timing (link stored inside, answer assembled outside) rather than about locus. Barron's own caveat is that the multi-day schedule may have already consolidated the outcome code out of hippocampus; a single-day version might put `Z` in both
