# T101 — Can the control layer address the episodic store directly, or only through a relay?

**Status:** `LEANING`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**Only through a relay.** The direct hippocampus→medial-prefrontal projection is monosynaptic and essentially unreciprocated, so the return route must be nucleus reuniens or entorhinal cortex — the premise of [[wiki/entities/nucleus-reuniens.md]] and of this wiki's whole controller→store story (Heidbreder & Groenewegen 2003; Jin & Maren 2015)

## Position B

**Directly.** A monosynaptic anterior-cingulate → dorsal CA1/CA3 projection exists in mouse and is optogenetically necessary *and sufficient* for spatial-memory retrieval, preferentially innervating learning-created hub neurons (Rajasethupathy et al. 2015, in Sigurdsson & Duvarci 2016; [[wiki/entities/medial-prefrontal-cortex.md]])

## Where it bites

Whether the controller→store write needs an intermediary module at all. If both hold, the resolution is that the *tiers* differ — the ventral tier receives from the store and reaches it only via relay, the dorsal tier writes to it directly — which makes the controller's read port and write port different modules, an asymmetry no architecture has
