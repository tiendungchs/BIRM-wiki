# T6 — What is out-of-distribution failure a failure *of*?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

A flat learner fits the mixture `E_θ[p(obs|θ)]`, a distribution no instance follows — o.o.d. failure is a missing level of hierarchy ([[wiki/concepts/latent-graph-discovery.md]])

## Position B

Networks generalise o.o.d. *prodigiously* — abstract patterns confidently classified as guitars, vast image sets mapped to object categories. The failure is directional: chosen features create insensitivity to all others, so the model extrapolates along the wrong axes (Geirhos et al. 2020)

## Where it bites

Prescription differs: *add hierarchy* (fit the right object) vs. *add bias* (choose the right invariances). If B is right, a correctly hierarchical model with the wrong feature preference still fails

## Status

`LIVE` — likely complementary; A explains why the fitted object is wrong, B why the extrapolation is confident
