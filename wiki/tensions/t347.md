# T347 — Does the entorhinal-hippocampal code de-alias geometrically identical subspaces, or only positions within one?

**Status:** `LIVE`
**Level:** `L2`
**Registry:** [[wiki/empirical-tensions.md]]
**Closes when:** A multicompartment environment is recorded with enough simultaneous cells to test, per compartment, whether *any* linear readout of the entorhinal-hippocampal population recovers compartment identity — as opposed to testing whether the position-coding cells do.

## Position A

**It de-aliases — that is the fast store's defining job.** Distinctness is one of the two constraints said to *generate* `g` ("different states get different codes, or memories written at them collide"), and it is a consequence of `g` being used as a memory address rather than of anything spatial (Whittington et al. 2020, [[wiki/concepts/path-integration.md]]). On the observation side the same requirement is met by dentate/CA3 pattern separation, and by clone allocation in [[wiki/entities/cscg.md]] — hardness source 3 in [[wiki/concepts/latent-graph-discovery.md]]. Every model in the wiki that writes `p = f(g, x)` into a store assumes the key is unique over the environment.

## Position B

**It does not, when the subspaces are geometrically identical.** In a hairpin maze of ten same-shape same-orientation arms, the grid map **fragments into a repeating per-arm submap**: firing-field positions correlate across arms with the same running direction (median `r = 0.58`, n = 105 MEC grid cells, 16 rats) and not across arms with opposite direction (median `r = −0.02`), giving a checkerboard population-vector correlation matrix; the two-dimensional hexagonal structure is gone (gridness `−0.14 ± 0.02` vs `0.57 ± 0.03` in the open field). Place cells repeat the same way — CA3 median `r = 0.72` (n = 111), CA1 `r = 0.70` (n = 47) — so the hippocampus does not disambiguate the arms either. The map resets at the turn: adjacent-bin population-vector correlation falls to `r = 0.44` at maximum-curvature points against a Monte-Carlo mean of `0.62` (below all 1,000 shuffles), and truncating an arm shows fields anchored to the **preceding** turning point, i.e. each submap is re-zeroed at its own boundary (Derdikman et al. 2009, `raw/derdikman-2009-grid-map-fragmentation-multicompartment.md`).

## Where it bites

Whether a structural code's address is globally unique or unique only *within a segment*. Under A a single `g` keys the whole environment and a downstream reader recovers position from `g` alone. Under B what is architecturally denied to the reader is **which compartment it is in**: `g` supplies an offset from the last boundary and nothing else, so the store's key must be a *pair* `(segment id, within-segment offset)` — and no model in the wiki has the first operand. It also inverts a transfer argument: repetition across identical compartments is exactly the reuse [[wiki/entities/state-space-composition.md]] wants from a building block, so the same measurement is a de-aliasing failure and a compositional success, depending on which page reads it.

## Status

`LIVE` — B is a direct measurement with the behavioural control that matters: in a "virtual hairpin" where rats ran the same zig-zag laps in an open field with **no internal walls**, the grid stayed two-dimensional and kept its open-field spatial phase (`r = 0.49 ± 0.03`, n = 28), so stereotyped trajectory, sharp turns and the reward schedule do not fragment the map — physical partition does. Three things keep A alive rather than refuted. (i) The measurement is of the *position-coding* cells: 23 place cells were excluded from analysis precisely because they fired only in the end arms, i.e. some cells do carry arm identity, and nobody tested whether the full population is linearly separable by arm. (ii) Late in an arm the code aligns better to the *upcoming* wall than the preceding one, so the submap is not a pure re-zeroed dead-reckoner. (iii) A and B are reconcilable if compartment identity is simply a second block the recordings did not sample — which is Position A restated as a prediction, and is the experiment named in `Closes when`.

**The upstream half of the question, which both positions state at the wrong stage** ([[wiki/concepts/hierarchy-of-associativity.md]], Lavenex & Amaral 2000). Every measurement in this row is taken at or below the entorhinal stage, but the code arriving there has already passed through two further association stages — perirhinal and parahippocampal cortices, each with a dense intrinsic associational network and heavy reciprocal connections to each other — whose stated function is to integrate unimodal into polymodal and then supermodal information *before* the hippocampal formation receives anything. Two consequences. (i) Position A's "different states get different codes" is a requirement the store cannot satisfy on its own: if the stack maps two situations to the same supermodal code, no dentate/CA3 mechanism separates them, so de-aliasing is a property of the whole input path and the hairpin-maze failure may be an upstream one. (ii) Position B's compartment-identity operand, if it exists, need not be a second *entorhinal* block — the perirhinal/parahippocampal stages carry object and visuospatial streams that could supply it, and the indirect routes there (V4 and posterior parietal cortex reach perirhinal cortex only disynaptically via parahippocampal cortex, and any entorhinal level tri-synaptically) mean the segregation of entorhinal afferents is *not* a segregation of content. The review offers no measurement of integration at any stage, so this narrows where to look rather than moving the row.
