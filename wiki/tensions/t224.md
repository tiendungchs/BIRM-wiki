# T224 — Does a correct external worked solution to a closely related problem help or hurt?

**Status:** `LIVE`  
**Level:** `L4`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Trace relatedness is swept: a correct solution to the same problem helps by +34 points, to a near-identical problem whose method fails it splits — the threshold between them is unmeasured.

## Position A

**Helps, strongly, and it is the wiki's cleanest positive.** Hendrycks et al. 2021 ([[wiki/entities/math-dataset.md]]) hand a model an increasing fraction of the ground-truth derivation and read accuracy off the hint curve: 0% of the solution ≈ 6%, **99% of the solution ≈ 40%**, a +34-point gain from conditioning on a correct trace produced outside the model. The same asymmetry organises the wiki's three-way trace decomposition — a correct *external* trace is positive as training signal and very positive as conditioning input, and only the *self-generated, unverified* trace is negative. Every retrieval-augmented and few-shot mathematics pipeline is built on this reading.

## Position B

**Hurts as often as it helps, once the trace is of a *different* problem.** Huang et al. 2025 ([[wiki/entities/math-perturb.md]]) supply the original problem **and its correct solution** as a one-shot example for a perturbation at embedding-cosine ~0.99 whose method no longer applies. The effect splits: 24–40% of prior errors are repaired for large closed models, and **18–40% of previously correct items are broken**, netting under 5%. The misleading half *grows with model capability* — 18–40% for large models against 4–15% for small open ones — so competence at in-context learning and vulnerability to an inapplicable demonstration are the same competence.

## Where it bites

The reconciling variable is whether the supplied trace is a trace **of the problem being asked**, and the wiki had been treating *external and correct* as sufficient. It bites wherever demonstrations are selected by embedding similarity — retrieval-augmented generation, few-shot prompt construction, and [[wiki/concepts/test-time-training.md]]'s fine-tune-on-the-neighbourhood move, against which the authors state the hypothesis explicitly. The missing measurement is a hint curve run on a *perturbed* item, i.e. accuracy as a function of the fraction of a derivation that is correct **for a problem one edit away**; nobody has drawn it.
