# T93 — Does abstracting a rule enable generalization, or only speed it up?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**Enabler.** Monkeys given two abstract rules (match / non-match) cued across modalities performed above chance on pictures they were **seeing for the first time**, which per-exemplar learning cannot produce: the alternative solution is 16 paired associates that say nothing about a new picture, so each new stimulus set would cost a fresh set of errors. Rule coding was correspondingly the most prevalent signal across prefrontal cortex, and the efficiency argument is representational — one abstract rule population instead of one population per cue modality (Wallis et al. 2001, in Miller et al. 2002; [[wiki/concepts/cognitive-control.md]])

## Position B

**Rate multiplier.** Higher-order rules are explicitly stated *not* to be necessary for acquiring the lower-order mappings under them — each exemplar can be learned one at a time without ever encoding the general rule — and the one place the strategy's value is quantified it is worth an exact 33 percentage points of initial-choice error, a better starting point and not learning: after PFv+o removal, reinforced mappings were not acquired at all across a 50-trial block despite the strategy loss accounting for only part of the error (Wise & Murray 2000; Murray et al. 2000; [[wiki/concepts/arbitrary-sensorimotor-mapping.md]])

## Where it bites

Whether an architecture should expect a rule layer to change the sample-complexity *class* on a new instance set or only its constant. Under A a reasoning model must contain a rule level to transfer at all; under B a rule level is an optimisation over an instance learner that must exist anyway, and building the rule level first is building the wrong thing (gap G8)

## Status

`LIVE` — and possibly not a disagreement about mechanism but about **edge type**: Miller's rules quantify over a *relation* (same / different) that is fully defined on stimuli never seen, whereas Murray & Wise's mappings are arbitrary edges with no shared content to factor out, where by construction no abstraction can predict a new edge. If that reading is right the discriminating variable is whether the target edge is computable from the rule, and the two results are the two ends of one axis rather than rival claims
