# T348 — Is an object-vector block path-integrated, or measured online from the referent?

**Status:** `LIVE`
**Level:** `L2`
**Registry:** [[wiki/empirical-tensions.md]]
**Closes when:** Object-vector cells are recorded in an environment the animal explored in light and then navigates in darkness *after the object has been removed*, testing whether the vector field persists at the remembered referent location — i.e. whether the code can be carried by self-motion to a place the referent is no longer visible from.

## Position A

**Path-integrated, like the grid.** [[wiki/entities/state-space-composition.md]] builds a hippocampal state space by conjoining structural blocks, and the load-bearing property of each block is that it is "a complete path-integrable map in its referent's own frame, updatable by self-motion exactly as a grid code is". This is what licenses **offline construction**: replay can carry a block to a location the animal has never occupied, and the whole zero-shot-policy and latent-learning result rests on it (Bakermans et al. 2025). The same assumption is implicit wherever the wiki treats vector cells as basis functions over transition statistics — a basis defined over transitions is by construction advanced by actions ([[wiki/entities/tolman-eichenbaum-machine.md]]).

## Position B

**Measured online from the visible referent.** Object-vector cells recorded in light and then in complete darkness in the same session lose spatial information (`P = 1.1 × 10⁻⁴`), spatial coherence (`P = 6.0 × 10⁻⁵`), peak rate (`P = 6.9 × 10⁻⁵`) and mean rate (`P = 8.0 × 10⁻⁴`), while their head-direction tuning **increases** (`P = 0.005`, n = 21 cells) — the code falls back toward the one signal that survives (Høydal et al. 2019, [[wiki/concepts/vector-coding.md]]). Grid cells in the same region survive darkness on non-visual self-motion alone (Dannenberg et al. 2020, `T46`), so this is not a general failure of medial entorhinal coding under deprivation; it is specific to the code whose origin is an external landmark. The cells' instant tuning in a novel room is equally consistent with online measurement — nothing has to be integrated because nothing has to be learned.

## Where it bites

Decides whether a vector block is an **integrator** (state advanced by actions, readable anywhere, composable offline) or an **observation function** (a re-derivation from the current sensory view, valid only where the referent is perceivable). The two give different architectures for the same picture: under A, composition-by-replay is available and a block can be evaluated at unvisited states; under B, every block evaluation is an inference from present sensation, offline construction has nothing to construct with, and what looks like a reusable map is a reusable *encoder*. It also bites `G39` — if the vector is re-measured each moment, the anchoring problem never arises for this code and the "free anchor" reading is free for a trivial reason.

## Status

`LIVE` — the darkness experiment is real but does not test the distinguishing case: the object stayed present, so B has only shown that the code needs *sensory access to the referent*, not that it fails when self-motion must carry it. Three things keep A alive. (i) Degradation is graded, not abolition — fields persist at reduced quality, which is what a drifting integrator deprived of its reset cue looks like as well as what a degraded observation looks like. (ii) The rise in head-direction tuning shows the self-motion machinery is still engaged and still driving these cells. (iii) A does not require *visual* integration specifically; a block updated by self-motion and reset by the visible referent would produce exactly this result, and is the vector-code analogue of the reset discipline `T46`/`T347` document for the grid. The named experiment separates them by removing the referent while keeping the frame.
