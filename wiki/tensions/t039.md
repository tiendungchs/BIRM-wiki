# T39 — Is place-cell remapping random?

**Status:** `LEANING`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**Random — the standard reading.** Global remapping is defined as rate *and* place becoming statistically independent, i.e. complete reorganisation ([[wiki/concepts/pattern-separation-completion.md]]); classical remapping models have grid modules realign randomly, producing a fresh place-cell set whose anchoring learning starts from scratch in each environment (Whittington et al. 2018 citing Alme et al. 2014)

## Position B

**Non-random, and constrained by the grid code.** Place cells remap to positions consistent with a preserved grid representation: across two cue-different same-size environments, the grid rate at the place-field peak correlates across environments (r = 0.320, p = 0.002) and the normalised place-peak-to-grid-peak distance correlates too (r = 0.170, p = 0.028) over 115 cell pairs, with the grid–grid correlation matrix itself preserved (p < 0.001) and the model reproducing r ≈ 0.3–0.35 (Whittington et al. 2018). **Replicated in a second lab's data**: 4 mice, real and virtual 60×60 cm arenas, gridAtPlace r = 0.273, p < 0.05 over 64 conservative pairs (r = 0.544 over 148 liberal pairs), against r = 0.322 / 0.63 for the original rat dataset re-run with the same pipeline (Whittington et al. 2020, data from Chen et al. 2018). The same paper adds an independent line of support: hippocampal cells in a non-spatial task remap spatially while **preserving** their lap selectivity, which is only explicable if the structural input survives the remap

## Where it bites

Whether structural knowledge survives a map change. If A, each environment is learned afresh and there is no transfer channel through the hippocampus; if B, remapping *is* the rebinding operation and prior structure is inherited for free — which is the mechanism the wiki's whole `p = f(g, x)` story depends on. Also constrains [[wiki/entities/hidden-state-inference-remapping.md]]: allocating a new hidden state must not license an arbitrary new map

## Status

`LEANING B` — B is a direct measurement where A is an assumption inherited from models; effect sizes remain modest and module identity of the recorded cells is unknown (so only a population-level non-random claim is testable), and both datasets were analysed by the model's authors — but there are now two independent datasets, in two species, one of them with a virtual-reality arena, plus a non-spatial confirmation in a third. **One complication from the same author:** TEM-t's place cells are attention *memory neurons*, and those remap **randomly**, i.e. the transformer rewrite of the model that produced position B natively predicts position A ([[wiki/entities/tem-transformer.md]], T40)
