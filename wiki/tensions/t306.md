# T306 — Should an analogical matcher emit every consistent interpretation, or commit to one?

**Status:** `LIVE`  
**Level:** `L1`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** One task is run where retaining `k > 1` structurally consistent interpretations measurably beats committing to the single best one — or where inhibit-and-resettle recovers the same set a full enumeration would, at the enumerator's accuracy and the relaxer's cost.

## Position A

**Enumerate.** [[wiki/entities/sme.md]] constructs *all* maximal structurally consistent gmaps and ranks them afterwards, and the design is defended on three grounds. (i) Many-to-one bindings — which SPROUTER, THOTH and RELAX permit, and which Kline's baseball case appears to demand (`(male NLpitcher)` matching both `(male ALpitcher)` and `(male ALdesignatedhitter)`) — are better handled as **several one-to-one analogies retained in parallel** (an offence interpretation and a defence interpretation) than as one relaxed-consistency mapping; humans reject many-to-one in explanatory analogies (Gentner 1983, 1989). (ii) Which interpretations exist is decided by structure alone and is independent of the evidence weights, so enumeration is the only part of the algorithm that is not a tuned heuristic. (iii) Behaviourally, once both analogs are in working memory people can select *either* the relational or the surface interpretation on instruction — which SME models by picking among its gmaps and ACME cannot, since it emits one compromise ([[wiki/entities/macfac.md]]).

## Position B

**Commit.** Enumeration is exactly the step that costs: SME's merge steps 2–3 are `O(N!)` worst case, and the trigger is flat, predicate-repetitive descriptions — which is what real domain descriptions look like (SME cannot complete Kline's own baseball analogy in hours). Every scalable matcher in the wiki instead returns one winner: ACME relaxes to a fixed point, [[wiki/entities/lisa.md]] grows a single correspondence Hebbianly under a 2–3-proposition phase budget, the APNN route takes an `argmax` of a dot product at `O(n·n′)` ([[wiki/concepts/analogical-mapping.md]]). SME's own authors concede the point in §6.2.2 and propose settling the match-hypothesis graph as an excitation/inhibition network — `O(N²)`, no gmap ever enumerated — with alternatives recovered on demand by inhibiting the winner and re-settling.

## Where it bites

Decides whether a mapping stage returns a set or a point, and therefore what the *downstream* stage is allowed to be. Under A, candidate-inference generation, the acceptance test and any task-set selection all operate on a menu — which is what makes analogy re-interpretable without recomputation, and it is the only account the wiki has of choosing between a surface and a relational reading of the *same* pair. Under B, mapping returns one commitment and every alternative must be re-derived, so re-interpretation costs a second pass and a wrong first commitment is invisible ([[wiki/concepts/analogical-mapping.md]]'s Limits: "`argmax` commits; there is no mechanism for the same element to map several ways"). The reconciliation is stated but untested — nobody has shown that inhibit-and-resettle recovers the gmap *set*, and it is not obvious it can, since relaxation has no notion of maximality and the merge-3 step that enforces it is precisely the one SME offers to drop.
