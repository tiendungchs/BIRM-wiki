# T363 — Does maximising control capacity land an agent on the states a task would have designated?

**Status:** `LIVE`  
**Level:** `L0`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** One environment family with an externally specified goal set is run under empowerment-greedy control with the sensor resolution, actuator resolution, horizon `n`, action-power constraint `P` and time step `Δt` **fixed in advance and identically across the family** (not tuned per scenario), reporting the fraction of designated goal states reached and the rank correlation between `𝔈(s)` and the task's own value `V*(s)`. Position A predicts a high hit rate and a positive rank correlation under one parameter setting; Position B predicts the hit rate is a function of the parameter setting and that some settings invert the ranking.

## Position A

**Capacity is a usable proxy for task value.** Greedy ascent on the state-dependent empowerment map drives a simple pendulum to the upright position — including multi-phase swing-ups from far initial states — and an acrobat and a bicycle likewise, with *no* value function learned over the phase space and transition dynamics estimated only along the path taken (Jung, Polani & Stone 2011, via Salge et al. 2013, [[wiki/concepts/empowerment.md]]). In the discrete cases the high-empowerment states are the ones a human observer would nominate: the centre of a maze (`𝔈` anticorrelated with average distance to all other states), the neighbourhood of a manipulable object, the closeness-central node of a box-pushing or scale-free transition graph. The claim is that "the states generally chosen as goals have high state-dependent empowerment" — a task-independent scalar recovering task-relevant targets across unrelated domains.

## Position B

**The coincidence is a property of the parameter setting, not of the quantity.** The same review states the contraindication: *if an externally desired goal state is not highly empowered, an empowerment maximiser will not seek it*, and how to integrate an explicit goal is "fully open". Three measured degeneracies make the agreement in Position A contingent rather than structural:

- **Flattening.** When the action repertoire and the sensor repertoire are mismatched, `𝔈` saturates at the smaller variable's max entropy for *every* state. 100-step empowerment in a 10×10 maze is `log 100` everywhere; an agent that senses its own action history is maximally empowered everywhere ("Tragedy of the Greek Gods"). At those settings there is no gradient and no behaviour at all.
- **Inversion.** Varying the action-power constraint `P` can reverse the empowerment *order* of two states in the same continuous system. Varying `Δt` produces swing-up, steady oscillation, or resting at the bottom from the same controller.
- **Non-monotone ascent.** Empowerment is not a value function: greedy ascent optimises no cumulated quantity, and the pendulum's own greedy trajectory passes *through* lower-empowered regions. In the maze, where any state is holdable by doing nothing, greedy ascent instead halts at the first local maximum. The authors state that no characterisation exists of which dynamics make local ascent approximate global optimisation.

## Where it bites

This is the row that decides whether `R5`'s drive-beyond-the-terminal-reward can be a capacity quantity at all. If Position A holds, an agent that has collected its reward has a principled default objective available — climb `𝔈`, model-free, goal-free, using dynamics it already has — and the wiki gains its first state value that needs neither reward nor goal. If Position B holds, empowerment is a quantity with three free parameters (resolution, horizon, power) whose *setting* encodes the task, which relocates the designer's goal specification rather than removing it, and the "task-independent" claim is doing no work.

The stakes extend past motivation. The same degeneracies bound empowerment's other two proposed jobs: the node score that tracks graph centrality ([[wiki/concepts/latent-graph-discovery.md]]) and the state-abstraction criterion `K_opt = argmin_K H(K)` subject to `𝔈(K) = 𝔈(R)` ([[wiki/concepts/node-definition-problem.md]]). Both are read off the same map, so a map that flattens or inverts with `P` and `n` yields a centrality estimate and a partition that do the same.

## Status

`LIVE` — both positions are stated in the same review, and neither is tested against the other because every published run tunes its parameters per scenario. The cheapest discriminating experiment is the fixed-parameter sweep in `Closes when`; the cheapest *negative* check is already available and unrun — recompute the maze and box-pushing empowerment maps at three horizons and report whether the `𝔈`↔closeness-centrality correlation survives the horizon that flattens the map. Adjacent rows: `G30` (no objective in the wiki is sensitive to path-consistency — empowerment is a candidate that fails on a new axis, coordinate-sensitivity), `G72` (nothing infers what counts as success — Position A would be a partial answer that needs no success criterion at all), `T358` (the sign disagreement about what an unfamiliar state is worth before it is sampled).
