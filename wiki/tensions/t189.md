# T189 — Should a model be selected for how confidently it answers, or for how well it answers?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Confidence-based stopping is separated from sufficiency: a model that omits the doubt-creating node is shown to be detectable by a signal `U` does not contain.

## Position A

**Confidence, and it is the only signal available.** [[wiki/entities/autotom.md]] grows an agent model by `U(M,q) = −H(P(q|X^{ts:t})) − α|M|`, stopping when the query posterior drops below one bit — no label is consulted anywhere, which is what lets the search run at inference time on an unseen question. It works: 82.43 average over five theory-of-mind benchmarks, and the ablations show the criterion is doing the work rather than the scaffold (a fixed POMDP loses 9.8 points, the initial proposal alone loses 4.9, all-timesteps loses 4.5 while doubling the tokens). The paper's own worked example is the mechanism running correctly — adding a goal node moves a 0.5/0.5 belief posterior to 0.1/0.9 *on the correct hypothesis*

## Position B

**Confidence is what an insufficient model maximises.** Nothing in `U` distinguishes "the model now explains the evidence" from "the model no longer represents the thing that would create doubt": omitting the belief node in a false-belief story yields a sharp and wrong posterior, and the authors name exactly this as their failure mode ("model adjustments may sometimes fail to recognize the relevance of certain mental variables, resulting in an insufficient model"). The wiki's other confidence-as-objective is [[wiki/concepts/precision-weighting.md]] / [[wiki/concepts/expected-free-energy.md]], where an entropy term is defended only because it sits *beside* a likelihood term that ties the model to observations — `U` has no such term. And the confidence being minimised is an entropy over LLM-invented conditionals that are never calibrated, so the quantity is a report of the backend's certainty, not of the model's

## Where it bites

Every unsupervised structure-selection criterion: this is the wiki's only candidate that can run per-query at inference time (G26, G29), and if it is only a confidence maximiser then structure discovery without labels has no objective at all. The discriminating experiment is cheap and unrun: plot final model utility against correctness on the ~17% of questions AutoToM gets wrong, and sweep `α` and `U_min`, neither of which has a reported sensitivity analysis

## Status

`LIVE` — A is 100% of the reported evidence and B is the authors' own stated limitation; nobody has separated them
