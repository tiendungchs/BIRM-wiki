# T319 — Is an area's integration timescale a fixed property of that area, or a run-time property of the network and its current input?

**Status:** `BOTH`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The same cortical areas are recorded under two different sensory drives in the same animals and their autocorrelation time constants are compared. A shows the ordering and the values are stimulus-invariant; B shows an area's time constant changes substantially with which modality is driven. The threshold below (perturbation amplitude) is the discriminating variable and must be swept, not fixed.

## Position A

**Intrinsic — timescale is a per-area constant, readable off structure.** Murray et al. 2014 order seven macaque areas by the time constant of spontaneous single-neuron fluctuations and find the ordering predicted by Felleman–Van Essen hierarchical position. [[wiki/concepts/broadcast-hierarchy.md]] derives the same ordering from anatomy that does not change with input: hypomyelination, low neurite density, convergent input and broad receptive fields at the apex. Every timescale bank in the wiki assumes this form — [[wiki/entities/ms-ssm.md]]'s stratified eigenvalue blocks, [[wiki/entities/s4.md]]'s `Δ`, [[wiki/entities/ltc.md]]'s per-unit rate — a decay constant attached to a unit, not to a state.

## Position B

**Emergent — timescale is a network state and moves with the input.** Chaudhuri et al. 2015 run the *same* macaque network under visual (V1) and somatosensory (area 2) drive and get two different dynamical hierarchies; undriven visual areas express the slow distributed state rather than their own fast one. Hierarchical position predicts the emergent time constant only at `r² = 0.25 / 0.14 / 0.22` (visual / somatosensory / rest). Area 8m is low in the hierarchy and slow because it sits in the prefrontal core; TEpd is high and fast because it does not. Scrambling long-range **weights** while preserving topology and the local gradient strongly attenuates the separation ([[wiki/concepts/timescale-hierarchy.md]]).

## Where it bites

Any architecture that provisions memory horizon per module. If A, a depth scalar or a per-unit `τ` is a sufficient parameterisation and `G67`/`G78` are about choosing numbers. If B, the same module must express different horizons depending on what is currently driving the network, and a fixed bank is the wrong object — what needs allocating is a *coupling* structure whose spectrum is input-conditioned. It also bites the diagnostic side: probing a trained model's timescales with one input distribution measures something that does not transfer.

## Status

`BOTH`, and the source that raises the conflict also names the threshold: **perturbation amplitude**. In the nonlinear (Wong–Wang) version of the model, timescales of *small* fluctuations around baseline reflect the isolated area's intrinsic properties — removing all long-range projections reproduces exactly the hierarchy-ordered intrinsic values — while responses to *large* or sustained input express time constants of the whole system, which are slower and input-dependent. Murray et al. measure spontaneous fluctuations, i.e. the small-amplitude regime, so A's evidence is not in contradiction with B's; it is A's evidence sampled below the threshold. The row stays live rather than resolved because the threshold has never been swept in an experiment: no study varies drive amplitude on fixed areas and shows the time constant crossing from the intrinsic value to the network value.
