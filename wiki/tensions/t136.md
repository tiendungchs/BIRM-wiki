# T136 — Does a hierarchical learner deliver a subgoal-specific reward of its own?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A reward-like signal at subgoal attainment is looked for in a hierarchically structured task — the discriminating measurement the source names and nobody has made.

## Position A

**Yes — pseudo-reward.** The options framework and MAXQ give each subtask its own reward function, delivered on reaching that subtask's subgoal, and it is what shapes the option-specific policy when external reward is silent; the framework therefore predicts a reward-like response to *subgoal attainment* in structures responsive to exogenous reward, and phasic dopamine at subtask boundaries scaled by the option-level prediction error (Botvinick, Niv & Barto 2009, [[wiki/concepts/temporal-abstraction-options.md]]).

## Position B

**No.** The HAM framework shapes subtask policies with ordinary exogenous reward plus fixed structural constraints on the machine, and has no pseudo-reward at all; MAXQ additionally decomposes the value function into components rather than keeping one `V_o` per option, so the prediction errors computed in a given domain differ between frameworks.

## Where it bites

It decides whether a machine hierarchical learner needs an *internal reward generator* per subgoal — with all of the specification burden that carries (who sets the subgoal, what its pseudo-reward is worth relative to the real one, what stops the agent from farming it) — or whether structure alone suffices. It also decides whether the flagship neural test is a test of HRL at all: a null result at subgoals refutes options/MAXQ and leaves HAM untouched.

## Status

`LIVE` — no experiment has yet looked for a reward-like signal at subgoal attainment in a hierarchically structured task, and the source names this as the discriminating measurement.
