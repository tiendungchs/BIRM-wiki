# T31 — Is the entorhinal integrator perfect or leaky?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Retrospective and trajectory coding in entorhinal cortex are reproduced from a perfect integrator, or shown to require leak — no wiki source currently does the former.

## Position A

**Perfect.** Path-integration models of the place code integrate velocity without loss and add dedicated error-correction machinery; a code is only a *position* if every route with the same total displacement lands in the same place, and periodicity is what makes it error-correcting ([[wiki/concepts/path-integration.md]], Whittington et al. 2022)

## Position B

**Leaky.** `ρ_i < 1`: entorhinal activity is a weighted sum over *recent* movements, not a position. Both extremes fail the data — `ρ = 1` (pure place) and `ρ = 0` (pure head direction) cannot produce the retrospective and trajectory coding actually observed in entorhinal cortex, and leak makes accumulated error stationary rather than unbounded, deleting the need for error correction (Howard et al. 2005; Frank et al. 2000)

## Where it bites

Decides whether a latent accumulator in a model should be norm-preserving with a correction channel, or discounted with a bounded horizon — and whether history-dependence (splitter-like coding) is a bug to be removed or the same knob doing useful work. Note the two may not be rivals: grid cells were not yet characterised in 2005, so the leaky account may describe a different entorhinal population than the modular grid code

## Status

`LIVE` — the modern grid literature assumes A, but no source in the wiki reproduces retrospective coding from a perfect integrator
