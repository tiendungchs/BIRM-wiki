# T369 — Under a state change, is the anti-reward channel an error against a prediction, or a valence read-out with a state-set origin?

**Status:** `LIVE`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** One preparation records identified lateral-habenula (or downstream dopamine) responses to reward **and** to reward omission while the reward's subjective value is lowered by two different routes — a stressor, and plain satiety/devaluation with no stressor — with the value drop matched behaviourally (licking bout duration or equivalent) across the two. A is right if the two routes produce the *same* pair of response changes, since both are then one constant added to the channel. B is right if satiety shrinks the omission response (as `actual − expected` requires) and only the stressor enlarges it, which makes the enlargement a second, stress-specific modification rather than a property of the value change.

## Position A

**One additive offset on the channel; the code is unchanged.** Shabel et al. 2019 ([[wiki/entities/lateral-habenula.md]]) image the same habenular neurons before and during acute tail-shock stress: the reward response inverts in sign (decrease → increase) and the omission response grows, both moved in the punishment direction by what is arithmetically one constant, `a'(outcome) = a(outcome) + c`. Nonselective cells are unchanged, the motor read-out (inter-lick interval) is unchanged, and the neural and behavioural time courses coincide. On this reading nothing about what the channel computes has changed — a slow controller has moved the **origin** against which outcomes are scored, which is the operator of [[wiki/concepts/affective-opponency.md]] and position B of `T362`.

## Position B

**Two modifications: a genuine value reduction plus a pathologically amplified omission term.** The authors' own alternative. The animal's reward value really does fall — licking duration halves, bout duration halves — which by `δ = r + γV(s′) − V(s)` should *shrink* the omission response, since less is being missed. The observed enlargement must then come from somewhere else: a separate stress-driven gain on the aversive/omission pathway, on top of the value change. On this reading the channel is still an error signal, and stress has written to two places — the value estimate and a second term — rather than to one origin.

## Where it bites

**Whether a recorded teaching signal can be read at all without knowing the state.** Under A, any `δ` recorded in one state is `δ + c(state)`; the constant is invisible to a downstream reader that sees only non-negative rates, and gets absorbed into whatever `V` an experimenter fits ([[wiki/concepts/reward-prediction-error.md]]). Under B the recorded signal is still an error, and the anomaly is confined to a pathological regime — the formula survives, with a second knob bolted on.

The two designs differ in what a builder must implement. A needs **one extra scalar per channel**, a state-written origin outside the fast learning loop, and it comes with a known failure mode: raise `c` far enough and every trial type returns bad news, so the channel's output stops depending on the outcome — an agent that keeps sensing and acting and stops pursuing, with nothing relearned. B needs a state-dependent **gain on the negative half specifically**, which is a different wire and predicts the reward and omission responses can be moved independently — A says they cannot, because they move together by construction.

It is also where `T361` and `T362` meet. `T361` asks what kinds of bad news this channel covers; this row asks whether, once the coverage is fixed, the quantity is referenced to a prediction or to a movable zero. `T362` asks the same question of the operator applied to *cached value*; this row asks it of the operator applied to the **teaching signal itself**, where the two are not interchangeable: an offset on a cached value re-ranks options, an offset on the teaching signal biases every future update.

## Status

`LIVE` — one study, four mice, 34–42 neurons, one stressor, two outcome types; no wiki source runs the non-stress value reduction that would separate the readings, and it is a cheap experiment in the same preparation. A also inherits an instrument caveat: calcium imaging is a slow non-linear proxy for firing, so "the same constant added to both responses" is an inference over two `ΔG/T` measurements and not over rates. `G116` bites in the usual way — licking is a consummatory action, so a hedonic reading of the bout-duration drop is not separated from an action reading.
