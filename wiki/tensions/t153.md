# T153 — Is a straight latent trajectory a good representation or a partial collapse?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Straightness is manipulated at fixed objective and planning performance re-measured, across more than one environment — the current link is a correlation with no intervention.

## Position A

**A good representation, and a target.** The temporal-straightening hypothesis (Hénaff et al.) holds that perceptual systems render temporally complex input as approximately straight paths precisely so that prediction becomes linear extrapolation; straightness measured on pretrained features discriminates real from generated video, and straighter latents have been reported to help planning. On this reading `S_straight = mean cos(v_t, v_{t+1})` is a property to regularise toward ([[wiki/concepts/population-geometry.md]]).

## Position B

**A collapse of the axis nobody constrained.** In LeWM the anti-collapse term acts on the *per-timestep marginal* only, straightness rises monotonically over training with nothing asking for it, and the model that has an explicit temporal-smoothness regulariser ends up **less** straight. The authors name their own result *temporal collapse* — the encoder is free to make successive embeddings near-collinear because no term prices it (Maes et al. 2026, [[wiki/entities/lewm.md]]).

## Where it bites

Whether the next JEPA-family objective should add a temporal regulariser or delete one. The limit settles the direction if not the set-point: a perfectly straight trajectory is one-dimensional and carries no information about the branching of futures, so the useful value is an interior optimum and nobody has located it or shown the effect is causal.

## Status

`LIVE` — no intervention run; the straightness/performance link is a correlation over one environment
