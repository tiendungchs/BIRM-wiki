# T415 — Which hippocampal recurrent field holds the item attractor: CA3, with the dentate as separator, or the dentate, with CA3 as a heteroassociative sequence stepper?

**Status:** `LIVE`  
**Level:** `L1`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** In the same animals: (i) the plasticity window is measured at the dentate's granule → mossy cell → granule recurrent synapses (B predicts NMDAR deactivation < 30 ms, shorter than one gamma cycle), and (ii) the CA3 → dentate backprojection or the mossy-cell loop is silenced selectively, with **multi-step** sequence fidelity (theta-sequence or replay length) and **single-step** completion from a partial cue both scored. B predicts that fidelity falls with step count while one-step completion survives. A predicts no sequence-specific loss.

## Position A

**CA3 is the autoassociator; the dentate is a competitive separator** (Rolls 2013; Kesner & Rolls 2015, [[wiki/entities/rolls-treves-hippocampal-model.md]]).

| Evidence | Source |
|---|---|
| CA3 output closer to the stored map than its *measured* dentate input, to a 135° cue conflict | Neunuebel & Knierim 2014, [[wiki/concepts/pattern-separation-completion.md]] |
| CA3 NMDAR knockout impairs completion from a partial cue | Nakazawa et al. 2002 |
| Slice: LTP from two sites, then either site alone evokes the full pattern | Jackson 2013, via Rolls 2013 |
| CA3's STDP kernel is **symmetric**, which writes associations in both directions, not forward links | Mishra et al. 2016, [[wiki/concepts/offline-replay.md]] |
| Dorsal dentate lesion: deficit graded with target–foil proximity, i.e. a separation deficit | Kesner & Rolls 2015 |

## Position B

**The dentate is the autoassociator; CA3 is a heteroassociator that links successive items** (Lisman 1999, `raw/lisman-1999-relating-hippocampal-circuitry-to-function.md`, theory, [[wiki/entities/hippocampal-formation.md]]).

| Argument | Content |
|---|---|
| CA3 plasticity window | CA3 NMDARs deactivate slowly (> 100 ms), so LTP survives a 100 ms gap between release and depolarization. Place cells A then B within 100 ms gives A → B and not B → A (Blum & Abbott 1996; Jensen & Lisman 1996) |
| Error concatenation | A pure heteroassociative chain degrades `A → B′ → C″`. A second, autoassociative weight set must restore `B′ → B` between steps (Sompolinsky & Kanter 1986; Kleinfeld 1986). Lisman puts it in a second network: CA3 sends `B′` to the dentate, the dentate returns `B`, CA3 steps to `C` |
| Timing | CA3 → dentate < 3 ms (Wu et al. 1998), dentate → CA3 < 5 ms (Yeckel & Berger 1990), so the round trip fits one ~25 ms gamma cycle, one step per cycle |
| Phase precession in the dentate | Seen there as well as in CA3 (cited to Skaggs & McNaughton 1996). B explains it as CA3's sequence fed back |
| The CA3 → dentate backprojection | Otherwise had no proposed function in 1999 |

Partial later support for B's CA3 half: feature coactivation in CA3 produces no attractor dynamics unless the path integrator assigned the environments different coordinates, and the authors propose that CA3's collaterals generate **phase sequences** instead (Colgin et al. 2010, `T389`).

## Where it bites

How a sequence-generating fast store is decomposed.

| | Under A | Under B |
|---|---|---|
| Blocks | One recurrent block holds items, with a separator in front | Two recurrent blocks in a loop: a stepper (hetero) and a clean-up (auto) |
| What the separator is | A front end that decorrelates | The clean-up attractor. Separation and clean-up sit in one block |
| What the CA3 → dentate wire carries | A control signal: how well CA3 completed sets how hard the dentate separates (`G38`, [[wiki/concepts/pattern-separation-completion.md]]) | Content: the degraded predicted successor |
| Reverse replay from the same weights | Allowed (symmetric kernel) | Forbidden. B → C is written, C → B is not, so reverse traversal needs other machinery (`T80`) |
| Machine form | One population with symmetric hold and asymmetric push terms (`MixedNet`, [[wiki/entities/dense-sequence-memory.md]]) | The two terms in two modules, gated separately |

## Status

`LIVE`. B is a theory paper with no direct test, and its dentate half has no measurement. The mossy-cell loop's computation is unmeasured (van Strien et al. 2009, [[wiki/concepts/pattern-separation-completion.md]]). A's evidence is later and partly direct: input-measured CA3 completion, and a symmetric CA3 kernel that removes B's mechanism for the forward bias. The two positions are not exclusive. CA3 could carry both a symmetric item component and an asymmetric transition component, which is `MixedNet` in one population. B would then reduce to a narrower claim, that the clean-up between steps is done in the dentate. No study has silenced the backprojection and scored sequence length.
