# T112 — Does removing a control signal reduce downstream selection, or eliminate it?

**Status:** `LEANING`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

Biased competition: the controller adds excitatory bias to systems already running their own competition, so removing it should leave a degraded but non-zero downstream signal (Miller et al. 2002; [[wiki/concepts/cognitive-control.md]])

## Position B

Muscimol inactivation of ventral prearcuate cortex drives feature selection in the frontal eye field to **chance** (AUROC 0.633 → 0.508, post-effect `P` = 0.53) while spatial selection in the same 42 cells is unchanged (0.717 → 0.698, `P` = 0.21) — elimination, not attenuation (Bichot et al. 2015; [[wiki/concepts/priority-map.md]])

## Where it bites

Whether a control module is an additive prior over a competent substrate or the sole computer of a signal the substrate cannot produce — the two predict different lesion profiles and different failure modes for an ablated component

## Status

`LEANING B, with a reconciliation` — the biased area has **0%** object selectivity of its own, so there is no local competition over features for a bias to tilt; bias-not-routing may hold wherever the target area duplicates the represented variable and fail wherever it does not, which makes "does the downstream area independently represent the biased dimension?" the discriminating test. **Test run (Bichot et al. 2019):** the same inactivation, recorded in **V4** — an area that *is* colour- and shape-selective — still eliminates feature selection before the first saccade in both monkeys and after it in one, with a reduced-but-surviving effect in the other (`t` = 3.4, `P` = 0.001) and the loss independent of each unit's own colour/shape tuning, while spatial selection in the same cells is intact. The predicted residual is one third the control effect, in one animal, in one window, and is not separable from incomplete muscimol coverage — so **B holds even where the substrate duplicates the variable**, and additive bias survives only as a small correction term
