# T262 — During an externally directed task, does the default mode network decouple from task-positive systems or integrate with them?

**Status:** `BOTH`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Task demand is varied systematically along the axis both sources name — conflict monitoring versus item maintenance — testing whether the coupling sign follows the recruited system.

## Position A

**Integrate.** Over rest → relaxed task → speeded task → rest, the stable default core's coupling to insula/inferior frontal cortex, anterior cingulate and middle cingulate rises from `0.05 ± 0.028` (several pairs negative) to `0.30`/`0.34` and returns to `0.03`; the *size* of that increase is the only connectivity change predicting accuracy (`r = 0.49`/`0.59`), and comparable increases are reported for movie watching, working memory, recollection and autobiographical planning (Gao et al. 2013, [[wiki/entities/default-mode-network.md]])

**Within-subject primary for the autobiographical-planning case** (Spreng et al. 2010, [[wiki/entities/lateral-frontoparietal-network.md]], `n = 20`). Content source is manipulated with display, goal state and step-ordering demand held fixed. The default network is up for autobiographical planning (`t = 6.49` vs counting) and down for Tower-of-London planning (`t = −3.57`). Default↔control coupling is `z' = 1.10` in the first and `0.06` in the second, and control↔dorsal attention is `0.91` and `−0.23`. So the default network **integrates** with the control network when the task's content is internal, and the coupling partner follows the task within subjects

## Position B

**Decouple.** The anticorrelation literature has the default and dorsal attention systems moving in opposite directions, with individuals showing the strongest intrinsic default coupling showing the most attenuated sensory-evoked responses (Buckner et al. 2008); and in a working-memory task, default↔working-memory-region connections become increasingly *negative* with load, with stronger negativity predicting **better** performance (Sala-Llonch et al., cited in Gao et al. 2013) — the opposite sign of the same brain–behaviour relation

## Where it bites

Whether an architecture's mode variable is a **gate** (turn the internal module's influence off while the external task runs) or a **router** (reassign which modules the internal one talks to). The first is one scalar; the second needs a per-partner coupling vector and a rule for which partner the current task requires. It also decides whether the internal system contributes to external task performance at all, or merely gets out of the way

## Status

`BOTH, task-conditioned` — the candidate reconciliation is in the sources themselves: which outside system is recruited depends on what the task demands (conflict monitoring and self-paced control here → salience/cingulate; item maintenance in the working-memory studies → suppression of exactly the regions competing for the same store). Task type has now been manipulated within subjects once, on a different axis from the one in `Closes when`: internal vs external **content source**, not conflict monitoring vs item maintenance (Spreng et al. 2010). The coupling partner followed the task, which supports the **router** reading in *Where it bites*. But the sign went from positive to ≈ 0, never to negative, and the recruited partner is the frontoparietal control network rather than the salience/cingulate set Gao et al. 2013 measured. So neither Position B's negative regime nor the closing axis is tested. Coupling there is the correlation of trial-averaged time courses, which shared response timing alone produces. Both sides are small-`N` fMRI coupling estimates, and the global-signal-regression caveat that forces negative correlations applies to the decoupling side. **A second reconciliation, by subsystem rather than by task** (Dixon et al. 2018, [[wiki/entities/lateral-frontoparietal-network.md]], no GSR). During externally directed control tasks (rule use, Stroop, 2-back), the default network stays positively coupled to the control network's FPCN_A half, at reduced strength. It is zero or negative with FPCN_B and dorsal attention. So both positions can hold in one task, on different parts of the "task-positive" set, and a network-level coupling sign depends on how the parcellation weights the two halves. This does not touch `Closes when`: no conflict-monitoring vs item-maintenance manipulation is made, and the coupling is whole-run correlation
