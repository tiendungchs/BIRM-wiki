# T262 — During an externally directed task, does the default mode network decouple from task-positive systems or integrate with them?

**Status:** `BOTH`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Task demand is varied systematically along the axis both sources name — conflict monitoring versus item maintenance — testing whether the coupling sign follows the recruited system.

## Position A

**Integrate.** Over rest → relaxed task → speeded task → rest, the stable default core's coupling to insula/inferior frontal cortex, anterior cingulate and middle cingulate rises from `0.05 ± 0.028` (several pairs negative) to `0.30`/`0.34` and returns to `0.03`; the *size* of that increase is the only connectivity change predicting accuracy (`r = 0.49`/`0.59`), and comparable increases are reported for movie watching, working memory, recollection and autobiographical planning (Gao et al. 2013, [[wiki/entities/default-mode-network.md]])

## Position B

**Decouple.** The anticorrelation literature has the default and dorsal attention systems moving in opposite directions, with individuals showing the strongest intrinsic default coupling showing the most attenuated sensory-evoked responses (Buckner et al. 2008); and in a working-memory task, default↔working-memory-region connections become increasingly *negative* with load, with stronger negativity predicting **better** performance (Sala-Llonch et al., cited in Gao et al. 2013) — the opposite sign of the same brain–behaviour relation

## Where it bites

Whether an architecture's mode variable is a **gate** (turn the internal module's influence off while the external task runs) or a **router** (reassign which modules the internal one talks to). The first is one scalar; the second needs a per-partner coupling vector and a rule for which partner the current task requires. It also decides whether the internal system contributes to external task performance at all, or merely gets out of the way

## Status

`BOTH, task-conditioned` — the candidate reconciliation is in the sources themselves: which outside system is recruited depends on what the task demands (conflict monitoring and self-paced control here → salience/cingulate; item maintenance in the working-memory studies → suppression of exactly the regions competing for the same store). Nobody has manipulated task type within subjects and measured the sign. Both sides are small-`N` fMRI coupling estimates, and the global-signal-regression caveat that forces negative correlations applies to the decoupling side
