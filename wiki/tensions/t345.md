# T345 — Is movement-correlated activity in a sensory area a valid proxy for the prediction term?

**Status:** `LIVE`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Spec:** `D257` ([[_brainstorm/birm-spec.md]] §11)  
**Closes when:** The motor-related activity that survives in visual cortex under complete darkness or retinal lesion is shown either to scale with a *predictable* sensory consequence (validating the proxy) or to be independent of one (invalidating it), with the predictable-consequence variable manipulated rather than removed.

## Position A

**Yes — and it is the only proxy available.** The experimenter controls the input `x` but not the prediction `P`, so under any trial-averaged or anaesthetised protocol the predictive and representational accounts of a response are algebraically identical. Self-generated movement is the one variable an experimenter can set that the animal has learned to couple to sensory feedback, which makes movement-conditioned responses the whole empirical base for predictive processing in cortex ([[wiki/concepts/prediction-error-neurons.md]]). The proxy is validated by its own gradations: A24b/M2 axon activity is largest when a *static* image preceded running onset, smaller when flow was already moving, smaller still in darkness — i.e. it tracks the predicted **change**, not the movement ([[wiki/entities/a24b-m2-v1-projection.md]])

## Position B

**No — it is contaminated, and by an unmeasured amount.** Motor-related activity in mouse V1 layer 2/3 persists under complete darkness and **even after complete retinal lesion**, and A24b/M2 axon activity in darkness is reduced but not zero. With no visual input there is nothing to represent and nothing predictable to predict, so this residual is neither a representation nor a prediction; Leinweber et al. concede it "cannot, strictly speaking, be explained in either the representation framework or the predictive processing framework" and offer only that darkness may be an unevolved-for singularity. Whatever the residual is — arousal, locomotor state, a generic efference copy — it rides the same cells and the same projection that carry the putative prediction, and no experiment has partitioned the two

## Where it bites

Every movement-conditioned result in the wiki's predictive-processing stack is read as `response = V(x) − P`, with the movement standing in for `P`. If a movement-locked, sensation-independent component exists on the same cells, then mismatch amplitudes, running-onset amplitudes, the reversal under inverted visuomotor coupling and the inactivation effect sizes are all sums of two terms with one measured. For a builder the consequence is concrete: a top-down channel implemented as `f(action, current state)` and one implemented as `f(action) + g(action, current state)` fit the same data, and only the second predicts a residual when the sensory channel is removed — so the paradigm cannot currently say whether the prediction path must be gated on the presence of something to predict

## Status

`LIVE` — the residual is a reported, replicated observation (darkness, and retinal lesion) with no account on either framework, and the graded-amplitude argument in Position A establishes only that *part* of the signal tracks the predicted change, not that all of it does. No experiment removes the predictable consequence while holding movement and arousal fixed
