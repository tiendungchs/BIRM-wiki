# T334 — Is an unobserved relational path written at encoding, or composed at retrieval?

**Status:** `LIVE`
**Level:** `L2`
**Registry:** [[wiki/empirical-tensions.md]]
**Closes when:** A single study measures reinstatement of the absent element at encoding *and* manipulates retrieval-time composition demand (e.g. varies path length between test and premise trials) in the same subjects, so that write-time integration and query-time composition make opposite predictions rather than the same one.

## Position A

**Written at encoding.** Zeithamova et al. 2012 read out the *unseen* third element of an `A–B–C` triad by classifier during re-presentation of `A–B`: null on the first repetition (before any `B–C` exposure), significant on the second and third, with the across-subject reactivation index predicting later `A–C` accuracy (r = 0.46). Critically, ventromedial prefrontal encoding activation predicts inference **after partialling out premise memory** (r = 0.38 → partial r = 0.53), which is the control the on-the-fly account needs to survive and does not. The composite is built during learning, for a query that has not been asked ([[wiki/concepts/retrieval-mediated-learning.md]])

## Position B

**Composed at retrieval.** Premise memory and inference accuracy correlate at **r = 0.76** in the same dataset — most of the variance in inferring is variance in having learned the two edges, and stronger direct associations alone yield better test-time composition with nothing integrated. Independently, the temporal context model derives ordering across non-co-occurring items purely from *retrieved-context overlap at test*, with no composite ever stored, and reads rodent transitive inference as this associative gradient rather than as inference ([[wiki/entities/temporal-context-model.md]]); TEM answers first-presentation transitive inference from a structural code with no write-time integration of the queried pair at all ([[wiki/entities/tolman-eichenbaum-machine.md]]). **And B now has a mechanism written for exactly this dispute, by the theory A is an amendment to**: REMERGE recirculates an exemplar-style similarity computation over pattern-separated traces — output combined with the external input, fed back, iterated to an attractor — so the `A–C` link is a property of the settled state and the store keeps its separated code. It predicts a dissociation A does not: **weak traces supporting poor item recognition can mediate near-normal generalization** (Kumaran & McClelland 2012, via Kumaran et al. 2016; [[wiki/entities/remerge.md]])

## Where it bites

Where a multi-hop capability is paid for, and therefore what the reader must contain. Under A the store returns the answer to a one-step lookup and no composition operator is needed; under B the store holds only observed edges and the reader needs a traversal operator running inside the query's latency budget, with error compounding per hop. This is the architectural choice behind every retrieval-augmented model's multi-hop failure, and it decides whether [[wiki/concepts/latent-graph-discovery.md]]'s path queries are a write-time or a read-time cost. It also sets what an ablation means: ablating the composition operator is free under A and fatal under B

## Status

`LIVE` — **and the source that proposes B's mechanism says the distinction is not even absolute.** Kumaran et al. 2016 state that no experiment separates encoding-based from retrieval-based models, that both plausibly run as a function of paradigm, training amount and training–test delay, and — the part that changes this row — that **generalized replay converts one into the other**: simultaneous offline reactivation of several related traces can write the settled state back as a new trace, so a retrieval-based mechanism manufactures over time the composite an encoding-based account assumes. Under that reading the two positions are one loop sampled at different points, and the row's real question becomes *how long after learning* the composite exists, which is a delay manipulation nobody has run. Two constraints survive the merge. **On B**: the reactivation curve in A's dataset is measured with *no query pending*, so a pure settling account owes an explanation of why the absent element is reinstated during plain re-presentation. **On A**: an ablation of the composition operator is free only if the composite is written for *every* overlapping pair, which is combinatorially hopeless.

**And the honest reading is that both run, with the open question being the selector, not the winner.** Write-time integration over every pair of overlapping episodes is combinatorially hopeless, so it cannot be the whole story; query-time composition over an unbounded graph is the observed multi-hop failure, so it cannot be either. Position A's own data contains Position B's strongest evidence (the r = 0.76), and the partial correlation removes it for vmPFC but *not* for bilateral hippocampus (r = 0.51 → partial r = 0.22, n.s.). The candidate selector the wiki can state and nobody has tested: integration is triggered where the fast store completes anyway, so pattern completion — not a policy — decides which paths get precomputed ([[wiki/concepts/pattern-separation-completion.md]]). The discriminating experiment is cheap in a machine: probe for the absent third item's content across repetitions of the first pair, where a query-time composer returns the first-repetition null at every repetition and a write-time integrator returns the rising curve
