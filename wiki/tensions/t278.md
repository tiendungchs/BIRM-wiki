# T278 — Is a single feedforward pass sufficient for object recognition, or is inter-areal feedback part of the computation?

**Status:** `BOTH`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The (clutter × occlusion × ambiguity × duration) boundary is measured, since A's null covers only foveal uncluttered unoccluded input under 200 ms.

## Position A

**Sufficient, for core recognition.** Image-selective activity is present across inferior temporal cortex by ~100 ms, one area's added latency is ~10 ms, and human evoked-potential signatures of identification appear by 150 ms — a budget a ten-stage cascade fills once with no room to spare. The first ~50 ms of the inferior-temporal response is already both selective and the *most* reliable epoch, and a linear read of a few hundred units from it supports near-ceiling identification generalizing over position, scale and context — in **passively viewing** animals, on **untrained** objects. Task, attention and plasticity effects on inferior temporal responses are small next to image-driven variance. The stated claim is a null hypothesis and it is narrow: sub-10 ms *local* recurrence (normalization) is inside it, feedback on the *learning* timescale is inside it, and rivalry, clutter/search and cross-fixation working memory are explicitly excluded (DiCarlo, Zoccolan & Rust 2012, [[wiki/entities/ventral-visual-stream.md]])

## Position B

**Part of the computation.** The hierarchy plus its feedback is an inference machine — high levels see the forest and instruct low levels how to process weak or occluded evidence, which is what makes recognition from degraded input possible at all (Lee & Mumford 2003; Friston 2010; [[wiki/concepts/predictive-coding-free-energy.md]]). The measurement one stage earlier is uncomfortable for the null: ~60–80% of a layer-4 V1 cell's response variance is contributed by other V1 neurons or by non-geniculate input, so the tissue carrying the 'feedforward wave' is a recurrent network whose feedforward drive is a minority shareholder (Olshausen & Field 2005, [[wiki/entities/early-visual-system.md]]). The wiki's later ingests add routes the null does not cost: transthalamic cortico-cortical relay carrying state ([[wiki/concepts/transthalamic-context-routing.md]]) and a content-free prefrontal state that gates what reaches report ([[wiki/concepts/cortical-state-bistability.md]])

## Where it bites

Whether a feedforward stack is a *sufficient* perceptual front end for a reasoning architecture or only its uncluttered-input special case — and therefore whether the recurrence every wiki architecture wants is needed for perception or only for what follows it. Also prices [[wiki/concepts/manifold-untangling.md]]: the local, feedforward, unsupervised untangling proposal is only a complete account of the stream under A

## Status

`BOTH`, with the threshold named by A's own authors and *not yet measured*: the null covers foveal, uncluttered, unoccluded, uncued input at < 200 ms and nothing else, so the dispute is over where in the (clutter × occlusion × ambiguity × duration) space the feedforward pass stops sufficing. The demand that separates the positions is procedural — name the tasks for which reentrance is claimed necessary *before* silencing feedback — and it is now runnable with the tools 2012 lacked
