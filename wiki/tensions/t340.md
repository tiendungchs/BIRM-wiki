# T340 — Does the episodic store return its output to the stream that wrote it, or to the other one?

**Status:** `LIVE`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Hippocampal output routing is measured under stream-typed input — pathway-specific recording or terminal imaging of CA1/subiculum → lateral vs medial entorhinal projections following an odour (lateral-typed) versus a spatial (medial-typed) drive. Position A predicts return traffic tracks the input stream; Position B predicts it lands on the medial division either way.

## Position A

**Reciprocal.** The entorhinal ↔ CA1/subiculum topology is strictly reciprocal and topographically preserved in every mammal studied — posteromedial entorhinal ↔ proximal CA1 / distal subiculum, anterolateral entorhinal ↔ distal CA1 / proximal subiculum — and layer Vb, which receives the hippocampal return, sits under the same transverse band as the layer II/III cells that wrote to it (Witter et al. 2017, [[wiki/entities/entorhinal-cortex.md]]). Every architecture in the wiki assumes this: [[wiki/entities/tolman-eichenbaum-machine.md]]'s `g`/`x` loop, [[wiki/entities/vector-hash.md]]'s grid↔hippocampal projection pair, and every complementary-learning-systems variant treat the store's interface as one bidirectional port. **And the topology now holds at cell-class resolution on the store's own output stage** (Kinman, Kraus & Cembrowski 2026, [[wiki/entities/subiculum.md]]): mouse subicular excitatory subtypes are typed by transcriptome, position and projection target together, and the proximal class (*Nnat*, *Chrna7*, *Nptx1*, *Robo1*) both receives lateral-entorhinal afferents and projects to lateral entorhinal cortex, while the distal class (*Nts*, *Cdh7*, *Elf1*, *Scn4b*) does the same with the medial division — so the reciprocity is a property of identified cells rather than of overlapping bulk tracer fields, which was the obvious deflationary reading of the earlier topography. **The primary underneath that review closes the loop in one preparation with numbers** (Cembrowski et al. 2018, [[wiki/entities/subiculum.md]]): anterograde trans-synaptic labelling puts lateral-entorhinal input on proximal subicular cells (91%, 296/327) and medial-entorhinal input on distal ones (99%, 81/82), while retrograde tracing from the same two divisions in the same animals recovers the same border for the return (lateral-projecting cells 96.5% proximal, medial-projecting 74.3% distal) — input side and output side measured against one reference injection, with a ~200 µm transition zone and ~1% interleaving. Two caveats the row should carry. The medial-entorhinal figure (74.3%) is the weakest of the seven projection classes tested, and one class — the interanteromedial thalamic projection — ignores the border entirely (41.9%), so the partition is near-total rather than total. And *individual* cells collateralise: 18.8% double-labelling within a region and 11 fully reconstructed axons mostly reaching several extrahippocampal targets, so the reciprocal wire to one entorhinal division is carried by cells that are simultaneously writing to accumbens or retrosplenial cortex.

## Position B

**Stream-crossing.** The only two studies that put input and output in one experiment find the return on the *other* division. In freely behaving cats, EEG separates the two: lateral entorhinal cortex is coupled to the olfactory domain, medial entorhinal cortex to the hippocampus (Boeijinga & Lopes da Silva). In the isolated *ex vivo* guinea-pig brain, olfactory stimulation produces sequential activation **lateral entorhinal → hippocampus → medial entorhinal → lateral entorhinal** — an input that entered through the lateral division comes back through the medial one. Witter et al. 2017 state the reciprocity prediction "is not supported by data" and call output-pathway specificity an underexplored challenge.

## Where it bites

Decides whether a machine store's **write port and read port are the same interface**. Under A the encoder that formats a query for the store is also the decoder that receives its return, and the store is a content-addressable memory in the ordinary sense. Under B they are different modules, and the store's output is delivered into the *structural* stream's coordinate system regardless of which stream wrote it — which collapses two claims the wiki currently keeps apart: "the hippocampus indexes cortical content" and "the hippocampus hands back a position". It also decides where a comparator can sit: a layer receiving both a copy of the write and the store's return ([[wiki/entities/entorhinal-cortex.md]]) only exists under A.

## Status

`LIVE` — and lopsided in evidence *type* rather than in weight. Position A is anatomy (tracer topology, replicated across rodent, monkey and human) with no functional test; Position B is function (one cat EEG study, one *ex vivo* preparation, both old, neither pathway-specific, the second in a preparation with no behaviour and no intact subcortical input). The cell-class results above strengthen A's *anatomy* without touching its evidence type — they still measure wires, not traffic, and the primary's one causal manipulation silences a class rather than a pathway, so it cannot see which direction the traffic runs — and it adds one thing the row should hold: if the return really crosses streams, it must cross **within** the subiculum, since the cells that project to each entorhinal division are not the cells that receive from the other. They are not strictly contradictory: an anatomically reciprocal projection can be functionally dominated by a non-reciprocal route, so the row may resolve as "reciprocal wiring, asymmetric traffic" — but that reading is itself an architectural claim (the same wire carrying different loads in the two directions, `G54`) and nothing has tested it.
