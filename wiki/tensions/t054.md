# T54 — What does a hippocampal representation do when the environment is metrically distorted?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**It rescales.** The metric reading of the map: fields stretch or compress with the environment, as grid fields distort when walls move and place fields track distance to boundaries ([[wiki/concepts/cognitive-map.md]] element 2)

## Position B

**It snaps to a discrete state.** Lengthening the grey zones of the 2ACDC track produces no uniform stretching: on near trials the pre-near-reward tuning *persists* through the extension, on far trials cells *jump* to the pre-far-reward state as if anticipating the later reward, and both reset on the first disambiguating cue (Sun et al. 2025)

## Where it bites

Decides whether the machine analogue is a continuous chart with a scale parameter or a state machine with an observation-triggered reset — and therefore whether interpolation between states is meaningful at all

## Status

`LIVE` — the two are measured in different paradigms (open-field boundary manipulation vs. a 1-D virtual corridor with a strong task-state structure), so the honest reading is that the map's format depends on whether the task defines discrete states, which is itself the untested claim ([[wiki/empirical-tensions.md]] T27)
