# T29 — Does de-aliasing conflict with generalisation?

**Status:** `LEANING`  
**Level:** `L0`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A clone model is shown to miss the co-recorded place cells — the claim is currently asserted rather than demonstrated — or to reproduce them, which would remove the need for a separate structural code.

## Position A

**No — one mechanism suffices.** Latent states inferred from sequences explain the non-spatial hippocampal zoo (splitter, lap, evidence cells) as a single principle: separate states with different futures. A clone model learns them from raw sequences with no structural prior ([[wiki/entities/cscg.md]])

## Position B

**Yes — they need separate machinery.** The same clone model would learn the splitter cells and *not* the co-recorded place cells, because it cannot profit from generalising the structure of space; every level of abstraction has to be represented simultaneously, which requires a reusable structural code alongside the de-aliaser ([[wiki/entities/tolman-eichenbaum-machine.md]], Whittington et al. 2022)

## Where it bites

Whether a reasoning model needs one latent-state learner or two coupled ones; the same trade-off as G40 seen from the representation side rather than the task side

## Status

`LEANING` toward B — the simulations showing both cell classes emerging together are TEM's, and the CSCG-would-miss-place-cells claim is asserted, not demonstrated. **A supports the coexistence half but not the transfer half.** In mouse CA1, place-like (correlated) and splitter (orthogonalized) responses coexist in one population *and* fall on a continuum with cells migrating between them, and the clone model reproduces the split — because the positions that stay correlated (track start and end) are exactly those where no latent distinction exists, not because it generalises the structure of space. In the same animals, a learned state machine *is* reused for a new cue pair at 147 vs 483 trials, which is transfer the clone model cannot express (Sun et al. 2025)
