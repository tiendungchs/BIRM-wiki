# T190 — Is cross-example consistency a symbolic intersection, or a vote over hypothesis labels?

**Status:** `LEANING`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The composition operator is actually invoked and deterministic intersection run against detection-count voting on the same tasks — currently only the vote is deployed.

## Position A

**Intersection.** `Π* = ⋂_i Π_i`, where a program is retained for example `i` only if `render(π(S(I_i))) = O_i` — deterministic, generator-independent, and the explicit reason the source gives for preferring its architecture to LLM solvers that "approximate consistency via stochastic voting rather than enforcing deterministic symbolic agreement" ([[wiki/entities/corethink-compositional-reasoner.md]], stated method; the same criterion is run for real by [[wiki/entities/ilp-arc-synthesizer.md]], whose clauses do execute)

## Position B

**A vote.** The same source's deployed pipeline never executes a program: pattern detection is repeated 5× per example at temperature 0, patterns are ranked by **detection count**, the top-3 are forwarded to the solver as a natural-language hint, and the composition operator `∘` is defined and never invoked. The authors concede it — "operationally, we approximate it by repeating structured pattern detection, retaining recurrent Unit Patterns … and forwarding only the resulting consensus hints"

## Where it bites

Decides which rung of [[wiki/concepts/external-verification.md]]'s ladder the wiki's best ARC-AGI-2 result actually stands on, and therefore what its +6.9-point hint ablation is evidence *for*: symbolic execution, or a strong structural prior delivered as text. It also decides whether the system is an instance of [[wiki/concepts/program-induction.md]] at all

## Status

`LEANING B` — B is the source's own account of what runs, and A appears only as the "idealized consistency objective". Note the ablation survives either reading, and under B it becomes a *sharper* result: voting over hypotheses beats voting over answers by 2.2× at additive rather than multiplicative cost, which is a claim about where to spend a vote, not about symbols
