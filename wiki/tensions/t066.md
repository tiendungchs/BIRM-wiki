# T66 — Does layer 6 supply a modulator signal, or the location code that decides what a column represents?

**Status:** `LIVE`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** L6 output is shown to be driver-grade by a manipulation that changes what a column represents rather than its gain. *(The first disjunct — "the assignment is given anatomy of its own" — was met at the Hawkins et al. 2019 ingest and removed.)*

## Position A

**Modulator.** Douglas & Martin 2004: L6 is the canonical source of *modulator*-type excitation — thin axons, small en-passant boutons — which changes a target's response quantitatively without altering the structure of its receptive field, and its main projections (L6 → L4, L6 → thalamus) are read as gain control on the incoming evidence stream ([[wiki/concepts/canonical-cortical-microcircuit.md]])

## Position B

**The location code.** The Thousand Brains Theory assigns L6 a grid-cell-like population path-integrating an efference copy from L5, whose output — broadcast via thalamus to L2/3 and L1 — is one of the *two* terms binding into an object representation. A feature at the wrong location is a different object, so this signal sets *what* the column represents, which is driver-grade content in the layer the anatomy types as modulatory ([[wiki/entities/thousand-brains-theory.md]]).

**The primary now argues the assignment from published anatomy rather than asserting it** (Hawkins et al. 2019): feedforward thalamic input is <10% of the synapses on L4 cells while ~45% come from L6a cortico-cortical neurons; L4 projects back onto those same L6 cells; the L6↔L4 arbor is narrow in spread, matching the topographically aligned bidirectional MEC↔hippocampus wiring the assignment is modelled on; and motor projections terminate significantly in L6, which is what a path integrator needs. The prediction is explicitly that cortical grid cells are L6a specifically — none of the S1/V2 grid recordings were layer-restricted, so the prediction is live and untested

## Where it bites

Decides whether a machine column's location input is a gain term (multiplicative gating on an evidence stream) or a first-class content input (half of a conjunctive code) — and, if the priming reading is right, dissolves the conflict: a signal can be structure-determining *and* sub-threshold, since it selects which units may fire without firing them

## Status

`LIVE` — the argument-from-anatomy now exists on both sides, and they use the *same* facts: the L6→L4 projection is numerically dominant and reciprocal (position B's evidence) and morphologically modulator-type, thin-axon and small-boutoned (position A's). Douglas & Martin's driver/modulator typing was itself imported from thalamic work with its inter-areal function stated as unexplored, so the row now hangs entirely on a causal manipulation nobody has run: silence L6a and ask whether the column's *identity* assignment changes or only its gain
