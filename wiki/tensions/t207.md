# T207 — Can a benchmark be simultaneously difficulty-calibrated and contamination-proof?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**No — calibration is the leak.** ARC-AGI-2's goal 6 requires public, semi-private and private subsets to be drawn from demonstrably similar distributions (mean human accuracy matched to ≤1pp) so scores transfer across them. The 2025 report then states that a reasoning system trained on substantial public-domain data can "overfit" a private set precisely *because* it is i.i.d. with the public one, asserts this is now happening to ARC-AGI-1 and -2, and evidences it with Gemini 3 Deep Think emitting correct ARC colour names in a harness that never mentions ARC

## Position B

**Yes — the private set still works, and the contamination is unquantified.** The same report cannot say whether the effect is accidental or deliberate, cannot measure its magnitude, and maintains that the format "provided a valuable scientific indicator". The empirical counter is the score structure itself: if distributional familiarity were doing the work, the 2024 ARChitects system would not have dropped from 56% to 2.5% on the re-authored set

## Where it bites

Whether a private evaluation set is a durable instrument or a depreciating one, which decides how the wiki reads *every* held-out score, and whether G17's developer-blindness criterion needs a distributional clause on top of its item-level one. Note the two positions are compatible if contamination raises a floor without touching the ceiling — nobody has measured either

## Status

`LIVE`. The report's answer is not a fix but a policy: continual benchmark adaptation ([[wiki/concepts/refinement-loop.md]]), i.e. re-author faster than the field can absorb the distribution. The decisive experiment is cheap: score a frontier model on private eval tasks *stratified by similarity to the public training set* under any fixed embedding, and check whether score tracks similarity
