# T144 — Does a world model's prediction quality tell you how good a world model it is?

**Status:** `LIVE`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A prediction metric is shown to order world models the same way downstream control does, on a model set where the task-critical object contributes little to reconstruction error. Same object as `G62`.

## Position A

**Yes — that is what training it means.** Every objective in the wave is a prediction loss (reconstruction ELBO for RSSM/Dreamer, embedding distance for JEPA, video fidelity for the neural-simulator branch), and [[wiki/concepts/prediction-compression-equivalence.md]] makes the stronger claim that log-loss *is* a measure of structure found, so lower prediction error means more of the environment captured.

## Position B

**No, not for control.** Conventional metrics like mean-squared error on future predictions "may not correlate with the performance of downstream tasks"; a model generating visually sharper predictions "might not necessarily enable a safer or more efficient control policy" (Long et al. 2025). The pixel-loss weighting is the mechanism: a small task-critical object contributes almost nothing to reconstruction error and vanishes from the latent (Dreaming), so the metric is anti-correlated with utility in exactly the cases that decide the task. **A second, exactly quantified mechanism now exists.** For an action-conditioned (LeJEPA-style) predictor under invertible observations and linear–Gaussian latent dynamics, a model with on-policy excess risk `δ` can have counterfactual error `δ / ρ_tr(π)`, where `ρ_tr` is the weakest conditional action excitation of the behaviour policy — attainably, and diverging as that policy becomes deterministic. At `ρ_tr = 0` two models with *identical* on-policy risk disagree about what alternative actions do. So prediction quality and control utility are not merely uncorrelated; the gap between them has a closed form, and the term that governs it is not in the model (Zhang et al. 2026). **A third mechanism, and it is not about representation at all.** Under an identical cross-entropy-method planner, energy function and GPU, an embedding-space model evaluates 800 candidate actions in 16 s while a 7B latent-diffusion video model evaluates 80 in 4 min, and the video model — the one whose training target *is* perceptual fidelity — scores 0% on both pick-and-place tasks against 80% and 50% (Assran et al. 2025, [[wiki/entities/v-jepa-2.md]]). Prediction quality and control utility can come apart simply because a search's quality is a function of how many candidates the model lets it afford. **And the family's origin paper already had the extreme case, which rules out the obvious repair.** Replace the prediction metric with the *return the controller realises inside the model* — the most control-relevant score available, since it is the optimised objective — and it does not merely fail to order models, it **anti-correlates**: across the MDN-RNN's sampling temperature, in-model return falls 2086 → 918 while real-environment return rises 193 → 1092, with the best in-model agent scoring below a random policy in the world (Ha & Schmidhuber 2018, [[wiki/entities/world-models-vmc.md]]). The mechanism is that model error is a *reward channel* for whatever optimises against it, so any score computed with the model in the loop is contaminated in proportion to how hard it was optimised.

## Where it bites

Model selection across this whole wave. If prediction error does not order models by planning utility, the RSSM-vs-JEPA comparison is not decidable on the numbers either lineage reports, and G62 has to close before any of it means anything.
