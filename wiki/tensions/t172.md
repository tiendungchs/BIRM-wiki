# T172 — Is an action-grounded vocabulary necessarily agent-relative?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A shared cross-embodiment interface reports which distinctions it *cannot* make for a member body — conceded by B's own literature and never measured.

## Position A

**Yes, by construction.** [[wiki/concepts/affordance-grounded-symbols.md]] defines a symbol as an equivalence class under *this* agent's repertoire — `b(x₁) = b(x₂) ⟺ ∀a ∈ A: effect(x₁,a) ≈ effect(x₂,a)` — so the same stone is one symbol to an agent that can lift it and another to one that cannot, and a distinction no action in `A` makes can never be represented. The *Umwelt* claim in a training objective

## Position B

**No, in practice.** One interface fitted above **22 robot types** and reported to beat single-embodiment training on each (Open X-Embodiment, 1.4M episodes); one shared discrete codebook above manipulators, bimanual arms, navigation and quadrupeds with only per-body decoders (UniAct, CrossFormer); optical flow and point tracks used as embodiment-agnostic intermediates; and latent action alphabets extracted from *human* video and used to pretrain robot policies (LAPA → GR00T N1) — all as reported in Kawaharazuka et al. 2025, [[wiki/concepts/cross-embodiment-transfer.md]]

## Where it bites

Whether the wiki's answers to G4 and G27 must be re-derived per body or pretrained once across many. If B, an agent's vocabulary is not bounded by its own repertoire and human data is directly usable; if A, every cross-embodiment interface is exporting only the perception-and-intent level and the field is measuring data scale, not body invariance

## Status

`LIVE` — and B's own literature concedes the weak form: a body-specific decoder survives in every design, no method uniformly handles manipulators, mobile bases and legs, and nothing reports which distinctions a shared interface *cannot* make for a member body
