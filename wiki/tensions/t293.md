# T293 — Does role-filler independence require the compound to preserve its constituents, or does an invertible conjunctive code with a scheduled unbinding step suffice?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**It requires preservation.** Penn, Holyoak & Povinelli 2008: "the ability to maintain role-filler independence while dynamically binding roles and fillers to particular relations seems to require the kind of concatenative compositionality posited by the PSS hypothesis" (citing Doumas & Hummel 2005; Hummel & Holyoak 2003). On this reading a compressed conjunctive code is the *long-term store* half of LISA's two-system architecture — the half the synchrony graft was needed on top of — and [[wiki/concepts/vector-symbolic-binding.md]] therefore sits at the representational level the source assigns to honeybees and scrub-jays. The evidence offered is indirect: no animal shows role-governed categories or domain-independent inferential systematicity, and the one architecture that shows them uses phase

## Position B

**An invertible code suffices.** Circular convolution has an exact-enough inverse (`a† ⊛ (a ⊛ b) ≈ b`), so both constituents *are* recoverable — the question is whether recovery-by-computation differs functionally from recovery-by-comparison. Nothing in the comparative record tests the difference, because no animal was ever given an unbinding operator. And the cost of the alternative is on the record: LISA's simultaneous addressability caps at 2–3 propositions and makes every similarity operation in the wiki's memory machinery inapplicable to the code ([[wiki/entities/lisa.md]])

## Where it bites

Decides whether `G104` is a missing *mechanism* or a missing *controller*. If preservation is required, every vector-symbolic architecture in the wiki is below the line and the fix is a new binding carrier. If scheduled unbinding suffices, the missing piece is a policy over `†` — what to unbind, when, and against which cleanup memory — which is a far cheaper thing to build and connects to [[wiki/concepts/memory-read-and-erase.md]]'s read-scheduling framing rather than to the code at all. The discriminating experiment is stated and unrun: take one task requiring a relation to be reasoned about independently of its current filler, and run it against (i) a phase code, (ii) an HRR with no unbinding, (iii) an HRR with a learned unbinding schedule Carried by [[wiki/concepts/relational-reinterpretation.md]], [[wiki/concepts/vector-symbolic-binding.md]] and [[wiki/entities/lisa.md]]
