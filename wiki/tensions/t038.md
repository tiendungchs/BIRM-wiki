# T38 — Do grid cells emerge from training on path integration?

**Status:** `LEANING`  
**Level:** `L3`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The task-versus-target question is settled by a sweep in which grids emerge under a readout that is not Difference-of-Softmaxes, or unsupervised next-observation prediction is shown to produce them without a hand-chosen readout.

## Position A

**Yes.** A series of deep-learning models report that recurrent networks trained to path-integrate develop hexagonal grid units, with the 4-fold→6-fold transition attributed to a non-negativity constraint on firing rates — read in the wiki as the trainable route to a periodic `g` ([[wiki/concepts/path-integration.md]], Whittington et al. 2022 reviewing Cueva & Wei 2018, Banino et al. 2018, Sorscher et al. 2019)

## Position B

**No — the target, not the task, makes them.** >11,000 networks: most path-integrate optimally, almost none show grid units under the lenient one-unit-above-0.8 criterion. Grids require Difference-of-Softmaxes readouts (Cartesian, polar, Gaussian and equi-norm DoG all fail; 1/1086 DoG runs matched DoS, and not across seeds); period is set monotonically by readout width `σ_E`; distributions are unimodal so no modules form and adjacent ratios are ≈1 not ≈1.4; and grids vanish under place-cell-like multi-field multi-scale readouts with position decoding unharmed. Analytically, gradient descent on the readout loss is attractor dynamics whose kernel is the readout *correlation matrix*, so a centre–surround target hand-builds the Turing instability (Schaeffer et al. 2022)

## Where it bites

The wiki's warrant for treating `g` as *learnable* rather than *installed*. If B, every trained-network citation for a periodic structural code is a demonstration that the code can be baked into a target, and the biological case rests on recordings plus first-principles attractor theory alone. It also decides whether the wiki's empty objective slot (G30) can be filled by emergence experiments at all ([[wiki/concepts/objective-identifiability.md]])

## Status

`LEANING B` — B is a direct large-scale replication-and-sweep of A's own code, and A's authors' undocumented DoS-for-DoG substitution is verified in the released code. What A retains: nobody disputes that *some* configuration produces grids, only that the task explains it. **A regains one leg:** Whittington et al. 2018 obtain grid, band, border and object-vector units from *unsupervised* next-observation prediction on graph worlds with a one-hot categorical target and no spatial readout at all — a target whose correlation matrix cannot be a centre–surround kernel, so B's mechanism does not apply. Unaudited on every other checklist item ([[wiki/entities/tolman-eichenbaum-machine.md]]). **And one more leg, with the audit partly run:** the spiking rewrite of that same model gets 59.6% ± 18.0 grid units from a one-hot categorical target across four seeds and publishes the ablation table — but its grids are 4-fold, single-scale and phase-uniform, so the population never forms the toroidal manifold, which is exactly the relational invariant B says target-driven models miss ([[wiki/entities/spiking-tem.md]])

**A third position is now on the wiki and it is neither A nor B: installed.** Peng et al. 2025 ([[wiki/entities/gcq.md]]) build a working world model on grid-like codes that are *defined before training* — the `N²` bump states of a toroidal continuous attractor network, with plain reconstruction as the only objective — and cite toroidal medial-entorhinal population activity present *before sensory experience* plus Gardner et al. 2022's toroidal topology as the biological version: the brain holds preconfigured bump patterns and learning is the assignment of sensory experience to them, not their formation. It is consistent with B (the code is not what the task selects) while denying B's implication that the code is therefore an artefact of a modeller's target. And it contributes the one direct test available: let the same model tune its installed codewords by gradient and it *moves away from them and scores worse* (T150).
