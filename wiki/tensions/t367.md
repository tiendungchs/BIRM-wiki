# T367 — Is the subgoal-level prediction error carried on its own channel, or on the reward channel with the running option as a mask?

**Status:** `LIVE`  
**Level:** `L2`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** One measurement separates the two errors *within* a structure that carries both. Either (a) cell-type-identified recording in a task with the delivery task's ellipse geometry, reporting whether the cells responding to a subgoal-distance change are the same cells that respond to a goal-distance change; or (b) an intervention that abolishes one error and spares the other (a manipulation of the option representation should, under position B, make the subgoal error leak into goal-level value — measurable behaviourally as choice becoming sensitive to subgoal distance, which it is not in the intact case, `p` = 0.43). Position A predicts disjoint or separably addressed populations; position B predicts one population whose *target* is switched by what the controller is currently maintaining.

## Position A

**Two channels.** The credit-assignment argument requires it: if a pseudo-reward prediction error rides the same broadcast scalar as the reward prediction error, the root value function is updated by an error about a state the environment never paid for, and the agent pays itself — the framework's own stated problem (Botvinick, Niv & Barto 2009, restated as an open computational problem by Ribas-Fernandes et al. 2011, [[wiki/concepts/pseudo-reward-prediction-error.md]]). A second channel is not extravagant in this wiki: the dopaminergic projection is already argued to carry at least three topographically separated signals with different sources and targets ([[wiki/concepts/broadcast-channel-decomposition.md]]), and the aversive side already resolves into an "address by axon" arrangement in which two afferent nuclei select near-disjoint dopamine populations ([[wiki/entities/ventral-tegmental-area.md]]). Under A, the option level owns a signalling pathway the goal level does not touch.

## Position B

**One channel, masked by the option identifier.** The measured anatomy gives no hint of separation: the subgoal-distance error appears in dorsal anterior cingulate cortex, habenula, amygdala and nucleus accumbens — the *same* four structures the reward prediction error is assigned to, with no reported difference in locus, only in what the regressor was built from (Ribas-Fernandes et al. 2011). The cheap architecture that fits this is one undifferentiated scalar plus a routing variable held elsewhere: the identity of the running option is maintained in a gated prefrontal stripe and determines which value table the scalar updates, which is [[wiki/entities/pbwm.md]]'s `δ_j = snr_j · δ` with the mask supplied by the hierarchy rather than by the sender. Guided activation already assigns exactly this identifier/policy split to the actor side ([[wiki/concepts/temporal-abstraction-options.md]]), so B reuses a variable the architecture needs anyway.

## A constructive third option: no second error at all

**[[wiki/entities/option-critic.md]]** (Bacon, Harb & Precup 2017) builds the single-channel pole without needing the mask. Both the intra-option policy gradient (`∂log π_{ω,θ}(a|s)/∂θ · Q_U(s,ω,a)`) and the termination gradient (`−∂β_{ω,ϑ}(s′)/∂ϑ · A_Ω(s′,ω)`) are derivatives of the *ordinary discounted return*, so the architecture contains exactly one reward, `r(s,a)`, and exactly one error. The option level is distinguished from the goal level by **which value function is indexed** — `ω` is an argument to the critic, not a gate on a second broadcast — so the routing question this row poses has no referent inside it, and the `r̃` : `r` ratio has none either.

This does not settle the row, which is about the brain. It does three things for it:

| | Consequence for this row |
|---|---|
| Position B gets an existence proof that it is *sufficient* | An option hierarchy that learns intra-option policies, termination conditions and the policy over options end-to-end, to deep-network scale, needs no second error pathway — so A's normative "the credit-assignment argument requires it" is refuted as a *requirement*, though not as a description of the brain |
| Position B's mask is shown to be optional | Option-critic does not mask a scalar with an identifier; it indexes a value function by `ω`. These are different implementations of B, and the measurement in `Closes when` cannot distinguish them — a third sub-position for whoever runs it |
| The price is named | Option-critic cannot express an option pursued for its own sake, or a level whose objective the root does not share; the intermediate target has no value detached from the current return, which is exactly the property that makes a conditioned reinforcer survive devaluation ([[wiki/concepts/conditioned-reinforcement.md]]). So the single-channel arrangement forfeits *want construction*, and the brain demonstrably does construct wants — an argument for A that does not depend on the credit-assignment worry |

## Where it bites

**Whether adding a level to a hierarchy costs a wire or a register.** Under A, every level a builder adds needs its own error pathway, and the pathways need relative gains set against each other — the unset `r̃` : `r` ratio becomes a per-level calibration problem. Under B, levels are free at the signalling layer and the entire cost moves into the maintenance of the option identifier: correctness then depends on that register being *exclusive and correct*, and every failure of it is a credit leak rather than a slowdown.

The two also differ in what is architecturally **denied**. A cannot express a learner that updates the option-level and goal-level values from one event without duplicating the event — which is what an option terminating *at* a rewarded state requires. B cannot express two option levels running concurrently, because one mask cannot select two tables at once; nested options would have to time-share the register, and the source's own framework permits options within options.

Evidence asymmetry runs the usual way and in the usual direction of caution. B's support is a null — no observed anatomical separation at 3 × 3 × 3 mm voxels and scalp EEG, resolutions at which two interleaved populations in one nucleus are indistinguishable in principle. A's support is a normative argument plus an analogy to a split established for a different variable (valence, not level). Neither side has a measurement that could have come out the other way.
