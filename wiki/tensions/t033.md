# T33 — Is CA1 a linear relay or a second recombination-and-completion stage?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A CA1 transfer curve is measured with the CA3 input recorded simultaneously — the discipline position A demands of everyone else, and which nobody has applied to CA1.

## Position A

**A relay.** Transfer-curve measurements put CA1 on the identity line — it neither separates nor completes — and human high-resolution fMRI agrees (Yassa & Stark 2011, [[wiki/concepts/pattern-separation-completion.md]]). **Weakened on inspection of the primary human source:** Bakker et al. 2008 gives CA1 a lure bias score of 0.59–0.83 with lure activity statistically indistinguishable from a true repeat, so it licenses only the negative half (CA1 does not separate); the identity-line claim is not in that data

## Position B

**A recombiner.** Competitive learning in CA1 reassembles the sub-parts of an episode that CA3 had to store separately, into an efficient retrieval cue for the cortical backprojection, and the CA3→CA1 pattern association generalises to the nearest CA1 pattern when CA3 completion was imperfect (Rolls 2013)

## Where it bites

Whether the fast store's read-out is a projection or a computation. Under B there is a *second* completion stage after the attractor, which changes what a machine must implement between memory and decoder, and it is also where the wiki's `C^HBP` fan-out constraint starts

## Status

`LIVE` — the two are not strictly incompatible (a stage can be linear in similarity while recombining components), and nobody has measured a CA1 transfer curve with the CA3 input recorded, which is exactly the discipline position A demands of everyone else. **There is a third position, and it is neither.** CA1's job is to hold a **sparse, invertible** mapping of the entorhinal pattern so that the cortical activity present at encoding can be regenerated from it — a learned codec. The argument is an interference argument rather than a transfer-curve one: a direct CA3→entorhinal readout would force a *dense* entorhinal population to rapidly learn each novel pattern-separated CA3 code, re-importing exactly the interference the dentate gyrus removed, and CA1's relative sparseness is what bounds it. Under this reading CA1 sits wherever invertibility requires, the measurement that discriminates it is whether the cortical pattern can be reconstructed from CA1 (not whether CA1's own codes are similar), and the live question becomes whether the code is componential enough to invert *novel* inputs ([[wiki/concepts/compositionality.md]]) — which every CLS model installs by pretraining (McClelland & Goddard 1997; O'Reilly et al. 2011)
