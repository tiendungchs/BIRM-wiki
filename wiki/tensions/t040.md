# T40 — Is a place cell a conjunctive cell or a memory index?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The hybrid is simulated and its prediction tested: a *bimodal* hippocampal population, grid-related and not, which no remapping analysis has looked for.

## Position A

**A conjunction.** In TEM a hippocampal cell is one element of the outer product `p = g̃ ⊙ x̃` — it fires only when its structural and its sensory input are both active. This predicts non-random remapping (T39), explains multiple fields as multiple consistent regions, explains lap cells retaining lap preference while remapping spatially, and is the form the recorded grid–place correlations support (Whittington et al. 2018, 2020)

## Position B

**An index.** In TEM-t a hippocampal cell is a *memory neuron* of the Krotov & Hopfield (2020) attention split, active when the current structural query matches a stored address; sparsity comes from the softmax, and it is one neuron per stored memory rather than one per `g`×`x` pair. This yields place fields and random remapping, and it scales to conjunctions across three or more cortical areas at additive cost (Whittington, Warren & Behrens 2022)

## Where it bites

Decides what the fast store's units *are*, and therefore what remapping data measure. It is also a scaling decision with opposite signs: the conjunctive form pays `×n_c` neurons per extra bound region and buys the non-random-remapping prediction; the index form pays `+n_c` and loses it. The wiki's `p = f(g, x)` shorthand is silent on which — it names the factorisation, not the binding implementation

## Status

`LIVE` — the source proposing B concedes A's data and offers a hybrid: hippocampal *feature* neurons `g̃ = gW_g` inherit the grid relationship, so a population-level grid–place correlation survives alongside randomly remapping memory neurons. Not simulated, and it predicts a *bimodal* hippocampal population (grid-related and not), which the remapping analyses have never tested for · see also T42, where the same product is reported to *abolish* the entorhinal code in a spiking reimplementation
