# T10 — Is an innate prior architecturally necessary, or just knowledge delivered early?

**Status:** `LIVE`  
**Level:** `L1`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A bounded learner is shown to absorb an installed prior from a first observation at a cost that matches having it built in, or the `O(1)`-interpreter assumption is shown to be exactly what a bounded learner cannot supply.

## Position A

**Necessary.** Core knowledge is a bank of domain-specific, entry-gated systems that guide learning top-down from the start; without them the learner has no `g`-side prior at all and the intended graph is unidentifiable ([[wiki/concepts/core-knowledge.md]], gap G16)

## Position B

**Not necessary.** For an ideal inductor, knowledge `z` presented as the *first observation* replaces `K(µ)` by `K(µ|z)` in the convergence bounds; as long as the code interpreting `z` is `O(1)`, the agent absorbs it within a few cycles — so "the boundary between implementation and training is unsharp", and innateness is a claim about *timing*, not architecture (Hutter 2000)

## Where it bites

Decides whether priors must be built into the architecture or can be supplied as data/context. If B holds at realistic scale, prompting and pretraining are substitutes for architectural priors; if A holds, they are not

## Status

`LIVE` — B's equivalence is asymptotic and assumes an `O(1)` interpreter and an agent that can already compress arbitrary input, which is precisely what a bounded learner lacks. The same source supplies A's strongest argument: if evolution encoded something `Ω`-like and incompressible into the genome, no `O(1)` program reaches human competence and the missing part is exactly the installed prior. Rathmanner & Hutter 2011 sharpen B without settling the row. Background knowledge has two delivery routes, conditioning the prior (`K(ν|y)`, suited to a partial hypothesis) and prefixing the data (`yx`, suited to past observations), and the authors call them theoretically nearly equivalent. `KL_n(µ‖M) < KL_n(µ‖ξ) + K(ξ) ln 2 + O(1)` bounds what an ideal learner loses by lacking a computable prior family `ξ`: at most `K(ξ)` bits of cumulative log-loss. That turns A's burden into a specific claim: for a bounded learner the cost of a missing prior is not `K(ξ)` but unbounded. Both results are asymptotic and assume the same `O(1)` interpreter, so the row stays `LIVE` ([[wiki/concepts/universal-induction.md]])
