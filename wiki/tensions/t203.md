# T203 — Is abstract format a hippocampal specialisation, or a shared property of the fronto-hippocampal system?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

**Hippocampal.** Courellis et al. 2024 record 2,694 human single units across six regions during an uncued serial reversal task and find the inference-linked reorganisation only in hippocampus: no other region changed shattering dimensionality, context or parity decodability, and **no other region held two variables in abstract format simultaneously** — amygdala (889 units), vmPFC (463), dACC (310) and preSMA (269) all recorded and all negative. VTC's context CCGP actually *decreased*. Under this reading the hippocampus is where the latent partition is constructed and prefrontal cortex consumes it

## Position B

**Shared.** Bernardi et al. 2020 run the monkey original of the same task and find context, value and action in abstract format in **all three** recorded areas — hippocampus, DLPFC and ACC — with action abstract in DLPFC and ACC but *not* in hippocampus, and CCGP for context dropping on error trials in all three. Prefrontal cortex holds a variable hippocampus does not, which is not the consumer relationship

## Where it bites

Whether a model needs one dedicated module that builds the abstract format, or whether the format is what every module in a control loop converges on when the same latent variable is worth carrying. Bears on [[wiki/concepts/complementary-learning-systems.md]]'s division of labour and on whether [[wiki/concepts/abstract-structural-codes.md]]'s `g` should be architecturally localised at all

## Status

`LIVE` — **and the two may not be in contradiction, because of an epoch confound the wiki should test before treating this as a disagreement.** Bernardi's prefrontal abstraction is measured in the 900 ms *before* stimulus onset; in the 900 ms *after*, DLPFC context CCGP falls to chance and ACC's is only weakly above it, while hippocampus keeps the format. If Courellis's analysis window is the post-stimulus one, B's prefrontal result and A's prefrontal null are the same fact at different times, and the real claim is that hippocampus is where the format is *maintained*, not where it is unique. Deciding it costs one re-analysis of an existing dataset ([[wiki/concepts/population-geometry.md]])
