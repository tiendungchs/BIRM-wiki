# T64 — Is the dendritic tree's *structure* load-bearing, or only its sparsity?

**Status:** `LIVE`  
**Level:** `L4`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Structured versus random connectivity is run at matched sparsity, matched input sampling, and *at scale* — the regime where the paper's own reported gap was narrowing and the comparison stopped.

## Position A

**Structure.** Chavlis & Poirazi 2025 report that dendritic ANNs — a tree partition (each soma reads its own disjoint dendrites) plus receptive-field-restricted sampling — beat randomly connected sparse ANNs (sANNs) of matched size on both efficiency scores across all datasets tested, and argue the point is that *nature located a good sparse architecture* in a space too vast to search, so it can be copied instead of pruned or evolved ([[wiki/entities/dendritic-ann.md]])

## Position B

**Only sparsity (plus input sampling).** The same paper's controls: when sANNs are given the *same* input-sampling rule, so the only difference is structured vs. random internal connectivity, the efficiency gap shrinks — "especially for larger models" — and dense ANNs given restricted input sampling alone already recover much of the gain. The tree may be one adequate member of a large equivalence class of sparse graphs at the right density

**A learned structure also beats random at matched density, and does not separate the two positions** (Mocanu et al. 2018, [[wiki/entities/sparse-evolutionary-training.md]]). Width and edge count are held equal. A mask rewired each epoch (drop smallest-magnitude, regrow random) beats the frozen random mask on every RBM, MLP and CNN tested: CIFAR-10 CNN 90.02% vs 88.26%. This supports A's weaker form: *some* structure beats random, and it need not be copied from biology. It is also compatible with B. The learned mask concentrates the *input* layer's edges on task-relevant pixels (MNIST centre vs border), so part of the gain is a learned input-sampling rule, which is B's variable. No internal-only comparison is reported.

**A found structure, frozen and copied, recovers almost none of the gain. The process that found it carries it** (Evci et al. 2020, [[wiki/entities/rigl.md]]). ResNet-50/ImageNet, 80% sparsity: the mask learned by gradient-directed rewiring, frozen and retrained from the original initialisation, scores 70.82 against 70.6 for a random frozen mask. Continued rewiring from a random start scores 74.55, and 76.06 at the same total compute. This cuts against A's "copy the architecture nature found" reading more than against A's weaker form. It is also not B, since a learned mask is still worth ~4 points over random, but only while it is still changing. Caveats: at this scale lottery tickets need weights rewound to an early step, which the frozen arm did not get. Input sampling is again learned along with the rest (MNIST centre-weighted input degree), so the two positions are still not separated.

## Where it bites

Decides whether "dendritic" is an architectural prior worth importing or a rebranding of sparsity. If B, the transferable rule is *restrict fan-in and pick receptive fields*, and any mask of that density will do; if A, the partition itself constrains which input variables may interact and is a prior over the latent graph's edge set ([[wiki/concepts/latent-graph-discovery.md]])

## Status

`LIVE` — the decisive experiment (structured vs. random at matched sparsity, matched sampling, *at scale*) is exactly the one whose gap the paper reports as narrowing, and it was not run beyond the small-model regime. The 2018 learned-mask result adds a matched-density win without separating input sampling from internal structure, so it does not close the row. The 2020 frozen-mask result adds a third reading, that the load-bearing thing is the rewiring process rather than either structure or sparsity. It is a single ResNet-50 run, so it adds a position without closing the row
