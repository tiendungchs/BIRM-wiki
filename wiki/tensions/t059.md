# T59 — Does a stored memory live in the synaptic weights, or in a mask over them?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Position A

The wiki's default and the premise of every capacity result it holds: content is written into the plastic matrix by a Hebbian or pseudoinverse rule, and the weights *are* the memory — [[wiki/entities/rolls-treves-hippocampal-model.md]], [[wiki/entities/sparse-distributed-memory.md]] (plastic counters), [[wiki/entities/dense-sequence-memory.md]], [[wiki/entities/vector-hash.md]] (plastic matrix over fixed addresses). Corrupting the weights destroys the memory

## Position B

Podlaski et al. 2025: apply contextual synaptic refinement to a **symmetric Gaussian random matrix containing no information about any pattern**, and arbitrary chosen patterns become stable attractors with the same overlap `m*_rand` and capacity `α*_rand` as the infinite-context Hebbian case. The weight matrix needs only zero-mean random structure; the memory is the binary mask. Consequences the authors draw: weights may be corrupted substantially with no loss, and **bounded/binary synapses suffice** ([[wiki/entities/context-modular-memory-network.md]])

## Where it bites

Decides where a builder spends precision and where forgetting happens. If content can live in a `N²`-bit mask over a frozen random substrate, then per-environment storage is bits not reals, weight noise is harmless, and the long-standing bounded-synapse objection to Hebbian capacity dissolves. If not, the result is an artefact of the mask being as expressive as the matrix it masks

## Status

`LIVE` — the demonstration is real but the mask is per-synapse and per-context, which the authors themselves price as a control network scaling `s·N`, i.e. larger than the memory it addresses; nothing shows the result survives at the coarser (dendritic-branch) gating resolution that is biologically defensible
