# T142 — Should the world model and the policy be decoupled, or learned as one entangled model?

**Status:** `LIVE`  
**Level:** `L1`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A decoupled and an entangled model are compared on re-goaling: the entangled one must pay for affordance fidelity in retraining steps when the objective changes.

## Position A

**Decoupled.** The wiki's default everywhere: learn `p(z′|z,a)` and `p(x|z)` task-agnostically, keep `π(a|z)` (or a cost) separate, and the payoff is re-goaling — the same transition structure serving any new objective at query time (gap G28). Dreamer/PlaNet-style state-space models, [[wiki/entities/h-jepa.md]]'s configurable world-model-plus-cost, and every model-based/model-free contrast on [[wiki/concepts/simulation-based-planning.md]] assume this split.

## Position B

**Entangled, and deliberately so.** The predictive-coding neurorobotics lineage (Tani and successors) trains a single joint model over sensation *and* action and generates behaviour by inference on it, reporting its robot results from that entangling rather than despite it; the affordance argument gives the reason — an action possibility is a property of the agent–environment pair, so an object's representation already contains what can be done to it, and factoring it out is throwing away the content ([[wiki/concepts/affordance-grounded-symbols.md]]). Taniguchi et al. 2023 pose the decoupling question as open.

## Where it bites

Decides whether G28 is a gap to be closed or a target to be abandoned: if entangling is what makes robot-scale learning work, immediate re-goaling is not free but has to be bought back with a separate mechanism. Also bites [[wiki/concepts/objective-identifiability.md]] — a task-agnostic representation has no task to be identified against.
