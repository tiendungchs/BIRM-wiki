# T316 — Does betweenness centrality measure routing load, or only a property of the graph?

**Status:** `BOTH`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** A node's shortest-path betweenness is compared, on the same graph, against its traffic under a decentralised model (communicability throughput, navigation path frequency, or biased-random-walk visitation at a stated `λ`), and the two rankings are reported with their correlation — settling whether "high betweenness" and "carries the traffic" name the same nodes, and at what threshold on `λ` they diverge.

## Position A

**It measures routing load, and the core is an integrative bottleneck.** Six independent graph measures — degree, strength, betweenness, closeness efficiency, k-core/s-core erosion and participation index — converge on the same bilateral posterior medial/parietal set in human cortex, which carries **>70% of all between-module edge mass** (Hagmann et al. 2008, [[wiki/concepts/connectome-hubs-and-cores.md]]). The reading is corroborated by a *non*-topological measurement: betweenness centrality predicts regional cerebral blood flow at `r² = 0.49`, so the nodes the statistic ranks highest are the ones the organism actually pays to run. The wiki builds on this reading throughout — `G84` asks for an architecture with a component whose job is to be the crossing point, and `L`/global efficiency are used as integration claims on [[wiki/concepts/small-world-topology.md]] and in `G85`.

## Position B

**It is defined only under a communication model the substrate cannot implement.** Betweenness counts the shortest paths through a node; characteristic path length and global efficiency average over shortest paths. All three therefore presuppose **shortest-path routing**, which requires every network element to know the connectivity of the entire network — an assumption Seguin, Sporns & Zalesky 2023 argue is untenable for a decentralised system ([[wiki/concepts/network-communication-models.md]]). Two consequences bite. First, the empirical comparisons go the other way: search information, path transitivity and communicability beat shortest-path length at predicting resting functional connectivity (Goñi et al. 2014) and at predicting **causal** stimulation propagation across 550 patients (Seguin et al., ref. 116). Second, only a *small proportion* of connections lie on any shortest path at all (refs. 40, 41), so a betweenness-based account of traffic assigns zero load to most of the wire — a conclusion the review treats as a reductio on `k = 1` routing.

## Where it bites

Whether a builder should place a single high-betweenness crossing point. Under **A**, `G84`'s prescription stands: identify the bottleneck, budget its capacity, price it metabolically. Under **B**, betweenness identifies a *bottleneck the graph would have if a central controller routed traffic*, and the actual load under a decentralised protocol is spread over many more edges — in which case the architectural move is not to build a crossing component but to make the *embedding* carry the routing information ([[wiki/concepts/latent-graph-discovery.md]]), and capacity should be budgeted per-edge rather than concentrated. It also decides what a diagnostic on a trained network means: shortest-path betweenness over a thresholded weight matrix would mark most learned weights as traffic-irrelevant, which magnitude-pruning curves contradict.

## Status

`BOTH` — and the review states the reconciling threshold itself, which is why this is a dispute of scope rather than of fact. Shortest-path *structure* genuinely shapes signalling, because broadcast-like models (communicability, the linear threshold model) reach shortest paths **without centralised knowledge**: the set of all walks contains the shortest path, so first arrival is via it. So A's statistic is a valid description of the graph and a valid predictor of anything that scales with topological position — including the blood-flow correlate, which is model-free and unaffected by B. What B removes is the *inference to traffic*: `L`, global efficiency and betweenness may not be read as claims about which edges carry load, only about what the graph permits. The row stays open rather than resolving because the discriminating measurement — betweenness rank against decentralised-model throughput on one graph — is cheap and, as far as either source reports, unrun.
