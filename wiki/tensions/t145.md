# T145 — Does conditioning a predictor on the action make it represent the effect of actions?

**Status:** `LIVE`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** Conditional action excitation is measured in the datasets the action-conditioned lineage trains on, and counterfactual error reported alongside on-policy prediction — B's query has been asked once without a number.

## Position A

**Yes — that is the point of the action-conditioned turn.** The whole latent-world-model lineage (V-JEPA 2-AC, LeWorldModel, Dreamer, TD-MPC) inserts the action into the latent predictor and justifies it empirically, by action sensitivity, rollout quality and downstream planning performance; a low action-conditioned prediction loss is taken as evidence that the model has captured how the world responds to what the agent does. **The strongest version of A does not rest on the loss at all.** AdaWorld extracts an action code from one video and applies it to a *different scene*, scoring the result against that scene's ground truth: FVD 767.0 against 1545.2 for the same architecture with the action condition zeroed, 70.5% human preference, and — on Procgen goal-reaching with a fixed MPC planner — 56.67% success against the action-agnostic model's 26.00%, which is the random planner's score. Transplanting a code across contexts is a test on-policy memorisation cannot pass (Gao et al. 2025, [[wiki/entities/adaworld.md]]).

## Position B

**No — action-conditioning plus low training loss demonstrates nothing.** In the one setting where it is provable, identifying the action response additionally requires positive **conditional** action excitation in the data. Measured at `σ = 0` (actions a deterministic function of state): on-policy prediction stays accurate, counterfactual error is large, and the state and action components `A` and `B` are not separately identifiable — the data constrain only the closed-loop map `A + BK`. The architecture is action-conditioned; the *learned object* is not (Zhang et al. 2026, [[wiki/concepts/learned-world-models.md]]).

## Where it bites

Every action-conditioned world model trained on data from a competent or converged policy — i.e. all of them past the early-training phase. It also decides how much of the JEPA-vs-RSSM comparison is about architectures at all: two models trained on the same low-excitation data are both estimating the same under-determined object. Limits: linear–Gaussian latent dynamics, invertible observations, synthetic 2-D experiments, unreviewed preprint. The two positions are less opposed than they look and the residue is the interesting part: A's transfer test is *cross-context*, not *counterfactual* — every code it applies was extracted from a transition that actually occurred, so it never asks the model about an action the environment never took from that state, which is precisely the query B proves is under-determined. **That query has now been run once, qualitatively.** Driving V-JEPA 2-AC with an *identical* action sequence under an open versus a closed gripper produces a cup that stays put in one case and travels with the arm in the other — an action pairing the environment did not execute, answered correctly. It is one decoded figure with no metric attached, and it is the only counterfactual probe of a large action-conditioned world model in the wiki (Assran et al. 2025, [[wiki/entities/v-jepa-2.md]]).

## Status

`LIVE`, with A ahead on everything that has been measured and B holding a query that has now been asked once, without a number
