# T46 — When landmarks and self-motion disagree, which one sets the structural code?

**Status:** `LIVE`  
**Registry:** [[wiki/empirical-tensions.md]]  
**Closes when:** The same cue/self-motion conflict is imposed on a heading code and a position code in one animal, testing whether the anchoring rule is variable-specific.

## Position A

**The landmark, by overwriting the integrator.** In the fly ellipsoid-body compass the entire population is imaged at once and the conflict is imposed directly: instantaneously displacing the visual cue makes the heading bump jump to follow it while *preserving its offset*, and varying the closed-loop gain between turning and scene rotation makes the bump track the **cue** with only slight scaling by the animal's own rotation. Self-motion runs the code only when no landmark is available (darkness), and then it drifts. The mammalian head-direction system is described the same way — distal cues rotate head-direction tuning, place fields and grid fields with them (Seelig & Jayaraman 2015; Epstein et al. 2017, [[wiki/concepts/cognitive-map.md]])

## Position B

**Physical self-motion, at least for position.** With visual and physical motion decoupled in mouse virtual reality, mEC grid cells predominantly follow *physical motion* while hippocampal place cells follow *visual input* (Chen et al. 2019), and mouse mEC grid firing survives complete darkness on non-visual self-motion alone (Dannenberg et al. 2020) — so the entorhinal integrator is not vision-dominated in the way the heading compass is ([[wiki/concepts/path-integration.md]])

## Where it bites

Decides the update discipline for any anchored structural code: a *reset* (overwrite `g` from the anchor, keep the offset) versus a *blend* (weight the two evidence streams by precision). The wiki's models do neither explicitly — TEM corrects drift by memory recall, which is closer to a blend, while the fly measurement says the correction is discrete and offset-preserving. Also bites G39 (what anchoring does once the anchor is identified) and G43 (concurrent integrators can plainly disagree about which cue stream to trust)

## Status

`LIVE` — the cleanest reconciliation is that these are different variables: heading is cheap to re-anchor and useless when wrong, so vision wins; position is anchored by boundaries rather than by any single landmark and has no equally fast reset. Untested — no experiment in the wiki imposes the same conflict on a heading code and a position code in one animal
