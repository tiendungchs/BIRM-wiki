## Wiki-internal shorthand

| Term | Meaning |
|---|---|
| **LGD** | Latent Graph Discovery — the wiki's core problem framing |
| **W / M** | Slow **W**eights (updated across episodes) / fast **M**emory (bound within an episode) — the two-timescale factorization |
| **g / x / p** | Structural code / sensory code / their conjunction `p = f(g, x)`, after TEM |
| **meta-graph / instance-graph** | Structure shared across a family of environments / the topology of one particular task |
