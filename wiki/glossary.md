# Glossary

Abbreviations used across the wiki. Per the schema, terms are expanded in place on first use *unless* they are near-universal (AI, ML, NN, DNA) or unwieldy — those live here.

## Machine learning

| Abbrev. | Expansion | Note |
|---|---|---|
| HRR | Holographic Reduced Representation | Nested relational structures encoded as fixed-width vectors: bind role to filler by circular convolution, superpose by addition, decode by an approximate inverse ([[wiki/concepts/vector-symbolic-binding.md]]) |
| VSA | Vector-Symbolic Architecture | The family of representations built from a bind/superpose/unbind algebra over high-dimensional vectors; HRR is the circular-convolution member ([[wiki/concepts/vector-symbolic-binding.md]]) |
| SSP | Spatial Semantic Pointer | An HRR extended to continuous features by *fractional* binding — `φ(x) = F⁻¹{e^{iΘx/l}}` — so binding is addition in feature space, inversion is negation, and the dot product is a kernel; particular phase matrices give grid-cell-like codes ([[wiki/concepts/vector-symbolic-binding.md]]) |
| CID | Connection Information Distribution | McClelland's scheme in which the activity of one set of units *sets the weights* between others; makes a tensor-product binding pattern and a fast weight matrix the same object read two ways ([[wiki/concepts/tensor-product-representation.md]]) |
| TPPS | Tensor Product Production System | Dolan & Smolensky's implemented production-system interpreter built on tensor-product representations — condition matching, variable binding, substitution and conflict resolution over distributed structures ([[wiki/concepts/tensor-product-representation.md]]) |
| MAP | Multiply-Add-Permute | The VSA model whose binding is the component-wise (Hadamard) product; the cheapest binder in circuits — `D` Pi neurons, no aggregation stage ([[wiki/entities/sigma-pi-reservoir.md]]) |
| MoE | Mixture-of-Experts | A layer whose parameters are partitioned into `E` expert blocks with a router sending each input to `k ≪ E` of them; the common variant of a sparse expert model ([[wiki/concepts/sparse-expert-routing.md]]) |
| FLOPs | Floating-Point Operations | The compute per example, which sparse expert models hold fixed while the parameter count grows — the decoupling the whole family exists for ([[wiki/concepts/sparse-expert-routing.md]]) |
| ECE | Expected Calibration Error | Absolute deviation between predicted probability and observed accuracy after binning examples by predicted probability; sparse expert models match the ECE of a 10× larger dense model ([[wiki/concepts/sparse-expert-routing.md]]) |
| SBC | Sparse Block Code | A VSA model whose `D`-dimensional vector is `K` blocks of size `L` with one active element per block; binding is block-wise circular convolution, and the sparsity cuts embedding synapses to `dD/L` — the model chosen for Loihi 2 ([[wiki/entities/sigma-pi-reservoir.md]]) |
| Sigma / Pi neuron | summation / multiplication unit | A Sigma neuron emits the inner product of its inputs with its weights; a Pi neuron accumulates two input channels and emits their **product**. Binding needs Pi units; a conventional network has only Sigma ([[wiki/entities/sigma-pi-reservoir.md]]) |
| SME | Structure Mapping Engine | Gentner's alignment search: mapped relations must match, arguments must map consistently, objects map one-to-one — the expensive second stage of analogical retrieval ([[wiki/entities/sme.md]], [[wiki/concepts/vector-symbolic-binding.md]]) |
| gmap | global mapping | One structurally consistent interpretation of an analogy: a maximal set of correspondences plus its candidate inferences and score. SME emits all of them ([[wiki/entities/sme.md]]) |
| MH | Match Hypothesis | SME's unit of local evidence — the conjecture that one base item corresponds to one target item; gmaps are maximal consistent sets of these ([[wiki/entities/sme.md]]) |
| SES | Structural Evaluation Score | SME's ranking of a gmap: the sum of its match hypotheses' evidence after systematicity has trickled down argument edges. Not normalised by analog size, so it cannot compare two different analogies ([[wiki/entities/sme.md]]) |
| BMS | Belief Maintenance System | The Dempster–Shafer-flavoured truth-maintenance layer SME scores with; 70–80% of its runtime and removable ([[wiki/entities/sme.md]]) |
| dgroup | description group | A collection of entities and the expressions about them — SME's unit of comparison ([[wiki/entities/sme.md]]) |
| QPT | Qualitative Process Theory | Forbus' formalism for physical processes as qualitative influences on quantities; the representation PHINEAS transfers by analogy ([[wiki/entities/sme.md]]) |
| MAC/FAC | Many Are Called / Few Are Chosen | Two-stage analogical retrieval: a cheap functor-count dot product over the whole memory, then SME on the survivors ([[wiki/entities/macfac.md]]) |
| LS / AN / SS / FA | Literal Similarity / Analogy / Surface Similarity / False Analogy | The 2×2 similarity taxonomy over shared object attributes × shared higher-order structure, used to grade any structural similarity estimator ([[wiki/concepts/vector-symbolic-binding.md]]) |
| APNN | Associative-Projective Neural Network | Rachkovskij & Kussul's vector-symbolic scheme: sparse binary "code-vectors", bound by context-dependent thinning, similarity as normalised overlap ([[wiki/concepts/analogical-mapping.md]]) |
| CDT | Context-Dependent Thinning | The APNN binding operator, `⟨Z⟩ = Z ∧ ⋁_k Π_k(Z)` over the OR of the constituents: fixed width, no inverse, and a composite that stays similar to its parts ([[wiki/concepts/analogical-mapping.md]]) |
| ACME | Analogical Constraint Mapping Engine | Holyoak & Thagard's localist mapping model: one node per candidate correspondence, relaxation of a structural/semantic/pragmatic constraint network, `O(n⁴)` ([[wiki/concepts/analogical-mapping.md]]) |
| LISA | Learning and Inference with Schemas and Analogies | Hummel & Holyoak's symbolic-connectionist analogy model: role-filler bindings carried by neural synchrony, correspondences learned as Hebbian mapping connections ([[wiki/entities/lisa.md]]) |
| CWSG | Copy With Substitution and Generation | The inference algorithm shared by every computational model of analogy: transfer each unmapped source proposition, replacing its arguments by their target correspondents and inventing a target element where none exists ([[wiki/concepts/analogical-mapping.md]]) |
| SFI | Semantic Facilitation Index | In a four-term analogy A:B::C:D, the association strength of the correct pair C:D relative to the distractor pair C:D′; negative-SFI problems are the ones frontal patients fail selectively ([[wiki/concepts/analogical-mapping.md]]) |
| MLC | Meta-Learning for Compositionality | Lake & Baroni's method: meta-train a standard seq2seq transformer over a stream of episodes, each defined by a fresh latent interpretation grammar, so systematicity is optimized for rather than assumed ([[wiki/entities/mlc.md]]) |
| SCAN | Simplified version of the CommAI Navigation tasks | Compositional instruction-to-action benchmark (`walk twice` → `WALK WALK`); the `add jump` split trains on one occurrence of a verb and tests its compositional uses, the `length` split tests extrapolation past the training output length ([[wiki/entities/scan.md]]) |
| NLI | Natural Language Inference | Given a context (premise), label a hypothesis *entailment* / *contradiction* / *neutral*; the canonical natural-language-understanding classification task, and the substrate of [[wiki/entities/anli.md]] |
| SNLI / MNLI | Stanford / Multi-genre Natural Language Inference | The two large static NLI corpora (image-caption premises; multi-genre premises) that ANLI's base models were trained on, and whose hypothesis-only artefacts (71.4% with the context deleted) motivated adversarial collection |
| ANLI | Adversarial Natural Language Inference | The three-round dataset produced by HAMLET; 162,865 train / 3,200 test ([[wiki/entities/anli.md]]) |
| HAMLET | Human-And-Model-in-the-Loop Enabled Training | Write-against-the-model → verify by two other humans → split → retrain → repeat; the benchmark-construction loop behind ANLI, and the wiki's only protocol that measures per-item difficulty at authoring time |
| COGS | Compositional Generalization Challenge based on Semantic Interpretation | Sentence-to-logical-form benchmark with 21 generalization types, 18 lexical and 3 structural ([[wiki/entities/mlc.md]]) |
| PCA | Principal Component Analysis | Projection onto the leading eigenvectors of the input correlation matrix; the fixed point of plain Hebbian learning on a linear unit, and of a Hebbian layer with lateral inhibition ([[wiki/concepts/synaptic-plasticity.md]]) |
| PLS | Partial Least Squares regression | Regression through a shared latent space: successive component pairs are extracted to maximise covariance between predictor and response blocks, so it handles predictors far outnumbering samples where ordinary least squares cannot. The transform stage of [[wiki/concepts/connectome-state-transformation.md]] (10 components mapping 100 rest components to 100 task components) |
| BHN | Binary Hopfield Network | The classical bipolar-state network with symmetric weights and asynchronous threshold updates ([[wiki/entities/hopfield-network.md]]) |
| LTI | Linear Time-Invariant | A system whose operator does not depend on position in the sequence: the same kernel convolves every step regardless of content. The property that makes [[wiki/entities/s4.md]] trainable as one FFT and that structurally excludes content-dependent reads (copying, binding, retrieval on demand) |
| MRA | Multi-Resolution Analysis | Representing a signal simultaneously at several scales — coarse trend plus successively finer detail. The framework [[wiki/entities/ms-ssm.md]] imports into a state-space layer |
| DWT / SWT | Discrete / Stationary Wavelet Transform | Recursive low-pass + high-pass filtering that splits a signal into approximation `a^s` and detail `d^s` coefficients. The DWT downsamples at each level and so is **not** translation-invariant; the SWT (a.k.a. undecimated) skips the decimation and dilates the filters by `2^{s−1}` instead, keeping every level at length `L` — a redundant representation, which is what buys translation-invariance. [[wiki/entities/ms-ssm.md]] uses an SWT with *learned* filters rather than a fixed wavelet basis, giving up perfect reconstruction on purpose |
| ERF | Effective Receptive Field | How far a model's output at position `m` *actually* depends on earlier positions, as opposed to how far it structurally could. Measured for attention by the average attention distance and for arbitrary sequence maps by [[wiki/entities/ms-ssm.md]]'s **mean mixing distance**, the row-normalised Jacobian `\|J_{m,n}\| / \|Σ_k J_{m,k}\| × (m−n)` |
| LRD | Long-Range Dependency | An input–output dependence spanning many time steps; the failure mode all of [[wiki/entities/s4.md]]'s baselines share |
| HiPPO | High-order Polynomial Projection Operators | A class of state matrices `A` for which the state of `x′ = Ax + Bu` is the coefficient vector of a projection of the *entire input history* onto an orthogonal polynomial basis — continuous-time memorisation. Swapping a random `A` for it is worth 60% → 98% on sequential MNIST and >15 points of validation accuracy on sequential CIFAR-10 ([[wiki/entities/s4.md]]) |
| LRU | Linear Recurrent Unit | A diagonal complex linear recurrence `x_k = Λx_{k−1} + exp(γ^log)⊙(Bu_k)` with `Λ = diag(exp(−exp(ν^log) + i·exp(θ^log)))`, eigenvalues drawn uniformly on a ring in the unit disc; matches S4/S4D/S5 across the Long Range Arena with no HiPPO and no discretisation ([[wiki/entities/lru.md]]) |
| ZOH | Zero-Order Hold | Discretisation of `x′ = Ãx + B̃u` under the assumption that `u` is constant between samples, giving `A = exp(ΔÃ)`, `B = (A−I)Ã⁻¹B̃`; exact under that assumption, and the source of S4's parameter sharing between `A` and `B`. The `B` multiplier is shown by [[wiki/entities/lru.md]] to be functionally a **normaliser** — its first-order expansion `ΔB̃` matches |
| S4D / S5 | Diagonal S4 / Simplified State Space layer | The two diagonal descendants of S4 that drop the low-rank correction; S5 additionally uses one multi-input multi-output SSM with a parallel associative scan rather than `H` independent single-channel ones. Both are the baselines [[wiki/entities/lru.md]] matches |
| GLU | Gated Linear Unit | `(Wx+b) ⊙ σ(Vx+c)` — the position-wise nonlinear block sitting between recurrent layers in the S4/LRU macro-architecture (Dauphin et al. 2017); in [[wiki/entities/lru.md]]'s account it is what supplies **spectral leakage**, moving signal energy between frequencies, which a linear recurrence cannot do |
| Glorot init | Glorot (Xavier) initialisation | I.i.d. entries with variance `1/N`; by the strong circular law the eigenvalues of such an `N×N` matrix converge to the **uniform measure on the unit disc**, which is why a Glorot-initialised linear RNN is approximately stable and why [[wiki/entities/lru.md]]'s diagonal draw can match it exactly |
| NPLR / DPLR | Normal Plus Low-Rank / Diagonal Plus Low-Rank | `A = VΛV* − PQ^T` with `V` unitary and rank `r ≤ 2`; conjugating away the unitary part leaves DPLR over `C`. S4's parameterisation, and the reason a maximally non-normal `A` can be computed in `Õ(N+L)` time rather than `O(N²L)` |
| FFT / iFFT | (inverse) Fast Fourier Transform | `O(L log L)` evaluation of a discrete Fourier transform; how S4 turns a length-`L` global convolution into a pointwise product |
| bpd | bits per dimension | Negative log-likelihood per input dimension in base 2; the standard density-estimation metric on images (S4: 2.85 on CIFAR-10 with no 2-D inductive bias) |
| ppl | perplexity | `exp` of the mean per-token cross-entropy; the standard language-modelling metric (S4: 20.95 on WikiText-103 against a Transformer's 20.51) |
| CAM | Content-Addressable Memory | A store retrieved by (part of) its contents rather than by an address; the Hopfield network is the standard model and [[wiki/entities/btsp-cam.md]] the binary-weight, non-recurrent alternative |
| CHN | Continuous Hopfield Network | Float-valued states; exponential capacity and one-step convergence, and the update is transformer self-attention (Ramsauer et al. 2020) |
| MHN | Modern Hopfield Network (Dense Associative Memory) | Hopfield network with a steep nonlinearity applied to the state–pattern overlap, giving polynomial or exponential item capacity ([[wiki/entities/dense-sequence-memory.md]]) |
| BM / RBM | Boltzmann Machine / Restricted Boltzmann Machine | Stochastic Hopfield network with hidden units, trained contrastively; *restricted* = bipartite visible↔hidden only, which makes whole layers updatable in parallel ([[wiki/entities/boltzmann-machine.md]]) |
| GPI | Generalized PseudoInverse rule | Decorrelates stored patterns inside the separation function, `Σ_ν O⁺_{μν} m^ν`; perfect sequence recall for linearly independent patterns ([[wiki/entities/dense-sequence-memory.md]]) |
| TAN | Temporal Association Network | Sompolinsky & Kanter 1986: symmetric "fast synapse" hold term plus asymmetric "slow synapse" transition term, capacity `≈0.1N`; the linear special case of the `MixedNet` |
| AIT | Algorithmic Information Theory | Kolmogorov complexity and its relatives; the formal language of both [[wiki/concepts/universal-induction.md]] and [[wiki/concepts/skill-acquisition-efficiency.md]] |
| LSA | Latent Semantic Analysis | Word meaning from a factorised document co-occurrence matrix; read here as a retrieved-context model of semantic learning |
| DSL | Domain-Specific Language | A restricted program space to search over; ARC's proposed solver hard-codes core-knowledge priors as one |
| LoT | Language of Thought | The claim that thought is conducted in recursively combinable typed expressions with a compositional semantics ([[wiki/concepts/language-of-thought.md]]) |
| PLoT | Probabilistic Language of Thought | LoT with a distribution over expressions, so concept learning is posterior inference over sentences of the internal language ([[wiki/concepts/language-of-thought.md]]) |
| GD | Generalization Difficulty | `H(Sol^θ_T \| TrainSol^opt_{T,C}) / H(Sol^θ_T)` — how far the shortest curriculum-optimal program must be edited to work at evaluation |
| AIXI | AI with (X) Induction (I) | Hutter's uncomputable universal agent; the formal ceiling ([[wiki/entities/aixi.md]]) |
| AIXItl | AIXI bounded to length `l̃` and per-cycle time `t̃` | Computable reduction of AIXI; dominates all self-certifying policies within those bounds |
| AIµ | The same agent with the *true* environment prior `µ` | Plain expectimax; optimal by construction, and the reference AIXI is measured against |
| CLS | Complementary Learning Systems | Fast hippocampal / slow cortical memory pair; also the name of the theory |
| Go-CLS | Generalization-Optimized Complementary Learning Systems | Sun et al. 2023's theory: consolidate a relation only while transport lowers generalization error |
| SNR | Signal-to-Noise Ratio | In Go-CLS, `σ_w²/σ_ε²` of the environment's mapping — the wiki's operational definition of a relation's *predictability* |
| CNN | Convolutional Neural Network | |
| AR | Activation Relaxation | Credit-assignment scheme whose equilibrium activations *are* the backpropagation gradients ([[wiki/concepts/biologically-plausible-credit-assignment.md]]) |
| DFA | Direct Feedback Alignment | Output error wired straight to every hidden layer |
| TP | Target Propagation | Credit assignment by propagating layerwise *targets* through learned inverses instead of gradients ([[wiki/concepts/biologically-plausible-credit-assignment.md]]) |
| DTP | Difference Target Propagation | TP plus a linear reconstruction-error correction; the published version still backpropagates through the penultimate layer |
| SDTP | Simplified Difference Target Propagation | DTP with that last gradient removed — fully gradient-free and weight-transport-free (Bartunov et al. 2018) |
| AO-SDTP | Auxiliary-Output SDTP | SDTP whose output layer carries extra random features of the penultimate layer, to raise target diversity |
| LC | Locally-Connected (layer) | Convolution-style receptive fields **without** weight sharing; the biologically defensible version of a convnet |
| DNC | Differentiable Neural Computer | Controller + external memory matrix addressed by content, write-order links and a usage-based free list, trained end to end ([[wiki/entities/differentiable-neural-computer.md]]). **Collision:** Arnsten et al. 2010 use DNC for *Dynamic Network Connectivity*; this wiki spells that one out ([[wiki/concepts/dynamic-network-connectivity.md]]) |
| NTM | Neural Turing Machine | The DNC's predecessor: same controller/memory split, but addressing is content plus index-shift, with no de-allocation and no write-order record across address jumps |
| bAbI | (not an abbreviation) | 20 synthetic question-answering tasks over short generated stories, each a set of constraints on an underlying graph; the DNC's language benchmark |
| DAGGER | Dataset Aggregation | Imitation-learning scheme mixing the expert and the learner's own policy so training states match the states the learner will actually visit |
| DNN | Deep Neural Network | |
| DQN | Deep Q-Network | Deep RL agent for Atari; origin of experience replay in deep RL |
| DRAW | Deep Recurrent Attentive Writer | Attentional generative model that builds an image incrementally |
| DRL | Deep Reinforcement Learning | |
| e-prop | Eligibility Propagation | Forward-only local credit assignment for spiking networks |
| ENU | Evolvable Neural Unit | Evolved somatic/synaptic compartment model with gated update dynamics |
| EBM | Energy-Based Model | A scalar compatibility function `F(x,y)` treated as fundamental, with no normalisation ([[wiki/concepts/energy-based-models.md]]) |
| EWC | Elastic Weight Consolidation | Fisher-weighted quadratic penalty protecting important weights |
| FA | Feedback Alignment | Fixed random backward weights in place of the forward transpose |
| NGRAD | Neural Gradient Representation by Activity Differences | Lillicrap et al. 2020's claim that every local approximation to backpropagation encodes gradients as activity differences; disputed in [[wiki/empirical-tensions.md]] T70 |
| GAN | Generative Adversarial Network | Contrastive EBM in which the contrastive samples come from a trainable generator |
| H-JEPA | Hierarchical JEPA | JEPAs stacked so higher levels predict further ahead on coarser representations ([[wiki/entities/h-jepa.md]]) |
| HiT-JEPA | Hierarchical Interactions of Trajectory Semantics via a JEPA | The first trained JEPA stack; levels differ in sequence *resolution* rather than prediction horizon ([[wiki/entities/hit-jepa.md]]) |
| H3 | Hexagonal Hierarchical Geospatial Indexing System (Uber) | Multi-resolution hexagonal tiling of the globe; the input tokeniser in [[wiki/entities/hit-jepa.md]] |
| IC / TC | Intrinsic Cost / Trainable Critic | The immutable and learned halves of LeCun 2022's cost module |
| InfoNCE | Information Noise-Contrastive Estimation | The standard multi-sample contrastive loss |
| i.i.d. | independent and identically distributed | Train and test drawn from the same distribution; the assumption behind standard benchmarking |
| JEA | Joint Embedding Architecture | Two encoders, energy = distance between their outputs |
| JEPA | Joint Embedding Predictive Architecture | JEA plus a predictor from `s_x` to `s_y`, optionally latent-conditioned; non-generative |
| KL | Kullback–Leibler divergence | `KL(P‖Q) = H(P,Q) − H(P)` — the surprise due purely to a wrong model, asymmetric in its arguments ([[wiki/concepts/divergence-objectives.md]]) |
| K(x) | Kolmogorov complexity | Length of the shortest program printing `x` |
| LGD | Latent Graph Discovery | The wiki's core problem framing |
| LSTM | Long Short-Term Memory | Gated recurrent architecture |
| STSP | Short-Term Synaptic Plasticity | Transient (<1 s) activity-induced change in synaptic efficacy — the Tsodyks–Markram `u`/`a` variables; the carrier of an activity-silent memory ([[wiki/entities/stsp-working-memory-rnn.md]], [[wiki/entities/stp-flickering-cann.md]]) |
| RPE | Reward Prediction Error | `r + γV(s′) − V(s)` — received minus expected reward; the quantity phasic dopamine firing is standardly read as reporting, which [[wiki/entities/pbwm.md]]'s PVLV contests and which [[wiki/entities/meta-rl-agent.md]] additionally supplies as a network *input* |
| MD | Mediodorsal Thalamus | The higher-order thalamic nucleus reciprocally connected with prefrontal cortex; in this wiki, the carrier of the *cueing context* variable ([[wiki/entities/mediodorsal-thalamus.md]]) |
| PFN | Prefrontal Network | Wang et al. 2018's name for prefrontal cortex plus the striatal and mediodorsal-thalamic nodes it loops with, modelled as one recurrent network ([[wiki/entities/meta-rl-agent.md]]) |
| UCB | Upper Confidence Bound | Optimism-under-uncertainty bandit algorithm; one of the baselines the frozen-weight meta-RL inner learner matches |
| MUA | Multi-Unit Activity | Spiking pooled across the neurons near one electrode, without spike sorting |
| GRU | Gated Recurrent Unit | Gated recurrent architecture with one fewer gate than LSTM; the gradient-trained baseline in [[wiki/entities/hag-reservoir.md]] |
| RC (reservoir computing) | Reservoir Computing | Map an input stream through a fixed random recurrent network and train only a linear readout ([[wiki/entities/hag-reservoir.md]]) |
| ESN | Echo State Network | The discrete-time rate-based instance of RC; `x[t+1] = σ(Wx[t] + W_in u[t] + b)` with only `W_out` trained |
| SCR | Simple Cycle Reservoir | Reservoir whose `W` is a full-cycle permutation scaled by one weight `λ`, with `{−1,+1}` input weights; **C-SCR** relaxes the input weights to `{±1,±i}`, **SMCR** (Simple Multi-Cycle Reservoir) uses `k` identical such rings in block-diagonal, **Twin SCR** uses two ([[wiki/entities/simple-cycle-reservoir.md]]) |
| FMP | Fading Memory Property | A causal filter is continuous in a weighted sup-norm `‖c‖_w = sup_t‖w_t c_t‖` with `w` strictly decreasing into the past — inputs with similar recent history give similar present output; the class over which reservoirs are universal, and the class abstract reasoning sits outside ([[wiki/entities/simple-cycle-reservoir.md]]) |
| ESP | Echo State Property | The reservoir state is a function of the input history alone, independent of initial state; for *linear* reservoirs it is equivalent to `ρ(W) < 1` (Grigoryeva & Ortega 2021) |
| APG | Autonomous Pattern Generation | Producing a precise extended temporal output when the input carries none of its structure — birdsong, a motor sequence, a remembered tune ([[wiki/concepts/autonomous-pattern-generation.md]]) |
| HAG | Hebbian Architecture Generation | Grows an ESN's recurrent edges from an empty matrix by homeostasis-gated long-window correlation (Cazalets et al. 2025) |
| IP | Intrinsic Plasticity | Per-neuron gain/bias adaptation toward a target output distribution; the standard plastic-reservoir baseline |
| CEVD | Cumulative Explained Variance Dimensionality | Fewest principal components reaching a variance threshold (0.9); a *linear* effective-dimensionality estimate, subject to the curvature caveat in [[wiki/concepts/population-geometry.md]] |
| NRMSE | Normalized Root Mean Square Error | Forecasting error metric |
| LVEBM | Latent-Variable Energy-Based Model | `F(x,y) = min_z E(x,y,z)`; the latent parameterises which relationship holds |
| MCTS | Monte Carlo Tree Search | Forward search used to improve a value function or policy |
| BIC | Bayesian Information Criterion | Model comparison score penalising parameter count; the COIN-vs-dual-rate comparison is reported as ΔBIC in nats ([[wiki/entities/coin-model.md]]) |
| COIN | COntextual INference | Heald et al. 2021's nonparametric Bayesian model of motor learning ([[wiki/entities/coin-model.md]]) |
| DP | Dirichlet Process | Prior over distributions with an unbounded number of components; the "sticky" variant biases self-transition |
| GEM | Griffiths–Engen–McCloskey distribution | The stick-breaking construction generating the global mixing weights of a hierarchical Dirichlet process |
| HDP | Hierarchical Dirichlet Process | Dirichlet processes sharing a common base measure, so components are shared across groups; supplies the two-level split in [[wiki/concepts/contextual-inference.md]] |
| SMC | Sequential Monte Carlo | Particle filtering; COIN's inference scheme ("particle learning") is an instance |
| MDL | Minimum Description Length | Total code length = model description + data-given-model; the *adjusted* compression rate in [[wiki/concepts/prediction-compression-equivalence.md]] is this two-part code |
| BPE | Byte-Pair Encoding | Sub-word tokenizer built by iteratively merging frequent byte pairs; a lossless pre-compressor sitting in front of the model |
| MPC | Model-Predictive Control | Plan over a horizon, execute the first action, replan (receding horizon) |
| meta-RL | Meta-Reinforcement Learning | Outer RL over tasks producing a second RL algorithm in recurrent activity |
| o.o.d. | out-of-distribution | Test data systematically different from training data; the only regime that separates a shortcut from the intended rule |
| PDP | Parallel Distributed Processing | 1980s movement; origin of distributed representations in cognitive modelling |
| RL | Reinforcement Learning | |
| RLVR | Reinforcement Learning from Verifiable Rewards | Online RL whose reward is an automatic acceptance test (exact-answer match, execution, a proof kernel) rather than a human preference model; the training-time half of [[wiki/concepts/external-verification.md]], and the regime in which reward hacking on the *grader* rather than on the task appears |
| PRM / ORM | Process / Outcome Reward Model | A learned scorer over each intermediate step versus over the completed solution only. The PRM localises the error and so supports credit assignment and targeted reranking, at the price of step-level labels (human, or Monte-Carlo rollout estimates) |
| CoT / PoT | Chain of Thought / Program of Thought | Emitting a natural-language derivation, or an executable program, before the answer; the two artifact types the rungs of [[wiki/concepts/external-verification.md]] check |
| ICL | In-Context Learning | Supplying worked examples in the prompt instead of updating weights; the cheapest form of test-time adaptation, and two-signed when the example's method does not transfer ([[wiki/entities/math-perturb.md]], T224) |
| HANS | Heuristic Analysis for NLI Systems | An NLI diagnostic corpus of premise–hypothesis pairs built so that three structural heuristics (lexical overlap, subsequence, constituent) give the wrong answer on half the items; labelled `entailment` / `non-entailment` only ([[wiki/entities/shortcut-suite.md]]) |
| ICS / SFS / EQS / CFS | Internal Consistency / Semantic Fidelity / Explanation Quality / Confidence Score | The four non-accuracy metrics of [[wiki/entities/shortcut-suite.md]]: pairwise contradiction rate within an emitted chain (label-free, instrument `I21`), BERT cosine between prompt and output (uninformative as published), their equal-weight mean, and the model's self-reported confidence |
| MRR | Mean Reciprocal Rank | Mean of `1/rank` of the target item over a set of retrieval queries; used here as a *design target* rather than a score — MRR 0.986 for recovering an original problem from its perturbation is the statement that similarity retrieval cannot separate the two ([[wiki/entities/math-perturb.md]]) |
| pass@k | — | Probability that at least one of `k` samples is correct — a measure of the *generator's coverage*, meaningful only when a reliable selector exists. Distinct from majority@`k` (plurality vote over `k` samples) and from pass@1 / greedy (the policy's modal behaviour) |
| MWP | Math Word Problem | A natural-language arithmetic problem to be mapped to an expression or program and evaluated; the task family whose perturbation benchmarks (SVAMP, GSM-Plus, GSM-Symbolic — see [[wiki/entities/gsm8k.md]]) supply the robustness evidence on [[wiki/concepts/shortcut-learning.md]] |

| MAML | Model-Agnostic Meta-Learning | The initialization-based meta-learner: find `θ` such that `n` gradient steps on any task drawn from `p(T)` suffice; agnostic because it needs only that the model be gradient-trainable |
| LSG | Learning Signal Generator | In natural e-prop, a second spiking network co-meta-trained to emit a per-neuron, per-timestep learning signal `L_j^t` that multiplies the trainee's local eligibility traces — a *generated* rather than measured error ([[wiki/concepts/analog-in-memory-computing.md]]) |

| sign-rank | — | The smallest rank of a real matrix whose entries match the signs of a given ±1 matrix; the no-margin version of the retrieval dimension bound |
| BM25 | Best Matching 25 | The standard sparse lexical retrieval score; a very high-dimensional sparse vector, which is why it escapes the dense-embedding dimension bound and why it collapses under synonym substitution |

| MRL | Matryoshka Representation Learning | Training so that truncated prefixes of an embedding remain usable, which is how deployed vectors are shrunk below their native dimension |

| ANM | Additive Noise Model | `Y = f(X) + V` with `X ⊥ V`; the function-class restriction that breaks cause/effect symmetry in the two-variable case, since such a distribution cannot be fit by an ANM in reverse (except linear `f` with Gaussian noise) |

| SEM | Structural Equation Model | A set of assignments `Xᵢ ← fᵢ(Pa(Xᵢ), Nᵢ)` with independent noises; environments are interventions on a shared SEM |

| CHMM | Critic Hidden Markov Model | Champion et al. 2023's third rung: an HMM plus a critic trained on a Bellman backup of expected free energy ([[wiki/entities/deep-active-inference-agent.md]]). **Collision:** unrelated to the *cloned* HMM behind [[wiki/entities/cscg.md]], which this wiki spells out |

Introduced in [[wiki/entities/lejepa.md]] (Balestriero & LeCun 2025), where the `N(0,I)` target is *derived* as the probe-risk minimiser; applied to a world model in [[wiki/entities/lewm.md]]. **Weak-SIGReg** (Akbar 2026) is the second-moment truncation: `‖Cov(ZS^⊤) − I_K‖_F` on a random sketch, `O(CK)` memory, usable as a supervised optimisation stabiliser on internal layers |
| ILP | Inductive Logic Programming | Learn a logic program (Prolog clauses) from positive and negative examples plus background knowledge; the search engine behind [[wiki/entities/ilp-arc-synthesizer.md]], and the one program-induction route in the wiki whose hypothesis language is declarative rather than a hand-authored domain-specific language |
| LSSL | Linear State-Space Layer | The predecessor of [[wiki/entities/s4.md]]: the same continuous-time recurrence, computed without the diagonal-plus-low-rank factorisation, hence orders of magnitude more memory at `N = 256` |
| SRN | Simple Recurrent Network | Elman's architecture — a single hidden layer with a copy of its own previous state as extra input; the baseline whose copy-every-step is a *fixed* write policy where later models learn one |
| DORA | Discovery Of Relations by Analogy | Doumas, Hummel & Sandhofer's extension of [[wiki/entities/lisa.md]]: learns explicit relational predicates from non-relational input by comparison, which is the half LISA assumes is already done |
| LPN | Latent Program Network | Test-time *gradient* refinement of a single latent program vector; the ARC-adjacent baseline that reaches 0.994 self-fit with 0.000 transfer, i.e. the sharpest available case of fitting demonstrations without solving the query |
| LAPS | Language for Abstracting Program Synthesis | Learns a library prior jointly with natural-language translation, so language is a second channel on the same prior rather than the representation itself |
| AUC | Area Under the Curve | Threshold-free summary of a classifier's ranking (of the receiver-operating-characteristic curve, or of the precision–recall curve where stated); **low = the two classes look alike**, which is how it is read in the typed-removal table on [[wiki/concepts/memory-read-and-erase.md]] |
| SMDP | Semi-Markov Decision Process | A Markov decision process whose actions take variable, stochastic durations — the formal setting in which an option is a first-class action ([[wiki/concepts/temporal-abstraction-options.md]]) |
| SPRT / MSPRT | (Multihypothesis) Sequential Probability Ratio Test | The statistically optimal stopping rule for accumulating evidence toward one of `N` hypotheses; the normative target that cortico–basal-ganglia models are argued to implement ([[wiki/concepts/evidence-accumulation.md]]) |
| BIP-ALM / LIMP | Bayesian Inverse Planning accelerated by Language Models / Language-Model-Implemented Mental Planning | The two fixed-model theory-of-mind baselines [[wiki/entities/autotom.md]] is scored against; both sit below a raw language model on the open benchmark, which is what makes the adaptive-model result load-bearing |
| NEF | Neural Engineering Framework | Eliasmith's method for compiling vector operations into spiking populations; the substrate claim attached to the vector-symbolic line ([[wiki/concepts/vector-symbolic-binding.md]], [[wiki/entities/arc-vsa-solver.md]]) |
| PSD | Positive Semi-Definite | A symmetric matrix with no negative eigenvalues; the type of a [[wiki/entities/conceptor.md]], which is what lets its singular values be read as a soft subspace with occupancy in `[0,1]` |
| QK | Query–Key | The `softmax(QKᵀ/√d_k)` product inside an attention head; written unexpanded where the two projections are being discussed as one object ([[wiki/entities/transformer.md]]) |
| ToMnet | Theory-of-Mind neural network | The learned (as opposed to inverse-planning) family of agent-modelling architectures; the graph-encoder variant is the wiki's canonical case of aggregate parity at 0.06 profile correlation ([[wiki/entities/agent-benchmark.md]]) |
| WReN | Wild Relation Network | The model built for PGM: a Relation Network scoring each candidate panel against the eight context panels by pairwise comparison, `s_k = f_φ(Σ g_θ(x_i, x_j))` ([[wiki/entities/pgm.md]]) |
| RN | Relation Network | Santoro et al. 2017's module: an MLP applied to every pair of object embeddings, summed, then passed through a second MLP — the pairwise-comparison inductive bias worth 20 points over a ResNet on PGM ([[wiki/entities/pgm.md]]) |
| REPL | Read-Eval-Print Loop | An interactive interpreter session; a Lean REPL server is what turns a proof assistant into a feedback channel an agent can iterate against ([[wiki/entities/olymmath.md]]) |
| MFCC | Mel-Frequency Cepstral Coefficients | Hand-designed short-window spectral features; the ~100× compression that speech models normally rely on, and the preprocessing S4 beats by working on raw samples |
| CCN | Computational Cognitive Neuroscience | A model class, not a field label: models constrained to fit neurobiological *and* behavioural data at once, which is the filter Helie et al. 2013 apply to get 19 basal-ganglia models out of ~25 years of literature ([[wiki/entities/basal-ganglia.md]]) |
| ASOT | Action Segmentation with Optimal Transport | Xu & Gould 2024's TAS method: an unbalanced optimal-transport plan from frames to `K` skill prototypes, regularised by a Gromov–Wasserstein temporal-consistency term; the segmentation stage of [[wiki/entities/hisd.md]] |
| GW | Gromov–Wasserstein | Optimal-transport distance comparing *intra*-space cost matrices rather than points across spaces; here it is what penalises nearby frames receiving different skill labels |
| CFG / PCFG | (Probabilistic) Context-Free Grammar | `(N, Σ, P, S₀)` — non-terminals, terminals, productions, start symbol; the probabilistic variant assigns rule probabilities and can marginalise over noisy parses ([[wiki/entities/hisd.md]]) |
| PU classifier | Positive-Unlabelled classifier | Trained from positive examples plus unlabelled data with no confirmed negatives; used to learn option initiation sets `I` and termination functions `β` from segmented observations |
| BC | Behavioural Cloning | Supervised imitation — fit `π(a\|s)` to demonstration state–action pairs, with no environment interaction and no reward |
| CEM | Cross-Entropy Method | Derivative-free optimiser: sample candidates from a Gaussian, keep the top-`k`, refit mean and variance, repeat; the planner used by [[wiki/entities/v-jepa-2.md]] and [[wiki/entities/adaworld.md]] to minimise a goal-distance energy over action sequences |

| RoPE | Rotary Position Embedding | Relative position encoded by rotating query/key feature pairs; the 3D variant splits the feature dimension into time/height/width thirds and rotates each separately ([[wiki/entities/v-jepa-2.md]]) |
| BYOL | Bootstrap Your Own Latent | The negative-free joint-embedding learner whose EMA target + online predictor asymmetry the whole JEPA lineage inherited ([[wiki/entities/byol.md]]) |
| MLLM | Multimodal Large Language Model | An LLM fed projected visual encoder outputs as input tokens (the LLaVA recipe); the setting of tension T149 |
| VLA | Vision-Language-Action model | Defined by its own field as a system taking images and a natural-language instruction and emitting control commands *directly* — excluding systems whose vision-language stage merely indexes a fixed skill library. | IDM | Inverse Dynamics Model | Infers the action that took the world from one observation to the next; the decoder that turns a predicted video into robot commands, and the device that makes action-free video trainable |
| LoRA | Low-Rank Adaptation | Fine-tune by learning a low-rank correction to frozen weights; reported competitive with full fine-tuning of OpenVLA at consumer-GPU cost (gap G65) |
| DoF | Degrees of Freedom | Independently controllable axes of a mechanism; the quantity that differs between bodies and makes action vectors non-commensurable across them |
| Muon | — | Optimiser that orthogonalises the update matrix before applying it; used in [[wiki/entities/lejepa.md]] §Part 8 as the *update-geometry* counterpart to SIGReg's representation-geometry constraint, with the two measured to compose additively |
| LeJEPA | Latent-Euclidean JEPA | The SIGReg + multi-view-prediction objective with one coefficient, no predictor and no teacher ([[wiki/entities/lejepa.md]]) |
| Epps–Pulley | — | Normality test comparing the empirical characteristic function to `N(0,1)`'s in weighted `ℓ₂`; chosen over moment- and CDF-based tests for bounded gradients, differentiability and `O(N)` distributed cost ([[wiki/entities/lejepa.md]]) |
| SWA (stochastic weight averaging) | Stochastic Weight Averaging | A running average of the encoder weights used at evaluation; in [[wiki/entities/lejepa.md]] it is what remains of teacher–student once collapse is handled by the loss (+~3 points on ViTs, 0 on ResNets) |
| LeWM | LeWorldModel | The 15M end-to-end pixel JEPA built on SIGReg ([[wiki/entities/lewm.md]]) |

| DINOv3 | — | The 7B/16 successor: same objective on a 1.69B-image corpus with constant (unscheduled) hyperparameters, plus a **Gram anchoring** phase and post-hoc high-resolution adaptation and distillation ([[wiki/entities/dinov3.md]]) |

| VGGT | Visual Geometry Grounded Transformer | Feed-forward multi-view 3D system (camera pose, depth, point maps) built on a frozen DINO backbone; improves on all metrics when its DINOv2 encoder is swapped for DINOv3 |

| SK | Sinkhorn–Knopp | Iterative matrix scaling toward doubly-stochastic; used (3 iterations, from SwAV) to force a batch's prototype assignments toward equipartition |

| LayerScale | — | Per-channel learnable scaling on each residual branch; in DINOv2 it costs linear-probe accuracy and buys training stability at scale |

| CLIP | Contrastive Language–Image Pre-training | Two randomly-initialised encoders trained with InfoNCE on 400M web image–caption pairs into one shared space; the field's default vision encoder |

| MLM / MIM | Masked Language / Image Modeling | Predict masked tokens or patches from the unmasked remainder |
| IB | Information Bottleneck | Find a code maximally informative about the sample and minimally informative about the nuisance (here, the distortion applied); Barlow Twins' `λ` is its trade-off parameter ([[wiki/entities/barlow-twins.md]]). | LARS | Layer-wise Adaptive Rate Scaling | The large-batch optimiser every ImageNet-scale SSL method in the wiki trains with (BYOL, Barlow Twins) |

| VL-JEPA | Vision-Language JEPA | A JEPA predicting a *text encoder's* embedding of the answer from video + a text query, with the decoder invoked only on demand ([[wiki/entities/vl-jepa.md]]) |

| HBToM | Hierarchically Bayesian Theory of Mind | Not an abbreviation of the wiki's coining — the model page is [[wiki/entities/hbtom.md]]; listed here because it appears as a bare column header in comparison tables |

| Sontag dimension | — | The dual of VC dimension: largest `d` such that **every** set of `d` inputs in general position can be shattered, bounded by `2w+1` for `w` programmable parameters (Sontag 1997). | LSM | Liquid State Machine | A generic untrained recurrent circuit used as a filter plus memoryless task-trained readouts; universal for time-invariant fading-memory filters given SP and AP (Maass, Natschläger & Markram 2002, [[wiki/entities/liquid-state-machine.md]]). | SP / AP (liquid state machines) | Separation Property / Approximation Property | The LSM's two sufficient conditions. | CRL | Continual Reinforcement Learning | Solve a sequence of environments, each a separate POMDP, retaining performance on all previous ones; *task-agnostic* CRL additionally forbids any signal that the environment changed ([[wiki/entities/continual-dreamer.md]]) |
| p2e | Plan2Explore | Sekar et al. 2020: exploration by **latent disagreement** — an ensemble of networks predicts the next latent state, and the ensemble variance is the intrinsic reward; the world model is frozen while the ensemble trains |
| TTT | Test-Time Training | Update parameters on the test instance itself before answering, using a self-supervised loss built from that instance; see [[wiki/concepts/test-time-training.md]] |
| SimCLR | Simple framework for Contrastive Learning of visual Representations | Chen et al. 2020: InfoNCE over two augmentations of the same image with in-batch negatives; the negatives-based baseline every negative-free method in the wiki is measured against |
| ResNet | Residual Network | Convolutional architecture whose blocks learn `x + f(x)`; the standard pre-transformer vision backbone, and the control architecture on which several joint-embedding tricks report **zero** gain |
| GPT | Generative Pre-trained Transformer | Decoder-only autoregressive transformer family; used in the wiki as the architecture label (e.g. [[wiki/entities/othellogpt.md]]) rather than as a product name |
| NEC | Neural Episodic Control | Pritzel et al. 2017: one differentiable neural dictionary per action, kernel-weighted 50-nearest-neighbour read; the wiki's canonical non-parametric value store ([[wiki/entities/neural-episodic-control.md]]) |
| NMN | Neural Module Networks | Andreas et al. 2016: a parse of the question is compiled into a layout over reusable typed modules, so the *computation* is composed rather than the memory addressed ([[wiki/entities/neural-module-networks.md]]) |
| CN-DPM | Continual Neural Dirichlet Process Mixture | Lee et al. 2020: an expansion-family continual learner that adds a component when the current mixture explains an input badly, with explicit Bayes over per-component generative models in place of a learned router ([[wiki/entities/cn-dpm.md]]) |
| ARCS | Analog Retrieval by Constraint Satisfaction | The retrieval stage paired with ACME: candidate analogs are graded by a stored predicate-similarity network (WordNet) rather than by identical predicates, which is the representation-language commitment [[wiki/concepts/analogical-mapping.md]] isolates — stripping the similarity network collapses retrieval |
| ANN | Artificial Neural Network | Used in the wiki almost exclusively as the *contrast* term for SNN: a rate-valued, non-spiking network, and the matched baseline every spiking energy or accuracy claim is scored against ([[wiki/concepts/spike-encoding-schemes.md]]) |
| MSE | Mean Squared Error | `L = E‖ŷ − y‖²`; the default regression loss, and the objective whose Gaussian-likelihood reading is what lets a predictive-coding network read its residual as a precision-weighted prediction error |
| DFS | Depth-First Search | The enumeration order in the wiki's program-synthesis solvers, usually run to a likelihood or cost threshold rather than to exhaustion; the brute-force arm `T309` measures a learned proposer against |
| ROC / AUC | Receiver Operating Characteristic / Area Under the Curve | Threshold-free ranking score for a binary decision; the metric under which a probe's *ordering* is reported separately from its calibration |

| meta-`d′`/`d′` | Metacognitive efficiency | Confidence sensitivity divided by the maximum achievable at the system's own first-order performance; `1` = ideal, `0.7` = 30% of the decision's evidence lost before the confidence read-out. | SLN% | Supragranular Labelled Neurons (percentage) | Proportion of a projection's source cells lying in the superficial layers; the graded quantity that replaces the binary feedforward/feedback rule and turns an under-constrained anatomical hierarchy into a metric one (Kennedy & Bullier 1985; Barone et al. 2000, [[wiki/concepts/canonical-cortical-microcircuit.md]]) |
| ICC / ECC | Internally Cued Condition / Externally Cued Condition | The two judgments contrasted on identical affective pictures — pleasant/unpleasant (internal) versus indoor/outdoor (external); the pairing that makes the self-referential contrast an *affective* one ([[wiki/entities/default-mode-network.md]]) |
| OKN | OptoKinetic Nystagmus | Reflexive eye movement tracking a moving field; used as the motor read-out from which a percept is inferred, which is why a code that generalises across it may be coding the read-out rather than the percept ([[wiki/concepts/population-geometry.md]]) |
| BF₀₁ / BF₁₀ | Bayes Factor (null over alternative / alternative over null) | Likelihood ratio between two models; `BF₀₁ > 3` is the wiki's usual threshold for evidence *favouring* a null, which is what lets an absence be reported as a finding rather than as a failure to detect |
| FLB / FLN | Faculty of Language in the Broad sense / in the Narrow sense | Hauser, Chomsky & Fitch 2002's factorisation: FLB = sensory-motor system + conceptual-intentional system + the computational core; FLN = the core alone (recursion plus its two interface mappings). | AIF | Active InFerence | Abbreviated form used where the phrase appears inside a compound (MD-AIF, FEP-AI); see [[wiki/concepts/predictive-coding-free-energy.md]] and [[wiki/concepts/expected-free-energy.md]] |
| RC (recurrent collateral) | Recurrent Collateral | The CA3→CA3 axon collaterals, ~1.2×10⁴ per neuron in rat, the substrate of the autoassociative attractor ([[wiki/entities/rolls-treves-hippocampal-model.md]]) |
