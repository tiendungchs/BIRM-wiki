# NEO (Neural Theorizer) and the Learning-to-Theorize paradigm

**A world model whose object of inference is not the next state but the *program that produced it*: from a single raw observation pair `(x, y)` — no DSL, no program labels, no task grouping, no language — induce a discrete executable program over a learned primitive vocabulary, where the primitives are VQ codebook symbols with no stipulated meaning and their semantics come entirely from one shared transition network that executes them.**

> **Provenance.** Baek, Lee, Baek, Lee & Ahn, *Learning to Theorize the World from Observation*, ICML 2026 Oral (PMLR 306; arXiv:2605.03413v2) — `raw/baek-2026-theorize-world-from-observation.md`. KAIST.

This is the wiki's **first ingested primary machine-learning source in the program-induction family** ([[wiki/concepts/program-induction.md]] opened with the admission that it had none), and the first system anywhere in the wiki that induces a primitive library *and* its semantics from raw observation. Every prior instantiation was handed its vocabulary: [[wiki/entities/bayesian-program-learning.md]] is given the relation types, [[wiki/entities/arc-agi.md]]'s intended solver is given a DSL to search, [[wiki/concepts/affordance-grounded-symbols.md]] is given the action repertoire that carves the symbols, [[wiki/entities/adaworld.md]] induces an edge alphabet but no nodes and no semantics beyond "whatever compresses this transition". NEO is the first to attack gap **G4** on both halves at once — vocabulary *and* operational meaning — and to do it with the output in a form a search can compose.

## The paradigm: L2T

The reframing is the contribution as much as the architecture. Contemporary world models operationalise understanding as **accurate future prediction**; L2T operationalises it as **construction of an explanatory theory**, on the developmental argument (theory-theory, *the child as scientist*) that children build and revise internal theories of how the world works before mature language.

| | Prediction-centric world model | Learning-to-Theorize |
|---|---|---|
| Inferred object | Next state / next embedding | The **program** `τ` that maps `x → y` |
| Trained by | Reconstruction, embedding distance, video fidelity | The same reconstruction loss — but routed through a *composed* execution trace |
| Sufficient solution | Any entangled composite map fitting the correlations | Only a decomposition into reusable parts |
| Scored by | Prediction error | **Transferability** — does the program induced from one pair work on a *different* pair generated by the same mechanism |
| Failure mode named | Compounding rollout error | Memorising `Left-Down` as one atom, so `Down-Paint-Rotate` is inexpressible |

**Data assumption, and why it matters.** `D_train = {(x_n, y_n)}` are i.i.d. phenomena. The programs `τ_n` and their execution functions are **never observed**. There is no few-shot grouping of examples sharing a program — explicitly contrasted with [[wiki/entities/arc-agi.md]], which supplies ~3 pairs per task and thereby hands the learner the "same program" signal for free. In the canonical world-modelling case one simply sets `x_n = x_{t_n}`, `y_n = x_{t_n + t'_n}` with both the time index and **the lag unobserved**. So the paradigm's input is a raw video stream cut at arbitrary points, which is why the authors claim it scales.

## Architecture

| Component | Form | Role |
|---|---|---|
| **Encoder / decoder** `E_θ, D_θ` | Pretrained, frozen for stability | Observation ↔ latent state `s` |
| **Program** `τ = (z_{i1}, …, z_{iK})` | Ordered sequence of discrete symbols from a VQ codebook `E = {e_1,…,e_{M'}}`, `M'` a hyperparameter (true `M` unknown) | The theory. A **learned Language of Thought**: symbols with *no predefined semantics* |
| **Theory programmer** `q_φ(z_{ik} \| s_k, y)` | Neural net on `(s_k, E_θ(y))` → categorical over codes; VQ-VAE realises the discreteness end-to-end | A **goal-conditioned policy over primitives** — the inference network, and the paper's central move |
| **Execution / transition** `f_θ(s_k, z_{ik})` | One **shared** deterministic network, `s_{k+1} = f_θ(s_k, z_{ik})` | Supplies the *semantics*: a symbol means whatever this network does with it |
| **MDL length selection** | `k* = argmin_k λ_MDL^k · ℓ(y, D_θ(s_k))`, `λ_MDL > 1`; backprop **only** through `ŷ_{k*}` | Per-instance adaptive program length; the simplicity bias |
| **State grounding** | `L_state = Σ_k ‖s_k − sg[E_θ(D_θ(s_k))]‖²`, gradient to the transition model only | Forces every *intermediate* state onto the manifold of decodable observations |
| **Objective** | `E[ℓ(y, ŷ_τ)] + λ_vq L_VQ + λ_state L_state`, truncated at `k*` | |

The probabilistic frame is a conditional ELBO over two latents, program `τ` and execution trace `s = (s_1,…,s_{K+1})`, with the variational posterior sharing the encoder and the executor with the generative model — so the only inference-specific parameters are the theory programmer's. Execution is deterministic (a degenerate transition), which the authors flag as a simplification and a limitation.

**The syntax/semantics split is the design.** Nothing tells the model what a code means. `q_φ` learns *which* symbol to emit (syntax); `f_θ` learns *what emitting it does* (semantics); the two are learned jointly from reconstruction alone. This is what makes the vocabulary co-discovered rather than authored — and it is also why the semantics are only guaranteed to be *operationally* coherent, never human-aligned or causal (the authors say so).

## OTIB — the benchmark, and the instrument that is the real export

**Observation-to-Theory Induction Benchmark.** Three domains, one protocol.

| Domain | Ground-truth primitives | Train lengths | Length-OOD |
|---|---|---|---|
| **GridWorld** (10×10, one object) | 4 moves (up/down/left/right) | 1–3 (`K=4`) | 4–8 (`K=10`) |
| **Arithmetic factorization** | `×2, ×3, ×5, ×7` | 1–3 | 4–6 |
| **Image editing** (CIFAR-10) | 8 edits (brightness ±, hue ±, h-flip, v-flip, rotate, mask) | 1–2 | 3–4 |

**`α` — the coverage knob.** `α ∈ {0.33, 0.66, 1.00}` is the fraction of in-range compositions placed in training; the rest are the compositional-OOD set. Anchors (the four triple-repeats `UUU/DDD/LLL/RRR`) are always included. The construction deliberately ensures **some primitives are never observed in isolation** and appear only inside longer entangled programs — at `α = 0.33` in image editing, *five of eight* primitives are absent as singletons — so recovering them requires decomposing multi-step hidden transitions. By construction the training compositions contain, in principle, enough evidence to recover the full primitive set.

**Three metrics the wiki did not previously have:**

| Metric | Definition | What it instruments |
|---|---|---|
| **Self-explainability** | `d(ŷ⁽¹⁾, y⁽¹⁾)` — execute the induced program on the pair it was induced from | Fit. A monolithic autoencoder maxes this trivially |
| **Transferability** | Induce `τ̂` from a **support** pair, execute it on a **query** pair generated by the same latent program, score `d(ŷ⁽²⁾, y⁽²⁾)` | Whether the theory is *reusable* rather than an encoding of `y⁽¹⁾`. This is the load-bearing metric |
| **Action primitiveness** | Over a dataset applying each ground-truth primitive once: fraction for which *some single* learned code reproduces it exactly | **Coverage** of the true primitive set — including primitives never seen in isolation |

A fourth, the **code–primitive alignment matrix** (learned code × ground-truth primitive, counted by exact-match outcomes), reads off *entanglement*: a near-diagonal matrix means primitive-level codes, off-diagonal mass means codes for composites.

**Why this matters beyond the paper.** Gap **G17** says no evaluation protocol can certify structure discovery. The support/query split is one, cheaply: it is a **second query against the same representation** — exactly the move [[wiki/concepts/compositionality.md]] proposed as a G17-class instrument (parse, don't just classify) and never had a machine instance of. The self-explainability / transferability *gap* is the diagnostic: Cont-Mono scores 0.975 and 0.001 on the two, which is a numerical signature of "the latent encodes `y`, not the mechanism". Nothing else in the wiki separates those two failure modes with one number.

## What this settles, and what it does not

**The library can be induced from raw observation, including primitives never seen alone.** Primitiveness 1.000 at `α = 0.33` means every ground-truth primitive is reproducible by some single learned code, while the GT ceiling for a memoriser — the fraction directly observable in training — is far lower. In image editing at `α = 0.66` the model recovers all three primitives absent as singletons. This is the wiki's first evidence that **cost 1 of [[wiki/concepts/program-induction.md]] ("somebody authors the library") is payable**, in toy domains, by decomposition pressure alone.

**Over-capacity is not the failure mode everyone assumed.** A 6× over-complete codebook (36 codes for 6 primitives, and 16 for 4 in arithmetic) *does not* degrade into one-code-per-observed-composition; it still allocates primitive-level codes and composes them, and scores slightly **better** (0.976 vs 0.933). The codebook-size worry that [[wiki/empirical-tensions.md]] T148 flagged as "a hypothesis nobody has swept" is swept here in the compositional setting, and it points the other way: the pressure that prevents memorisation is not scarcity of codes.

**What prevents memorisation is `λ_MDL`, and it is sharp in the wrong direction.** At `λ_MDL = 1.2` primitiveness collapses to 0.213 and the alignment matrix fills with composite codes — a **stronger** simplicity bias produces *shorter, more entangled* programs. Mean explanation length tracks the GT length only for `λ ∈ {0.8, 1.0}`. So description-length pressure is not monotonically good for structure: it trades program length against vocabulary primitiveness, and the useful regime is a band, not a limit. This is a measured statement about gap **G26** and a new tension (**T155**).

**State grounding is the whole thing.** Removing `L_state` takes primitiveness to 0.002 and *every* score to 0.000 — total collapse, not degradation. The mechanism: without it, intermediate states are unconstrained (only `s_{K+1}` must decode to `y`), so the model learns shortcut transitions through off-manifold latents that are useless as building blocks. **The reusability of a primitive is a property of the space its output lands in, not of the primitive.** For [[wiki/concepts/manifold-constrained-learning.md]] this is the same constraint installed as a loss rather than found in a cortex, and it is the sharpest ablation in the recent waves: the single cheapest term in the objective is the one carrying the entire result.

**The amortised policy and the vocabulary fail separately, and the wiki now has the number.** At length-OOD on arithmetic, NEO scores 0.019–0.038 while its primitiveness is 1.0 — the primitives are all there, and the *policy composing them* is what breaks over a 6-step horizon. Sampling `B = 1024` programs and majority-voting over those that reproduce the support pair recovers 0.696–0.707, at roughly **180× inference cost**. This is the wiki's first quantified amortisation gap ([[wiki/concepts/amortized-inference.md]]) with the deficit *localised*: not a knowledge failure, a search failure. It also means a benchmark score attributing failure to representation may be measuring the proposer (new tension **T156**).

**Compositional structure is what makes test-time search work at all.** Monolithic baselines are **flat** in `B`; NEO climbs monotonically toward saturation. Cont-Mono-Opt is the controlled version of this — test-time *gradient* refinement of a monolithic latent, and it stays at 0.000 transfer while improving self-explainability to 0.994. So the deficit is not the amortisation gap and not the search budget: **there is nothing in a monolithic latent for search to search over.** That is the cleanest argument in the wiki for why the test-time-compute lever needs a compositional representation underneath it.

**Intervention comes free with the format.** Because execution is `s_{k+1} = f_θ(s_k, z)` over a symbol set, one can override the programmer's choice and run a counterfactual trace — including through latent states never encountered in training. Cheap, and unmeasured beyond a figure.

**What it does not settle.** Deterministic execution (no multi-modal futures — the failure [[wiki/entities/spelkenet.md]] shows is fatal for reading structure out of a plural world); reconstruction-based stopping (`ℓ ≤ ε`) which is brittle under noise and partial observability; small discrete primitive sets and short programs; **synthetic domains only** — the image-editing task is CIFAR-10 with photometric edits, not a physical scene; semantics grounded only by reconstruction, so alignment with human concepts or causal factors is not claimed; and the encoder/decoder are pretrained and frozen, so nothing here shows the perceptual and program levels can be learned together.

## Comparison

| | **NEO** | [[wiki/entities/adaworld.md]] (Cont-Mono) | Genie/LAPO (Disc-Mono) | LPN (Cont-Mono-Opt) | [[wiki/entities/bayesian-program-learning.md]] |
|---|---|---|---|---|---|
| Program representation | **Sequence** of discrete symbols | One continuous vector | One discrete code | One continuous vector | Structured stochastic program |
| Vocabulary origin | **Induced from observation** | Induced (continuous) | Induced (discrete) | Induced | Learned primitives, **authored relations** |
| Semantics from | **Shared executor** | Decoder conditioning | Decoder conditioning | Decoder conditioning | Hand-specified generative model |
| Length | **Adaptive per instance (MDL)** | Fixed (1) | Fixed (1) | Fixed (1) | Variable, in the prior |
| Test-time search | Sampling + majority vote (helps a lot) | None | None | Gradient (helps self-fit, **not** transfer) | Posterior sampling |
| Comp-OOD transfer | **0.933** | 0.000 | 0.000 | 0.000 | n/a |
| Supervision | Observation pairs only | Video only | Video only | Input–output pairs | Stroke-level causal data |

The three baselines are not straw men: they are re-implementations of the wiki's own reference systems for latent-action induction. **The paper's result is therefore a direct negative finding about [[wiki/entities/adaworld.md]]'s representation class** — a monolithic latent action, continuous or discrete, amortised or optimised, transfers at *zero* to compositions it was not trained on, under a protocol AdaWorld's own cross-video transfer test does not run (AdaWorld transfers a code to a new *scene*; OTIB asks for a *composition* the training set never contained).

## Connections

- **[[wiki/concepts/program-induction.md]]** — the wiki's first ingested primary source in this family, and the first payment on its cost 1: the library is induced from raw observation pairs with no DSL, no program labels and no task grouping, with primitiveness 1.000 including primitives never observed in isolation.
- **[[wiki/concepts/language-of-thought.md]]** — a *learned* language of thought with the innateness question dissolved into an engineering one: the symbols are VQ codes with no stipulated meaning, the syntax is the theory programmer, the semantics is one shared executor, and MDL is the prior that does the pruning the overgeneration argument demands.
- **[[wiki/concepts/compositionality.md]]** — answers its "where does the primitive library come from" open problem in the toy case, and supplies the parse-based instrument it proposed for G17 as a working protocol (support/query transferability).
- **[[wiki/concepts/learned-world-models.md]]** — a fifth role for the same object: not simulator, dynamics model, reward model or instrument, but **theorizer** — the inferred quantity is the mechanism rather than the future, and its open problem "learning cup and table should give a cup on a table free" is exactly what OTIB measures.
- **[[wiki/entities/adaworld.md]]** — re-implemented here as the Cont-Mono baseline and refuted on the axis it never tested: a monolithic induced action code transfers across *scenes* but at 0.000 across *compositions*, and test-time gradient refinement of it does not help.
- **[[wiki/concepts/amortized-inference.md]]** — the wiki's first quantified amortisation gap with the deficit localised: primitiveness 1.0 with length-OOD transfer 0.02, recovered to 0.70 by sampling 1024 programs at ~180× cost, so the failure is in the proposer and not in the model.
- **[[wiki/concepts/manifold-constrained-learning.md]]** — the same constraint as an engineering term: `L_state` forces every intermediate execution state back onto the decodable manifold, and removing it collapses primitiveness to 0.002 — reusability is a property of the space a primitive's output lands in.
- **[[wiki/concepts/latent-graph-discovery.md]]** — hardness source 2 attacked with the semantics attached: an edge alphabet *and* the transition operator realising it, co-discovered, with intermediate execution states as node content — while the nodes themselves are still whatever the frozen encoder produces.
- **[[wiki/concepts/universal-induction.md]]** — the simplicity prior in a working system and out of the limit: `λ_MDL^k · ℓ` is Occam with a tunable exponent, and the sweep shows that too much of it buys short entangled programs rather than structure.
- **[[wiki/entities/arc-agi.md]]** — the explicit contrast on the data assumption: ARC hands the solver a few-shot group of pairs sharing one program, OTIB withholds it and trains on i.i.d. phenomena, so the "which examples share a mechanism" signal is itself withheld.
- **[[wiki/entities/bayesian-program-learning.md]]** — the same two-level factorisation (library / program) with the authorship moved: BPL is given its relation types by the prior and demonstrates one-shot classification; NEO is given nothing and demonstrates compositional transfer, on toy domains.
- **[[wiki/concepts/affordance-grounded-symbols.md]]** — the rival grounding route: there a symbol means "a situation my action repertoire cannot distinguish from this one", requiring an action set; here a symbol means "whatever the shared executor does with it", requiring none — so NEO trades the repertoire-limited criterion for no external criterion at all.
- **[[wiki/entities/spelkenet.md]]** — the same intervention move in a different slot: both override a model's own conditioning to read structure out of it, but SpelkeNet pokes a *stochastic* model and reads a partition, while NEO's executor is deterministic — which is the property SpelkeNet's negative control (CWM) shows is fatal when the true response is plural.
- **[[wiki/entities/gcq.md]]** — the opposite trade on the vocabulary: GCQ installs a metrically-ordered codebook by construction and hand-writes the action→displacement map; NEO installs nothing and learns both the codes and their effects, at the price of no metric, no group structure and no guarantee the alphabet is minimal.
- **[[wiki/concepts/external-verification.md]]** — this page's 1024-sample majority vote placed in the family it belongs to: the same greedy → vote → verifier-selected gap that reads 74 → 83 → 93 for o1 on AIME and ~60 → 88.9 for a Lean-checked prover, which makes NEO's 0.019 → 0.70 a test-time-scaling result rather than a quirk of its programmer.
