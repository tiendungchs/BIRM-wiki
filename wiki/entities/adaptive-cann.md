# A-CANN (Adaptive Continuous Attractor Neural Network)

**A continuous attractor network with one extra term — a slow negative feedback current that destabilises whatever state the network is currently holding — so a single scalar `m` trades representational *stability* against representational *mobility*, and sweeping it walks the network through four qualitatively different computations without changing a weight.** Li, Chu & Wu 2024, arXiv:2410.06517 (review + unifying analysis of Fung/Mi/Wu-line A-CANN results).

The dilemma the page exists to answer: an attractor holds information reliably *because* it resists being moved, which is exactly what makes memory search, tracking and update slow. Adaptation is the resolution — reliability on the fast timescale `τ`, mobility on the slow timescale `τ_v`.

---

## Model

| Component | Specification |
|---|---|
| Substrate | 1-D CANN, neurons at `x ∈ (−∞,∞)`, density `ρ`, translation-invariant Gaussian recurrence `J(x,x′) = J₀/(√(2π)a)·exp[−(x−x′)²/2a²]` |
| Neural dynamics | `τ dU/dt = −U + ρ∫J(x,x′) r(x′,t) dx′ − V(x,t) + I^ext(x,t)` |
| Firing rate | `r = U²/(1 + kρ∫U²dx′)` — divisive normalisation, `k` = strength of the unmodelled global inhibitory pool (shunting inhibition) |
| **Adaptation** | `τ_v dV/dt = −V + mU`, with `τ_v ≫ τ`. `m` = adaptation strength |
| Adaptation substrate | Spike-frequency adaptation is used; the authors state short-term synaptic depression gives the same dynamics — the model constrains the *timescale and sign*, not the biophysics |
| External input | `I^ext = α exp[−(x − v_ext t)²/4a²]` — a moving Gaussian of strength `α`, speed `v_ext` |

**The whole model is two coupled bumps.** `U` is the activity bump at position `z(t)`; `V` is the adaptation bump lagging it by `s_v(t)`. Everything below is what happens when a bump is chased by its own delayed shadow.

### Model reduction: four numbers instead of `2N`

The bump is Gaussian and stays Gaussian, because attractor dynamics erase distortions perpendicular to the attractor manifold faster than they accumulate. Projecting onto the first two **motion modes** of each bump — height (`u₀ ∝ e^{−(x−z)²/4a²}`) and position (`u₁ ∝ (x−z)e^{−(x−z)²/4a²}`) — collapses a `2N`-dimensional neurodynamic system to a 4-D state-space model in `(A_u, A_v, z, s_v)`:

```
τ dA_u/dt   = (−A_u + ρJ₀A_r/√2) − A_v e^{−s_v²/8a²} + ⟨I^ext, u₀⟩
τ A_u dz/dt = s_v A_v e^{−s_v²/8a²} + ⟨I^ext, u₁⟩
τ_v dA_v/dt = −A_v + m A_u e^{−s_v²/8a²}
τ_v A_v ds_v/dt = s_v e^{−s_v²/8a²}(τ_v A_v²/(τA_u) − m A_u) + (τ_v A_v/τA_u)⟨I^ext, u₁⟩
```

The second line is the load-bearing one: **the bump's velocity is proportional to the offset `s_v` between activity and adaptation**. Motion is generated by the lag, not by any velocity input — which is why an A-CANN moves in the dark.

## The four regimes, and the scalar that selects them

Sweeping adaptation strength `m` against input strength `α` (equivalently, intrinsic mobility against external drive) gives a complete phase diagram. `m₀ ≡ τ/τ_v` is the mobility threshold.

| Regime | Condition | Behaviour | Computational reading |
|---|---|---|---|
| **Static bump** | `m < τ/τ_v` and `0 < k < k_c2 = ρJ₀²/(8√(2π)a(1+m)²)` | Stationary state, neutrally stable along the manifold | Classical CANN: hold a value |
| **Smooth (phase-locked) tracking** | `m − τ/τ_v < α/A_u` | Bump follows the input at `v_ext` with constant offset `s_u` | Track a driving signal |
| **Oscillatory tracking** | `α/A_u < m − τ/τ_v < (α/A_u)(1 + √(τA_u/(τ_v α)))` | Hopf bifurcation → limit cycle: bump sweeps forward and back around the input | Theta sweeps; sample around the current estimate |
| **Travelling wave** | `m − τ/τ_v > (α/A_u)(1 + √(τA_u/(τ_v α)))` | Bump moves spontaneously at `v_int`, ignoring input | Free search / sequential retrieval of the whole manifold |

**Intrinsic speed** (no input): `v_int = (a/τ_v)·√(m τ_v/τ − √(m τ_v/τ))`, real exactly when `m > τ/τ_v` — the stability analysis and the wave solution agree on the same threshold.

**Mechanism of the wave.** The most active neurons receive the strongest suppression, so the bump is pushed off its own location; recurrence re-forms it next door, where adaptation begins again. Self-chasing, with no external drive and no readout of position anywhere.

### Anticipative tracking: delay compensation for free

In the smooth regime the offset solves to `s_u ≈ (A_u τ_v/α)·v_ext·(m − τ/τ_v)`, so:

- `v_int > v_ext` ⟹ `s_u > 0` — **the bump leads the input**;
- `s_u` is *linear* in `v_ext`, hence the **anticipation time `t_ant = s_u/v_ext ≈ (A_u τ_v/α)(m − τ/τ_v)` is independent of input speed** and increases roughly linearly with `m`.

This is the model's sharpest empirical hit: rodent anterior-thalamic head-direction cells anticipate actual head direction by 20–25 ms *independent of rotation speed*. A speed-independent lead is what a competition between a fixed intrinsic speed and an external drive produces; it is not what a learned forward model or a fixed delay line produces.

### Oscillatory tracking: theta sweeps from a bifurcation

At `m₀ = α/A_u + τ/τ_v` the two eigenvalues cross the imaginary axis with non-zero imaginary part — a Hopf bifurcation, hence a limit cycle rather than a slow drift. Solving the harmonic ansatz `s_u = c_u sin ωt + d_u`, `s_v = c_v sin(ωt+γ) + d_v`:

```
ω  = √( 2√π α a k (1+m) / [ τ τ_v (J₀ + 2√π a k α) ] )        (sublinear in α and in m)
d_u = (τ_v A_u/α) v_ext (m − τ/τ_v)      d_v = τ_v v_ext
```

With biological parameters `ω` lands in the theta band (~8 Hz) **independent of running speed**, and the sweep of the bump around the true position reproduces, at the population level, theta sweeps of decoded position, and at the single-cell level, phase precession *and* procession as the input passes through a field. So theta-band structure here is a property of a bifurcation, not of an imposed oscillator — nothing in the model has an 8 Hz clock, which puts it directly against every wiki model that supplies theta as an external drive ([[wiki/empirical-tensions.md]] T58).

### Noisy adaptation: Lévy flights at the boundary

Add noise to the adaptation strength itself, `τ_v dV/dt = −V + mU + σ_m ξ_m f[U]`. Define

- **distance-to-boundary** `μ = 1 − m τ_v/τ`, **noise-to-strength** `γ = σ_m/(2√π a m)`.

The offset `s(t)` obeys a linear SDE with *multiplicative* noise, `τ_v ds/dt = −(μ + γξ)s + σ_s ξ_s`, whose Fokker–Planck stationary solution is heavy-tailed, `p(s) ∝ (σ_s² + γ²s²)^{−(1+μ/γ²)}`, giving

```
p(‖Δz‖) ∝ ‖Δz‖^{−1−α},     α = 1 + 2μ/γ²
```

| `α` | Regime |
|---|---|
| `α > 2` | Brownian motion (Central Limit Theorem) |
| `0 < α < 2` | **Lévy flight** — anomalous/super-diffusion, intermittent long jumps |

Reading: when mean adaptation sits *near* the travelling-wave threshold, noise intermittently pushes the network across it, so the bump alternates local Brownian jitter (below threshold) with long ballistic jumps (above). Lévy flights are the optimal search strategy for sparse targets in an unknown space, and place-cell reactivation during immobility has been reported to follow Lévy statistics. **The exponent — hence the exploration/exploitation balance — is set by two ratios of quantities a controller could plausibly modulate**, not by a schedule.

## What it contributes

| Claim | Why it matters here |
|---|---|
| **Stability and mobility are separable, and one scalar dials between them** | Every attractor-memory design in the wiki inherits the retrieval-vs-search dilemma; this is the wiki's only mechanism that resolves it *without a second network* — add a slow negative-feedback copy of the state and set its gain |
| **Search, tracking, prediction and holding are one circuit at four parameter settings** | Not four modules with a router. Gap G15 asks for a control policy over simulation; here the policy is a single continuous knob whose thresholds are known in closed form (`m` vs `τ/τ_v` and vs `α/A_u`) |
| **Anticipation without a forward model** | A constant lead time falls out of intrinsic-vs-driven speed competition. Nothing is trained, and no delay is measured — see [[wiki/concepts/predictive-coding-free-energy.md]] |
| **The exploration exponent is a formula** | `α = 1 + 2μ/γ²`: exploration breadth is a closed-form function of how close the gain sits to a bifurcation and how noisy that gain is |
| **Motion-mode projection as a model-reduction recipe** | `2N` → 4 state variables with the bifurcation structure preserved. Any bump-carrying module in a larger architecture can be *substituted* by its 4-D reduction, which is what makes attractor modules composable at all **(brainstorm)** |

**(brainstorm) The exportable design pattern is "criticality as a control interface".** Rather than scheduling exploration, park a retrieval dynamics just below its own instability and modulate two quantities: the distance to the boundary (`μ`, a gain) and the noise on that gain (`γ`). Below threshold the system is a memory; at threshold it is a Lévy searcher; above it, an exhaustive sequential scanner. The same two knobs cover "hold the answer", "sample around the answer" and "go find another answer" — which is exactly the trio [[wiki/concepts/energy-based-models.md]] names as unmechanised (its "multi-modal exploration is unmechanised" open problem, with the Necker cube as the target behaviour). The cost is one extra state variable per unit and two global scalars.

**(brainstorm) A tighter claim about theta.** Because oscillation frequency `ω ∝ √(α(1+m))` and anticipation time `t_ant ∝ τ_v(m − τ/τ_v)`, *the same* `m` sets both how fast the system samples and how far ahead it looks. A controller that raises adaptation gain gets a longer prediction horizon and a faster sampling rhythm together — which predicts that theta frequency and the lead of the decoded position should co-vary under any manipulation of adaptation, a test nothing in the wiki has run.

## Comparison

| Mechanism for destabilising an attractor | Carrier | Timescale | Selective? | Behaviour produced |
|---|---|---|---|---|
| **A-CANN adaptation (this page)** | Slow current `V` tracking `U` (SFA or STD) | `τ_v ≈ 25–150 ms` | No — suppresses whatever is currently active | Wave, oscillation, anticipation, Lévy flight |
| **Short-term plasticity** ([[wiki/entities/stp-flickering-cann.md]]) | Synaptic `u·x`, `τ_f > τ_r` | 0.6–1.9 s | Yes — per-synapse, so it *re-favours* the abandoned state | Flickering between two discrete maps |
| **Spiking noise + adaptation** ([[wiki/entities/rolls-treves-hippocampal-model.md]]) | Poisson noise crossing basin walls | ms | No | Ordered walk through ~7 discrete attractors |
| **Theta reset of global inhibition** ([[wiki/entities/stp-flickering-cann.md]]) | External rhythm on `I₀` | 100 ms | No | Periodic re-run of the competition |
| **Explicit posterior sampling** ([[wiki/entities/hidden-state-inference-remapping.md]]) | Computed responsibilities | per cycle | Yes — by evidence | Sampling proportional to probability |

The sign difference in the second row is the substantive one: STP's rebound *pulls the state back* to where it just was; SFA-style adaptation *pushes it away*. A system with both has an attractive and a repulsive history term at different timescales, which no model in the wiki combines.

## Limitations

- **One bump on a 1-D continuum.** The state is a scalar position. Nothing here represents a graph, a relation, or a composite; "memory search" means sweeping a line, and "all stored memories" means all points on one manifold. The travelling-wave-as-memory-search argument is asserted by analogy and never run on a memory task.
- **The reduction assumes the bump stays Gaussian.** Valid when `I^ext` and `V` are small and noise is weak; the constant-height assumption is acknowledged to fail in the oscillatory regime, where it is used anyway as an approximation.
- **No learning of any kind.** `J(x,x′)` is hand-designed and translation-invariant; nothing writes to it. This is a dynamics paper — it says what a stored manifold *does*, never how it got there.
- **The Lévy result is a scaling claim about `‖Δz‖`, not a search benchmark.** No target-finding task is run; optimality of Lévy search is cited from the foraging literature.
- **`m` is exogenous.** The paper's central knob has no controller. What would set adaptation gain in a behaving system — neuromodulation is the obvious candidate — is not modelled, so G15's *policy* is still missing even though the *interface* is now explicit.
- **Review, not new experiment.** The empirical anchors (head-direction anticipation, theta sweeps, phase precession, Lévy-distributed place-cell reactivation) are prior findings the framework accommodates; no prediction is tested here.

## Connections

- **[[wiki/concepts/path-integration.md]]** — the same substrate with the velocity source moved inside: where path integration drives the bump with a measured action `a_t`, adaptation drives it with the lag between activity and its own slow feedback, so the network integrates *nothing* and still moves — and the two forces compete when both are present, which is what produces anticipative tracking.
- **[[wiki/entities/stp-flickering-cann.md]]** — the sibling destabilisation mechanism with the opposite sign: short-term plasticity is a *per-synapse* trace that pulls the state back toward the map just abandoned, adaptation is an *activity-following* current that pushes it away from wherever it is now.
- **[[wiki/entities/fly-central-complex.md]]** — the anatomical CANN in which this page's claims are directly testable: the head-direction bump's measured drift in darkness and its persistence with no input are the static-bump regime, and a speed-independent anticipatory lead is what the smooth-tracking solution predicts for any such ring.
- **[[wiki/concepts/offline-replay.md]]** — supplies a generator for spontaneous sequences that needs no stored sequence: above the mobility threshold the bump sweeps the manifold on its own, and near the threshold with noisy gain it produces Lévy-distributed jumps matching reported statistics of place-cell reactivation during immobility.
- **[[wiki/concepts/simulation-based-planning.md]]** — makes the rollout/hold decision a continuous parameter rather than a discrete mode switch: adaptation gain relative to input strength interpolates from "locked to the world" through "sweep around the current estimate" to "run free through the state space".
- **[[wiki/concepts/working-memory.md]]** — quantifies the cost of maintenance: the same adaptation that lets a stored state be updated quickly is what destabilises it, and `m = τ/τ_v` is the exact point at which a maintained value stops being maintained.
- **[[wiki/concepts/predictive-coding-free-energy.md]]** — a prediction-ahead with no prediction: a constant anticipation time emerges from a speed competition inside the dynamics, so lead time is set by a gain rather than by a learned generative model or an error signal.
- **[[wiki/concepts/energy-based-models.md]]** — the landscape made non-stationary by construction: adaptation raises the energy of the currently occupied minimum, so the state cannot rest, which is a mechanism for the multi-modal exploration that page lists as unmechanised.
- **[[wiki/concepts/inhibitory-control-of-coding.md]]** — the global inhibitory pool enters only as a divisive-normalisation scalar `k`, and that scalar sets a hard existence boundary (`k < k_c2`) for the bump — the abstraction that page argues against, here carrying a phase-transition threshold.
- **[[wiki/concepts/synaptic-plasticity.md]]** — the dynamics are indifferent to which slow negative feedback supplies them (spike-frequency adaptation or short-term depression), so this is a case where a *computational* role is pinned down while its synaptic implementation is explicitly left open.
- **[[wiki/concepts/population-geometry.md]]** — a worked instance of dimensionality reduction done analytically rather than empirically: projecting onto the bump's height and position motion modes turns `2N` neurons into a 4-D state space that preserves the bifurcation structure.
- **[[wiki/entities/rolls-treves-hippocampal-model.md]]** — the discrete-attractor counterpart of the same trick: adaptation there walks the state through a chain of stored attractors driven by spiking noise, here it walks a continuous manifold driven by its own lag, and both derive a *dynamical* rather than a slot-based notion of how much can be held.
- **[[wiki/entities/hopfield-network.md]]** — the static counterpart whose symmetry forbids motion: the same relaxation-to-a-minimum with discrete fixed points and no adaptation, so it holds a memory but cannot track, anticipate or sweep — the deficit this page's slow negative feedback exists to remove.
- **[[wiki/entities/hodgkin-huxley-model.md]]** — supplies single-unit derivations of both of this model's abstracted terms: divisive inhibition `k` is what a rest-reversal conductance does biophysically, and the adaptation variable `v` that destabilises the bump is the network-scale counterpart of sodium inactivation `h`, a slow negative feedback driven by the fast variable.
- **[[wiki/concepts/attractor-dynamics.md]]** — this model is the stability-vs-mobility dilemma of relaxation resolved by one scalar, with analytic thresholds for each regime.
- **[[wiki/entities/pbwm.md]]** — the same hold-versus-update conflict resolved discretely: a per-stripe binary gate whose *timing* is learned, instead of this page's continuous adaptation gain with a closed-form threshold — so failure is a mistimed overwrite rather than drift.
- **[[wiki/entities/trnn.md]]** — this page's adaptation term (`τ_v dV/dt = −V + mU`) transplanted into a trained ReLU network: the travelling-wave regime above `m = τ/τ_v`, learned rather than derived, and shown to be the better working-memory design on distractor, multi-item and spatial navigation tasks (Liu et al. 2025).
