# Sigma-Pi Reservoir — splitting a reservoir into a buffer and a separately-configured feature expansion

**Take the two jobs a reservoir is supposed to do at once — buffer the recent input history, and expand it into nonlinear features — and put them in two different circuits. The buffer stays a standard linear reservoir (a permutation ring). The expansion becomes a network of *Pi* neurons that multiply their inputs, computing vector-symbolic **binding**, which the paper proves is an unbiased randomized approximation of the polynomial kernel `⟨x,y⟩^p`. The feature space is then configurable — order, delay set and dimensionality are three independent knobs — and its dimensionality grows *quadratically* in polynomial degree instead of exponentially.**

> **Provenance.** Kleyko, Kymn, Thomas, Olshausen, Sommer & Frady, *Principled neuromorphic reservoir computing*, Nature Communications 16 (2025-01-14) (`raw/kleyko-2025-neuromorphic-reservoir-computing.md`). Baselines: Gauthier et al. 2021's "next-generation reservoir computing" (the explicit product representation), an echo state network, and a multilayer perceptron. Hardware: Intel Loihi 2, programmed via *Lava* / *Lava-VSA*.

This is the wiki's first page where [[wiki/concepts/vector-symbolic-binding.md]] is not a representation *choice* but a **derived answer to a function-approximation question**, and its first VSA store with an explicit dimensioning rule.

## The claim the architecture rests on

Two ways to combine state vectors from different time points, and their similarity structures:

| Operation | Representation | Inner product of two trajectories | Reading |
|---|---|---|---|
| **Concatenation** `⊕` | `V_C = X(i−1) ⊕ X(i)` | `⟨X(i−1),X(j−1)⟩ + ⟨X(i),X(j)⟩` — a **sum** | Two trajectories are similar if they agree at *any one* time point |
| **Tensor product** `⊗` | `V_T = X(i−1) ⊗ X(i)` | `⟨X(i−1),X(j−1)⟩ · ⟨X(i),X(j)⟩` — a **product** | Similar only if they agree at *all* time points |

Sum-similarity is *disjunctive*, product-similarity is *conjunctive*. A task-relevant feature space needs both, mixed deliberately. The paper's central correspondence (after Frady et al.'s sparse block codes) is that the VSA algebra reproduces both at fixed width:

```
superposition + permutation   ≈  concatenation          (a memory buffer)
binding (∘)                   ≈  tensor product         (higher-order features)
```

So the explicit *product representation*

```
G = ⊕_{t∈T} vec( ⊗^t ( ⊕_{l=1}^{k} X(M_l) ) )        dim = Σ_t C(dk+t, t+1)      — exponential in order
```

has a dimensionality-preserving randomized twin

```
F = Σ_{t∈T} ( ∘^t ( Σ_{l=1}^{k} W_ρ^{l−1} ( W_in X(M_l) ) ) ) ∈ ℝ^D      — D is a free hyperparameter
```

where `W_in ∈ ℝ^{D×d}` is a random projection (the same first step as any reservoir), `W_ρ` is a mixing matrix with the echo state property — in practice a **permutation** `ρ`, one synapse per neuron — and `M = (i, i−s, …, i−(k−1)s)` is the chosen delay tuple. `T` selects which polynomial orders are present.

### The dimensioning rule — the wiki's first one for a superposition store

For the homogeneous polynomial kernel `κ_p(x,y) = ⟨x,y⟩^p`, build `φ_p(x) = ψ_1(x) ∘ … ∘ ψ_p(x)` with `ψ_t(x) = (1/√D)·W^{(t)}x`, components i.i.d. zero-mean unit-variance. Then

```
E[ ⟨φ_p(x), φ_p(y)⟩ ] = ⟨x,y⟩^p = κ_p(x,y)
```

for component-wise product, circular convolution and block-wise circular convolution binders alike — and (Pham & Pagh, via Hoeffding) for any `ε > 0`,

```
D = O( (pR/ε)² ),        R = max(‖x‖₁, ‖y‖₁)
```

suffices for `|φ_p(x)·φ_p(y) − κ_p(x,y)| ≤ ε` with high probability. **`D` is quadratic in the polynomial degree where the explicit feature map is exponential.** This is the price/fidelity curve [[wiki/architectural-gaps.md]] G42 says no machine fast store has: it says how many dimensions buy how much similarity fidelity at what order, and therefore when the store is full.

**Remark 1 is an implementation gift.** `p`-wise independence is enough, so `ψ_2 = ρ(ψ_1)`, `ψ_3 = ρ²(ψ_1)`, … — one projection matrix stored once, the rest generated by a permutation with cycle time ≥ `p`. The buffer's mixing matrix and the kernel's independent draws are *the same permutation*.

## The circuits

| Neuron | Computation | Role |
|---|---|---|
| **Sigma** | inner product of inputs with weights, emitted as one graded spike; optional threshold suppresses small outputs (spike-traffic reduction) | superposition, aggregation, the linear buffer |
| **Pi** | two input channels, each accumulating synaptic input; emits their **product** | binding / tensor product |

Resource cost of the feature stage, by VSA model (`D` = dimension, `d` = input channels, `L` = block size):

| VSA model | Binding operation | Pi neurons | Sigma neurons | Embedding synapses |
|---|---|---|---|---|
| HRR | circular convolution | `D²` | `D` | `dD` |
| MAP (multiply-add-permute) | Hadamard product | `D` | — | `dD` |
| SBC (sparse block code) | block-wise circular convolution | `DL` | `D` | `dD/L` |

Two structural consequences:

- **The binder is recurrent-reusable.** Binding is closed at width `D`, so its output can be fed back into one of its own input populations: order-`t` features cost `+D` one-to-one synapses and `t` extra iterations, **not** extra circuitry. Arbitrary polynomial order at constant hardware.
- **The buffer is nearly free.** A permutation matrix is the simplest effective reservoir — one synapse per neuron.

**Loihi 2 realisation.** 24-bit "graded spikes" carry vector components as fixed-point integers (binary point `2^12`; 8-bit weights at `2^7`); Pi neurons are written with the chip's programmable neuron engine. Sparse block codes are chosen because sparsity is what the chip rewards: `K = 10` blocks of `L = 20`, `D = 200`.

## Results

**Chaotic-system autoregressive prediction (CPU).** Lorenz63 (`dt = 0.025`, `r = 400` training points ≈ ten Lyapunov times), double-scroll, Mackey–Glass; readout is ridge regression in every condition.

| System | Explicit product representation | Randomized distributed representation | Reading |
|---|---|---|---|
| Lorenz63 | 28 features | **matches at `D = 28`** | Parity at equal dimension — not a compression that costs accuracy |
| Double-scroll (1st + 3rd order) | 62 features | matches at `D = 34` | **45% fewer dimensions** |
| Mackey–Glass | 3rd order, `D = 84`, NRMSE `3.59×10⁻¹` | 4th order at `D = 100`, NRMSE `1.80×10⁻¹` | 4th order costs +150% dimensions explicitly, **+19%** here — the error halves |

Echo state network baseline improves with `D` but needs more of it than the higher-order feature spaces on Lorenz63 (not guaranteed on every system). The multilayer perceptron is "nowhere near" on any of the three.

**Loihi 2 (target: a random quadratic function of the two most recent Lorenz63 states).** Three networks: buffer only; second-order features of the current state only; buffer **and** its second-order features. Only the third predicts well, and its error falls with block count. Neither of the first two contains features matching the target — *the feature space is diagnosable by inspection*, which is the whole point of making it configurable. Chip results track their CPU counterparts closely across eight random instantiations.

## What this changes in the wiki

**1. It splits a reservoir claim the wiki has been carrying whole.** Every reservoir page here treats one recurrent circuit as simultaneously the memory and the nonlinear expansion. The paper's premise, sourced to the reservoir literature itself, is that **saturating pointwise nonlinearities mainly cause memory fading and leave a feature space closely resembling a linear recurrent network's** — the reservoir is doing the concatenation job and only weakly the tensor-product job. [[wiki/entities/simple-cycle-reservoir.md]] proved the recurrent coupling is expressively free within the fading-memory class; this says the *nonlinearity* is nearly free too, in the sense that it does not deliver the higher-order features it is credited with. That relocates the design question from "which recurrent topology" to "which polynomial orders, over which delays, at what dimension" — three named knobs, plus ridge regularisation `α`. See [[wiki/empirical-tensions.md]] T238.

**2. It gives the VSA line an approximation theory instead of an analogy.** [[wiki/concepts/vector-symbolic-binding.md]] justifies binding by its algebraic properties (closure, invertibility, similarity preservation) and prices it in dot-product variance. Here binding is *derived*: it is the operation whose expected inner product equals the polynomial kernel, and the variance is bounded as a function of `D` and degree. Fractional binding already made similarity a tunable kernel; this makes **the whole superposition** a kernel machine's feature map, with the standard kernel-machine cost (quadratic in data points) traded for a fixed `D`.

**3. It contradicts the wiki's "VSA needs huge dimensionality" premise.** [[wiki/concepts/vector-symbolic-binding.md]]'s preconditions say `n` in the low thousands. Here `D = 28` matches an explicit 28-feature basis, and `D = 200` runs on-chip. The paper says this outright — "randomized distributed representations attain strong performance even with low dimensions, which contradicts the existing narrative". The reconciliation is that the two are counting different things: Plate needs `n` large enough to keep *many superposed symbolic items* mutually near-orthogonal and decodable, while here `D` need only be large enough to make a *scalar kernel value* accurate, and nothing is ever unbound. **Decoding, not representing, is what costs dimensions.** `(brainstorm)`

**4. It supplies the compositional spike encoding [[wiki/concepts/spike-encoding-schemes.md]] said did not exist.** That page's standing complaint is that every catalogued scheme encodes a scalar or a vector of scalars, so "the interface into every spiking architecture in the wiki is flat". A graded-spike SBC vector on Loihi 2 carrying a bound role–filler structure is a relation presented to a spiking substrate, with a hardware cost table attached.

**5. It is the wiki's cleanest instance of an architecture read off a mathematical requirement.** `(brainstorm)` G29 asks for architecture search to be mechanised. [[wiki/entities/simple-cycle-reservoir.md]] constructs a reservoir from a *target linear system*; here the target is a *function class* (polynomials of order `T` over delays `M`) and the circuit — buffer width, Pi-neuron count, recurrence depth — falls out of Table 1 by arithmetic. Neither searches. Both suggest the mechanisable version of G29 is "state the function class, then compile", and the open question is what states the function class.

## Limitations

| Limitation | Consequence |
|---|---|
| **Fading memory throughout** | The buffer is a contractive/permutation reservoir and the feature stage is memoryless. Everything [[wiki/entities/simple-cycle-reservoir.md]] excludes — non-decaying variable binding, discrete state, a rule applied `10⁶` steps later — is excluded here too. Higher-order features enrich *what function of the recent window* is computed, not *how far back the window reaches* |
| **The delay set `M` and order set `T` are hand-chosen** | The configurability is the contribution and also the unpaid bill: nothing selects which orders or which delays a task needs. `D` alone has a heuristic (start at the product representation's feature count, then reduce) |
| **The approximation is noisy by construction** | The recovered kernel is the true kernel plus concentration noise; there is no certificate on any single inner product (the same defect as every approximate matcher here, G37/G17) |
| **Readout is ridge regression on a fixed feature space** | No learning anywhere except one linear layer. The features are randomized, not fitted — this is a random-feature method, and it inherits the usual worse-than-learned-features scaling on high-dimensional inputs |
| **Prediction only** | Every experiment is autoregressive forecasting of low-dimensional chaotic systems. No classification, no structured output, no task where the polynomial-kernel assumption is questionable |
| **Sigma-Pi neurons are idealised** | The paper's biological defence is one citation to multiplication-like nonlinearity in single cells; it does not claim the circuit is a cortical motif |
| **Diminishing returns** | Beyond a point, much larger `D` buys slight NRMSE improvement — same shape as the explicit representation, just shifted |

## Connections

- **[[wiki/concepts/vector-symbolic-binding.md]]** — supplies the theory that page's algebra never had: binding is the operation whose expected inner product *is* the polynomial kernel `⟨x,y⟩^p` (for Hadamard, circular-convolution and block-convolution binders alike), superposition-plus-permutation is concatenation, and the resulting dimensioning rule `D = O((pR/ε)²)` prices the dot-product variance that page pays in — while contradicting its stated precondition of `n` in the low thousands (`D = 28` suffices when nothing is ever unbound).
- **[[wiki/entities/simple-cycle-reservoir.md]]** — the same demotion of the recurrent circuit from the other side: that page proves the *coupling* is expressively free inside the fading-memory class, this one argues the *nonlinearity* fails to deliver the higher-order features it is credited with and moves them to a separate Pi-neuron circuit — and both then use a permutation ring as the buffer, so the two constructions agree on what is left of the reservoir.
- **[[wiki/entities/liquid-state-machine.md]]** — the monolithic thesis this splits: the LSM's separation property is supplied by a single richly heterogeneous spiking circuit that buffers and expands at once, where here the buffer is a bare permutation and the expansion is an explicitly ordered polynomial basis — so the LSM's biological richness is being asked to do a job that can be specified, configured and priced instead.
- **[[wiki/entities/hag-reservoir.md]]** — the opposite response to the same complaint about random reservoirs: HAG grows the recurrent graph to improve the feature space, this leaves the recurrent graph maximally trivial and adds an orthogonal circuit for the features, so the two make rival claims about where a reservoir's expressive deficit lives (T238, T174).
- **[[wiki/entities/spiking-neural-networks.md]]** — the substrate demonstration and a demand on it: Loihi 2's 24-bit graded spikes and programmable neuron engine make a Sigma-Pi VSA circuit implementable today, and the resource table (`D` vs `DL` vs `D²` Pi neurons) is a rare case of a representation chosen *because of* a hardware sparsity constraint rather than despite it.
- **[[wiki/concepts/spike-encoding-schemes.md]]** — closes that page's "no compositional encoding" gap: a sparse-block-code vector transmitted as graded spikes encodes a *binding*, not a scalar, so the interface into a spiking architecture need not be flat — at a stated cost of `DL` Pi neurons and `dD/L` embedding synapses.
- **[[wiki/concepts/dendritic-computation.md]]** — the biological warrant for the Pi neuron, and the wiki's stronger version of it: this page needs multiplication of two synaptic input groups, and dendrites supply a whole bank of independent supralinear cluster detectors per cell — so a Pi neuron is a deliberately minimal read of a nonlinearity the biology has in abundance.
- **[[wiki/concepts/retrieval-capacity.md]]** — the second dimensioning bound in the wiki, and a mismatched one: that page bounds `d` by *which subsets a similarity store can return*, this bounds `D` by *how accurately an inner product approximates a kernel*, and the gap between them is exactly the decoding step this scheme never performs.
- **[[wiki/concepts/sparse-distributed-representations.md]]** — sparse block codes used as an engineering choice rather than a coding-theoretic one: sparsity is selected because Loihi 2 charges for synapses, and it buys a `1/L` factor on the embedding at the cost of `L`× more Pi neurons.
- **[[wiki/concepts/autonomous-pattern-generation.md]]** — the same reservoir-plus-linear-readout skeleton pointed at prediction instead of generation: both keep all training in one ridge-regressed layer, and both are bounded by the driver — a clock there, the delay tuple `M` here.
- **[[wiki/concepts/latent-graph-discovery.md]]** — a fully specified *observation-to-feature* stage with no discovery in it: the delay set, the polynomial orders and the dimension are all authored, so what this contributes to the target problem is a cheap, configurable, hardware-realisable substrate for whatever does the discovering.
- **[[wiki/concepts/compositionality.md]]** — compositionality justified by approximation theory rather than by productivity: the reason to build features by binding here is that the resulting similarity is a *product* of constituent similarities, which is the conjunctive semantics a composed representation is supposed to have.
