# S4 (Structured State Space sequence model)

**A *linear time-invariant* state-space model whose state matrix is initialised to a HiPPO continuous-time-memorisation matrix and reparameterised as normal-plus-low-rank, so that one parameter set can be evaluated three ways — as a continuous ODE, as an `O(N)`-per-step recurrence, or as a single global FFT convolution — and whose long-range ability, by the paper's own ablation, comes from that *initialisation* rather than from the parameterisation, the training, or the architecture.**

> **Provenance.** Gu, Goel & Ré 2022, *Efficiently Modeling Long Sequences with Structured State Spaces*, ICLR 2022 (`raw/gu-2022-s4-structured-state-spaces.md`). Body text only; the source file has **all figures dropped** (Fig. 2's Path-X kernel visualisations, Figs 3–4's ablation curves) and **two internal numeric inconsistencies** (see Limitations), so the ablation is held from prose and the exact separation sizes are unavailable.

Why the wiki holds this page:

1. It is the **first system here to carry a dependency of 16,384 steps** — a task every prior sequence model answers at chance — and it does so with a *linear, contractive, fading-memory* state update, i.e. from inside the class [[wiki/entities/simple-cycle-reservoir.md]] proved most reasoning operations are excluded from. That forces the wiki to separate "fades" from "fades too fast to be useful", which it had been conflating.
2. Its ablation is the wiki's cleanest instance of **long-range capability being a property of an initialisation, not of an architecture** — every initialisation reaches 100% train accuracy and they differ by >15% in validation ([[wiki/empirical-tensions.md]] T177).
3. It prices the conditioning question T174/T175 left open: the state matrices that *work* are exactly the ones that are maximally **non-normal**, and their exact diagonalisation has entries of size `2^{4N/3}`. *(Superseded in part: [[wiki/entities/lru.md]] shows a **normal** diagonal matrix drawn from the same spectrum beats the dense non-normal one at matched initialisation — T311. What is left of this point is that HiPPO specifically is non-normal, not that non-normality is what works.)*

## The object

The continuous state-space model, one 1-D input channel to one 1-D output channel through an `N`-dimensional latent state:

```
x′(t) = A x(t) + B u(t)          A ∈ R^{N×N},  B, C ∈ R^{N×1}
y(t)  = C x(t) + D u(t)          D absorbed as a skip connection, set to 0
```

Discretised by the **bilinear (Tustin) transform** at step size `Δ`, giving a recurrence and, by unrolling from `x_{−1}=0`, a convolution:

| View | Form | Cost | Used for |
|---|---|---|---|
| **Continuous** | `x′ = Ax + Bu` | — | changing the sampling rate; `Δ` is the resolution of the implied underlying signal, `u_k = u(kΔ)` |
| **Recurrent** | `x_k = Ā x_{k−1} + B̄ u_k`, `y_k = C̄ x_k` | `O(N)` per step, `O(N)` state | autoregressive generation at constant memory |
| **Convolutional** | `y = K̄ ∗ u`, `K̄ = (C̄B̄, C̄ĀB̄, …, C̄Ā^{L−1}B̄)` | one FFT pair, given `K̄` | parallel training |

The three are the **same operator**, not three approximations of it. That is the architectural primitive worth extracting: a sequence model that is simultaneously a differential equation, an RNN, and a CNN, with the mode chosen per use rather than per model.

### Why a generic `A` fails, and what HiPPO does

A linear first-order ODE solves to an exponential, so a random `A` gives gradients scaling exponentially in sequence length — the vanishing/exploding problem in its purest form. **HiPPO** (Gu et al. 2020; Voelker et al. 2019) specifies a class of `A` for which the state `x(t)` is the coefficient vector of a projection of the input history onto an orthogonal polynomial basis — the state *is* a compressed encoding of the entire past, not a leaky accumulation of it.

The size of that swap, measured by the predecessor model (LSSL): **sequential MNIST 60% → 98% from changing `A` alone.**

## The computational problem, and the three-step fix

Everything below exists to make `K̄` computable. Computing it naively is `L` successive multiplications by `Ā`: `O(N²L)` time, `O(NL)` space, against an `Ω(L+N)` lower bound. At `N = 256` the predecessor LSSL used orders of magnitude more memory than a comparable RNN.

**Lemma 3.1 (conjugation is an equivalence relation on SSMs).** `(A,B,C) ∼ (V⁻¹AV, V⁻¹B, CV)` computes the *identical* operator `u ↦ y`, with the state merely re-based by `V`. The state basis is unobservable from the input/output map.

> This is the second independent statement of that fact in the wiki — [[wiki/entities/simple-cycle-reservoir.md]] Prop. 12 is the same lemma — and both papers build their entire method on it. **Any claim about what a linear recurrent model's state "represents" is a claim about a chosen basis, not about the model.**

**Lemma 3.2 (the obstruction).** The HiPPO matrix is diagonalised by `V_ij = C(i+j, i−j)`, with `V_{3i,i} = C(4i, 2i) ≈ 2^{4i}` — entries up to `2^{4N/3}`. The good matrix is *maximally non-normal*: it is not unitarily diagonalisable, and its exact diagonalisation is numerically infeasible. A previously proposed fast algorithm for `K̄` is proved unstable for the same reason.

**The S4 parameterisation (NPLR → DPLR).**

| Move | Mechanism | Effect |
|---|---|---|
| **Normal Plus Low-Rank** (Thm 1) | Every HiPPO matrix (LegS, LegT, LagT) is `V Λ V* − P Q^T` with `V` unitary, `Λ` diagonal, and rank `r = 1` or `2` | Conjugating by the *unitary* part is free; only a rank-1 correction is left. Over `C`, this is **diagonal plus low-rank (DPLR)** |
| **Truncated generating function** | Compute `Σ_{j<L} K̄_j ζ^j` at the `L`-th roots of unity, then one inverse FFT | Replaces a matrix **power** with a matrix **inverse** (the resolvent) |
| **Woodbury identity** | `(A + PQ*)⁻¹` in terms of `A⁻¹` | The low-rank correction is removed; the problem reduces to the diagonal case |
| **Cauchy kernel** | The diagonal case *is* `1/(ω_j − ζ_k)` — a Cauchy matrix, with stable near-linear algorithms via the Fast Multipole Method | `Õ(N+L)` time, `O(N+L)` space |

**Theorem 2 (recurrence).** One step in `O(N)`: `Ā` is a product of two DPLR matrices, since the inverse of a DPLR matrix is DPLR.
**Theorem 3 (convolution).** `K̄` reduces to 4 Cauchy multiplies, `Õ(N+L)` / `O(N+L)` — essentially tight.

Net against the LSSL at width 512: **29.6× faster training step, 392× less memory**, while *exceeding* its accuracy.

### The layer

Initialise `A` to HiPPO; by Lemma 3.1 and Thm 1 it is unitarily equivalent to `(Λ − PQ*, B, C)` with `Λ, P, Q, B, C ∈ C^{N×1}` — **5N trainable parameters per channel**. `H` independent copies handle `H` features, mixed by a position-wise linear layer (`O(H²) + O(HN)` per layer), with nonlinearities between layers.

**The core module is linear**; the deep model is nonlinear only through the interleaved activations. Structurally this is a depthwise-separable CNN whose kernels are **global** — length `L`, not length 3.

> Follow-up work found this parameterisation can be numerically unstable when `A` has eigenvalues in the right half-plane; the repair is `Λ − PP*` in place of `Λ − PQ*`, i.e. **stability bought by constraining the parameterisation rather than by a penalty or a projection** — the same move [[wiki/entities/ltc.md]] gets from the driving-force form of its ODE.

## Complexity (Table 1)

`L` sequence length, `B` batch, `H` hidden dimension, `N` tied to `H`; tildes are log factors.

| | Global conv. | Recurrence | Attention | **S4** |
|---|---|---|---|---|
| Parameters | `LH` | `H²` | `H²` | `H²` |
| Training | `L̃H(B+H)` | `BLH²` | `B(L²H + LH²)` | `BH(H̃ + L̃) + BL̃H` |
| Space | `BLH` | `BLH` | `B(L² + HL)` | `BLH` |
| Parallel | yes | **no** | yes | **yes** |
| Inference (1 step) | `LH²` | `H²` | `L²H + H²L` | **`H²`** |

S4 is the only column that is best-or-tied on parallel training *and* constant-cost inference. The convolution view buys the first, the recurrent view the second, and Lemma 3.1 is why they are the same weights.

**Path-X** is the entry that matters here: decide whether two markers in a 128×128 image are joined by a path, presented as a length-16,384 1-D sequence with no 2-D prior. ## The ablation: it is the initialisation

Section 4.4, on sequential CIFAR-10 at ≤100K parameters. Figures dropped; prose retained.

| Question | Result |
|---|---|
| Random Gaussian `A` vs HiPPO `A`, frozen | HiPPO far better |
| …with `A` trained | **All initialisations reach perfect training accuracy. Validation accuracies remain separated by over 15%** |
| Random *diagonal* Gaussian `A` (the cheap structured option) | Does not close the gap |
| Random **NPLR** `A` — S4's parameterisation without HiPPO | "still do not perform well" — the effectiveness "primarily comes from the HiPPO initialization, not the NPLR parameterization" |
| Full S4 + 0.1 dropout | **84.27% sCIFAR test at 100K parameters** |

**Three readings the wiki should carry:**

1. **The separator is a prior, not capacity.** Every variant *fits*. What HiPPO supplies is generalisation, and it supplies it through the starting point of an optimisation that then moves freely. Gradient descent does not recover it from data, and does not destroy it either.
2. **NPLR is a compiler, not a model.** The wiki's habit is to read a parameterisation as an architectural claim. Here the parameterisation exists *entirely* to make an `Ω(L+N)` algorithm reachable, and contributes nothing on its own. The architecture-shaped part of S4 is one matrix's initial value.
3. **This is a fourth slot the three-component framework does not have.** Architecture (a linear SSM layer), learning rule (Adam on all 5N parameters), and objective (cross-entropy) are all held fixed across the ablation arms, and the >15% swing lives in none of them. See [[wiki/concepts/three-component-framework.md]].

## What this changes in the wiki

### 1. The fading-memory exclusion list survives — but the wiki's *use* of it was too strong

S4's state update is `x_k = Ā x_{k−1} + B̄ u_k` with a nonlinear readout stack: **precisely [[wiki/entities/simple-cycle-reservoir.md]]'s object** (linear state, all nonlinearity outside the recurrence, contractive `Ā`). The SCR page concluded that enlarging `n` "buys a longer `λ`-exponential horizon, never a non-fading one", and listed variable binding, a rule applied 10⁶ steps later, and discrete state as excluded. **All of that stands.** What does not stand is the implicit corollary the wiki had been leaning on — that a fading-memory model is therefore *practically* short-ranged. S4 carries the Path-X dependency across 16,384 steps with `N` in the tens, from inside the class.

The reconciliation is that SCR's theorem quantifies over *architectures* and finds them interchangeable at fixed `λ` and `n`; it says nothing about **where in the class a given `A` sits**. HiPPO is the answer to that second question and it is worth 15 points of validation accuracy and the difference between 50% and 96% on Path-X. So the operative design variable inside the fading class is not the topology (free, per SCR) and not the width (a rate, per SCR) but **the spectrum and its conditioning** — the quantity T174 and T175 both name as unmeasured and neither measures.

### 2. Non-normality is the load-bearing property, and the two papers escape it in opposite directions

Both papers hit the same wall: the state matrices worth having are not unitarily diagonalisable.

| | [[wiki/entities/simple-cycle-reservoir.md]] | **S4** |
|---|---|---|
| Escape | **Dilate**: Egerváry's construction embeds `W` in a larger *unitary* `U` | **Split**: `A = VΛV* − PQ^T`, unitary part diagonalised, rank-1 part corrected by Woodbury |
| Price | state dimension `n → (N+1)·n·k`, `k > nm` | complex arithmetic, `O(N)` extra parameters, `Õ(N+L)` algorithm |
| What is preserved | exact `ε`-closeness of outputs, `‖W‖` invariant | the exact operator, up to floating point |
| Resulting model | perfectly conditioned, one recurrent parameter | maximally non-normal, `5N` recurrent parameters |

`(brainstorm — now adjudicated against, [[wiki/empirical-tensions.md]] T311)` The pairing suggests a hypothesis the wiki can state and nobody has tested: **non-normality is how a contractive system holds information longer than its eigenvalues suggest.** A normal contraction decays at exactly `λ^k` in every direction; a non-normal one can *transiently amplify* along non-orthogonal eigendirections while every eigenvalue is inside the unit disc. HiPPO's diagonaliser having entries `2^{4N/3}` is a statement that its eigendirections are catastrophically non-orthogonal — which is the same object read as an obstruction (S4's Lemma 3.2) or as a memory mechanism (this hypothesis). If it holds, SCR's ring is universal in exact arithmetic and *useless in floating point at the same `n`*, because it purchased perfect conditioning by discarding the very structure that stores the past. The discriminating experiment is stated in SCR's own limitations and still unrun: construct the C-SCR approximant of a fitted S4 and compare at matched `n`. **Orvieto et al. 2023 ([[wiki/entities/lru.md]]) ran the cheap surrogate and the hypothesis lost.** By the strong circular law a Glorot dense `A` has spectrum uniform on the unit disc, so drawing a *diagonal* `Λ` from that same measure isolates non-normality with the spectrum held fixed — and the diagonal (hence **normal**) arm wins: sCIFAR 72.2 → 86.5, ListOps 50.4 → 58.8, ~8× faster training. The finished diagonal model carries Path-X at 94.2% and a six-task LRA average of 86.3 against this page's 86.09. Non-normality is not the memory mechanism; it is one expensive way to sit in the right part of the spectrum, and SCR's dilation did not discard anything load-bearing. The residual: LRU still loses Path-X and sCIFAR to S4D by 3.3 and 2.5, and nobody has measured `sup_k ‖A^k‖ / ρ(A)^k` on a fitted S4 directly.

### 3. `Δ` is the schedulable timescale register, demonstrated

[[wiki/entities/simple-cycle-reservoir.md]] closes with a brainstorm: a one-parameter recurrent core is an architecture whose memory horizon can be *set* by a controller, with a guarantee that no expressivity is lost at any setting. **S4 runs it.** `Δ` is the step size of the implied continuous system; halving the test-time sampling rate and rescaling `Δ` accordingly preserves **96.30%** of 98.32% on raw speech, with no retraining and no gradient step. A single scalar retunes the entire model's temporal resolution post-hoc.

This is the first *demonstrated* member of the wiki's timescale-register family ([[wiki/concepts/neuromodulatory-metaparameters.md]]), and it differs from the others in a way worth naming: LTC sets the rate **per unit, per instant, from the content** and cannot separate the two ([[wiki/architectural-gaps.md]] G54); CfC gives the rate its own head but multiplies it by elapsed time inside a gate; S4's `Δ` is **global, content-independent, and settable from outside the network** — which is exactly what a neuromodulator is and what neither of the other two provides. The cost is that it is one number for the whole model and nothing learns to set it.

### 4. The LTI boundary, and the triangle it completes

S4's kernel `K̄` is **the same at every position**, independent of the content passing through. That excludes, by construction:

| Operation | Why LTI cannot |
|---|---|
| Copy an item seen earlier because *this* token asks for it | The read is a fixed filter; there is no query |
| Bind a value to a variable and hold it against interference | Requires an input-conditioned write gate |
| Skip a stretch of irrelevant input | Requires an input-conditioned rate |

The wiki now holds all three corners of a triangle, and each one has the other's virtue:

| | Input-dependent rate | Long-range | LRA avg |
|---|---|---|---|
| [[wiki/entities/ltc.md]] | **yes** (`τ_sys = τ/(1+τf)`) | no (conceded) | — |
| **S4** | no (LTI) | **yes** (Path-X 16,384) | 86.09 |
| Liquid-S4 *(secondary source, `(tentative)`)* | **yes** | **yes** | **87.32**, ~30% fewer parameters |

The Liquid-S4 row on [[wiki/entities/ltc.md]] previously floated without a baseline; S4's 86.09 is it, and the delta is +1.2 points at ~70% of the parameters. That is a small margin for a mechanism the LTC line treats as its central idea — worth remembering when the primary source is ingested.

### 5. Path-X is a connectivity query, and it is the closest thing here to a reasoning result

Deciding whether two markers are joined by a path is, stripped of pixels, a **reachability query on a latent graph** — [[wiki/concepts/latent-graph-discovery.md]]'s navigate half, with the graph delivered as an unlabelled raster and the edges to be inferred. It is worth being precise about what it is *not*: the paths are perceptual contours, the answer is one bit, there is no variable, no composition, and no held-out structure. But it is the first task in the wiki on which a *non-attentional, constant-inference-cost* model answers a global relational question over 16K observations that every attention-based model answers at chance — and it does so with a learned local→global filter hierarchy rather than with a traversal.

`(brainstorm)` If the mechanism really is what the dropped figure describes — early layers extracting local contour fragments, late layers integrating them at column scale — then S4 solves path-connectivity by **repeated global smoothing**, not by walking edges. That is a genuinely different algorithm for the same query than [[wiki/entities/maze-solving-transformers.md]]'s adjacency heads or [[wiki/concepts/successor-representation.md]]'s discounted occupancy, and the three ought to be compared on a common connectivity benchmark. Nothing in the wiki does.

## Limitations

| Limitation | Consequence |
|---|---|
| **Linear time-invariant** | One fixed kernel for all content. No selection, no copying, no binding, no input-dependent skipping. This is the whole of what later gated-SSM work exists to add |
| **The result is an initialisation** | By the paper's own ablation. So "S4 is a good architecture" is not the finding; "HiPPO is a good prior on `A`, and NPLR makes it affordable" is. **And the second clause does not survive either** — [[wiki/entities/lru.md]] matches the six-task LRA average, Path-X included, with eigenvalues drawn *uniformly on a ring* and no HiPPO, no NPLR and no discretisation, so what the prior had to supply was a magnitude range near 1 plus a restricted phase (T177) |
| **Numerical instability in the shipped parameterisation** | Conceded in a footnote: eigenvalues can drift into the right half-plane; the repair (`Λ − PP*`) came from follow-up work, not this paper |
| **Internal numeric inconsistency** | The text states Path-X 88% and LRA average 80.48%; Table 4 states 96.35% and 86.09%. Both are reproduced above with the discrepancy flagged. Likely a version skew between text and table; the wiki should not cite a single figure without saying which |
| **Figures dropped in extraction** | Fig. 2 (Path-X kernels), Figs 3–4 (the ablation curves) are absent from the source. The kernel-hierarchy claim and the ablation separations are held **from prose only** |
| **`D` and `Δ` are hyperparameters at training time** | `Δ` is retunable at test time, which is the interesting result, but nothing *learns* it or sets it per input |
| **No abstract reasoning task** | ListOps (59.60%) is the closest and is the weakest LRA column by 27 points. Everything else is perception, audio, forecasting or language modelling. Same boundary as every other sequence model in the wiki |
| **`N` tied to `H` in the complexity table** | The stated training cost assumes it; the scaling in `N` alone at fixed `H` is not reported |
| **Universality not addressed** | Unlike [[wiki/entities/ltc.md]] and [[wiki/entities/simple-cycle-reservoir.md]], this paper makes no expressivity claim at all — it is an algorithms paper with benchmarks. Which is consistent with T175's conclusion that universality was never the useful instrument |

## Connections

- **[[wiki/entities/simple-cycle-reservoir.md]]** — the same object class (linear contractive state update, nonlinearity outside the recurrence) and the same founding lemma (conjugation is an equivalence relation on state-space models: SCR Prop. 12 = S4 Lemma 3.1), reached from opposite ends: SCR proves the recurrent structure is expressively free and pays for it in dimension via unitary dilation, S4 finds the matrices that actually work are maximally *non-normal* (`V` entries up to `2^{4N/3}`) and pays for it with a rank-1 Woodbury correction instead — so S4 is the empirical demonstration that SCR's exclusion list holds while its practical corollary ("fading ⇒ short") does not, and the residual design variable inside the class is the spectrum, which neither paper measures.
- **[[wiki/entities/ltc.md]]** — the complementary half of the same design space and the source of the Liquid-S4 row's missing baseline: LTC makes the *rate* input-dependent and concedes it cannot do long range, S4 fixes the rate entirely (LTI) and carries 16,384 steps, and the secondary-source Liquid-S4 that has both reports 87.32% LRA against S4's 86.09% at ~30% fewer parameters — a +1.2-point margin for the mechanism LTC's whole line is built on.
- **[[wiki/entities/cfc.md]]** — both delete an integrator, for opposite reasons and at opposite prices: CfC removes the ODE solver because stiffness made step count the dominant cost, and loses invertibility and the causal reading; S4 keeps a continuous-time semantics but never integrates it, evaluating a closed-form convolution kernel through a generating function, which is why its `Δ` remains a meaningful physical resolution that can be rescaled at test time where CfC's `t` is a per-sample input to a gate.
- **[[wiki/concepts/attention.md]]** — the sharpest attention-free datapoint in the wiki: on Long Range Arena S4 beats all 11 Transformer variants on every task by 20+ average points and is the only model above chance on Path-X, while generating 60× faster than a Transformer at within 0.8 perplexity on WikiText-103 — so quadratic content-dependent scoring is not what the long-range tasks needed; what it *is* needed for is the content-dependent read S4's LTI kernel structurally cannot perform.
- **[[wiki/concepts/working-memory.md]]** — the strongest available separation between a long *horizon* and a maintained *variable*: 16,384-step dependencies are reachable by a fixed linear filter with an `O(N)` state and no gate, which removes "long-range dependency" as evidence for a working-memory mechanism; what remains diagnostic is holding a value against interference and reading it on demand, neither of which an LTI kernel can express.
- **[[wiki/concepts/temporal-abstraction-options.md]]** — a multiscale temporal decomposition obtained without any hierarchy being imposed: early layers learn kernels covering a few steps of local context, late layers learn kernels spanning the full 16,384 positions at varying frequencies, and the timescale of the whole stack is rescalable after training by the single scalar `Δ`.
- **[[wiki/concepts/neuromodulatory-metaparameters.md]]** — the wiki's first *demonstrated* external timescale register: `Δ` is global, content-independent, and settable from outside the network at test time, retaining 96.30% accuracy at half the sampling rate with no retraining — which is what LTC's endogenous per-unit `τ_sys` and CfC's rate head are both by construction unable to be, and what a neuromodulator actually is.
- **[[wiki/concepts/three-component-framework.md]]** — the ablation lands outside all three slots: architecture, learning rule and objective are held fixed while only the *initial value* of `A` varies, every arm reaches 100% training accuracy, and validation separates by more than 15 points — so the framework's slots do not contain the variable that decided this result.
- **[[wiki/concepts/latent-graph-discovery.md]]** — Path-X is a reachability query (are these two markers joined by a path?) over 16,384 unlabelled observations with the edges to be inferred, solved not by traversal but by a learned local→global filter hierarchy, at 96.35% where every attention-based model is at chance — the navigate half answered by smoothing rather than by walking.
- **[[wiki/entities/maze-solving-transformers.md]]** — the same connectivity question with a different algorithm: an attention head that places weight on tokens at path-length 1 is an explicit learned adjacency, where S4 answers the reachability query with a fixed global convolution and no adjacency anywhere in the model, which makes the pair the wiki's cleanest available contrast between traversal and diffusion as implementations of the same query.
- **[[wiki/concepts/prediction-compression-equivalence.md]]** — the constant-memory version of the same trade: S4's recurrent view holds the entire past in an `N`-dimensional coefficient vector (a HiPPO projection of the input history onto an orthogonal polynomial basis) and generates at `O(H²)` per token, against a Transformer's exact but linearly-growing cache, so the compression is lossy by construction and the loss profile is set by the choice of basis rather than by a learned criterion.
- **[[wiki/concepts/manifold-constrained-learning.md]]** — a rare case where the geometry is chosen rather than discovered and the choice is decisive: the state trajectory lives on whatever manifold `A` imposes, HiPPO's is the coefficient space of a polynomial expansion of history, and swapping it for a random one costs 15 points of generalisation while costing nothing in fit.
- **[[wiki/entities/ms-ssm.md]]** — the stratified version of this page's single initialisation interval, and its sharpest opponent: MS-SSM partitions the *same total state* into `S+2` bands whose eigenvalues are initialised into disjoint intervals (coarse bands near `|λ|=1`), which beats S4 by 3.4 points on ListOps — the column flagged above as S4's weakest — while the headline S6 variant loses to S4 by 4.7 on the other five Long Range Arena tasks; it also prices the variable this page could only name, since at fixed state the *spread* of the spectrum is worth 25 points on ListOps where doubling the state is worth 4, and it supplies a measurement instrument (mean mixing distance, the row-normalised Jacobian) for the local→global kernel hierarchy this page asserts from a dropped figure (Karami et al. 2025).
- **[[wiki/entities/transformer.md]]** — the claim this page's Long Range Arena result falsifies, now sourced: attention was introduced because self-attention gives `O(1)` maximum path length where recurrence gives `O(n)`, on the stated premise that shorter forward/backward paths make long-range dependencies learnable — and a fixed content-independent kernel with `O(L)`-deep flow carries 16,384 steps where every attention variant is at chance ([[wiki/empirical-tensions.md]] T179), leaving content-dependent reading rather than path length as attention's irreducible function (Vaswani et al. 2017).
- **[[wiki/concepts/fast-weight-programming.md]]** — the other constant-state route, and the one that keeps the content-addressed read this model structurally cannot do: a linear-attention head's state is a full matrix written by outer products and read by a query, so copying and binding stay expressible — at the price of a hard `d_dot` capacity bound that a fixed convolution kernel never has to pay because it never claims to store bindings (Schlag et al. 2021).
- **[[wiki/entities/lru.md]]** — this page's ablation conclusion carried to its limit and then priced down: LRU keeps the macro-architecture and the LTI boundary while deleting HiPPO, the ZOH discretisation, the `Δ` parameter sharing and the non-normal structure, and matches the six-task Long Range Arena average (86.3 vs 86.09) with Path-X at 94.2% — showing by direct ablation on S4D that the `(exp(ΔÃ)−I)Ã⁻¹B̃` input multiplier is a **normaliser** equivalent to `γ = √(1−|λ|²)`, that S4D-Lin's small `Δ` was silently supplying a restricted eigenvalue **phase**, and that the matrix exponential's benefit is magnitude/phase decoupling for Adam rather than accurate integration (Orvieto et al. 2023, T177/T311).
- **[[wiki/concepts/parallel-timescale-streams.md]]** — what this page's shared `Δ` rescaling is a single-stream approximation to: `Δ` sets one global decay constant per channel over one sequence of states, while the measured biological arrangement is six state streams with lifetimes spanning ~20 ms to ~3000 ms, identical relative transition structure and no shared clock — a timescale spread this page can match and a stream multiplicity it cannot.
