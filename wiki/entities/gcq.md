# GCQ — Grid-like Code Quantization

**A world model whose codebook is not learned but *is* the attractor set of a continuous attractor network, and whose codeword selection is conditioned on the action sequence — so quantisation runs over an observation–action *trajectory* rather than a frame, and an `n`-step latent is compressed to one discrete starting index per attractor module plus the actions.**

> **Provenance.** Peng, Dong & Wu, *Vector Quantization in the Brain: Grid-like Codes in World Models*, NeurIPS 2025 — `raw/peng-2025-grid-code-quantization-world-models.md`. Peking University (McGovern Institute / Academy for Advanced Interdisciplinary Studies).

Two moves, and they are separable. **(1)** Replace VQ-VAE's learned static codebook with the `N²` bump states of a toroidal CANN — a *prestructured* codebook in the sense of [[wiki/concepts/attractor-dynamics.md]]'s Axis 1, imported into a trained perception pipeline for the first time in the wiki. **(2)** Make the codeword a function of the action history, which collapses spatial and temporal compression into one operation and deletes the two-stage `VQ-VAE + autoregressive predictor` design that every RSSM-lineage world model uses.

## Architecture

| Component | Form |
|---|---|
| **Codebook** | `N²` neurons on a torus `S¹×S¹`; `τ ∂U_{θ,φ}/∂t = −U + ρ Σ W_{θ,φ}(θ',φ') r_{θ',φ'} + I`, Gaussian translation-invariant `W`, divisive normalisation `r = U²/(1 + kρ Σ W U²)`. Fixed points are 2-D Gaussian bumps `e_{θ,φ}(θ',φ') = A exp(−(‖θ−θ'‖²_S + ‖φ−φ'‖²_S)/2a²)` — **one codeword per bump, `K` codewords, `d` neurons each** (`K = d` puts each bump centre on a neuron; `K > d` puts some between neurons) |
| **Why CANN and not a lookup table** | With constant input `I` then released, the network converges to `argmax_{θ,φ} Σ_{θ',φ'} e_{θ,φ}(θ',φ') I_{θ',φ'}` — **the relaxation dynamics *are* the nearest-codeword search**, by inner product, with no explicit comparison over the codebook ([[wiki/concepts/attractor-dynamics.md]]'s search-free-retrieval row, used as a quantiser) |
| **Actions** | Bump displacements: `a^±_θ = e_{θ±Δθ,φ} − e_{θ,φ}`, `a^±_φ = e_{θ,φ±Δφ} − e_{θ,φ}`. 5 per CANN (4 shifts + stay). `m` CANNs run in parallel → up to `5^m` discrete actions, or `dim(A) ≤ 2m` continuous ones; `P`-dimensional attractors give `2P+1` per module. **The dataset-action → CANN-action map is defined by hand and required to be injective** |
| **Latent** | `s_i ∈ ℝ^{m×d}` — `m` parallel bump sequences, quantised independently |
| **Sequence template matching** | For each module `j`, build `K` candidate trajectories `e_i ⊕ a^j_{1:n−1} = {e_i, e_i + a^j_1, …, e_i + a^j_{1:n−1}}` and pick `k_j = argmin_i ‖s^j_{1:n} − (e_i ⊕ a^j_{1:n−1})‖`. **The only free variable is the base index**: `ŝ^j_{1:n} = e_{k_j} ⊕ a^j_{1:n−1}` |
| **Loss** | `L = ‖o_{1:n} − ô_{1:n}‖² + β‖s_{1:n} − sg[ŝ_{1:n}]‖²` — reconstruction + commitment only. **No codebook loss, because there is no codebook to train.** Straight-through estimator for the discrete step |
| **Encoder/decoder** | Must have a *global* receptive field: each code is tied to an action, and changing an action changes the whole observation, so ResNet-style local blocks are wrong by construction. ViT wins on parameters, stability and score |

**The compression claim in one line:** an `n`-frame observation sequence is represented by `m` integers in `[1,K]`, given the actions. Everything else in the latent is regenerated by the CANN's own dynamics — the [[wiki/concepts/path-integration.md]] "store the shift, not the state" result ([[wiki/entities/vector-hash.md]]) applied to a perceptual encoder rather than to a memory.

## Operations on the resulting map

| Operation | Mechanism | Cost |
|---|---|---|
| **Long-horizon prediction** | Match an initialisation sequence to get `e_k`, then keep applying actions to the bump and decoding | One decode per step; latent update is a shift |
| **Goal-directed planning** | Greedy descent on the map: `s_i ⊖ s_j = argmin_{a∈A} ‖s_j + a − s_i‖`, execute, re-observe, repeat until the no-op `a_∅` is selected | **Constant per step** — no rollout, no search |
| **Inverse model** | Encode two observations onto the map, run the same `⊖` operator between them to read out the action(s); the recovered action sequence can then be replayed onto a *different* observation's latent | Same |

## Results

**Encoder/decoder ablation, Google Street View** (FID `r`/`p` = reconstruction/prediction):

| Block | Image size | #Params | FID_r ↓ | FID_p ↓ | PSNR_r ↑ | PSNR_p ↑ |
|---|---|---|---|---|---|---|
| ResNet + FC | 3×80×40 | 330M | 48.05 | 48.57 | 25.70 | 25.59 |
| Hybrid | 3×80×40 | 64M | 21.29 | 22.31 | 29.07 | 28.54 |
| **ViT** | 3×80×40 | 90M | **13.27** | **13.92** | **31.32** | **31.34** |
| ViT | 3×128×128 | 112M | 42.56 | 43.41 | 27.82 | 27.77 |

**Fixed vs learnable codewords** (adding `γ‖sg[s] − ŝ‖²`, i.e. the VQ-VAE codebook loss, so the bumps can move):

| Codebook | FID_p ↓ | PSNR_p ↑ |
|---|---|---|
| **GCQ, fixed** | **43.41** | **27.77** |
| GCQ, learnable | 47.76 | 24.48 |

**Letting the model improve its own codebook makes it worse.** The authors attribute this to training instability — the codes stand in dynamical relations to each other (`e_i + a` must still be a codeword), which a per-code gradient does not respect.

**Long-horizon prediction.** Prediction FID is reported flat in horizon length while VQ+UNet (96M) and VQ+Transformer (121M, TransDreamer-style) degrade; flat in *initialisation* length too. The named failure it fixes: a two-stage model mispredicts after a full rotation in Street View, where GCQ returns to the same bump. Zero-shot prediction on unseen 2DMaze environments, and on 3DShapes where "actions" are abstract feature increments (size, colour) rather than movements.

**Datasets.** 2DMaze (full observability), Google Street View (real, partially observed, translation + rotation actions), MPI3D and 3DShapes (actions = feature-level changes). Static setting: sequence length 1 on ImageNet vs VQ-VAE, reported as minimal degradation (appendix, no numbers in the converted source).

**Planning, inverse modelling and zero-shot transfer are reported by figure only** — no success rate, no baseline, no metric.

## What this settles, and what it does not

**Path-consistency is enforced on the *encoder*, not just on a recurrent update.** G3's answer so far has been "path integration makes it true by construction of the update rule". GCQ is the first case in the wiki where path-consistency is a constraint on a *perception* module: the commitment loss pushes the encoder's output onto an action-integrated trajectory, so the only way the encoder can reduce its loss is to emit codes whose differences are the actions that were actually taken. The quantiser is the enforcement mechanism.

**Rollout stability is imposed, not learned — and that is the whole result.** Because `ŝ_{1:n} = e_k ⊕ a_{1:n−1}`, the predicted latent is a pure function of one index and the action sum. Error *cannot* compound in the latent, which is exactly why prediction FID is flat in horizon where an autoregressive predictor's is not. So the headline comparison is not "a better-fitted dynamics model" but "a model whose dynamics were never fitted"; the price is that the world has no channel through which to surprise it after initialisation, and any mismatch is absorbed silently by the decoder.

**It is the wiki's first implemented instance of G39's anchoring operation.** [[wiki/concepts/cognitive-map.md]] element 2 and G39 describe anchoring as `argmax` over the symmetry group relating a stored frame to the present one, scored by the stored state's predictive fit, and note that outside space nothing supplies the group. Here the group is the torus's own translation group, the offset is `k_j`, and the score is the L2 fit of the whole observation sequence. Two things to keep. (i) It is **batch anchoring, not online reset**: all `n` observations vote jointly on one offset, and thereafter the rollout never re-anchors — the opposite arrangement to the fly's discrete landmark reset ([[wiki/entities/fly-central-complex.md]]) and to TEM's retrieve-to-correct loop ([[wiki/entities/tolman-eichenbaum-machine.md]]). (ii) The group is available *because* the topology was installed, which is why the operation exists here and not on abstract structures.

**The scaffold has every edge, so G6 is maximal rather than absent.** A bump on a torus can always move in all four directions. Nothing in the map represents a wall, a blocked corridor or an unreachable state; the environment's actual adjacency lives only in the decoder's pixels. **(brainstorm)** This predicts a specific failure the paper does not test: goal-directed planning by greedy latent descent should walk into obstacles, because `⊖` scores only latent distance and the latent knows of no invalid transition. That the planning results are qualitative and the 2DMaze observation is a *full view* of the maze makes the untested case exactly the interesting one. The repair the wiki already has for this shape is [[wiki/entities/spacetime-attractor.md]]'s: learn a transition superset and let sensory input *inhibit* the transitions absent here.

**The vocabulary is authored at both ends.** Nodes come from the neuron count (`K` bumps), edges from a hand-written injective map from dataset actions to bump displacements. Set against [[wiki/entities/adaworld.md]], which induces the edge labels from 2000M unlabeled frames and supplies no nodes, the two papers are exact complements and neither has both halves: GCQ has a node set with no discovery, AdaWorld has an edge alphabet with no nodes. G4 and G27 are untouched here — but G27 gains a *fourth* source of discretisation, one the wiki did not have: **the finite neuron count of a continuum**. Discreteness is not thresholded, allocated, or bottlenecked; it falls out of representing a continuous manifold with finitely many units.

**The topology is the assumption, and every dataset satisfies it.** A torus is a product of two cycles. 2DMaze is a grid, Street View is translation plus a rotational axis, 3DShapes and MPI3D are products of bounded factor dimensions — all chosen, plausibly correctly, to be representable on `m` toroidal modules. G47 is not addressed, and the one experiment that touches it points the *wrong* way for learning: making the codebook adaptable degraded every metric. That is a datum for T77 and a new tension T150, with the caveat that the learnable ablation perturbs code *content* within a fixed topology and never tests a wrong topology at all.

**No control metric.** Prediction FID and PSNR against two VQ baselines is the whole quantitative comparison, and the planner is the part with no numbers — G62's complaint, in a paper whose central claim is that the representation makes planning cheap.

## The neuroscience hypothesis, and where it lands

The paper offers GCQ as a computational account of grid-code formation that is neither hand-built tuning nor emergence from a task: **the brain may hold a fixed set of CANN-generated toroidal patterns as a biological codebook, and learning is the assignment of sensory experience to those preexisting patterns.** Supporting citations: toroidal population topology in grid cells (Gardner et al. 2022), toroidal activity in medial entorhinal cortex *before* sensory experience, and the argument that grid codes come from internal recurrent mechanisms rather than feedforward architectures.

This is a third position on [[wiki/empirical-tensions.md]] T38, which the wiki had as a two-sided question (do grid cells emerge from path-integration training, or are they an artefact of the supervised readout target?). The third answer is that they are *installed prior to learning* and neither emerge nor are targeted — and it is the position most consistent with the wiki's existing verdict that the trained-RNN route is non-generic (Schaeffer et al. 2022) and with [[wiki/concepts/objective-identifiability.md]]'s reading that "grid cells fall out of path integration" is closer to hand-designing an attractor via the loss. The paper's own contribution to that debate is architectural rather than biological: it shows the installed version is *sufficient* for a working system, and, in the fixed-vs-learnable ablation, that letting the same system tune the installed patterns costs performance.

|---|---|---|---|---|
| Codebook | Fixed CANN attractors, metrically ordered | Learned, unordered | Continuous, `β`-bottlenecked (no codebook) | Fixed grid-module states |
| Space and time | Compressed **jointly** | Two stages | Two stages (VAE + diffusion) | Memory only |
| Where the action enters | Selects the codeword *trajectory* | Input to the temporal predictor | Induced condition on the predictor | Stored as the shift |
| Action alphabet | Hand-mapped, injective, `≤5^m` | Given | **Induced from video** | Given |
| Rollout error | Cannot compound in the latent | Compounds | Compounds | n/a |
| Planning | Greedy `⊖` on the map, `O(1)`/step | Rollout + search | Cross-entropy-method MPC | n/a |
| Reported control metric | **None** | — | Procgen success rate | — |

## Connections

- **[[wiki/concepts/attractor-dynamics.md]]** — supplies the codebook and the search: the prestructured regime of Axis 1 used as a *quantiser*, where relaxation to the inner-product-maximising bump is nearest-codeword lookup with no comparison step; and the fixed-vs-learnable ablation is the page's first measurement that letting a scaffold adapt costs performance.
- **[[wiki/concepts/path-integration.md]]** — the update rule moved into a perceptual encoder: quantising against `e_i ⊕ a_{1:n−1}` makes path-consistency a *loss constraint on the encoder's output* rather than only a property of a recurrent update (G3), and reproduces the "store the shift, not the state" compression at sequence rather than memory scale.
- **[[wiki/concepts/learned-world-models.md]]** — a fourth transition design point against that page's deterministic/stochastic/hybrid trichotomy: a transition that is *not fitted at all* but is a fixed group action on an installed manifold, which is why its rollout error does not compound and why it cannot represent multi-modal futures or invalid transitions.
- **[[wiki/concepts/cognitive-map.md]]** — the map is the CANN's own state space, so element 1 is installed, element 3 (route planning) reduces to greedy bump displacement at constant cost, and element 2 is implemented for the first time as an `argmax` over the torus's translation group scored by a whole observation sequence — batch anchoring with no online reset.
- **[[wiki/entities/adaworld.md]]** — the exact complement: AdaWorld induces the edge-label alphabet from unlabeled video and supplies no nodes; GCQ supplies a node set (`K` bumps) with a hand-written action map and no discovery. Both are discrete-vs-continuous data for T148, from opposite directions.
- **[[wiki/entities/vector-hash.md]]** — the same prestructured grid scaffold used for memory capacity rather than for perceptual compression; both get their properties from the scaffold being frozen, and both leave the scaffold's origin unexplained (G47).
- **[[wiki/entities/tolman-eichenbaum-machine.md]]** — the learned counterpart: TEM *trains* a path-integrating structural code by predicting observations and corrects drift by retrieval, where GCQ installs the code and corrects nothing after the initialisation window.
- **[[wiki/entities/spacetime-attractor.md]]** — the repair for this page's every-edge problem: a learned transition superset gated down by sensory input gives an attractor map that knows which transitions are unavailable *here*, which GCQ's torus by construction cannot.
- **[[wiki/entities/fly-central-complex.md]]** — the contrast on anchoring: a measured discrete landmark reset that preserves offset, against GCQ's single batch fit over the whole initialisation sequence.
- **[[wiki/concepts/objective-identifiability.md]]** — strengthens that page's reading of the grid-cell emergence literature by removing the loss from the question entirely: here the periodic code is installed, the objective is plain reconstruction, and the representation is what it is regardless.
- **[[wiki/concepts/latent-graph-discovery.md]]** — an instance where the graph is *given in full* — nodes by neuron count, edges by an authored action map, topology by the recurrent weights — and only the observation-to-node assignment is learned; useful as the limiting case that isolates how much of the problem the assignment alone is.
- **[[wiki/concepts/prediction-compression-equivalence.md]]** — compression is the mechanism rather than a diagnostic here: an `n`-frame sequence is `m` integers given the actions, which is what makes the world model and the tokeniser the same object.
- **[[wiki/concepts/simulation-based-planning.md]]** — planning without rollout or search: the goal's map position minus the current one, descended greedily one valid action at a time at constant cost per step, and terminating on a learned no-op.
- **[[wiki/entities/spelkenet.md]]** — the other flow/observation quantiser in the wave, with the interpretability sign reversed: this page's codebook is installed and every code has a known meaning by construction, while a learned flow codebook needs post-hoc *epigraphy* (average the continuous vectors that map to each token) before any expectation can be taken over it.
