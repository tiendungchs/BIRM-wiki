**The finding of this pass is that two of the wiki's three self-checks were themselves broken, and each had been returning a clean result by being wrong in a way nobody could see.**

1. **`S4` was returning ~500 false positives and nobody had run it at scale.** The check compares each table row's column count against its separator row. Written as specified it carries the separator's width *across table boundaries*, so on any page with more than one table every row of every table after the first is measured against the previous table's width. Run over the whole wiki it flagged **over 500 rows**; the corrected form — reset the expected width on the first non-table line — flags **four**, of which **three were real defects**. The correction is one line: `{ w=0 }` as the default action.
2. **The three defects it found include a repeat of the exact expression fixed at the last pass.** `G80`'s unescaped restriction bar `(λ_I,j − λ_V,j)|_{t_k+d_ji}` was repaired in [[wiki/architectural-gaps.md]] at the 264-source pass — and **the same expression sat unescaped in [[wiki/entities/spiking-neural-networks.md]]** the whole time, because the fix was applied to the row that was found rather than to the string. The other two: **`G92`** carried `p(y|do(x))` and `p(y|x)` unescaped, shifting its `From` and `Status` cells two columns left, and [[wiki/entities/default-mode-network.md]] had a **missing cell** in the two-subsystem table (the negative coupling between the medial-temporal and dorsomedial subsystems was written once for a three-column row). All three repaired.
3. **`S1` degraded by 5.7×, and the check is the only reason it is visible.** **17 asymmetric `Connections` edges out of 5,401** — **0.85 per ingest**, against 0.15 at the last pass and 0.10 at the one before. The cause is legible in the list: fourteen of the seventeen point *into* pages created during wave 12 ([[wiki/concepts/transthalamic-context-routing.md]] ×3, [[wiki/concepts/manifold-untangling.md]] ×2, [[wiki/entities/global-neuronal-workspace.md]] ×3), so the asymmetry is a **new-page** effect: an ingest that creates a page reliably links *out* of the pages it touches and does not always return from the new one. All seventeen repaired, each with a sentence stating the relation from the target's side. **`S1` should be read as a wave-shaped rather than a constant cost** — it is near-zero in a wave that writes to existing pages and about one per ingest in a wave that creates them.
