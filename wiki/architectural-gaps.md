# Architectural Gaps

What a brain-inspired reasoning model needs and no current architecture supplies. Updated after every ingest that opens or closes a gap, and rewritten at each lint pass.

**Status key:** `OPEN` — no known solution · `PARTIAL` — solved in a restricted setting · `CONTESTED` — candidate solutions exist and disagree.

> **Provenance:** rows G1–G13 were derived from [[wiki/concepts/latent-graph-discovery.md]] alone; G14–G15 come from the first ingest (Hassabis et al. 2017). Where an ingest has supplied evidence, the `From` column names it. Everything still unmarked records a *mechanism the framing names*, not an architecture the wiki has checked.

| G1 | **Two-level separation exists as a timescale split, not as a factorization** | Meta-graph and instance-graph co-occur in every observation; a flat learner fits the mixture `E_θ[p(obs\|θ)]`, which no individual instance follows — so it cannot transfer at all | The *two learning rates* are instantiated and validated: complementary learning systems (fast hippocampal store + slow cortex + replay) and meta-RL (slow weights training a fast recurrent inner learner). The *factorized code* `p = f(g, x)` is not — no transfer in the historical record moved a factorization. **Where the split is written down by hand it works and is cheap**: a hyperprior over per-agent goal preferences and rationality, with per-agent parameters as the instance level, adapts by an exact Dirichlet–categorical conjugate update in 8 trials and predicts the 9th ([[wiki/entities/hbtom.md]]) — no gradient, no replay. | G2 | **De-aliasing without a hand-built state space** | The same observation recurs at structurally distinct graph positions; without path-sensitive identity the model merges nodes that must stay distinct | Clone cells, or identity carried by path-integrated `g`; sparse conjunctive coding in the fast store gives distinct codes to repeated observations; **module membership as a free identity tag** — 10-month-olds fail to individuate two entities typed by the same core system (duck/truck) and succeed when they are typed by different ones (ball/doll), so a bank of entry-gated priors de-aliases without path context. **Third free tag:**  an *event* is a **set** of co-active predictive encodings, so two identical observations sitting in different active sets are different events without any path integration. **Fourth answer, and the only one that is a tunable circuit rather than a tag:** expansion recoding through a sparse layer whose transfer function is *steeper than identity* — dentate granule cells separate at the smallest input changes and drive the separated code onto CA3 through detonator synapses, with lesion and NMDA-receptor-knockout data showing the step is necessary for discrimination and dispensable for undemanding conditioning (Yassa & Stark 2011). Its price is that it de-aliases *everything*, including repeats that should have been recognised, so it only works with a controller (G38). **Now built, two ways, with complementary costs:** a clone-structured hidden Markov model whose per-observation clone pool is frozen at 0/1 and whose transitions are learned by expectation-maximisation — local, fast, one environment, zero transfer ([[wiki/entities/cscg.md]]) — and an action-accumulated latent that de-aliases by *position* and transfers, but is slow to acquire ([[wiki/concepts/path-integration.md]], [[wiki/entities/tolman-eichenbaum-machine.md]]). Merging them is stated as the obvious next model and not yet done. **Fifth answer, and the only one that is not a computation at all:** *randomization* — the mossy-fibre projection (~46 inputs per CA3 cell) destroys the input's similarity structure and hands the store a random address, so any two events pick near-orthogonal cell sets with no decision, no threshold and no learned code (Rolls 2013). It is confined to the write path precisely because it cannot recognise a repeat, which is what makes the anatomically separate read port necessary rather than merely convenient. **Sixth answer — randomization moved one stage earlier and made exponential** ([[wiki/entities/vector-hash.md]]): a *fixed random* projection from a prestructured grid code into the store, with any pointwise nonlinearity (rectification suffices; a linear layer fails), makes the store's state set strongly full rank, so every one of exponentially many positions is a distinct, error-correcting address and new environments de-alias against all previous ones by taking a random initial phase. Unlike the mossy-fibre version it *can* be read as well as written, because the address is regenerated by the grid dynamics from a partial cue rather than re-hashed | Hardness 3; [[wiki/concepts/complementary-learning-systems.md]], [[wiki/concepts/core-knowledge.md]], [[wiki/concepts/event-segmentation.md]], [[wiki/concepts/pattern-separation-completion.md]] | `PARTIAL` |
| G3 | **Nothing enforces path-consistency of `g`** | The structural code is only a graph position if it *commutes* — same position reached by any path. No training signal or architectural constraint is named that makes it so; without it `g` degenerates into a second content code | **No longer a brainstorm — but conditional.** Path integration builds the code by accumulating action displacements (`z_t = f(Wz_{t-1} + Ba_t)`), so equal total displacement lands on the same code by construction, in four implemented model families and three animal phyla; hexagonal symmetry itself follows from a third-order regularisation term implementable as a non-negativity constraint. | G4 | **Vocabulary co-discovery at scale** | When the alphabet of edge labels is itself latent, primitives *and* their semantics must be induced jointly with structure. | G14 | **No consolidation channel: instance structure never becomes meta structure** | Biology transports one-shot hippocampal bindings into cortical structure by replay during offline periods. Machine replay only stabilizes a *single* learner (decorrelating a training stream); nothing converts what the fast level discovered about one instance into a revision of the meta-graph | Replay/consolidation, named biologically; episodic control uses the fast store for behaviour but has no path back into the slow one. **The biological channel now has a measured selection criterion, and it is not the one machines copied**: replay suppresses salient-but-idiosyncratic stimuli, upsamples rarely-visited space and prefers remote to imminent trajectories, converging on an inductive bias toward *transferable* content — because consolidating everything overfits (Liao & Losonczy 2024; [[wiki/concepts/offline-replay.md]]). That gives the channel a specification a builder can implement (weight rehearsal by cross-episode recurrence and inverse visitation, not by reward or TD-error) and leaves the transport itself unbuilt, plus a new sub-problem: seven jobs claim the same replay budget under incompatible sampling policies. **One of those jobs is not transport at all but *construction*:** awake ripples increasingly co-activate a cue and an outcome never experienced together, without the intermediary, only when the chain ends in reward, and with the outcome cell firing *first* — so the offline period also writes edges the agent never traversed, in the direction of credit rather than of use (Barron et al. 2020; [[wiki/concepts/offline-replay.md]]). **And the transport has a wiring cost nobody prices** (Rolls 2013): reinstating a cortical pattern requires `C^HBP = C^RC · a_nc/a_CA3` hippocampally-originating afferents per cortical cell — ≥12,000 even in the best case — which makes a monosynaptic read-out impossible and forces a *polysynaptic reverse hierarchy* with gradual fan-out per stage. So the sparser the fast store (better capacity), the more expensive the read-back, a trade-off every retrieval-augmented architecture treats as free. The same source disputes the *schedule* (waking, not sleep — [[wiki/empirical-tensions.md]] T34) and adds a confound: a changed cortical representation after learning is not evidence of transfer, since a changed CA1 code alters cortical firing through fixed connections. **A candidate for what the channel carries, one level up from the episode** (Lisman et al. 2018, [[wiki/concepts/memory-allocation-excitability.md]]): an hours-long CREB-dependent excitability tag makes temporally proximal episodes share a cell population *before* consolidation runs, and is proposed (untested) to raise those cells' sharp-wave-ripple participation — so the unit transported would be a tag-glued *cluster* of episodes rather than one episode, which is already an abstraction step, and replay priority becomes a decaying scalar set at encoding rather than a computed quantity. **The valve now has a specification, and it is implementable today** (Lindsey & Litwin-Kumar 2024, [[wiki/concepts/recall-gated-consolidation.md]]): gate the slow store's write by the fast store's recall of the *proposed update*, `Δw_LTM ∝ g(w_STM · w*)`, which filters one-off experience out of long-term storage because reliable and unreliable updates are indistinguishable at a synapse but separable across a population. The gating argument reduces to one broadcast scalar per event — prediction accuracy, reward × decision confidence, or familiarity, depending on the learning rule — so it needs no task boundary, no importance estimate, no stored exemplars and no offline pass, and it provably beats every synapse-local consolidation mechanism when reinforcement arrives in bursts. What it does **not** supply is the transport itself: the slow store still learns from the same event stream rather than receiving anything the fast store discovered, so the gate answers *which* updates deserve to become structure and leaves *how instance structure becomes meta structure* exactly where it was  **The transport is now built, and it inverts the gap's premise** (Sun et al. 2023, [[wiki/concepts/generalization-optimized-consolidation.md]]): a sparse Hopfield notebook one-shot-binds a random index to the slow learner's activity, settles into that index from random initialisation offline, reinstates the slow learner's input and output layers through return weights, and the slow learner runs gradient descent on *its own reactivated targets* — self-distillation from the fast store, with the environment never re-seen. So instance structure does become meta structure, in a linear model, with no privileged access to the data. What the same model shows is that running this channel unregulated is **harmful**: the optimal number of reactivations is finite and set by the predictability of the relation, and past it generalization degrades, falling below chance in low-SNR environments. For a relation the slow learner cannot model — because of noise, architecture mismatch, unobserved inputs or its own attention — the optimal transport is **zero**, which makes permanent fast-store residence a designed outcome rather than an unfinished consolidation and means the fast store is required at deployment, not only during training. The transport's value peaks where stored examples ≈ slow-learner parameters, the double-descent point that is simultaneously the worst regime for overfitting, so the channel is most valuable exactly where regulating it matters most. What remains missing is the regulator itself: the three estimators that work in the model (held-out validation, maximum-likelihood SNR from input–output covariance, initial learning speed) are either biologically implausible or need a prior linking data statistics to predictability that is deferred to meta-learning, and the criterion disagrees with the recall gate above on recurring-but-unmodellable relations ([[wiki/empirical-tensions.md]] T81) **And a constraint on the cargo** (Euston et al. 2012, [[wiki/entities/medial-prefrontal-cortex.md]]): the cortical learner already represents the context, event and response terms at acquisition — what transfers is only the *association among them*, inside a bounded 0–2 h post-task window, with cortical consolidation then continuing ~2 weeks. That makes the machine version a *partial* write (freeze the representations, replay only into the associative weights) rather than a full-parameter distillation, and it predicts the otherwise odd asymmetry that a cortical lesion costs more at remote than at recent delays without the region being dispensable early ([[wiki/empirical-tensions.md]] T97). | [[wiki/concepts/complementary-learning-systems.md]], [[wiki/concepts/offline-replay.md]], [[wiki/concepts/memory-allocation-excitability.md]], [[wiki/concepts/recall-gated-consolidation.md]], [[wiki/concepts/generalization-optimized-consolidation.md]] | `PARTIAL` — the selection criterion is specified and computable, and a transport loop exists in a linear model; what is unbuilt is the regulator that stops it |
| G15 | **No control policy over simulation** | Planning is path search, but nothing decides when to roll out, how deep, which branch, or when the answer is good enough. Without it, model-based reasoning is either always-on (unaffordable) or hand-scheduled (not general) | Prefrontal control of hippocampal rollout, proposed biologically; controller-queries-model architectures implement the interface but not the policy. **Active inference supplies the *when* and the *switch*, not the *how deep*:** homeostatic divergence read as free energy both initiates the rollout and sets its target, the epistemic-vs-goal trade-off arbitrates exploration against exploitation on the same quantity, and dropping bottom-up gain (`γ → 0`) with strong biased competition (`β ≪ 0`) is the operational switch from perception into simulation. **A second candidate for the same half:** a rational *arbitration* between model-based and model-free control on a flexibility-vs-speed trade-off, supervised metacognitively, with habitization as the observed shift — which prices planning against its own cached output rather than against a homeostatic drive ([[wiki/concepts/amortized-inference.md]]). **A third supplies the *interface* in closed form and still no policy:** in an adaptive continuous attractor one scalar — adaptation gain `m` relative to input strength `α` — moves the same circuit continuously from locked-to-input, through oscillating around the current estimate, to running free through the state space, with both switching thresholds analytic (`m = τ/τ_v` and `m = τ/τ_v + α/A_u`), and a noisy gain parked at the boundary makes exploration breadth itself a formula (`α_Lévy = 1 + 2μ/γ²`) ([[wiki/entities/adaptive-cann.md]]). So "when to roll out" and "how broadly" become two continuous knobs rather than mode switches — but what *sets* the gain is exogenous in that model, so the row's missing piece is now sharply localised: a controller for one scalar. No computational account of the metacognitive estimator is given, and neither candidate answers *how deep*. **A fourth candidate dissolves the row instead of filling it**: if the planner is a spacetime attractor, there is no rollout to schedule — the whole trajectory is a fixed point, depth is the number of delay-subspaces (an anatomical constant), and the plan is done when the dynamics converge, so *when*, *which branch* and *when to stop* all disappear and only *how many subspaces to build* remains ([[wiki/entities/spacetime-attractor.md]], Jensen et al. 2026). The cost is that this works only where the structure is already embedded in the weights; novel environments still need the search this row is about. **The first candidate to remove a free parameter rather than add a knob:** written over occupancies the active-inference planning objective is `⟨ℓ,μ⟩ + Φ(μ)`, a linear preference cost plus one convex negative-entropy term, so the epistemic-vs-goal arbitration named above has **no mixing coefficient** — the balance is the objective's geometry (Milosevic et al. 2026). The same result sharpens what is still missing: the nonlinearity means no globally Bellman-optimal value function exists, so "which branch" cannot be read off a cached `V` and the planner must relinearise between iterations; and *how deep* is still unanswered, though now priced, since the mirror-descent smoothness constant is `L = ½T(T+1)` **The first candidate with a *stopping* rule rather than a starting one:** rewriting the same objective as a ρ-POMDP belief utility (`ρ_EFE(b,a) = I_a(b)` for information-gathering actions, `0` for terminal ones) makes *keep looking vs. commit* one scalar comparison — observe while `−c_k + I_k(b) + E_o[max_a V]` exceeds `max_i E_b[R_i]` — and the crossover appears without a tuned threshold, a confidence criterion or a metacognitive estimator (Cooper & Velasquez 2026). Measured against tuned additive bonuses this is exactly where the difference lives: at `w = 100` on Diagnosis a bonus agent takes 13.21 tests for 99.3% success and `−3.63` reward, the derived weight takes 9.73 for 97.1% and `−1.50`, and *planning depth amplifies the miscalibration* rather than damping it. ## How gaps are used

A gap is worth recording only if it is *actionable*: it names a mechanism the wiki would adopt if it existed. Gaps that reduce to "the problem is hard" are folded into the open-problems section of the relevant concept page instead.

**Dependency structure.** These are not independent. G16 sits *under* G1: it says the factorization G1 wants is not the kind of thing data can supply, so G1 is a design decision to be paid for rather than a result to be waited for. G17 is the instrument problem for the whole table — without an out-of-distribution test, no gap can be shown closed, because an architecture that assumed the latent variable away is indistinguishable from one that recovered it. G1 is the root — G2 and G3 are the conditions under which its factorization is meaningful, and G9 is what happens when it is applied to itself. G7→G8 and G11→G12 are each a problem followed by the mechanism that would dissolve it. G13 is the accounting frame for all of them: an architecture is scored by which hardness sources it reaches, not by whether it "works". G14 and G15 are the two halves of the write/read loop around the factorization: G14 is how the meta-graph gets updated from experience, G15 is how the graph gets used once it exists. G19 and G20 are the corresponding pair one level down, on the *write rule for fast M*: G19 is what gets written, G20 is when the signal that authorizes the write arrives. G18 is the tax on G9's new candidate answer — self-reference buys the third tier, and generalization is the price. G21–G23 open a column the table did not have: what is in the graph *before* learning. G23 is the condition under which installed priors can be stacked at all; G21 is what they cannot do once installed; G22 is the reason G21's candidate answers do not obviously work. G21 also inverts G4 — where G4 asks how a vocabulary is induced, G21 assumes several are given and asks how they are joined.

**What would close one.** A gap closes when an ingest supplies an architecture that (a) instantiates the named mechanism and (b) is tested on a task where the corresponding latent variable is actually hidden. An architecture that assumes away the latent variable does not count as evidence. Per G17, condition (b) means an **out-of-distribution** test with a well-defined intended solution — an i.i.d. result never closes a gap here.

> **Provenance (second ingest).** Rows G16–G17 come from Geirhos et al. 2020; G6 was revised by the same source from "correlational edges can survive" to "shortcut solutions are the default outcome across every subfield studied".

> **Provenance (third ingest).** Rows G18–G20 come from Schmidgall et al. 2023, which also moved G9 from `OPEN` to `PARTIAL` by naming self-referential meta-learning as a candidate third tier. G19 is G6 restated one level down: the same shortcut problem, now in the *write rule for fast M* rather than in the slow learner's weights — which means fixing G6 at the slow level does not fix it at the fast one.

> **Provenance (fifth ingest).** Rows G24–G26 come from Hutter 2000, which also moved G13 from `OPEN` to `PARTIAL` by supplying AIXItl. The source changes the table's status in one respect: G25 is the wiki's first gap with a *proof* that its answer does not exist, rather than a report that none has been found. Its dependents are G17 (an o.o.d. certificate cannot be fully general because active-case optimality is uncertifiable) and G13 (the "which hardness sources to drop" question has no principled answer partly because there is no yardstick to score the drop against). G26 sits under G16 as G16 sits under G1: the bias must be paid for (G16), and the strongest bias available does not buy the thing G1 wants (G26).

> **Provenance (fourth ingest).** Rows G21–G23 come from Revencu & Csibra 2023. They shift the table's centre of gravity: G1–G20 all concern what a learner must *acquire*, while these three concern what it must be *given*, and what being given several disconnected priors then costs. G2 also gains a second answer from this source — an entity typed by a different core system is individuated without any path context, so module membership is a free de-aliasing tag.

> **Provenance (sixth ingest).** Spelke & Kinzler 2007, the primary source behind G21–G23, adds no new row but changes three. G17 gains its second candidate instrument (signature limits + the resource-stress probe), which is the first proposal in the table for certifying a *prior* rather than a learned structure. G23 gains a reason rather than just a statement: an ungated geometry prior would be actively wrong on movable objects, so entry tests are correctness machinery, not efficiency machinery. And the source adds a constraint that cuts across G21–G23 — installed priors must be **defeasible** ([[wiki/empirical-tensions.md]] T11), since the core principles are false outside the scale of action and are in fact overridden, always via an external symbol system.

> **Provenance (seventh ingest).** Butz 2016 adds G27 and moves three rows off `OPEN`: G5 to `PARTIAL` (a processing loop that is genuinely joint at the instance level, still phase-separated at the meta level) and G15 to `PARTIAL` (homeostatic free energy answers *when to plan*, leaving *how deep* to G24). It is the first source to give G16 a concrete architecture-lever proposal rather than a restatement, and the first to give G21/G22 a composition mechanism that needs no shared symbolic format — composition as relaxation to a joint free-energy minimum, with selection falling out as "no minimum, no composition". G27 is a column the table did not have: G1–G26 all concern the graph's *contents*, G27 concerns whether there are discrete nodes at all. Note the dependency it creates: G27 sits under G2 and G3, since identity and path-consistency are only well-posed once the node set exists.

> **Provenance (eighth ingest).** Lake et al. 2017 adds G28–G29 and changes two rows. G17 gains its first *shift-free* instruments — vary the query, not the data — which matters because every earlier candidate required constructing a distribution shift with a known intended solution, and that construction is the expensive part. G15 gains a second answer to *when to plan* that is priced in the currency of control (flexibility vs. speed, arbitrated metacognitively) rather than of prediction error. G28 is the sharpest single test in the table: it holds the transition structure fixed by construction, so it isolates the *use* half of the framing from the *discovery* half, and it is the reason a model-free system and a model-based one are distinguishable at all after both have converged. G29 sits alongside G16 and G26 as the third independent argument that the target is not reachable by optimising a fixed model on more data — G16 says the data cannot select it, G26 says the strongest bias does not expose it, G29 says the search operator cannot reach it.

> **Provenance (ninth ingest).** Richards et al. 2019 adds G30 and re-labels the table rather than extending it: every existing row can now be sorted into the slot it belongs to (objective / learning rule / architecture), and the sort is what exposes G30 — the wiki's rows cluster in the architecture slot, the objective slot is nearly empty, and it is the only one of the three that is *not directly observable* in brains, so the transfer channel could not have filled it. G16 gains a rival count of the control surface (three components, data demoted to an anchor — T15) and G19 gains a sharper diagnosis: an unselective local rule may not merely be writing the wrong edges but writing *orthogonally to every objective*, which by this source's criterion is change rather than learning.

> **Provenance (tenth ingest).** Chollet 2019 adds G31–G32 and rewrites G17's answer column. The shift it forces is that **evaluation is a design problem with a target quantity**, not a genre of test: every earlier instrument in G17 described what a test should *look like*, and this one says what it should *measure* — and adds the requirement none of them had, that the tasks be unknown to the **developer**, since priors and data are two interchangeable ways of buying skill without generalization. G16 is sharpened in the same move: the four levers are the channels through which a developer pays for the intended rule, and the intelligence formula charges for exactly that payment, so the wiki's control surface and its scoring function are two views of one quantity. G26 gains an antagonist rather than an answer — [[wiki/empirical-tensions.md]] T16 — since the shortest curriculum-consistent program is now argued to be the *wrong* object, not merely an insufficiently structured one.

> **Provenance (eleventh ingest).** LeCun 2022 adds G33–G34 and is the first source in the table to arrive as a *design* rather than as a finding, a formalism or a critique — so it changes the answer column of many rows while closing none, because it reports no experiments. G15's *when to plan* is joined by a mechanism for **what to plan toward** at coarse levels (subgoal = a condition on the lower-level state, scored by a learned cost, with the intermediate vocabulary learned rather than predefined) — and G33 is what that mechanism still assumes. G24's depth question is partly relocated rather than answered: if each level's horizon is set by what its representation can still predict, planning depth is read off the encoder instead of chosen. G30 gains its second candidate objective, and G34 is the reason to distrust it — most terms in a representational objective are anti-degeneracy machinery, not signal. G2 gains a cheap de-aliasing rule (allocate a new memory slot when the query is far from every key) and G5's meta half is untouched, since reconfiguration is not structure learning. G28 is the row this source engages most directly and does not close: a *configurable* world-model engine with a separately-specified cost is exactly the transitions/preferences factorization G28 asks for, stated as a design goal — with no demonstration that swapping the cost yields immediate re-goaling.

> **Provenance (twelfth ingest).** Delétang et al. 2023 adds G35 and changes the *type* of two rows rather than their content. G26 stops being an argument and becomes a measurement: a model can hold the best code length on a modality while demonstrably lacking its structure. G17/G31 gain a cheap partial instrument — compression rate as a function of position in the stream, which needs no authored tasks, no labels and no distribution shift, and is honest only as a *necessary* condition (a flat curve on a structured stream means nothing was found; a steep one does not certify what was). G30's objective slot turns out never to have been empty: autoregressive log-loss *is* minimum code length, and the adjusted rate is the same two-part code the genome-bottleneck argument runs with the design/parameter split moved.

> **Provenance (thirteenth ingest).** Choi 2026 adds G36 and sharpens G26's instrument. It is the wiki's first source arguing intelligence is a property of the *finished arrangement* rather than of the process that built it ([[wiki/empirical-tensions.md]] T20), and the first to make recurrence a necessary rather than convenient condition: without a loop no rule can be reused across positions, the domain is pinned to the input dimension, and `ℐ` cannot diverge.

> **Provenance (fourteenth ingest).** Zhi-Xuan et al. 2022 adds no row and supplies the first *worked* answer to three. G1 gains a demonstration that the meta/instance factorization, when authored rather than discovered, makes instance binding an exact closed-form update — which is what the row has been asking for on the acquisition side and cannot get on the discovery side. G23 gains its first implemented near-relative (FEASIBILIZE), gating hypotheses on world state instead of entities on properties. G17 gains a sixth instrument, paired violation of expectation, and with it the table's first evidence of a model scoring *below* chance — a shortcut anti-correlated with the intended rule, which no accuracy-only protocol can distinguish from noise. The source also sharpens what "no structure discovery" costs: the model's environment dynamics are hand-written PDDL, so its win over minimal-bias baselines is unmatched on inputs ([[wiki/empirical-tensions.md]] T21), and every gap about *acquiring* a graph is untouched by it.

> **Provenance (sixteenth ingest).** Ying et al. 2020 adds G37 and is the first source in the table whose contribution is an *operation* rather than a mechanism, a bound or a critique: the wiki had discovery and navigation and had been assuming retrieval between them. It also touches three rows without closing any — G34 gains an anti-collapse device that costs nothing (an asymmetric order energy punishes a constant encoder on its own negatives), G32 gains a case where the curriculum is *derived* from the task's compositional structure rather than tuned (+6% AUROC, lower variance), and G17's problem reappears in miniature: a 97.9 AUROC matcher with 49% precision is the ranking-metric version of "the test cannot certify what the model found".

> **Provenance (nineteenth ingest).** Yassa & Stark 2011 adds G38 and changes G2 and G37 in the same move, because it is the wiki's first source to treat de-aliasing and retrieval as *one* quantity rather than two mechanisms: they are the two sides of a single transfer function from input similarity to output similarity, and the interesting object is neither side but the curve's steepness and offset. That reframing turns a design constant into a control problem (G38) and makes the aging literature an engineering result — a store whose bias drifts toward completion does not forget, it returns a neighbour with confidence. It closes nothing: no functional form is given for the controllers, and the review's own caveat is that the input axis of every published curve is uncalibrated.

> **Provenance (twentieth ingest).** Epstein et al. 2017 adds G39 and splits G37 rather than answering it: retrieval and *orientation* are separate operations, and every schema mechanism in the table had been conflating them. It touches two other rows. G15 gains its first candidate for the *which branch* half — graph-theoretic features (degree and closeness centrality of the current node) are represented in posterior and anterior hippocampus before the search, and breadth-first-search cost shows up in lateral prefrontal cortex — so the pruning information a search needs is read off the map rather than computed by the search. G3's periodic-code candidate gains reach (a sixfold entorhinal *and* ventromedial-prefrontal signal over a morphed-stimulus concept plane, with signal strength tracking performance) and a boundary (the social-space result is a vector code, not a grid, and hippocampal coding of discrete transition-defined spaces needs no continuum at all) — so "maps outside space" is better evidenced than "grids outside space".

> **Provenance (twenty-first ingest).** Whittington et al. 2022 adds G40–G41 and is the first source to *downgrade* a row rather than open one: G3, the wiki's oldest architectural hole, moves from `OPEN` to `PARTIAL` because path integration makes path-consistency a property of the update rule in implemented models — and immediately opens G41, the precondition it needs (the actions must compose). G2 gains two built mechanisms with mirror-image costs (fast-and-local vs. transferable) and the observation that merging them is straightforward and undone. G40 is the row the wiki had no space for: every page here treats factorisation as free, and the warping of grid cells toward stable rewards is a measured case of a brain choosing *not* to factorise.

> **Provenance (twenty-second ingest).** Rolls 2013 adds G42 and is the first source in the table to price a mechanism in *synapses per neuron* rather than describing it. That changes the type of three rows. G38's cholinergic controller acquires a functional form (one scalar moving recurrent read-out gain down and recurrent learning rate up together) and stops being a named neuromodulator. G14's consolidation channel acquires a cost — `C^HBP = C^RC a_nc/a_CA3`, hence a polysynaptic reverse hierarchy — which inverts an assumption every retrieval-augmented architecture makes: a sparser store is *harder*, not cheaper, to read back. G2 gains a de-aliasing answer that is not a computation at all (random hashing on the write path), and with it the reason the read port must be anatomically separate. The row it does not touch is the one it most exposes: this is the wiki's most quantitatively developed hippocampal model and it has no transfer story whatsoever, so capacity and generalisation are being optimised by different models of the same tissue ([[wiki/empirical-tensions.md]] T28).

> **Provenance (Chandra et al. 2023).** Moves G42 from `OPEN` to `PARTIAL` — the wiki's first machine-side store with a derived capacity and a *graceful* overload — and in doing so changes the type of two more rows. G2 gains a de-aliasing answer that is randomization *readable in both directions*, because the address is regenerated by frozen dynamics instead of re-hashed. G37's relaxation answer loses its two worst properties (content-dependent basins, linear capacity) and keeps its worst limitation (no similarity structure among addresses). The row it most exposes is G1: this is a complete instance-level store whose shared level is *installed outright* — grid modules, periods, torus topology and the traversal order of a non-spatial episode are all supplied — so it is the cleanest demonstration in the table that capacity and structure discovery are separable problems, and that solving the first buys nothing toward the second. It also lands a negative result the objective slot (G30) should carry: an unconstrained autoencoder of matched size trained end-to-end by backpropagation is *beaten* by the frozen-scaffold architecture, so the inductive bias is not something the optimiser finds on its own.


> **Provenance (Li et al. 2026).** Touches G42 from the other side without moving it: [[wiki/entities/mm-tem-hippoformer.md]] is the wiki's first fast store whose *forgetting is learned* — a data-dependent gate `α_t = σ(W_α m_t)` decaying the memory MLP's fast weights, alongside a data-dependent write rate and momentum — which is exactly the decide-when-to-forget policy this row says nothing has, supplied with no capacity estimate to decide it against. So the gap sharpens rather than closes: the machinery for graceful forgetting now exists and is trained end-to-end on task loss, meaning the store's effective capacity is whatever the outer loop happened to find, unmeasured and unreported. The row it most exposes is G30 — the same paper fills its objective slot with *supervised bidirectional retrieval* (`x → g`, `g → g` as explicit auxiliary losses, ablating either one degrades generalisation sharply), which is the first candidate objective in the table that targets the address property of `g` directly rather than a spatial readout of it.

> **Provenance (Seelig & Jayaraman 2015).** Opens no row and closes none, but changes the evidential status of G39 and G43. G39's anchoring operation is now *observed running end to end* in a complete, identified population ([[wiki/entities/fly-central-complex.md]]): a reusable ring code, one arbitrary re-assignable landmark offset, winner-take-all selection when two landmarks alias, and — the part no model in the wiki has — an offset-preserving **reset** rather than a precision-weighted blend when landmark and self-motion conflict, with its own defended time constant. What stays open is exactly what the row says: the conversion from visual features to an offset-free orientation estimate is unknown even here, in the simplest instance anyone has. G43 gains a measurement rather than an anatomical inference — concurrent integrators demonstrably disagree about which cue stream to trust (fly heading follows vision, mouse mEC grids follow physical motion; [[wiki/empirical-tensions.md]] T46) — so arbitration is not an abstraction the wiki invented. It also supplies the first isolated test of the third regime every integrator needs and none is evaluated on: hold the code with *both* input streams removed (>30 s, correct on resumption).

> **Provenance (Constantinescu et al. 2016).** Opens no row. Changes G43 by supplying the first *measured relation between two concurrent frames* rather than another instance of one: entorhinal and ventromedial-prefrontal hexagonal codes over the same conceptual space are aligned to a common grid angle, each stable across sessions more than a week apart. If frames are mutually registered, the arbitration this row asks for collapses from coordinate conversion into weighting — but the same data are equally consistent with a single entorhinal code read out prefrontally, so the row's count question ("how many frames are running") is now measurable and still unmeasured ([[wiki/empirical-tensions.md]] T47). It also sharpens G3 and G41 from the evidence side: the abstract space in which a periodic code has been observed is a hand-designed continuous 2D plane whose increments commute by construction, and the authors state as their own open question how such codes behave in conceptual problems not embeddable that way — so the wiki's best abstract-grid result is drawn from exactly the regime where G41 is trivially satisfied.

> **Provenance (Courellis et al. 2024).** Adds G45 and changes the *instrument* column of two rows without moving either. G17's certification problem gains its sharpest negative result yet: in human hippocampus, decoding accuracy for the latent variable was statistically unchanged between sessions with and without one-shot inference, while cross-condition generalization and parallelism rose and then vanished again on error trials — so a protocol that scores decodability would have certified nothing and missed everything ([[wiki/empirical-tensions.md]] T25). G40 gains its second measurement and it points the opposite way from the first: entanglement and factorisation are not endpoints of one axis, because shattering dimensionality and CCGP rose *together* in the same population (T50), so a controller that decides "factorise vs entangle" is choosing which directions to make parallel, not how many dimensions to use. G39 is untouched but sharpened by the mechanism: the abstract context direction is bought by a 60% global firing-rate contraction with one dichotomy's separation spared, which is the first candidate answer in the table to *how* a code is made to generalize rather than what it should look like.

> **Provenance (Mishchanchuk et al. 2024).** Opens no row and closes none, but converts G37's statistical answer from a fit to an intervention. The "maintain a posterior over which stored model is generating the current data" answer had rested entirely on behavioural model comparison (COIN) and on simulations against published place-cell data; here ablating ventral CA1 in trained mice moves behaviour from a state-inference strategy to a cached-value one and removes the state-inference signature from accumbens dopamine, while imaging in the same region finds an abstract, cross-generalizing code for the task's latent context. Retrieval is therefore a *localised, necessary* operation rather than a normative description of behaviour. Two rows are sharpened without moving. G27's allocation criterion gains nothing at all — the fitted agent is a fixed-cardinality 2-state sticky hidden Markov model, so the number of contexts is supplied by the experimenter and the paper is evidence for belief maintenance over a known context set only; the wiki should stop reading causal hippocampal results as support for the nonparametric half. G15's arbitration question gains a mechanism note from the wrong direction: the model-free error signal is computed over the inferred belief state, so "model-free" describes the update rule and not the input, and removing the state estimator leaves a competent Q-learner running over an impoverished state space rather than a broken agent ([[wiki/concepts/amortized-inference.md]], [[wiki/concepts/contextual-inference.md]]).

> **Provenance (Zheng et al. 2024).** Opens no row and closes none, but is the first source in the table to report the setting of G40's knob *as measured in a brain* rather than as a stated rule: two relational structures over one item set are held factored, in non-overlapping hippocampal-formation territory, under exactly the conditions ("the components always co-occur") that the rule predicts should favour an entangled code. It also gives G12 its first evidence that structure types are physically sorted at all, while leaving the router unbuilt, and adds [[wiki/empirical-tensions.md]] T51 against the conjunctive-map assumption that T40/T42 and the whole `p = f(g̃ ⊙ x̃)` line rest on.

> **Provenance (Valero et al. 2025).** Opens no row and closes none, but changes the *type* of G38's answer. Every prior candidate set one scalar for the whole structure; recording all four interneuron families simultaneously shows the separation/completion bias is a vector of separately addressable channels, each causally tied to one feature of the place code and each verified by activating that family alone during behaviour. The gap's actuator is therefore built and characterised, and what remains open is strictly the controller above it. It also lands a smaller point on G44 and on [[wiki/concepts/representation-probing.md]]: unit *classes* can be recovered from intrinsic activity statistics fitted on a small causally-labelled subset and then validated against properties withheld from the fit — no model in the wiki has a unit taxonomy of any kind.

> **Provenance (Sun et al. 2025).** Adds G46 and changes the evidential status of three rows without moving them. G2's de-aliasing answer is now *watched being built* in a brain rather than argued for — and is shown not to be implied by task success, since long short-term memory networks and transformers solve the same aliased sequence with their states still correlated, which adds a false-positive class to G17 (behavioural success, in or out of distribution, does not certify that a learner split its nodes). G38's separation/completion bias gains the observation that the separating axis is *latent-state* distance rather than input distance and that the bias is position-specific within one animal, which is further evidence against the single-scalar shape. G30's empty objective slot gains a concrete candidate term with a demonstrated necessity: nothing in a prediction loss produces orthogonalization, and it appears only under soft winner-take-all competition or an explicit decorrelation penalty ([[wiki/empirical-tensions.md]] T53).

> **Provenance (Qu et al. 2026).** Opens no row and closes none, but changes the evidential status of G39, G14 and G30. **G39** (anchoring a retrieved structure to the present situation) gains its only case where the registration is *inherited rather than recomputed*: four new items inserted into an already-learned conceptual map are reasoned about through the entorhinal grid orientation estimated **before** the insertion, and per-subject agreement between the new items' inferred trajectories and that pre-existing orientation predicts non-local inference accuracy (`r` = 0.21) while being uncorrelated with age — so frame constancy is both the mechanism and a scoreable quantity, and the same regression runs unchanged on any model with a persistent `g` ([[wiki/concepts/cognitive-map.md]]). **G14** (instance structure never becomes meta structure) gains the missing *partial-update* case: what must be protected is selected by role (`g` held fixed, bindings and the metric readout rewritten) rather than by an importance estimate, and the two contributions dissociate — the grid code's contribution to assimilation does not develop with age while the medial-prefrontal distance code's does ([[wiki/concepts/continual-learning.md]]). **G30** (the `g`/`x` factorization occupies only one slot of three) gains its first *external* validation of the architecture bet rather than another instance of it: across 203 developing humans, structural-code strength predicts Raven's matrix-reasoning score and training sessions to criterion, which is the wiki's only measured link between a candidate `g` and the ability the objective slot is supposed to deliver. All of it is cross-sectional and correlational, and the space is a hand-designed 2-D Euclidean plane, so G11's non-embeddable slice is untouched.

> **Provenance (Kanerva 1993).** Opens no row and closes none, but is the oldest source in the table and changes the *type* of three answers. **G42** gains the first capacity model any of these stores had — `τ ≈ 0.10·M`, derived from an explicit signal-to-noise ratio and independent of pattern size — and, more usefully, the first **per-retrieval confidence read-out** (`|s_u|`, each output bit's distance from its vote threshold), which is the observable the row says every machine store lacks. **G38** gains its first *schedule*: the optimal active fraction `p = (2MT)^(−1/3)` falls as the store fills, so the separation/completion set point is load-dependent by derivation rather than by controller, and a machine knows its own load exactly. **G19** gains error-gated writing (CMAC), where the gate is computed from the store's own read rather than delivered by a separate pathway. The same source supplies the counterweight the wiki's random-projection stores need: random addressing is optimal **only for uniform data**, and every known fix — hard addresses drawn from the data distribution, per-location activation radii, per-cue weighted distances — makes the addressing stage data-dependent, which is the one thing [[wiki/entities/vector-hash.md]] and [[wiki/entities/rolls-treves-hippocampal-model.md]] both keep random on purpose ([[wiki/empirical-tensions.md]] T55).

> **Provenance (Chaudhry et al. 2023).** Opens no row and closes none, but splits **G42** in two: every capacity number in the table so far counts *items*, and this source shows that the number of *chained transitions* a store supports is a different quantity with different scaling and a gap that can diverge with network size — so "how full is the store" and "how far can it roll out" are separate questions, and no other entry answers the second. It also moves the knob: capacity here is bought at the read-out nonlinearity with the code, the sparsity and the learning rule untouched, which is orthogonal to every other lever in the row (fan-in, active fraction, address space) and is the cheapest of them to implement. The row it most exposes is not its own but **G1/G30**: the patterns are supplied, the successor of each is supplied, and the entire content of the result is how many supplied edges survive traversal — the storage side of a graph the source has no way to discover. And it lands a warning the whole table should carry: capacity derived from i.i.d. random patterns can be off not by a constant but *qualitatively*, with a network well inside its predicted capacity recalling nothing at all on correlated real data.

> **Provenance (Douglas & Martin 2004).** Opens no row and closes none, but is the first source to supply *anatomy* for three rows the wiki has only ever argued about functionally. **G43** (arbitration between concurrent reference frames) gains a named circuit rather than a hypothesis: the operation [[wiki/concepts/distributed-reference-frames.md]] calls "voting across columns" is, on this account, soft winner-take-all among superficial pyramidal cells mediated by perisomatic (basket, chandelier) inhibition — propagated between columns by patchy lateral connections with a measured 2:1 spacing-to-diameter geometry, and between areas by layer-5 feedback into the superficial layers of other areas. It is *iterated* rather than one-shot, because the selected cells feed back onto the dendrite-targeting interneurons that set which inputs each pyramid integrates, so the competition and the hypothesis space co-evolve — which is a shape no arbitration proposal in the wiki has. What it does not supply is the objective the competition optimises or any simulation of it; the authors label it a tentative hypothesis. **G12** (no routing policy between structure types) gains a candidate primitive: cortex distinguishes *driver* from *modulator* excitatory edges morphologically, so "which input controls what this unit represents" is decided by edge type rather than by a learned gate. **G17** (no protocol can certify structure discovery) gains an instrument from an unexpected direction — the superficial-layer-neuron percentage makes hierarchical depth a continuous quantity *measured from the connectivity*, and it resolves a degeneracy (enormous numbers of hierarchies satisfy the binary feedforward/feedback rule) that its discrete predecessor could not; the machine analogue, estimating a learned hierarchy from the mixing proportion of two edge types and comparing it against the designed one, does not exist. It also lands a caution on every weight-magnitude reading in the table: with <10% of layer-4 excitatory synapses sufficient to drive cortex through recurrent amplification, an edge's weight is not an estimate of its causal influence.

> **Provenance (Litman 2025).** Opens no row and closes none, but changes what the *learning-rule* slot of **G30** costs. The row's complaint is that a design needs an objective a rule can ascend; the standard reply for two-phase energy-based rules was that they only approximately ascend one (exact as `β → 0`). That reply is withdrawn: the contrastive update is the *exact* gradient of the Helmholtz free-energy difference `J(θ) = A(θ,1) − A(θ,0)` at any finite nudging strength, with no convexity, unique-minimum, weight-symmetry or small-`β` assumption, and its apparent bias is a `T·KL(ρ_1‖ρ_0)` regulariser (Theorem 5.1). So for any architecture whose dynamics minimise an energy, objective *and* learning rule are filled by one choice — G30's slot problem is solved for that family, and what stays open is whether `J` is the objective the factorization needs, since nothing here is sensitive to path-consistency. It also puts a floor under the estimator: the useful signal scales with the phase displacement, and below `β ≈ 10⁻²` the difference the rule measures is smaller than the sampler's own noise, so "take a small enough step to be safe" is not available.

> **Provenance (Lebedev et al. 2004).** Adds **G48** and puts a confound under every prefrontal delay-recording result the wiki cites. > **Provenance (Lundqvist et al. 2018).** Adds **G49** and gives **G48** its missing half. G48 said a store needs a pointer register as well as a content register; this source shows what the pointer is *for* — in a two-object sequence match with no motor confound at the first test, gamma bursting and object information ramp up in the delay before each test object, **for the item about to be tested only**, and not before an equally predictable sample or before a test object that an earlier mismatch has made irrelevant. > **Provenance (Poursiami et al. 2025, [[wiki/entities/hami.md]]).** Adds no row and joins two. **G38** (nothing sets the separation/completion bias, and it is not a constant) gets its first *measured landscape* rather than another candidate controller: the bias reduced to one cosine-similarity threshold per factor, swept exhaustively, with 43.54% of the space at ≥90% accuracy and a contiguous plateau (context ∈ [0.20, 0.99], event ∈ [0.45, 0.95]) at 95.03% ± 2.34%. Two consequences. First, **G38 and G42** (no store knows when it is full) are *the same parameter* here — over-completion loses accuracy directly, over-separation loses it through capacity, because too many symbols exhaust the episodic buffer; every prior treatment of the two rows priced them independently. Second, the usable ranges for the event and context factors of one conjunctive code **differ**, which is an argument that G38's missing controller needs more than one output channel, against every candidate in the wiki (cholinergic mode bit, `f_q`, DG↔CA3 loop) emitting a single scalar. The honest counterweight: the plateau is wide and the threshold is a frozen constant that works, so on a stationary observation distribution G38 is not urgent — the row's force is entirely in the non-stationary case, which this source does not test.

> **Provenance (Harvey et al. 2026, [[wiki/entities/hisd.md]]).** Adds no row and closes none, but is the first source to attack **G33** with a working system rather than a family census, and it moves the question sideways in a way worth recording: hierarchy is recovered by *compressing a corpus of behaviour*, with no adjacency estimate anywhere, so the wiki's assumed dependency G27 → [[wiki/concepts/latent-graph-discovery.md]] → G33 is shown to be optional rather than necessary. Two rows are sharpened without moving. **G27** (nothing supplies the discretisation) gains a segmenter with an *interpretable* granularity knob instead of a hand-set threshold — a Gromov–Wasserstein radius `r` fixing the minimum expected segment length — and, one level up, the first stopping rule the wiki has for how deep a temporal hierarchy goes: keep a rule only if the corpus uses it twice. Both are offline and batch, needing the whole trajectory set, a maximum skill count `K` and pre-extracted features, so the row's *streaming* case is untouched. **G24** (no principled horizon or depth) gets the same partial relief from the other end: depth is whatever the compression converges to rather than a hyperparameter, and mis-specifying `K` degrades gracefully rather than collapsing. The failure mode is the most transferable finding: a soft, noise-tolerant segmenter feeding a *deterministic* grammar throws away exactly the uncertainty that would have paid, and on noisy 44-skill Minecraft data every episode gets its own private parse tree (500 unique trees, mean size 283 against a ground truth of 22.7) — over-separation at the symbolic level, the same trade **G38** names for the fast store, with a probabilistic parse as its completion step.

> **Provenance (Kable & Glimcher 2007, [[wiki/concepts/subjective-value.md]]).** Adds no row and closes none, but supplies **G24** with its first *measurement* of a horizon in a working agent rather than a derivation, and the measurement is unflattering to every rule in the row: the discount rate is a per-agent constant spanning **238×** across ten subjects (`k = 0.0005` to `0.1189`), stable across sessions separated by up to six months, and fitting one population rate destroys the neural value effect outright in ventral striatum and posterior cingulate cortex. So the horizon is neither derived, nor priced, nor read off the representation — it is a trait, and the wiki has no account of where a trait-level `k` comes from or what would set it well. Two further consequences. The fitted kernel is **hyperbolic**, which admits no stationary value function, so the row's implicit assumption that depth and discounting are interchangeable holds only for the exponential family (T141). And the discount is applied *inside the represented value at choice time*, in regions that do not select actions — which relocates part of **G28** (nothing separates transitions from preferences): outcome valuation and action valuation are separately addressable stages in the biology, whereas every `Q(s,a)` architecture in the wiki fuses them.

> **Provenance (wave 7.3).** Zhang et al. 2026 opens **G63** and adds a computable necessary-condition check to **G62**. The row it opens is unusual for this table in that the missing component is not a module but a *constraint on the agent's own behaviour*: every other gap here asks for something to be built, this one asks for something (the actor's conditional action variance) to be deliberately not optimised away. It also sharpens **G27** by exclusion — actions are observed inputs throughout, so nothing in the result bears on where an action alphabet comes from.

> **Provenance (wave 7.5).** Koenig et al. 2024 opens no row and closes none, but supplies the first *positive* instance of a mechanism two rows have only ever asked for. **G8** (rule reification has no implementation) and **G11** (no mechanism for the non-embeddable symbolic slice) both want a continuous learner's content to become a manipulable rule; a KAN-ODE gets there by making the learned function itself readable — per-edge univariate activations, plottable individually, and in the one demonstrated case convertible by symbolic regression into `0.995u(1.003 − u)` against a truth of `u(1 − u)` ([[wiki/entities/kan-ode.md]]). What the case actually licenses is narrower than the rows need, and in an instructive way: the symbolised module was a **single node learning a single scalar residual inside an otherwise hand-written PDE**, so the interpretability came from the *factorisation* (known operator + learned remainder) rather than from the KAN, and the extracted equation was never re-integrated to check it reproduces the model it replaced — the decoded-but-unused problem of [[wiki/concepts/representation-probing.md]] applied to a function instead of an activation. The result also sharpens **G11**'s open question into a controller: nothing in the wiki decides *which* part of a model to attempt symbolisation on, which is G12's routing problem in a new place. **G27** is untouched and in fact presupposed — the KAN's input and output dimensions *are* the physical state variables, handed over. **G62** applies unchanged: every architectural choice in the paper is selected on training MSE, on data generated by integrating the equation being recovered.

> **Provenance (wave 7.6).** Gao et al. 2025 ([[wiki/entities/adaworld.md]]) moves **G4** from `OPEN` to `PARTIAL` — the first at-scale induction of an edge-label vocabulary in the wiki, and the first result anywhere in it where the *action* alphabet is fitted rather than handed over. It also gives **G62** its sharpest single datum: an action-agnostic world model is ~14% behind on unseen-environment PSNR (20.34 vs 23.58) and at chance on Procgen goal-reaching (26.00% vs a random planner's 26.17%, against 56.67%), so the perceptual metric reports a gradient where the control metric reports a cliff — though the planning table omits the flow and discrete baselines, so it separates action-aware from action-agnostic and does not rank the action-aware variants. **G63** gets a lever rather than a fix: the paper's data-collection "policy" is thousands of unrelated demonstrators across 1016 environments, so conditional action excitation comes from *source heterogeneity* instead of from dither in one agent's controller — free where dither costs reward, and unmeasured. **G1** is untouched and visibly so: nothing in the bottleneck distinguishes change the agent caused from change the environment caused, which is the controllable/non-controllable split Iso-Dream has and this does not.

> **Provenance (wave 7.10 ingest).** Maes et al. 2026 ([[wiki/entities/lewm.md]]) opens no row and changes two. G34 gains a third anti-collapse family — distribution matching by random-projection normality testing — and, more usefully, the first *cost* metric for the row: the number of coupled coefficients a practitioner must balance, six to one, with the search cost falling from polynomial to logarithmic. It also attaches the family's failure mode, which is new in kind: an anti-collapse term with a fixed target distribution imposes a latent dimensionality, and an environment of lower intrinsic dimension is degraded by it. G62 gains a fixed-FLOPs comparison that reverses a fixed-episode ranking, which localises planning cost in the model's token count rather than in whether it predicts pixels or features. G63 is untouched but newly relevant: the paper names "sufficient data coverage" as its central data requirement and measures nothing resembling `ρ_tr`.

> **Provenance (wave 7.16).** Weller et al. 2026 ([[wiki/concepts/retrieval-capacity.md]]) opens no row and puts a **ceiling** on one. **G37**'s cheapest answer — embed everything once, answer queries by a coordinate comparison — is shown to have a capacity that is fixed before training: a store read by ranking `⟨q, v_i⟩` over `d`-dimensional vectors can realize all `k`-subsets of `n` items with margin `γ` only if `d ≥ log C(n,k)/log(1+1/γ)`, a sphere-packing count, with a further ~4.5× empirical multiplier even for vectors optimised freely against the test set. The instantiation is the part that should worry the row: on *who likes apples?* over 46 documents, every single-vector model from 32 to 4096 dimensions fails (best recall@2 54.3, none solved at recall@20), in-domain fine-tuning moves recall@10 from 0.0 to 2.8 (so it is not domain shift), and a **cross-encoder that scores the query and the document jointly solves it at 100%** — so the operation G37 needs is expressible exactly when it is not amortised ([[wiki/empirical-tensions.md]] T163). Three smaller consequences. (i) The row's *precision* problem (T22) gains a companion: the failures are not merely unflagged but **unpredictable in kind** — the theorem says some subsets are unaddressable and cannot say which. (ii) **G17** gains a benchmark-side result of the kind it collects: scores on the field's standard retrieval leaderboard are uncorrelated with this task, and the reason is structural — an annotated query set of 3k samples an infinitesimal fraction of the `C(325000, 20) ≈ 7×10⁹¹` retrieval sets the corpus admits, so the leaderboard prices coverage of the sampled queries only. (iii) A model-free difficulty statistic arrives with it: qrel graph density and average query strength (LIMIT 0.085 / 28.5 against NQ 0 / 0, FollowIR 0.026 / 0.59), computable from any dataset before a model is run. **G18** (rule reification) is touched from an unexpected side — logical operators over attributes make all `C(n,k)` subsets *askable*, so a rule over an unbounded instance set provably cannot be served by a precomputed key per instance.

> **Provenance (wave 7.22).** Siméoni et al. 2025 ([[wiki/entities/dinov3.md]]) opens no row and changes the *predicate* of one while giving another its first candidate shape. **G34** has framed collapse as a cheapest-solution problem — an objective whose minimum carries no information — and every answer in the row is a provision that makes that minimum non-trivial. A ViT-7B trained 1M iterations on a stationary distribution with the DINOv2 objective minimises it correctly throughout (no flat term, no constant encoder, stable patch norms, ImageNet linear probe monotonically rising) and *still* loses its dense read-out, whose patch-level linear probe peaks at 200k iterations and ends below its own early value. So the row's failure class is incomplete: a read-out the objective does not measure can be destroyed while the objective is in perfect health, which makes collapse-avoidance a state monitored **per read-out** rather than a property certified once from the loss ([[wiki/empirical-tensions.md]] T168) — and it puts training horizon alongside I-JEPA's pair sampler as a large lever that is a coefficient in nobody's objective. **G30** gains the first loss in the wiki with the right *shape* for the relational half of the `g`/`x` split: `L_Gram = ‖X_S X_Sᵀ − X_G X_Gᵀ‖_F²` penalises relations between elements and nothing else, is label-free, is invariant to any transformation preserving inner products, and is measured holding a relational structure in place against a content objective that was eroding it — at no cost to the content objective. It is not the quantity the row asks for (no path-consistency term, relations within one input rather than across episodes, and the target must be supplied by a reference network), so the row stays `OPEN`; what is new is the existence proof that such a structure can be maintained by gradient descent while the code carrying it keeps moving.

> **Provenance (wave 7.25).** Chen et al. 2025 ([[wiki/entities/vl-jepa.md]]) opens no row and changes three. **G34** gains the continuous version of its non-term entry (above): the target branch's learning rate has an interior optimum and the whole lineage ships one endpoint or the other. **G27** gains its first *priced* boundary detector on a semantic stream — Ward-variance agglomerative clustering with temporal connectivity over a non-autoregressive embedding stream, Pareto-dominating uniform sampling and matching 1 Hz decoding at 0.35 Hz — with the row's standing complaint intact, since the number of segments `N` is still set by hand and the clustering is offline. **G30** (the objective slot is nearly empty) gains a lever that is neither a loss term nor an architecture: *what space you predict into*. Swapping the target text encoder with everything else fixed moves classification by up to +14.4 and retrieval by +10.4 while costing up to −6.6 on question answering, so the target encoder performs part of the model's abstraction and how much is currently a free parameter nobody derives.

> **Provenance (wave 7.26).** Akbar 2026 ([[wiki/entities/lejepa.md]] §Part 8) opens no row and rewrites the premise of one. **G34** is stated as *every self-supervised objective's cheapest solution is to represent nothing* — a claim about degenerate **minima**, which every answer in the row addresses by making the minimum non-trivial. A ViT minimising plain supervised cross-entropy, whose minimum is certifiably non-degenerate because the label term prices a constant encoder, collapses to 20.73% top-1 under AdamW with aggressive augmentation and recovers to 72.02% with one covariance-isotropy term. So collapse is not specific to self-supervision and not diagnosable from the objective's solution set; the offered mechanism is stochastic drift of the representation density (Dean–Kawasaki), driven by finite batches, high learning rates and augmentation, which puts the row's provisions in the category of **drift controls** and reinforces T168's per-run reading. Two secondary corrections to the row's answer column: the family's *cheapest* rung — a Frobenius norm on a **sketched** covariance, `O(CK)` and therefore applicable to internal hidden layers rather than only a projector output — matches or beats the full characteristic-function test in 5 of 8 head-to-head settings ([[wiki/empirical-tensions.md]] T171), and an anti-collapse term on the representation composes additively with an optimiser acting on the update (Muon, 62.44 → 74.56) where the row's existing composability evidence is all negative (T166). One dataset, one author, no seed variance, and no measurement of the spectrum being fixed — `(tentative)`.

> **Provenance (wave 7.27).** Kawaharazuka et al. 2025 ([[wiki/concepts/cross-embodiment-transfer.md]]) opens **G65** and supplies evidence on three standing rows. **G59** (*every hierarchical controller lets its lower level see the same observation as its upper level*) now has an unbroken sample of ~15 hierarchical robot policies, whose only reported narrowing is of the *instruction* channel; the biology's version — withhold the image from the low level — is run by nobody. **G33** gains the subgoal-image branch (SuSIE, CoT-VLA generate an intermediate goal image rather than a trajectory) and the observation that these hierarchies split on control *rate* and body-independence rather than on policy order. **G4**/**G27** are contested rather than advanced: five families of action interface shared across heterogeneous bodies (tension T172), each of which relocates the repertoire-relative part into a per-embodiment decoder instead of removing it. Survey — all results attributed to their own sources.

> **Provenance (LINT, 171 ingests).** No row opened or closed. **G34** acquires a page of its own — [[wiki/concepts/representational-collapse.md]] — because thirteen wave-7 ingests had turned this row's answer into ~60% of [[wiki/concepts/energy-based-models.md]] plus scattered treatments on twelve entity pages, with no single statement of the six loci. Three things the row's phrasing now understates and the page carries: the provision need not be a *term* (loci 4–6 are an update rule, a normalisation and a penalty on relations within one input); the `(x, y)` **pair sampler** moves the result more than any choice among the families (15.5 → 54.2, [[wiki/entities/i-jepa.md]]); and the row's founding premise — that collapse is the objective's cheapest *minimum* — is false, since a supervised cross-entropy with no degenerate minimum collapses anyway and is repaired by the same term. **The consequence for the rest of this table is one sentence:** G30 asks for an objective maximised when `g` is path-consistent, and a *constant* `g` is path-consistent trivially, so G34 is not a neighbouring row but a filter every candidate for G30 must pass first.

> **Provenance (wave 8.2).** Hasani et al. 2021 ([[wiki/entities/ltc.md]]) opens no row and closes none, but fills a slot the table has never named and sharpens two. **The slot:** every memory horizon in this wiki is a constant (`τ` in a CT-RNN, `λ` in a reservoir), a hyperparameter (BPTT truncation), or an *external* modulatory register ([[wiki/concepts/neuromodulatory-metaparameters.md]]); an LTC computes it per-unit, per-instant, from the input, as `τ_sys = τ/(1 + τ·f(x, I, θ))`, with Thm 1 bounding the result. It arrives with the reason nobody should have expected the row to close: `f ≥ 0` ⇒ `τ_sys ≤ τ`, so adaptation only ever *shortens* memory below a learned ceiling, the authors concede vanishing gradients and that LTCs "would not be the obvious choice for learning long-term dependencies", and [[wiki/entities/simple-cycle-reservoir.md]]'s exclusion list therefore survives an input-dependent nonlinear rate — a strengthening of that negative result beyond the linear class it was proved in. **G54** (*no architecture distinguishes a channel that carries content from one that only carries timing*) gets its extreme counter-instance: the same `f` is the drive and the rate, so nothing can set the horizon independently of what is being written, and the minimal repair — a second network `g` owning the decay term alone — is one line of arithmetic that nobody has run. **G29** is touched from the measurement side rather than the search side, via T175: architecture search needs an objective, and the only architecture-sensitive expressivity measure the wiki now holds (trajectory length) is **exponential in solver step count**, on which a stiff LTC spends up to 133× the baseline — so the wiki has no per-FLOP expressivity measure, and the one it has cannot be used to choose. **G24** is untouched: this is a memory horizon, not a planning horizon, and no result here bears on how far ahead anything should look.
