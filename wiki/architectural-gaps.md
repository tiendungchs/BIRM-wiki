# Architectural Gaps

What a brain-inspired reasoning model needs and no current architecture supplies. Updated after every ingest that opens or closes a gap, and rewritten at each lint pass.

**Status key:** `OPEN` — no known solution · `PARTIAL` — solved in a restricted setting · `CONTESTED` — candidate solutions exist and disagree.

> **Provenance:** rows G1–G13 were derived from [[wiki/concepts/latent-graph-discovery.md]] alone; G14–G15 come from the first ingest (Hassabis et al. 2017). Where an ingest has supplied evidence, the `From` column names it. Everything still unmarked records a *mechanism the framing names*, not an architecture the wiki has checked.

| # | Gap | Why it blocks the target | Best current answer | From | Status |
|---|---|---|---|---|---|
| G1 | **Two-level separation exists as a timescale split, not as a factorization** | Meta-graph and instance-graph co-occur in every observation; a flat learner fits the mixture `E_θ[p(obs\|θ)]`, which no individual instance follows — so it cannot transfer at all | The *two learning rates* are instantiated and validated: complementary learning systems (fast hippocampal store + slow cortex + replay) and meta-RL (slow weights training a fast recurrent inner learner). The *factorized code* `p = f(g, x)` is not — no transfer in the historical record moved a factorization | Two-Level Graph Hierarchy; Hardness 1; [[wiki/concepts/complementary-learning-systems.md]], [[wiki/concepts/meta-learning.md]] | `PARTIAL` |
| G2 | **De-aliasing without a hand-built state space** | The same observation recurs at structurally distinct graph positions; without path-sensitive identity the model merges nodes that must stay distinct | Clone cells, or identity carried by path-integrated `g`; sparse conjunctive coding in the fast store gives distinct codes to repeated observations; **module membership as a free identity tag** — 10-month-olds fail to individuate two entities typed by the same core system (duck/truck) and succeed when they are typed by different ones (ball/doll), so a bank of entry-gated priors de-aliases without path context | Hardness 3; [[wiki/concepts/complementary-learning-systems.md]], [[wiki/concepts/core-knowledge.md]] | `PARTIAL` |
| G3 | **Nothing enforces path-consistency of `g`** | The structural code is only a graph position if it *commutes* — same position reached by any path. No training signal or architectural constraint is named that makes it so; without it `g` degenerates into a second content code | **(brainstorm)** A periodic/grid-like code updated by *adding* displacements: addition commutes, so routes with equal total displacement land on the same code — consistency from the update rule rather than from a loss | Architectural Requirements; [[wiki/concepts/abstract-structural-codes.md]] | `OPEN` |
| G4 | **Vocabulary co-discovery at scale** | When the alphabet of edge labels is itself latent, primitives *and* their semantics must be induced jointly with structure. Learnable embeddings are necessary but not sufficient; nothing does this beyond toy domains without a hand-given DSL | Learnable observation + action embeddings | Hardness 2; Open Problems | `OPEN` |
| G5 | **No joint discover-and-navigate loop** | Hard tasks give no discovery-then-use phase separation: the graph estimate must update *while* it is being searched. Architectures that assume a fixed model at inference time cannot express this | Joint loop (update estimate and navigate concurrently) — named, not built | Hardness 4 | `OPEN` |
| G6 | **Spurious edges survive training — and are the default, not the exception** | Correlational edges work in-distribution and fail out of it. Documented across computer vision, language, reinforcement learning and algorithmic decision-making as one phenomenon; shortcut opportunities do *not* dilute as datasets scale by orders of magnitude, so "more data" is not a route. Invariance across environments is the stated fix, but it presupposes an environment partition the model is not given | Invariant causal edge discovery; explicit intermediate-node traversal; domain generalisation/randomisation where several environments *are* given | Hardness 5; [[wiki/concepts/shortcut-learning.md]] | `OPEN` |
| G7 | **Non-stationary topology is tractable only under untested conditions** | Lifting rule-state into the node (`s' = (base_state, rule_config)`) restores stationarity in principle, but the lifted space is `(base) × (rule-configs)` — learnable only if rule-config factorizes and rewrites are sparse, legible, bounded, and meta-stationary. Nothing tests whether real domains meet that | Rule-state lifting; rewrite generator → slow W, active edge set → fast M | Hardness 6 | `OPEN` |
| G8 | **Rule reification has no implementation** | The biological reading — a rule represented as a first-class node with its own factorized code, so rule-change is an ordinary edge — is the mechanism that would make G7 cheap. No architecture represents its own transition rules as navigable content | — (biological reading only) | Hardness 6, biological reading | `OPEN` |
| G9 | **W is flat; there is no third tier** | Two levels suffice only while the rewrite is expressible in the base vocabulary. Self-amendment that edits the rule-changing rules needs a distinct rewrite-graph level, and W itself would have to be a discoverable graph rather than a parameter blob | **Self-referential meta-learning** — a network that recursively modifies *all* its parameters, so the learner can modify the meta-learner, in principle to arbitrary depth. The first named mechanism for this row. Not yet demonstrated on structure acquisition, and the reported cases restrict the search space until self-improvement is tractable | [[wiki/concepts/meta-optimized-plasticity.md]] | `PARTIAL` |
| G10 | **Self-generated intermediate nodes are unreliable** | Multi-hop traversal requires the model to materialize its own intermediate states; when it does, they are not dependable graph positions, so errors compound along the path | — | Open Problems | `OPEN` |
| G11 | **No mechanism for the non-embeddable symbolic slice** | The navigation frame is warranted where structure is orderable, continuous, or transition-sampled. Modular arithmetic, syntactic recursion and type-checking admit no metric embedding — if navigation does not reach them, a second mechanism is needed and none is named | — | Epistemic status; Open Problems | `OPEN` |
| G12 | **No routing policy between structure types** | Given a metric/transition-sampled module and a declarative/relational one, nothing decides which structure goes where. The arbitration is a prerequisite for G11's second mechanism to be usable at all | — | Open Problems | `OPEN` |
| G13 | **No tractable system covers all six hardness sources** | AIXI is the only known system that does, and it fails on computability. Every real architecture is a bounded-program approximation that drops whichever sources its search budget cannot reach — and there is no principled account of which to drop | AIXI as the formal ceiling; bounded approximations unscored | Formal Ceiling | `OPEN` |
| G14 | **No consolidation channel: instance structure never becomes meta structure** | Biology transports one-shot hippocampal bindings into cortical structure by replay during offline periods. Machine replay only stabilizes a *single* learner (decorrelating a training stream); nothing converts what the fast level discovered about one instance into a revision of the meta-graph | Replay/consolidation, named biologically; episodic control uses the fast store for behaviour but has no path back into the slow one | [[wiki/concepts/complementary-learning-systems.md]] | `OPEN` |
| G15 | **No control policy over simulation** | Planning is path search, but nothing decides when to roll out, how deep, which branch, or when the answer is good enough. Without it, model-based reasoning is either always-on (unaffordable) or hand-scheduled (not general) | Prefrontal control of hippocampal rollout, proposed biologically; controller-queries-model architectures implement the interface but not the policy | [[wiki/concepts/simulation-based-planning.md]], [[wiki/concepts/attention.md]] | `OPEN` |
| G16 | **The intended graph is not identifiable from data alone** | Shortcut and causal rules are equally consistent with the observations, so no objective computed on one environment can prefer the structural rule. The `g`/`x` factorization G1 asks for therefore cannot be *discovered* — it must be imposed through inductive bias. The complete control surface is four levers (architecture, training data, loss, optimizer) and there is no account of which one buys graph-structured solutions, nor at what cost | Multi-environment invariance where a family is given; cross-entropy's early-stopping-at-first-sufficient-predictor identified as the sharpest loss-side target | [[wiki/concepts/shortcut-learning.md]] | `OPEN` |
| G17 | **No evaluation protocol can certify structure discovery** | i.i.d. testing cannot separate a recovered meta-graph from a correlation holding in the sample, so every "architecture X reasons" claim is unscoreable and the hardness-source scoring table has no valid instrument. Existing o.o.d. benchmarks are domain-specific, hand-built, and must be revised as models learn to game them (the Winograd Schema Challenge was found to contain the shortcuts it was designed to remove) | Controlled-shortcut datasets (Shift-MNIST / biased CelebA / unfair dSprites), where the intended rule is known by construction and the accuracy drop is the measurement; three design conditions for a valid o.o.d. test | [[wiki/concepts/shortcut-learning.md]] | `OPEN` |
| G18 | **Discovered learning rules do not generalize outside the rule-search restrictions imposed by hand** | Meta-optimized plasticity is the wiki's only route to making slow **W** a *searched* object rather than a parameter blob, but when the rule search space is large and few restrictions are placed on the mechanism, generalization degrades. The freedom that makes rule discovery interesting is the same freedom that breaks it, so the expressiveness needed for structure acquisition is exactly what the method cannot afford | **Variable-shared meta-learning**: rules parameterized by parameter-shared recurrent networks that exchange information locally, which generalize to classification problems unseen during meta-optimization (and analogously for discovered RL algorithms). Restriction by *architecture* rather than by hand-written rule form is the only route shown to survive o.o.d. Which restrictions buy generalization and which merely shrink the space is uncharacterized | [[wiki/concepts/meta-optimized-plasticity.md]] | `OPEN` |
| G19 | **No local rule is selective about what it writes** | Every rule that can write during deployment ([[wiki/concepts/synaptic-plasticity.md]]) is a coactivity/covariance detector. It fires on shortcut-driven coactivity exactly as readily as on structural coactivity, so a fast **M** written by local plasticity accumulates spurious edges at the *instance* level — the same failure as G6, now inside the mechanism the wiki wants for online binding. Metaplasticity gates *how much* a synapse may change, never *whether the change is warranted* | Meta-optimizing the rule so the outer loop's task distribution filters what the rule writes on — i.e. importing the multi-environment identifiability argument into the update rule. Named here, not built | [[wiki/concepts/synaptic-plasticity.md]], [[wiki/concepts/meta-optimized-plasticity.md]] | `OPEN` |
| G20 | **No local rule reaches delayed credit *and* stays online** | The two available regimes are mutually exclusive: e-prop is forward-computable but requires a real-time error at each step and is blind to errors delayed beyond individual-neuron timescales; REINFORCE / node perturbation handle arbitrarily delayed sparse reward but are high-variance and give no per-step signal. Multi-hop traversal has precisely the delayed-sparse credit structure, evaluated only at the end of a path, so neither regime fits the wiki's target task | Eligibility traces plus a retroactive neuromodulatory signal — the mechanism both families share and neither exploits fully | [[wiki/concepts/synaptic-plasticity.md]], [[wiki/concepts/biologically-plausible-credit-assignment.md]], [[wiki/entities/spiking-neural-networks.md]] | `OPEN` |
| G21 | **No mechanism composes the outputs of two specialized modules** | Core knowledge shows a meta-graph can be *pre-installed* — six domain fragments with their own node types, edge vocabularies and constraints — but the fragments are encapsulated and compete for a limited attentional resource, so nothing joins them. A content such as "Mary broke the five bottles she liked" needs number, object, agent and social outputs in one representation. Modularity is the wiki's standing architectural stance ([[wiki/concepts/attention.md]]), and it has no binding operation. Worse, if language supplies the common format, then core concepts are a *different kind* from the concepts used as building blocks, so the priors cannot serve as compositional primitives without an unspecified translation layer (the equivocation problem) | Two rivals, both contested: natural-language syntax + compositional semantics (Spelke 2022) vs. an innate language of thought whose format the core systems already speak (Revencu & Csibra 2023) | [[wiki/concepts/core-knowledge.md]] | `CONTESTED` |
| G22 | **Nothing selects which compositions get built** | A composer must be answerable in both directions at once. Driven from outside (corpus, teacher) it **undergenerates** — the primitives are what everyone assumes and therefore rarely says, and many symbols (logical operators, tense/aspect, modals) have no primitive counterpart. Driven from inside it **overgenerates** — nothing explains why a handful of the astronomically many available compositions are ever built. Granting composition at all inherits the combinatorial explosion; it is postponed, not solved. This is gap G4 (vocabulary co-discovery) restated as a *selection* problem rather than an induction problem | None. **(brainstorm)** A machine is not forced to choose: give it an internal composer and use the external corpus as a *pruner* over the generated space rather than as its source | [[wiki/concepts/core-knowledge.md]] | `OPEN` |
| G23 | **Machine priors are unconditional; a prior needs an entry test** | A core system applies only to a subset of entities *and* only to a subset of their properties — a pile of sand fails cohesion and never enters the object system. Every inductive bias the wiki has (convolution's translation prior, attention's adjacency, a plasticity rule) applies to all input unconditionally, so a prior that is wrong for part of the domain cannot be locally disabled; it is smeared over everything. Without an entry test, adding more priors monotonically adds more misapplied constraints, which is why the architecture lever (G16) does not obviously scale by stacking | Core systems' selectivity, stated as a property, with no computational account of what evaluates the entry condition. **(brainstorm)** The gated form also supplies the routing policy G12 asks for: the test that admits an observation to a fragment *is* the router | [[wiki/concepts/core-knowledge.md]] | `OPEN` |

## How gaps are used

A gap is worth recording only if it is *actionable*: it names a mechanism the wiki would adopt if it existed. Gaps that reduce to "the problem is hard" are folded into the open-problems section of the relevant concept page instead.

**Dependency structure.** These are not independent. G16 sits *under* G1: it says the factorization G1 wants is not the kind of thing data can supply, so G1 is a design decision to be paid for rather than a result to be waited for. G17 is the instrument problem for the whole table — without an out-of-distribution test, no gap can be shown closed, because an architecture that assumed the latent variable away is indistinguishable from one that recovered it. G1 is the root — G2 and G3 are the conditions under which its factorization is meaningful, and G9 is what happens when it is applied to itself. G7→G8 and G11→G12 are each a problem followed by the mechanism that would dissolve it. G13 is the accounting frame for all of them: an architecture is scored by which hardness sources it reaches, not by whether it "works". G14 and G15 are the two halves of the write/read loop around the factorization: G14 is how the meta-graph gets updated from experience, G15 is how the graph gets used once it exists. G19 and G20 are the corresponding pair one level down, on the *write rule for fast M*: G19 is what gets written, G20 is when the signal that authorizes the write arrives. G18 is the tax on G9's new candidate answer — self-reference buys the third tier, and generalization is the price. G21–G23 open a column the table did not have: what is in the graph *before* learning. G23 is the condition under which installed priors can be stacked at all; G21 is what they cannot do once installed; G22 is the reason G21's candidate answers do not obviously work. G21 also inverts G4 — where G4 asks how a vocabulary is induced, G21 assumes several are given and asks how they are joined.

**What would close one.** A gap closes when an ingest supplies an architecture that (a) instantiates the named mechanism and (b) is tested on a task where the corresponding latent variable is actually hidden. An architecture that assumes away the latent variable does not count as evidence. Per G17, condition (b) means an **out-of-distribution** test with a well-defined intended solution — an i.i.d. result never closes a gap here.

> **Provenance (second ingest).** Rows G16–G17 come from Geirhos et al. 2020; G6 was revised by the same source from "correlational edges can survive" to "shortcut solutions are the default outcome across every subfield studied".

> **Provenance (third ingest).** Rows G18–G20 come from Schmidgall et al. 2023, which also moved G9 from `OPEN` to `PARTIAL` by naming self-referential meta-learning as a candidate third tier. G19 is G6 restated one level down: the same shortcut problem, now in the *write rule for fast M* rather than in the slow learner's weights — which means fixing G6 at the slow level does not fix it at the fast one.

> **Provenance (fourth ingest).** Rows G21–G23 come from Revencu & Csibra 2023. They shift the table's centre of gravity: G1–G20 all concern what a learner must *acquire*, while these three concern what it must be *given*, and what being given several disconnected priors then costs. G2 also gains a second answer from this source — an entity typed by a different core system is individuated without any path context, so module membership is a free de-aliasing tag.
