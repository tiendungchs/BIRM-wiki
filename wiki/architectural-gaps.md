# Architectural Gaps

What a brain-inspired reasoning model needs and no current architecture supplies. Updated after every ingest that opens or closes a gap, and rewritten at each lint pass.

**Status key:** `OPEN` — no known solution · `PARTIAL` — solved in a restricted setting · `CONTESTED` — candidate solutions exist and disagree.

> **Provenance:** rows G1–G13 were derived from [[wiki/concepts/latent-graph-discovery.md]] alone; G14–G15 come from the first ingest (Hassabis et al. 2017). Where an ingest has supplied evidence, the `From` column names it. Everything still unmarked records a *mechanism the framing names*, not an architecture the wiki has checked.

|---|---|---|---|---|---|
| G1 | **Two-level separation exists as a timescale split, not as a factorization** | Meta-graph and instance-graph co-occur in every observation; a flat learner fits the mixture `E_θ[p(obs\|θ)]`, which no individual instance follows — so it cannot transfer at all | The *two learning rates* are instantiated and validated: complementary learning systems (fast hippocampal store + slow cortex + replay) and meta-RL (slow weights training a fast recurrent inner learner). The *factorized code* `p = f(g, x)` is not — no transfer in the historical record moved a factorization | Two-Level Graph Hierarchy; Hardness 1; [[wiki/concepts/complementary-learning-systems.md]], [[wiki/concepts/meta-learning.md]] | `PARTIAL` |
| G2 | **De-aliasing without a hand-built state space** | The same observation recurs at structurally distinct graph positions; without path-sensitive identity the model merges nodes that must stay distinct | Clone cells, or identity carried by path-integrated `g`; sparse conjunctive coding in the fast store gives distinct codes to repeated observations | Hardness 3; [[wiki/concepts/complementary-learning-systems.md]] | `PARTIAL` |
| G3 | **Nothing enforces path-consistency of `g`** | The structural code is only a graph position if it *commutes* — same position reached by any path. No training signal or architectural constraint is named that makes it so; without it `g` degenerates into a second content code | **(brainstorm)** A periodic/grid-like code updated by *adding* displacements: addition commutes, so routes with equal total displacement land on the same code — consistency from the update rule rather than from a loss | Architectural Requirements; [[wiki/concepts/abstract-structural-codes.md]] | `OPEN` |

Learnable embeddings are necessary but not sufficient; nothing does this beyond toy domains without a hand-given DSL | Learnable observation + action embeddings | Hardness 2; Open Problems | `OPEN` |
| G5 | **No joint discover-and-navigate loop** | Hard tasks give no discovery-then-use phase separation: the graph estimate must update *while* it is being searched. Architectures that assume a fixed model at inference time cannot express this | Joint loop (update estimate and navigate concurrently) — named, not built | Hardness 4 | `OPEN` |
| G6 | **Spurious edges survive training — and are the default, not the exception** | Correlational edges work in-distribution and fail out of it. Documented across computer vision, language, reinforcement learning and algorithmic decision-making as one phenomenon; shortcut opportunities do *not* dilute as datasets scale by orders of magnitude, so "more data" is not a route. Invariance across environments is the stated fix, but it presupposes an environment partition the model is not given | Invariant causal edge discovery; explicit intermediate-node traversal; domain generalisation/randomisation where several environments *are* given | Hardness 5; [[wiki/concepts/shortcut-learning.md]] | `OPEN` |

| G8 | **Rule reification has no implementation** | The biological reading — a rule represented as a first-class node with its own factorized code, so rule-change is an ordinary edge — is the mechanism that would make G7 cheap. The first named mechanism for this row. Not yet demonstrated on structure acquisition, and the reported cases restrict the search space until self-improvement is tractable | [[wiki/concepts/meta-optimized-plasticity.md]] | `PARTIAL` |
| G10 | **Self-generated intermediate nodes are unreliable** | Multi-hop traversal requires the model to materialize its own intermediate states; when it does, they are not dependable graph positions, so errors compound along the path | — | Open Problems | `OPEN` |

| G12 | **No routing policy between structure types** | Given a metric/transition-sampled module and a declarative/relational one, nothing decides which structure goes where. The arbitration is a prerequisite for G11's second mechanism to be usable at all | — | Open Problems | `OPEN` |

| G14 | **No consolidation channel: instance structure never becomes meta structure** | Biology transports one-shot hippocampal bindings into cortical structure by replay during offline periods. | G15 | **No control policy over simulation** | Planning is path search, but nothing decides when to roll out, how deep, which branch, or when the answer is good enough. | G16 | **The intended graph is not identifiable from data alone** | Shortcut and causal rules are equally consistent with the observations, so no objective computed on one environment can prefer the structural rule. The complete control surface is four levers (architecture, training data, loss, optimizer) and there is no account of which one buys graph-structured solutions, nor at what cost | Multi-environment invariance where a family is given; cross-entropy's early-stopping-at-first-sufficient-predictor identified as the sharpest loss-side target | [[wiki/concepts/shortcut-learning.md]] | `OPEN` |
| G17 | **No evaluation protocol can certify structure discovery** | i.i.d. testing cannot separate a recovered meta-graph from a correlation holding in the sample, so every "architecture X reasons" claim is unscoreable and the hardness-source scoring table has no valid instrument. | G18 | **Discovered learning rules do not generalize outside the rule-search restrictions imposed by hand** | Meta-optimized plasticity is the wiki's only route to making slow **W** a *searched* object rather than a parameter blob, but when the rule search space is large and few restrictions are placed on the mechanism, generalization degrades. The freedom that makes rule discovery interesting is the same freedom that breaks it, so the expressiveness needed for structure acquisition is exactly what the method cannot afford | **Variable-shared meta-learning**: rules parameterized by parameter-shared recurrent networks that exchange information locally, which generalize to classification problems unseen during meta-optimization (and analogously for discovered RL algorithms). Restriction by *architecture* rather than by hand-written rule form is the only route shown to survive o.o.d. Which restrictions buy generalization and which merely shrink the space is uncharacterized | [[wiki/concepts/meta-optimized-plasticity.md]] | `OPEN` |
| G19 | **No local rule is selective about what it writes** | Every rule that can write during deployment ([[wiki/concepts/synaptic-plasticity.md]]) is a coactivity/covariance detector. It fires on shortcut-driven coactivity exactly as readily as on structural coactivity, so a fast **M** written by local plasticity accumulates spurious edges at the *instance* level — the same failure as G6, now inside the mechanism the wiki wants for online binding. Metaplasticity gates *how much* a synapse may change, never *whether the change is warranted* | Meta-optimizing the rule so the outer loop's task distribution filters what the rule writes on — i.e. importing the multi-environment identifiability argument into the update rule. Named here, not built | [[wiki/concepts/synaptic-plasticity.md]], [[wiki/concepts/meta-optimized-plasticity.md]] | `OPEN` |
| G20 | **No local rule reaches delayed credit *and* stays online** | The two available regimes are mutually exclusive: e-prop is forward-computable but requires a real-time error at each step and is blind to errors delayed beyond individual-neuron timescales; REINFORCE / node perturbation handle arbitrarily delayed sparse reward but are high-variance and give no per-step signal. Multi-hop traversal has precisely the delayed-sparse credit structure, evaluated only at the end of a path, so neither regime fits the wiki's target task | Eligibility traces plus a retroactive neuromodulatory signal — the mechanism both families share and neither exploits fully | [[wiki/concepts/synaptic-plasticity.md]], [[wiki/concepts/biologically-plausible-credit-assignment.md]], [[wiki/entities/spiking-neural-networks.md]] | `OPEN` |

## How gaps are used

A gap is worth recording only if it is *actionable*: it names a mechanism the wiki would adopt if it existed. Gaps that reduce to "the problem is hard" are folded into the open-problems section of the relevant concept page instead.

**Dependency structure.** These are not independent. G16 sits *under* G1: it says the factorization G1 wants is not the kind of thing data can supply, so G1 is a design decision to be paid for rather than a result to be waited for. G17 is the instrument problem for the whole table — without an out-of-distribution test, no gap can be shown closed, because an architecture that assumed the latent variable away is indistinguishable from one that recovered it. G1 is the root — G2 and G3 are the conditions under which its factorization is meaningful, and G9 is what happens when it is applied to itself. G7→G8 and G11→G12 are each a problem followed by the mechanism that would dissolve it. G13 is the accounting frame for all of them: an architecture is scored by which hardness sources it reaches, not by whether it "works". G14 and G15 are the two halves of the write/read loop around the factorization: G14 is how the meta-graph gets updated from experience, G15 is how the graph gets used once it exists. G19 and G20 are the corresponding pair one level down, on the *write rule for fast M*: G19 is what gets written, G20 is when the signal that authorizes the write arrives. G18 is the tax on G9's new candidate answer — self-reference buys the third tier, and generalization is the price.

**What would close one.** A gap closes when an ingest supplies an architecture that (a) instantiates the named mechanism and (b) is tested on a task where the corresponding latent variable is actually hidden. An architecture that assumes away the latent variable does not count as evidence. Per G17, condition (b) means an **out-of-distribution** test with a well-defined intended solution — an i.i.d. result never closes a gap here.

> **Provenance (second ingest).** Rows G16–G17 come from Geirhos et al. 2020; G6 was revised by the same source from "correlational edges can survive" to "shortcut solutions are the default outcome across every subfield studied".

> **Provenance (third ingest).** Rows G18–G20 come from Schmidgall et al. 2023, which also moved G9 from `OPEN` to `PARTIAL` by naming self-referential meta-learning as a candidate third tier. G19 is G6 restated one level down: the same shortcut problem, now in the *write rule for fast M* rather than in the slow learner's weights — which means fixing G6 at the slow level does not fix it at the fast one.
