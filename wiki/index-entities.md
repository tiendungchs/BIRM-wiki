# Index — Entities

Models, frameworks, benchmarks, and biological systems. One page per artefact. No researcher pages. Updated whenever an entity page is created.

## Models and frameworks

| Page | What it is | Load-bearing for |
|---|---|---|
| [[wiki/entities/aixi.md]] | Sequential decision theory (expectimax) with the unknown environment prior replaced by the universal semimeasure `ξ`; uncomputable, plus the `AIXItl` reduction that is computable at `t̃·2^l̃` per cycle | The wiki's formal ceiling — the only system covering all six hardness sources; the separability vocabulary; self-certified value as a policy-selection criterion |
| [[wiki/entities/bayesian-program-learning.md]] | Concepts as simple stochastic programs over a shared library of pen primitives, sub-parts, parts and relations; inference recovers the program from one example | The wiki's only architectural (not emergent) `g`/`x` factorization; human-level one-shot classification and a passed visual Turing test; the causal end of the generative spectrum |
| [[wiki/entities/hbtom.md]] | Hierarchically Bayesian Theory of Mind: inverse planning over an MDP with a Dirichlet prior on per-agent goal preferences and an inverse-Gamma prior on per-agent rationality; plausibility read out as a product of three posterior-surprise metrics | The wiki's first primary source for Bayesian inverse planning and its cleanest architectural two-level hierarchy (hyperprior → per-agent params → per-trial goal); 96.0–99.7% pairwise accuracy on the Baby Intuitions Benchmark against baselines at chance, with the entire state space hand-supplied |
| [[wiki/entities/coin-model.md]] | COntextual INference: a switching state-space model with a sticky hierarchical Dirichlet process prior over an unbounded context set; one posterior drives memory creation, probability-weighted expression, and responsibility-scaled updating of *every* memory | The wiki's only model of retrieval-and-allocation over a growing memory library, and its only experimental demonstration that behavioural change ≠ learning: evoked recovery confirmed as a novel prediction, ΔBIC 302.6/394.1 nats over the dual-rate model, three "learning rate" phenomena reproduced parameter-free with the learning rates unchanged |
| [[wiki/entities/h-jepa.md]] | A fully differentiable modular agent around one *configurable* world-model engine; predictions in representation space (JEPA), stacked across time scales (H-JEPA), planning by cost minimisation over action sequences | The wiki's most complete design for a reasoning agent and its least-evidenced entry: jumpy planning via subgoals-as-conditions, abstraction as long-range predictability, Mode-2 → Mode-1 amortisation, the case against generative world models |
| [[wiki/entities/neuromatch.md]] | Neural approximate subgraph isomorphism: anchored `k`-hop neighbourhoods embedded by a GIN into an order-embedding space where `G_q ⊆ G_u` iff `z_q ≼ z_u` componentwise; queries answered by coordinate comparison plus neighbour voting | The wiki's only structural-retrieval architecture and its clearest case of structural amortisation: median 95.5 AUROC, ~100× faster than exact search, zero-shot transfer from random graphs to real domains — and 49% precision under natural class skew |
| [[wiki/entities/maze-solving-transformers.md]] | Small decoder-only GPTs (1.2M / 9.6M parameters) trained by next-token prediction on token-serialised mazes, then interpreted with linear probes, direct logit attribution and the tuned lens | The wiki's cleanest separation of *discovery* from *use*: a whole maze linearly decodable from one token's residual stream at layer 2 (0.83–0.99 per wall), an adjacency head respecting in-context topology — and rollouts that still cross walls while reaching the target ≈100% of the time (T25) |
| [[wiki/entities/spiking-neural-networks.md]] | Networks whose units communicate by binary, time-located spikes; leaky integrate-and-fire dynamics, STDP-native, run on neuromorphic hardware (Loihi, TrueNorth, SpiNNaker) | The test case for the implementation-level exclusion ([[wiki/empirical-tensions.md]] T1); a substrate-level primitive for *directed* edges; why local learning stops being optional |
| [[wiki/entities/cscg.md]] | A hidden Markov model with a frozen per-observation clone pool, so learning transitions *is* learning a de-aliased state space; expectation-maximisation, local rules, planning by inference | The clone-cell answer to gap G2 made concrete; hippocampus-as-map; fast single-environment maps with zero transfer |
| [[wiki/entities/tolman-eichenbaum-machine.md]] | A reusable path-integrating structural code plus a Hebbian relational memory binding it to this environment's sensory codes, trained only on next-observation prediction across many worlds (TEM; SMP is the pixel-input sibling) | The wiki's clearest built realisation of `p = f(g, x)` and of the meta/instance split; the model side of place, grid, splitter, lap and evidence cells; hippocampus-as-index; the derivation of grid codes from two memory-addressing constraints, and the two-dataset evidence that remapping is non-random |
| [[wiki/entities/tem-transformer.md]] | A transformer whose position encodings are generated by an action-driven recurrent operator (`e_{t+1} = σ(e_t W_a)`), with queries/keys reading only position and values only stimulus; shown algebraically to be TEM with a softmax | The proof that the wiki's `p = f(g, x)` architecture and the transformer are one computation: grid and band cells in the position encodings, place cells in the memory neurons, additive rather than multiplicative scaling in the number of bound cortical regions, and the export route for `g` into language (grammar as positional encoding) |
| [[wiki/entities/rolls-treves-hippocampal-model.md]] | The quantitative CA3-autoassociation theory: dentate competitive network → mossy-fibre randomization → single diluted CA3 attractor → reverse hierarchy of pattern associators back to cortex, with closed-form capacity at every stage | The wiki's only capacity accounting for a fast store (`p_max ≈ kC/(a ln(1/a))`); why recurrence is *diluted*; hash-on-write vs. embed-on-read; the backprojection fan-out constraint; `7 ± 2` from noise-driven attractor transitions |
| [[wiki/entities/hidden-state-inference-remapping.md]] | Place-field remapping as a posterior over hidden states under a Chinese Restaurant Process prior; the four remapping categories as one axis of log posterior odds | The normative *why* behind pattern separation/completion; `α` as the allocate-vs-reuse knob; posterior uncertainty read off population heterogeneity; anchoring as an argmax over rotational offsets nested inside retrieval |
| [[wiki/entities/temporal-context-model.md]] | A normalised leaky integrator of item-retrieved context as the sole retrieval cue; hippocampus reinstates past context states | The one equation that yields both the entorhinal place code and free-recall contiguity; graph distance recovered from co-occurrence alone; leaky-vs-perfect integration |
| [[wiki/entities/spiking-tem.md]] | The TEM generative/inference factorisation rebuilt from leaky integrate-and-fire neurons, binary Bernoulli-sampled latents, STDP memory and an 8 Hz theta rhythm, over a full LEC/MEC/DG/CA3/CA1 anatomy | The wiki's only implementation-level rewrite of an architecture it already holds, and so its sharpest test of T1: grid cells at 59.6% of MECII units collapse to 0.0% without a neuromodulatory gain, 10.1% without STDP, 25.6% without theta inhibition; phase precession and phase locking dissociated by two named mechanisms; grid emergence peaks at *intermediate* sensory ambiguity; and the `g̃ ⊙ x̃` conjunction had to be deleted (T42) |
| [[wiki/entities/vector-hash.md]] | A frozen grid-cell state set randomly projected into hippocampus, turning exponentially many prestructured states into convex uniform attractors, with content attached by a separate plastic layer and sequences stored as 2-D velocity shifts | The wiki's first *derived* memory capacity and its only graceful-overload store (memory continuum, no cliff); strong generalization from `O(MK_max)` visits to `O(K^M)` states; 11 maps with zero forgetting and no replay; the first circuit model of the memory palace |
| [[wiki/entities/mm-tem-hippoformer.md]] | TEM's relational memory rebuilt as a meta-learned MLP whose fast weights are written online by surprise-gated gradient descent with a learned forget gate (mm-TEM), plus a 32-step transformer run alongside it (Hippoformer) | The wiki's third rewrite of `p = f(g, x)` and its first fast store with a *learned* forgetting policy; the prediction horizon as the determinant of grid scale; the first quantitative link from grid score to reasoning accuracy and the counterexamples to it; the negative control showing a path-integrating positional encoding buys short-range accuracy and no structural transfer |
