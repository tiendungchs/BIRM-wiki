# G24 — No principled planning horizon exists, even in the ideal agent

**Status:** `CONTESTED`  
**Kind:** `part`  
**Level:** `L3`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A horizon is set by a quantity the agent computes rather than by a hyperparameter, and the resulting depth tracks the task's actual reward timescale across at least two orders of magnitude.

## Why it blocks the target

Path search needs a depth. Known lifetime `T` is unavailable in practice; every damping scheme introduces a timescale (exponential → `1/λ`, power-law `k^−α` → an effective horizon `∼k`, `h_k = β·k` → a fixed multiple of elapsed history). The unbounded limit is definable but *misbehaves*: in Hutter's own example the optimal agent postpones the rewarding switch forever and scores zero. And `ξ` is only shown to approximate `µ` for `k ≫ h_k`, which no long horizon satisfies — so the ideal agent's plan is untrustworthy exactly where planning matters

## Best current answer

Bounded horizons in the separable classes; `h_k = β·k` as the least arbitrary parameter-free choice (`β_human ≈ 1`). Whether the choice is a detail or a central topic is stated as unresolved by the source itself. **One architecture converts the question into a resource allocation**: a spacetime attractor represents every step to the horizon simultaneously, so the horizon is set by how many delay-subspaces the tissue affords — linear in neuron count, and exponential in the depth of a stacked hierarchy if the abstract state space can be supplied ([[wiki/entities/spacetime-attractor.md]], Jensen et al. 2026). This answers *how deep is affordable*, not *how deep is right*. **A second architecture makes the horizon a physical constant rather than a choice**: where the plan is an exponentially attenuating reward wave over the learned graph, planning is reliable exactly as far as the wave stays above the noise floor, so depth `≈ log(SNR)/attenuation per relay` — and it is *extendable by re-representation*, since a coarser graph reaches the same physical distance in fewer relays (ablating the coarse population breaks detour planning at 4× maze scale but not at 1×; [[wiki/entities/pfc-columnar-planning-model.md]], Martinet et al. 2011). **A third route sets the discount factor itself from a measurable statistic**: value estimates learned with `γ → 1` have high variance, that variance is visible in the temporal-difference error, so an agent can lower its own horizon exactly when its long-range predictions have stopped being reliable — the only rule in the wiki that answers *how deep is right* from data the agent already holds, though it answers it with a bias–variance heuristic and no convergence guarantee (Doya 2002, [[wiki/concepts/neuromodulatory-metaparameters.md]]). This is the first candidate where the answer to *how deep* is neither chosen nor discounted-in, but read off the representation. **A third reading prices the horizon instead of setting it:** for active-inference planning the mirror-descent relative-smoothness constant is `L = ½T(T+1)`, so the admissible step size falls as `1/T²` and the optimisation cost of a deeper plan is quadratic in the depth, independent of the environment — and passing to an infinite horizon is not a limit but a *choice*, since entropy does not commute with time aggregation (`H(d^π) ≥ (1−γ)ΣγᵗH(μ_t)` by Jensen), leaving two inequivalent objectives that no principle selects between (Milosevic et al. 2026) **The first source to *measure* a required depth rather than derive one:** for a belief-state planner the depth that matters is the number of information-gathering actions a confident commit needs, and discounting below that number destroys the epistemic term's advantage outright — on a 4-condition diagnosis task the gain over reward-only planning is `+7.8 pp` at `γ = 1.0`, `+1.0 pp` at `γ = 0.95` and **`−1.6 pp` at `γ = 0.90`**, while a single-observation task (Tiger) is insensitive to `γ` across `[0.90, 1.0]` (Cooper & Velasquez 2026). So the horizon requirement is a property of the *task's* observation structure, is checkable before deployment, and is one place where a discount factor is not a harmless reparameterisation of a horizon but a truncation below it  **A fourth route makes depth a per-node comparison rather than a global horizon:** search accumulates *computational noise* — the inaccuracy that pruning and partial expansion inject into a derived value — with each iteration, so under partial evaluation the agent expands a node while that accumulated variance stays below the cached value's uncertainty and falls back on the cache when it does not (Daw et al. 2005, [[wiki/concepts/amortized-inference.md]]). Depth is then the crossing point of two variances the agent already tracks, it can differ along one behaviour chain — which is how an overtrained action one step from reward stays goal-directed while the action before it does not — and it needs neither a lifetime estimate nor a discount factor. It is also the only entry here that prices *thinking itself* rather than the model's error, and no machine planner computes the term.

**A fifth route replaces the horizon with a prior over the risk that ends the episode.** `γ = e^{−λ}` for a per-step hazard `λ`, so a discount function is the Laplace transform of a prior `p(λ)`: a Dirac prior gives exponential discounting, an exponential prior gives the hyperbola `1/(1+kt)`, a uniform prior gives `(1−e^{−kt})/(kt)`, and `Q_π^{δ(0),Γ_k} = Q_π^{p_k,1}` — discounting in a safe world equals not discounting in a hazardous one. This does not derive a horizon either, but it changes what the unanswered question *is*: not "how many steps ahead" but "what do you believe about the risk that stops you", which is a quantity an agent could estimate from experience rather than a hyperparameter. It also removes the need to commit: hold `n_γ = 10` horizons on one shared encoder, one affine head each, and the horizon becomes a **read-out weighting** chosen after learning. Robustness is the empirical payoff — with the hazard coefficient wrong by 2–4× or the prior's functional form wrong outright, the multi-horizon estimator still beats every tuned single `γ` on the value profile, while a single `γ` tuned to pick the right arg-max path can get the whole profile wrong invisibly (Fedus et al. 2019, [[wiki/concepts/multi-horizon-value-learning.md]]).
