# G4 — Vocabulary co-discovery at scale

**Status:** `PARTIAL`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** Node vocabulary and edge-label vocabulary are induced jointly on a domain whose primitives were never in the training distribution, with the grain of the vocabulary set by a stated principle rather than by the author's hand.

## Why it blocks the target

When the alphabet of edge labels is itself latent, primitives *and* their semantics must be induced jointly with structure. Learnable embeddings are necessary but not sufficient; nothing does this beyond toy domains without a hand-given DSL **A free parameter of this row that no source sets by principle: the *grain* of the vocabulary.** The wiki's two ARC attacks author their DSLs at opposite scales — 7 fine predicates that execute, reject for free and force task selection to be conditioned on them ([[wiki/entities/ilp-arc-synthesizer.md]]), against 22 coarse macro-patterns with enumerated categorical parameter menus, each covering a whole transformation family, which make search unnecessary (induction becomes classification by a frozen LLM) and rejection impossible, with a hard ceiling exactly where the macros stop ([[wiki/entities/corethink-compositional-reasoner.md]]). Coarsening trades search cost against coverage monotonically; nothing in the wiki chooses a point on that curve for a reason.

## Best current answer

**The *edge-label* half is now done at scale, and only that half.** AdaWorld induces a continuous action alphabet from ~2000M frames of unlabeled video across 1016 environments with a β-VAE bottleneck over consecutive frame pairs; the codes cluster by action *across* environments, transfer to unseen contexts with no training (LIBERO FVD 767.0 vs 1545.2 action-agnostic), compose by vector average, and reduce adaptation to a new action space to 100 samples per action plus 800 finetune steps ([[wiki/entities/adaworld.md]]). Four things it does not supply: the **nodes** the labels sit between (G27 untouched — the alphabet is defined over raw frame pairs), any separation of agent-caused from world-caused change, any *semantics* beyond "whatever compresses this transition", and a quantitative test of the composition. The action/context split is set by one hyperparameter `β`, and lowering it makes codes more expressive while overlapping *less* across environments — so transferability is bought, not discovered **The complement is now on the wiki and it makes the split explicit** ([[wiki/entities/gcq.md]]): a model that installs a *node* set (the `K` bump states of a toroidal continuous attractor network) and writes the dataset-action → bump-displacement map by hand, requiring only that it be injective and that `|A| ≤ 5^m`. So the wiki now holds both halves of the vocabulary problem solved separately — an edge alphabet induced at scale with no nodes, and a node set installed at zero cost with no edge discovery — and nothing that does both. **And the semantics half is now attacked directly, at toy scale** ([[wiki/entities/neo-neural-theorizer.md]]): a VQ codebook whose symbols have no stipulated meaning, plus one *shared* deterministic executor `f_θ(s, z)` that assigns them operational semantics, both fitted to i.i.d. observation pairs with no DSL, no program labels and no task grouping. Action primitiveness reaches **1.000** — every ground-truth primitive is reproducible by a single learned code — at a training coverage where several primitives never appear in isolation and must be recovered by decomposing entangled multi-step transitions. Three findings that transfer past the toy domains: (i) **over-capacity is not the enemy** — a 6× over-complete codebook still allocates primitive-level codes and scores slightly better, so nobody needs to guess `M`; (ii) what prevents memorisation is a **simplicity weight inside a band** — `λ_MDL = 1.2` drives primitiveness to 0.213 by rewarding short *entangled* explanations (T155); (iii) the whole result rests on a **state-grounding loss** forcing intermediate execution states back onto the decodable manifold — remove it and primitiveness is 0.002, i.e. an induced primitive is reusable only if its output lands somewhere the next primitive can start from. Still missing: nodes (the encoder is pretrained and frozen), any arity or binding (symbols concatenate only), and any domain that is not synthetic. **The hardest form of this row now has a benchmark axis of its own** ([[wiki/entities/arc-agi-2.md]]): *in-context symbol definition* — tasks where an object stands for something other than itself and the correspondence is defined **inside the episode** (rectangles with `n` holes encode the colour for shapes with `n` holes). The vocabulary is neither authored nor induced across tasks but *created per task and discarded*, and the authors name it as "a major challenge for frontier AI systems". Note what it is not: no rotation, count or topology operation constructs a referential relation, so this axis is not reachable by recombining the declared Core Knowledge priors, and it ties this row to G69 (nothing creates variables on demand).

**The *program* half has a partial answer of a different shape** ([[wiki/entities/dreamcoder.md]]): grow the vocabulary by compressing refactorings of solved programs, and the domain primitives are never authored — `map` and `filter` from a generic functional basis, `fold` then `unfold` from a 1959 Lisp subset plus the Y-combinator, inner products and an inverse-square-law schema from `map`/`fold` plus arithmetic. Unlike the continuous-side answers it yields entries a program can be *written in*, with types. Three reasons it does not close the row. The grain is still not set by principle but by the description-length objective's balance against the library prior — the free parameter this row names, now merely relocated. The base primitives (control flow, higher-order functions, recursion, types) are authored, and the paper argues they *should* be. And nothing is co-discovered: the vocabulary is grown one domain at a time from tasks whose solutions are already expressible, so no primitive is ever induced that the starting basis could not reach.
