# G45 — No architecture can be told its latent structure

**Status:** `OPEN`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A system's representation is reorganised by a *description* of the latent structure, with the change persisting after the description is withdrawn — which prompting a language model does not do.

## Why it blocks the target

Discovering a latent variable by trial and error is exponentially costly in the number of candidate factors, and it is the only channel every model in the wiki has. Humans have a second one: a ~4-minute verbal description of an uncued task structure produced, in the patients whose behaviour it changed, a hippocampal context geometry whose parallelism was indistinguishable from that of patients who discovered the same structure through experience — with **new stimuli**, so nothing was copied and the surface mappings were relearned either way (Courellis et al. 2024). The instruction is not sufficient (a third of patients received it and changed neither behaviour nor code), so what is needed is not a knowledge-injection path but a mechanism by which a description **redirects what the learner factorises**

## Best current answer

None. Prompting a language model is not this: it supplies the answer at inference time rather than changing what the system's representation is organised around, and it leaves no trace once the context window clears. The nearest wiki relatives are curriculum design (G32) and core knowledge's entry-gated priors ([[wiki/concepts/core-knowledge.md]]), both of which are set by the designer before training rather than accepted mid-stream. The cheap test exists: identical data streams, one arm given a natural-language statement of the latent variable, score CCGP of that variable in the representation

## From

Courellis et al. 2024; [[wiki/concepts/population-geometry.md]], [[wiki/concepts/contextual-inference.md]]
