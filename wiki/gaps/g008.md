# G8 — Rule reification has no implementation

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** An architecture stores its own transition rules as first-class nodes and effects a rule change by ordinary edge traversal, with no weight update, on a task where the rule changes mid-episode.

## Why it blocks the target

The biological reading — a rule represented as a first-class node with its own factorized code, so rule-change is an ordinary edge — is the mechanism that would make G7 cheap. No architecture represents its own transition rules as navigable content

## Best current answer

Still none in a machine, but the biological reading now has a measurement rather than an argument: with a cue→action mapping and its reversal recorded in the same prefrontal cells, ≈50% code the *pairing* against ≈30% cue and ≈20% response direction, so the edge has an activity vector of its own and is not merely the synapses between its endpoints ([[wiki/concepts/arbitrary-sensorimotor-mapping.md]]). What is observed is representation, not the construction rule or the read-out. The companion review adds the level above: strategies and higher-order rules are lost by ventral/orbital prefrontal ablation while *surviving* hippocampal ablation that destroys new instance learning, so rule-level and instance-level content are separately destructible and therefore separately stored — the concrete machine form being a second bank of gated stripes whose inputs are the first bank's contents and gating history (Murray et al. 2000). **And the top of the ladder now has an existence proof with the confounds designed out**: prefrontal cells coding *match* vs. *non-match* with same-rule cues drawn from different sensory modalities and different-rule cues from the same modality, invariant to which cue instructed the rule and which picture was held, before the required response is knowable and with reward expectation equal — a rule with no stimulus, action or reward content left, generalising to stimuli seen for the first time (Wallis et al. 2001, in Miller et al. 2002; [[wiki/concepts/cognitive-control.md]]). The gap that survives is now sharply narrower: what is missing is not evidence that a rule can be a represented object but any *learning rule that produces one*, and — newly — any **conflict-resolution policy over rule-nodes**: the moment two reified rules can both apply, something must decide which is in force, and the only worked answer in the wiki is a commercial game's (recency-override on a *semantic* "contradicts" test that its designers could not specify and offloaded to a public ruling database, [[wiki/entities/fluxx.md]]). The design fork is now stateable — keep the activation predicate syntactic and decidable so no conflict can arise ([[wiki/entities/baba-is-ai.md]]'s tile alignment), or accept an arbiter and price it — **and a third branch now exists, which is the one to copy**: [[wiki/entities/nomic.md]] resolves conflicts by **ordinal priority over rule-nodes** — a strict tier dominance (an immutable rule voids a conflicting mutable one *entirely*), then lowest-numbered-wins within a tier, then a self-declared deference/precedence clause that supersedes the number, then the number again as a cycle-breaker for mutual claims. This is total, decidable, and computed from **metadata rather than content**, so it never requires detecting contradiction at all: the rules are ranked before the conflict, and the only predicate left is the weaker *these two rules bear on the same question*, which is where it hands off to a specified internal arbiter rather than to an email address. It carries a design constraint the wiki had been eliding — the entrenchment ordering must **equal** the precedence ordering, since a rule that is expensive to edit but loses conflicts to cheap rules protects nothing — and it says nothing about how the applicability test is learned, so the learning-rule half of the row is untouched — since reward-gated association among co-active units explains a conjunction and cannot explain a variable deliberately decorrelated from every co-active event **A learning rule that produces one now exists in a restricted form** (Collins & Frank 2013, [[wiki/entities/c-ts-model.md]]): prefrontal stripes wired to the context layer by *random* projections start with no intrinsic meaning, and pure reinforcement learning — no supervision at any level — makes a gated stripe into a task-set, because the stripe's only effect is to route the stimulus to a different parietal destination and thereby license a different action set. What the stripe means is defined entirely by the downstream policy it enables, so the rule-object is constructed rather than observed, and quantitative fits confirm that gating a stripe corresponds to creating or re-using a task-set in the algorithmic model. Three restrictions keep the row open: the stripe pool is fixed at three, the abstraction is only over *which policy*, never over a relation, and nothing can read a stripe's content outside the loop it gates.  **And the residue is now localisable to policy rather than to representation.** Baba Is AI supplies reification from *outside* — the rule is an object in the world, with a position, a perceptual code and the same `push` affordance as a ball, so nothing has to be discovered for rule-change to be an ordinary action. Models that demonstrably parse the rules (100% when obeying them suffices) still do not consider editing them, which points the surviving gap at G61 (exploration is not part of the selector) and at G33 (nothing decomposes a task into subgoals) rather than at the code ([[wiki/entities/baba-is-ai.md]]).
