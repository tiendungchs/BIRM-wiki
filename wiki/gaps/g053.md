# G53 — No architecture delivers one signal to two modules by the same wire, and none lets a third module license a pair's connection

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** One signal is delivered to two modules by a single trained relay, and a third module licenses a pair's connection, with the collateralised version beating two independent copies of the same edge.

## Why it blocks the target

Coordination between modules in the wiki is always *computed*: a shared phase, an attention weight, a synchronising protocol. Biology gets it structurally — single nucleus-reuniens neurons collateralise to both hippocampus and medial prefrontal cortex, and the ventral-hippocampal cells recruited during fear renewal are the ones projecting to both prefrontal cortex *and* amygdala, so both targets receive the identical spike train at the identical time with nothing negotiating it. The same triangle also gates writes: basolateral-amygdala stimulation blocks potentiation on the hippocampal→prefrontal edge, and the hippocampus gates the reciprocal prefrontal↔amygdala circuit — each pair's edge licensed by the third vertex, with no node privileged as the gate-setter

## Best current answer

**None.** G52 gives an edge its own state but still treats that state as externally set; this row says the setter is the network's own third node, and that a relay can be a broadcast identity rather than a transmission. The nearest machine construct is a shared embedding written into two streams, which is neither a trained module nor fed by both endpoints. Concrete test on the first half: replace an A→B/B→A pair with one relay module fed by both and broadcasting one output to both, and check whether coordination phenomena otherwise attributed to oscillatory phase-locking appear with no oscillation in the model
