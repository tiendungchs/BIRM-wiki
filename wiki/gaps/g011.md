# G11 — No mechanism for the non-embeddable symbolic slice

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A machine acquires arbitrary non-embeddable bindings in single-digit trials without disturbing embedded structure, and states the rule that decides which pairing gets written.

## Why it blocks the target

The navigation frame is warranted where structure is orderable, continuous, or transition-sampled. Modular arithmetic, syntactic recursion and type-checking admit no metric embedding — if navigation does not reach them, a second mechanism is needed and none is named

## Best current answer

The slice now has a biological instance and a price: an arbitrary cue→action edge has endpoints with no spatial, perceptual or causal relation, gives zero transfer to any other edge, and is acquired in ~3 trials/cue by a frontal–striatal–hippocampal network — so the brain's answer to non-embeddable structure is a dedicated fast binder, not a better embedding ([[wiki/concepts/arbitrary-sensorimotor-mapping.md]]). Nothing states how the binder chooses *which* pairing to write. **A machine instance of the slice, with a failure mode worth copying** ([[wiki/concepts/cross-paradigm-interface.md]]): the HRN holds symbols as integrate-and-fire nodes and operators (`inhibit`, `copy`, `filter`, `order`) as a second node type, with edges written by Hebbian binding from a perceptual front end — and when the front end is deliberately corrupted it degrades gracefully where a program-synthesis reasoner over the same scene returns empty outputs, because the graph's prior edges shrink the answer space. The schema and the operator vocabulary are authored, so this supplies the *substrate* the row asks for and none of the discovery **A second machine instance, and the first where the operators are *typed* with arity** ([[wiki/entities/neural-module-networks.md]]): five signatures over three data types, with `combine: Attention × Attention → Attention` occupying an argument position that no untyped architecture in the wiki has anywhere — so composition legality is a decidable check rather than a learned statistic, and layouts of a depth never trained on execute correctly. The bindings are still not arbitrary and not fast: the type system, the operator inventory and the layout predictor are all authored, and each module's behaviour is acquired by gradient descent over the whole corpus rather than in single-digit trials.
