# G96 — Top-down control needs an address inside the control layer, and every model gets it by reading the ground truth

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A controller aims top-down modulation at the right control units without reading the ground-truth weight matrix, closing the loop that random feedback addressing leaves open.

## Why it blocks the target

A controller can only modulate what it can aim at. In a mixed-selectivity control population there is no coordinate for "the units that project to the red-tuned sensory neurons" — the mapping is the random weight matrix itself, which no controller has access to. Every top-down mechanism in the wiki either assumes the address (a configurator emitting tokens, [[wiki/entities/h-jepa.md]]; a bias vector added to the right logits, [[wiki/concepts/cognitive-control.md]]) or sidesteps it by making the projection topographic, which destroys the mixed selectivity the readout needs. This is one level below G60: that row asks *what to look for*, this one asks **where to push**

## Best current answer

**A route that needs no address, plus a stimulus-driven way to find one — neither closing the loop.** Park & Serences 2025 ([[wiki/concepts/random-feedback-addressing.md]]) removes half the problem: with near-random reciprocal connections and balanced weights, feedback aimed at the *wrong* control units is uncorrelated with the target population's tuning axis and cancels, so the aim need only be approximately right and no inverse model is required — the transpose of the feedforward matrix is the address book. But *which* control units to drive is supplied to the model by running the ground-truth network on the stimulus first and taking the top 20% by firing rate. The authors' proposed biological substitute is **GANE** ([[wiki/concepts/neuromodulatory-metaparameters.md]]): locus-coeruleus norepinephrine amplifying local glutamatergic hot-spots, so the address is *found* by the stimulus's own activity rather than computed — which works only for a feature currently on the retina, and leaves unspecified what prioritises the relevant hot-spot to start the positive-feedback loop. So: a delivery mechanism that tolerates an imprecise address exists, an activity-based way to locate one exists for present stimuli, and nothing addresses a feature that is merely *anticipated*
