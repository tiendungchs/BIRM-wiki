# G41 — No test decides whether a domain's actions compose

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A test decides from data alone whether a domain's action set has closure, and correctly refuses path integration on a domain where it silently degrades today.

## Why it blocks the target

Path integration answers G3 only where the action set has closure (`North+East+South+West = 0`, `Parent+Sibling+Niece = 0`). Where it does not — a bare social network, a relation set with no consistent labelling — the code silently stops being a position and degenerates into a second content code, which is exactly the failure G3 exists to prevent. The precondition is a property of the domain, is stated as a caveat in the source, and is checked by nobody
