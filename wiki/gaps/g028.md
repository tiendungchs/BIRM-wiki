# G28 — Nothing composes a learned environment model with an arbitrary new reward at query time

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A learned environment model is combined with a reward function never seen in training and planned on immediately, with retraining steps counted at zero, across a set of novel goals in one environment.

## Why it blocks the target

Model-based control is supposed to buy immediate re-goaling: the same transition structure serving any new objective with no relearning. **The base case is the field's most-cited agent** (Mnih et al. 2015, [[wiki/entities/dqn.md]]): 49 Atari games, one network trained per game at 200M emulator frames each, no estimate of `p(s′|s,a)` or of `r` formed anywhere, and every training reward clipped to `{−1, 0, +1}` so that reward *magnitude* is not represented at all. There is no object in the system into which a new objective could be written — which sets the floor this row measures from, and shows the deficit is a design decision rather than an accident of capacity. Humans do it across ~11 novel Frostbite goals and across Go variants on different board sizes, topologies and rules; every deep reinforcement-learning system must be retrained, and most Go variants would need reprogramming by the humans who built the system. Without it, "model-based" names a training procedure rather than a capability **And the failure is now demonstrated in the cheapest possible setting** (Kessler et al. 2023, [[wiki/entities/continual-dreamer.md]]): Minigrid FourRooms-v0 with the layout, start state, start orientation, obstacles and dynamics held *identical* and only the goal location moved between the two tasks. A task-agnostic model-based agent with a persistent replay buffer solves one of the two and never both, across seeds. So the re-goaling failure does not require a new environment or a distribution shift — the transition structure is already learned and shared, and the stored experience of the old objective is what blocks the new one. The authors name this **interference** and state explicitly that none of their replay-selection methods is intended to address it.

## Best current answer

None. The requirement is stated sharply — the environment model must be **modularly combinable** with an arbitrary reward function and deployed immediately for planning — and no cited architecture meets it. **(brainstorm)** This is gap G1's factorization along an unused axis: not `g` vs `x` but *transitions* vs *preferences*, and unlike `g`/`x` it is directly measurable (swap the reward, count the retraining). **A restricted mechanism now exists.** The successor representation already factorizes transitions from preferences (`v = Sr`, relearn `r` only), and its known defect — `S` is contaminated by the policy that produced it — is measurably reduced by one coefficient in the local write rule: making the rule invariant to temporal order stores the SR of `½(P_forward + P_backward)`, provably closer to the uniform-policy transition matrix, and the resulting agent reaches *moved* goals in fewer steps with the map frozen, including in mazes whose corridors changed between train and test (Keck et al. 2025). Three limits keep this from closing the row: the state space must be reversible (on a directed graph the effect inverts), the reward must be re-learned rather than *supplied*, and the transition structure is over a state space someone already provided (G27). **Biology supplies the target behaviour the machine side is missing.** Park et al. 2021: subjects build a 2-D map of a social hierarchy with no objective attached, then at test compute a value function they were *told* rather than trained on (the area spanned by a pair's better rank per dimension) for pairs never encountered, at 98.7% accuracy — and the value signal in medial prefrontal cortex and temporoparietal junction is stronger for queries aligned to the entorhinal grid orientation, i.e. the new objective is being evaluated by vector operations *in the map's own frame*. That is reward supplied, not relearned, over a map built for nothing in particular — the exact composition this row asks for, with the mechanism left as "read the map along the query direction" ([[wiki/concepts/cognitive-map.md]]). **The row's premise is itself contested.** Decoupling `p(z′|z,a)` from `π(a|z)` is a design choice, not a property of world models: the predictive-coding neurorobotics lineage (Tani and successors) deliberately *entangles* them, learning one joint model of sensation-and-action from which behaviour is generated by inference, and reports its robot successes from that entangling — while the affordance argument says perception and action are not separable in the first place. Taniguchi et al. 2023 raise "to what extent should we decouple world model and policy representations?" as an open question rather than a settled preference, which makes this row's target contingent on an answer nobody has ([[wiki/empirical-tensions.md]] T142)
