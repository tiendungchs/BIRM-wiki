# G36 — Nothing measures the capacity to *construct* an arrangement, only the arrangement

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L4`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A measure scores the *transition* between arrangements — the construction, not the artefact — and separates a system that learned a function from one handed the same function, without routing through the uncomputable `GD`.

## Why it blocks the target

`ℐ = log₂N/C` scores a finished system's generalization and is explicitly blind to origin: a hand-written multiplication algorithm and a network that learned the same function score identically and both count as *knowing*. Choi names the missing half — **understanding**, the capacity to build or modify the arrangement for a new domain — and defers it. This is [[wiki/concepts/skill-acquisition-efficiency.md]]'s process/artifact split arriving from the artifact side, and it is the wiki's target: a reasoner must generate a new instance-graph for a domain family it has not seen, not merely execute one

## Best current answer

None. Chollet's `SkillProgramGen` names the engine but supplies no measure of it that is not defined through the uncomputable `GD` (G31); `ℐ` supplies a measure but only of the emitted arrangement. No source in the wiki scores the *transition* from one arrangement to another
