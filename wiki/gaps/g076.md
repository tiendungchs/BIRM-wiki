# G76 — A temporally coded output has no loss function

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A loss is defined directly on spike times, general over spike counts and unrestricted in output cardinality, and trains a timing code that no rate-convolved surrogate reaches.

## Why it blocks the target

Every architecture in the wiki that argues timing carries content ([[wiki/concepts/temporal-coding.md]], [[wiki/entities/spiking-neural-networks.md]], [[wiki/entities/spiking-tem.md]]) can *read* a timing code and none can be *trained toward one*, because there is no agreed distance between a desired and an observed spike train. This blocks the target directly: if the execution half of latent-graph discovery emits a structured temporal signal, nothing scores it, and the whole supervised apparatus of the wiki silently assumes a rate-like or symbolic output

## Best current answer

Six proposals, none general (Tavanaei et al. 2019). SpikeProp takes a timing error but constrains each output unit to **exactly one** spike; SPAN and the alpha-kernel family convolve the train into a continuous function first — so they measure a rate-like discrepancy and reintroduce the blindness the timing code exists to avoid; ReSuMe expands Widrow–Hoff into STDP-against-teacher plus anti-STDP-against-output, which needs the teacher's spike train and trains a single neuron; the Tempotron emits 0 or 1 spikes and therefore cannot be read by another Tempotron. The **Chronotron** is the only entry that scores timing as such — the Victor–Purpura distance, the minimum cost of creating, removing and moving spikes, made piecewise differentiable by hand — and nothing says what those three costs should be for a task, nor how the metric extends past one postsynaptic neuron. **(brainstorm)** The move-cost structure is suggestive: selecting an axonal delay *is* moving a spike, so the metric and the mechanism of [[wiki/concepts/temporal-coding.md]] may be the same object, which nothing has exploited **Wave 11.7 narrows the row rather than closing it** (Gardner & Grüning 2016, [[wiki/concepts/spike-train-error-metrics.md]]): a spike-train loss with an actual *derivation* now exists — ascend the log-likelihood of emitting a specified train under an exponential escape rate (concave, because `SRM₀` is linear), then take `Δu → 0` to recover a deterministic LIF neuron — and it fixes by derivation the presynaptic eligibility kernel (the postsynaptic **potential**, not the current SPAN and PSD chose by hand). Its two variants separate on a phase portrait: an **instantaneous** target-minus-actual error has its attractor at `w/ϑ = 1`, a property of the PSP peak that is *independent of the target time*, with the true solution a repeller; **exponentially filtering** the error (`τ_q ≈ τ_m`) moves the attractor onto the solution and stabilises it. Priced: capacity `α_m` at 1 ms precision 0.07 (instantaneous) / 0.14 (filtered) / 0.15 (Victor–Purpura), and below 0.8 ms the instantaneous rule stores **nothing** while the filtered one still holds ≈0.07 at 0.2 ms. What survives of the row: every rule in the inventory, derived or not, trains **one** output neuron; `τ_q` sets the achievable precision floor and is found by parameter sweep (`G78`); and nothing says where the target spike train comes from for a task that is not hetero-association. **Wave 11.10 breaks the single-neuron half and leaves the metric half untouched** (Mészáros et al. 2025, [[wiki/concepts/learnable-synaptic-delays.md]]): EventProp with delays admits any loss of the form `L = l_p(𝒮) + ∫ l_V(V,t) dt`, computes an exact gradient for it through multiple hidden layers and through recurrent connections, with multiple spikes per neuron — so *deep credit assignment in the timing domain* now exists and the row's standing residue ('every rule trains one output neuron') is spent. What replaces it is sharper: on every task past the toy, the loss chosen was a **first-spike latency** (time-invariant MSE, Yin-Yang) or a **max-membrane-voltage** classification objective, not a distance between spike trains. The machinery to backpropagate a train distance is now available and nobody has put one through it — so the two halves of this row have been solved separately and never composed.
