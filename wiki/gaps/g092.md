# G92 — No architecture in the wiki derives the agent/world boundary; every one of them has it drawn by hand

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** The agent/world boundary is derived from the action stream — the argmax of a controllability statistic against efference copy — rather than drawn by the designer, and supports a correct intervention the observational model gets wrong.

## Why it blocks the target

A world model that supports counterfactual reasoning has to know which variables it can set and which it can only observe — that is what makes an intervention different from an observation, and it is the difference between `p(y|do(x))` and `p(y|x)`. In every wiki architecture the split is a *wiring decision*: the action channel is whatever the designer connected to the actuators, the observation channel whatever they connected to the sensors, and the model never represents the boundary as something that could have been otherwise. The costs are three. (i) A system that cannot re-derive the boundary cannot extend it — tool use, a new effector, a delegated sub-agent all require re-wiring rather than re-inference. (ii) The self/other distinction needed for the agent core system ([[wiki/concepts/core-knowledge.md]]) and for any theory-of-mind module has to be installed separately, since nothing derives it. (iii) Coherence conditions on a world model that quantify over the self — the space/time/cause requirement below — cannot be checked by the system itself

## Best current answer

One computable proposal, unimplemented: bodily states are the states that are **uniquely perceivable and uniquely controllable**, so the boundary is the argmax of a controllability statistic — mutual information between a variable and the agent's own efference copy, conditioned on the rest of the observation stream — and it is learnable from the action stream with no supervision (Safron 2022, [[wiki/entities/integrated-world-modeling-theory.md]]). Nothing in the wiki computes it. The nearest machinery is [[wiki/concepts/counterfactual-probing.md]], which *applies* interventions at points chosen by the experimenter, and [[wiki/concepts/affordance-grounded-symbols.md]], which carves categories by the effects of actions but takes the action set as given

**The nearest running system is a feature filter, not a boundary.** The Intrinsic Curiosity Module ([[wiki/entities/intrinsic-curiosity-module.md]], Pathak et al. 2017) trains an encoder only to predict the agent's own action from consecutive frames. So the retained features are those the efference copy explains, learned with no supervision from the action stream, which is Safron's statistic in practice. It misses the closing condition in two ways. (i) The uncontrolled world is **discarded**, not represented as observable-but-not-settable, so there is no partition of variables. (ii) No intervention is ever scored against an observational model. The paper also claims the space keeps *uncontrolled factors that affect the agent*, but the inverse objective does not require them and this is never tested. **(brainstorm)** Cheapest extension: a second forward model on the residual the encoder discards, so both sides of the split are modelled and the boundary is the partition between the two encoders.
