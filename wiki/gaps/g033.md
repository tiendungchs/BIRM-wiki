# G33 — Nothing decomposes a task into subgoals

**Status:** `PARTIAL`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A configurator selects a subgoal sequence from the world model's own state, on a task whose decomposition was never demonstrated, and beats a flat planner given the same budget.

## Why it blocks the target

Hierarchical planning is now mechanised down to one missing step: a high-level action can be a *condition on the lower-level state* ([[wiki/entities/h-jepa.md]]), so subgoals need no symbolic vocabulary — but something must decide *which sequence of subgoals* a complex task becomes, and configure the cost module for each in turn. This is also the read half of G15 at a second level: not "when to plan" but "plan toward what"

## Best current answer

None. LeCun 2022 assigns the job to a **configurator** module, describes its interface precisely (modulate parameters and attention circuits of perception, world model and cost; extra input tokens in transformer modules), calls it "the most mysterious" part of the architecture, and leaves the decomposition itself "open for future investigation". Hierarchical reinforcement learning has been attacking the same question for longer and offers five partial answers, none settled: subgoals as innate/evolved primitives; states recurring in *rewarded* trajectories; **access points found by partitioning the estimated transition graph** (the only family that needs no signal the graph does not already contain); intrinsic reward for making unexpected salient events recur; and subgoals imported from an impasse or from watching another agent. The same source supplies the cost of getting it wrong — a wrong option set does not merely slow learning, it can make the optimal path unreachable (Botvinick, Niv & Barto 2009). **A sixth family is now built and measured** ([[wiki/entities/hisd.md]]): symbolise unlabelled observation trajectories by optimal-transport segmentation, compress the corpus with a grammar, and keep every rule the corpus uses twice — subgoals by *recurrence* rather than by bottleneck-ness, requiring no reward, no actions, no interaction and no transition graph, and producing the option-of-options nesting the options framework permits but never constructs. It is also the first evidence that the decomposition itself pays: with the discovered skill set held fixed, making the composite nodes selectable beats using the same skills flat, and both beat primitive-action PPO, which fails the task. What it does not supply is a *task-conditioned* decomposition — the grammar is induced once over a demonstration corpus, not configured per goal at query time (Harvey et al. 2026) **The cost of leaving this to the experimenter is now visible on hardware** ([[wiki/entities/v-jepa-2.md]]): V-JEPA 2-AC solves real-robot pick-and-place from three hand-chosen goal images on a fixed 4/10/4 step timetable with no achievement detector, and this is exactly what reduces the planner to **horizon 1** — so the missing decomposition is not a convenience being substituted for, it is *search depth* being substituted for, and the source lists the un-decomposed version as a task it cannot do. It also shows the cheapest possible subgoal representation: not a symbol and not a learned cost but an *image*, whose embedding under the already-trained encoder is the thing descended toward
