# G113 — A probe that perturbs the system to read it is certified read-only by a null, and no instrument in the wiki has a positive control for non-interference

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A perturbation-based read-out reports a *positive control* — a manipulation known to transform the state, run through the same behavioural test, shown to be detected — so that the non-interference claim rests on a demonstrated detection threshold rather than on a failure to reject; or an interference-free read is established by a design that needs no such claim.

## Why it blocks the target

An activity-silent store emits nothing to decode ([[wiki/concepts/working-memory.md]]). The only instrument that reaches it drives the system with a fixed content-free input and decodes the response ([[wiki/concepts/representation-probing.md]]). That instrument is an **intervention**, and every conclusion drawn from it — that the trace was already there, that the retro-cued item was genuinely erased, that an unattended item is held without attention — presupposes the intervention did not create, move or transform what it found. If the impulse instead reactivated a latent item into an active state, the whole family of results is a retro-cue effect in disguise and says nothing about silent carriers.

This is not confined to one paper. It is the general form of a condition the wiki's probe table never states: a probe that only *reads* (a linear decoder, a logit lens) needs no such assumption, and every probe that *acts* on the system needs it. The acting probes are the ones that license causal claims, so the wiki's strongest instruments are the ones with the weakest validity argument.

## Best current answer

**One behavioural null, and it is the only certification anywhere in the wiki.** Wolff et al. 2017, Experiment 3: vary the impulse–probe stimulus-onset asynchrony (0 / 50 / 100 / 250 / 500 ms; 0 = no impulse) and test for an accuracy benefit. `F`(4,76) = 1.184, `P` = 0.325; no uncorrected pairwise comparison against the no-impulse condition reaches significance (all `P` > 0.12).

Why that is not enough, in decreasing order of severity:

1. **It is a failure to reject, with no stated power.** `n` = 20, 280 trials, a **single** angle difference (±16°) rather than the 6–7 used in the decoding experiments, so the psychometric slope — the parameter the same paper shows carries the decoding–behaviour relationship — is not even estimable here. The design is built to detect a shift in overall accuracy and is the wrong shape for the effect it is ruling out.
2. **There is no positive control.** Retro-cues and transcranial magnetic stimulation are both reported in the literature to convert a latent item to an active one. Neither was run through this behavioural test, so nothing establishes that the protocol *could* have detected a reactivation.
3. **The interleaved-sham discipline is available and was not used.** [[wiki/concepts/perturbation-elicitability.md]]'s stimulation protocol scores an identically framed null condition per trial; the impulse null is a between-condition ANOVA over a sparse asynchrony grid.
4. **A behavioural null is the wrong currency.** The result being protected is a *decoding* result. A perturbation could alter the state in a way that changes the decodable pattern without changing accuracy on this task — which is exactly the dissociation the same paper exploits in the other direction when it argues that delay decoding tracks attention while behaviour tracks memory.

Two cheap designs that would close this, neither run: (i) ping on a random half of trials and test whether *decoding of the un-pinged item at a later ping* differs, i.e. use the instrument against itself; (ii) run the asynchrony sweep with a retro-cue substituted for the impulse and show the same analysis detects the known reactivation.

## Status

`OPEN` — the instrument is worth having and is the only route to a carrier that holds no activity; the gap is that its licence is a single underpowered null in one paper, and the wiki now cites results that depend on it on three pages. Adjacent: `G112` — the ping does not close that row either, because Experiment 3's whole content is that the manipulation leaves the *scored output* unchanged, which makes this a decoding instrument and not the behavioural protocol `G112` asks for.
