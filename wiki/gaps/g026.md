# G26 — Nothing selects hypotheses by structure rather than by description length

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** An objective selects a hypothesis by its factorization into structural position and content rather than by total code length, shown by preferring a longer program that recovers the graph over a shorter one that does not.

## Why it blocks the target

The one provably sufficient inductive bias is the simplicity prior, and it identifies a *short program* for the data — not a factorization of it into `g` (structural position) and `x` (content). The shortest program's internal variables need not correspond to the graph at all, so even an ideal inductor may recover the environment without exposing its structure in navigable form. G16 says the factorization must be paid for with bias; this says the strongest known bias does not buy it

## Best current answer

None. **(brainstorm)** The candidate is a *constrained* code length — minimize description length subject to the code being reusable across instances of the family, i.e. price `g` and `x` on different budgets rather than one **A third candidate, and the first that is exactly solvable and running**: charge the code length over the *demonstration set jointly* rather than over one program. [[wiki/entities/arc-vsa-solver.md]] selects an ARC action set by minimum hitting set with a cost counting each distinct operation and each distinct operation–parameter pair used across all demonstrations, on the stated principle that "recurring operations and parameters have greater explanatory power" — so an action explaining two output objects in two different demonstrations beats an equally short action explaining one. It is still a coding cost and so does not leave this row's family, but it changes the *unit* the code is charged over, cannot be evaluated on a single example, and prefers reuse to brevity where the two conflict. NP-complete, exactly solved fast in practice.

**A fourth candidate, and the one with the longest run**: charge description length over the **solved corpus plus the library** rather than over one program, and restrict candidates to fragments of *semantically equivalent refactorings* of solutions ([[wiki/entities/dreamcoder.md]]). This is the same "length under enforced re-use" the NEO near-miss identifies, reached from the library side rather than the executor side: a fragment is only cheap if several independent solutions can be rewritten to share it. The evidence that re-use rather than brevity does the work is the *Memorize* ablation — installing whole solutions gives the same expressivity and the same opportunity for reuse, and loses. What it does not do is score the *recovered vocabulary*: the libraries are evaluated by tasks solved and by depth (`r = 0.79` with tasks solved), never against a ground-truth primitive set, so it demonstrates that the criterion is useful without showing that it selects structure.

## Status

`OPEN` — now with a measured counterexample **and a measured near-miss**. Counterexample: Chinchilla 70 B compresses flattened ImageNet patches to 48.0%, beating PNG (58.5%), while the flattening destroyed 2-D adjacency and the model has no object, depth or occlusion structure — world-class code length with none of the graph recovered (Delétang et al. 2023). Near-miss: [[wiki/entities/neo-neural-theorizer.md]] shows description length *can* select structure when the code length is charged against a **shared executor** — the same operator must realise every symbol on every instance, so a short program is only cheap if its parts are reused — recovering the exact ground-truth primitive set (primitiveness 1.000, near-diagonal code–primitive alignment). But the same sweep supplies the counter-pressure: raise the simplicity weight 20% and it selects short *entangled* programs instead (primitiveness 0.213), because one code for `Left-Down` is a shorter explanation than two. So the operative bias is not description length but **description length under enforced re-use**, and the two pull against each other with nothing but a hyperparameter sweep against ground truth to set the balance ([[wiki/empirical-tensions.md]] T155). **A third criterion now exists and is neither structure nor length** ([[wiki/entities/autotom.md]]): select the model that minimises the entropy of *the query's* posterior, penalised by variable count — `U(M,q) = −H(P(q|X)) − α|M|`, stopping at one bit. It is **query-conditioned**, which is the property this row's two candidates both lack: the same observations select different structures for "what does she believe" and "what is she trying to do", so what the criterion recovers is the sub-graph that is *load-bearing for a question* rather than a factorisation of the data. Two costs. It selects for confidence, not correctness — a model omitting the variable that would introduce doubt scores best (T189) — and it needs a query, so it cannot run unsupervised over a corpus the way an MDL objective can. **(brainstorm)** the combination this row wants may be the two composed: length under re-use to fix the vocabulary offline, query entropy to select the sub-graph online
