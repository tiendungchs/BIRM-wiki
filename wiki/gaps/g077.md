# G77 — Every high-performing temporal code in the wiki needs a time origin that nothing supplies

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A temporal code that needs a time origin gets one from a reference the system generates and maintains itself, and holds its accuracy advantage over origin-free codes under realistic jitter.

## Why it blocks the target

The best-scoring timing schemes are all *globally referenced*: time-to-first-spike measures latency from stimulus **onset**, phase coding measures it against a reference **oscillation**, sequential and parallel binary codes need a **clock**. Each therefore presupposes a signal that is not in the data and that no architecture in the wiki generates — and the objection is biological, not pedantic: Rullen & Thorpe's argument for rank-order coding is precisely that *the brain cannot know when a stimulus began* (Auge et al. 2021). The same hole sits under [[wiki/concepts/temporal-coding.md]]'s mechanism, which assumes an already phase-locked input volley and does not say what phase-locks the first stage, and under [[wiki/entities/spiking-tem.md]], whose theta-phase inhibition is driven by an oscillator supplied by the modeller. It blocks the target because a discovered graph must be re-entered at arbitrary times: a code readable only relative to an externally-marked `t=0` cannot represent structure encountered mid-stream

**The same hole sits under value learning, and it is older than the spike-code literature.** Temporal-difference models of the dopamine record cannot use one weight per cue — the omission dip lands at the *trained* delay, so the cue must be represented as a vector of time-since-onset components (the complete serial compound, `xᵢ(t) = 1` exactly `i` steps after cue onset). That is a tapped delay line whose `t=0` is stamped by cue onset, and the model's authors concede that "virtually nothing is known about how the brain represents a stimulus for substantial periods of time into the future; therefore, all temporal representations are underconstrained from a biological perspective" (Schultz, Dayan & Montague 1997, [[wiki/concepts/reward-prediction-error.md]]). So the row is not a niche problem of spiking codes: a system that cannot detect stimulus onset can learn *whether* a cue predicts reward but not *when*

## Best current answer

Three partial answers, none complete. (i) **Drop the reference** — rank order, inter-spike interval, synchrony and temporal-contrast codes need no origin, and the price is measured: rank order forfeits absolute amplitude entirely (a constant signal is unrepresentable) and is jitter-fragile enough to cost 4.8 points against time-to-first-spike on one identical gas-classification pipeline. (ii) **Generate the reference internally** — an intrinsic oscillation makes phase self-referential, which is what the septal theta drive does for hippocampus ([[wiki/concepts/inter-areal-synchrony.md]]: coherence is supplied by a third region rather than computed by either endpoint), but then the origin is arbitrary and shared only by whatever the same oscillator reaches. (iii) **Make the reference the previous event** — temporal contrast encodes the derivative against a running baseline, so every event carries its own origin; nothing has tried to build a *representation* on that, only sensors
