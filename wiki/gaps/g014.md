# G14 — No consolidation channel: instance structure never becomes meta structure

**Status:** `PARTIAL`  
**Kind:** `part`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A machine transports what the fast store learned about one instance into a revision of the slow meta-graph, using replay selected by transferability rather than by recency or salience, with a regulator that stops consolidation before it overfits.

## Why it blocks the target

Biology transports one-shot hippocampal bindings into cortical structure by replay during offline periods. Machine replay only stabilizes a *single* learner (decorrelating a training stream); nothing converts what the fast level discovered about one instance into a revision of the meta-graph

## Best current answer

Replay/consolidation, named biologically; episodic control uses the fast store for behaviour but has no path back into the slow one. **The biological channel now has a measured selection criterion, and it is not the one machines copied**: replay suppresses salient-but-idiosyncratic stimuli, upsamples rarely-visited space and prefers remote to imminent trajectories, converging on an inductive bias toward *transferable* content — because consolidating everything overfits (Liao & Losonczy 2024; [[wiki/concepts/offline-replay.md]]). That gives the channel a specification a builder can implement (weight rehearsal by cross-episode recurrence and inverse visitation, not by reward or TD-error) and leaves the transport itself unbuilt, plus a new sub-problem: seven jobs claim the same replay budget under incompatible sampling policies. **One of those jobs is not transport at all but *construction*:** awake ripples increasingly co-activate a cue and an outcome never experienced together, without the intermediary, only when the chain ends in reward, and with the outcome cell firing *first* — so the offline period also writes edges the agent never traversed, in the direction of credit rather than of use (Barron et al. 2020; [[wiki/concepts/offline-replay.md]]). **And the transport has a wiring cost nobody prices** (Rolls 2013): reinstating a cortical pattern requires `C^HBP = C^RC · a_nc/a_CA3` hippocampally-originating afferents per cortical cell — ≥12,000 even in the best case — which makes a monosynaptic read-out impossible and forces a *polysynaptic reverse hierarchy* with gradual fan-out per stage. So the sparser the fast store (better capacity), the more expensive the read-back, a trade-off every retrieval-augmented architecture treats as free. The same source disputes the *schedule* (waking, not sleep — [[wiki/empirical-tensions.md]] T34) and adds a confound: a changed cortical representation after learning is not evidence of transfer, since a changed CA1 code alters cortical firing through fixed connections. **A candidate for what the channel carries, one level up from the episode** (Lisman et al. 2018, [[wiki/concepts/memory-allocation-excitability.md]]): an hours-long CREB-dependent excitability tag makes temporally proximal episodes share a cell population *before* consolidation runs, and is proposed (untested) to raise those cells' sharp-wave-ripple participation — so the unit transported would be a tag-glued *cluster* of episodes rather than one episode, which is already an abstraction step, and replay priority becomes a decaying scalar set at encoding rather than a computed quantity. **The valve now has a specification, and it is implementable today** (Lindsey & Litwin-Kumar 2024, [[wiki/concepts/recall-gated-consolidation.md]]): gate the slow store's write by the fast store's recall of the *proposed update*, `Δw_LTM ∝ g(w_STM · w*)`, which filters one-off experience out of long-term storage because reliable and unreliable updates are indistinguishable at a synapse but separable across a population. The gating argument reduces to one broadcast scalar per event — prediction accuracy, reward × decision confidence, or familiarity, depending on the learning rule — so it needs no task boundary, no importance estimate, no stored exemplars and no offline pass, and it provably beats every synapse-local consolidation mechanism when reinforcement arrives in bursts. What it does **not** supply is the transport itself: the slow store still learns from the same event stream rather than receiving anything the fast store discovered, so the gate answers *which* updates deserve to become structure and leaves *how instance structure becomes meta structure* exactly where it was  **The transport is now built, and it inverts the gap's premise** (Sun et al. 2023, [[wiki/concepts/generalization-optimized-consolidation.md]]): a sparse Hopfield notebook one-shot-binds a random index to the slow learner's activity, settles into that index from random initialisation offline, reinstates the slow learner's input and output layers through return weights, and the slow learner runs gradient descent on *its own reactivated targets* — self-distillation from the fast store, with the environment never re-seen. So instance structure does become meta structure, in a linear model, with no privileged access to the data. What the same model shows is that running this channel unregulated is **harmful**: the optimal number of reactivations is finite and set by the predictability of the relation, and past it generalization degrades, falling below chance in low-SNR environments. For a relation the slow learner cannot model — because of noise, architecture mismatch, unobserved inputs or its own attention — the optimal transport is **zero**, which makes permanent fast-store residence a designed outcome rather than an unfinished consolidation and means the fast store is required at deployment, not only during training. The transport's value peaks where stored examples ≈ slow-learner parameters, the double-descent point that is simultaneously the worst regime for overfitting, so the channel is most valuable exactly where regulating it matters most. What remains missing is the regulator itself: the three estimators that work in the model (held-out validation, maximum-likelihood SNR from input–output covariance, initial learning speed) are either biologically implausible or need a prior linking data statistics to predictability that is deferred to meta-learning, and the criterion disagrees with the recall gate above on recurring-but-unmodellable relations ([[wiki/empirical-tensions.md]] T81) **And a constraint on the cargo** (Euston et al. 2012, [[wiki/entities/medial-prefrontal-cortex.md]]): the cortical learner already represents the context, event and response terms at acquisition — what transfers is only the *association among them*, inside a bounded 0–2 h post-task window, with cortical consolidation then continuing ~2 weeks. That makes the machine version a *partial* write (freeze the representations, replay only into the associative weights) rather than a full-parameter distillation, and it predicts the otherwise odd asymmetry that a cortical lesion costs more at remote than at recent delays without the region being dispensable early ([[wiki/empirical-tensions.md]] T97). **And the machine-learning method that currently wins on the wiki's benchmark has no such channel at all**: test-time training fits a fresh per-task model from the base weights and throws it away, so a system that has just solved 99 ARC tasks starts the 100th knowing exactly what it knew at the start (Chollet et al. 2024). **The wiki's first measured write-back of this shape, and it is one system** (Chollet et al. 2026, [[wiki/concepts/refinement-loop.md]], [[wiki/entities/neural-episodic-control.md]]): SOAR fine-tunes an LLM on **its own program-search traces**, improving open-source ARC-AGI-1 performance by up to 52% with no human-authored DSL and no solution dataset — the instance-level search product becoming meta-level weights, which is exactly this row's missing channel. Everything else in the 2025 ARC record leaves it open in the same form: TTT, evolutionary program synthesis, zero-pretraining nets and application-layer harnesses all build a per-task artefact and discard it, so four substrates reproduce the gap verbatim. **And the row now has a price rather than a complaint** ([[wiki/entities/neural-episodic-control.md]], Pritzel et al. 2017): an agent whose value function *is* the fast store leads every parametric Atari agent by 2–3× median human-normalised score below 20M frames and is overtaken by prioritised replay at 40M, on the same data and with the store strictly larger and its metric strictly better trained at the crossing. What the parametric agents have is a mechanism that turns repeated experience into a smoother function instead of more entries — i.e. this row's missing channel is what converts a data-efficiency advantage into an asymptotic one, and its absence is measurable as a crossing point on a learning curve. That gives the row a cheap test any candidate channel must pass: bolted onto the episodic agent, it should move the crossing right or delete it.

**And a machine loop now exists, in a symbolic slow store** ([[wiki/entities/dreamcoder.md]]): the abstraction sleep phase takes the programs found while solving individual tasks, searches their *refactorings* for fragments that recur across the corpus, and installs the best one as a library primitive — instance structure becoming meta structure, with the transported object a named reusable entry rather than a weight update. It supplies both halves this row asks for. **Selection by transferability**: a fragment cannot be adopted unless it pays for itself across several solutions (the *Memorize* ablations, which install whole solutions without compressing, lose across domains). **The regulator**: the phase halts when no further addition raises the posterior `P[L]·Π_x max_ρ P[x|ρ]P[ρ|L]` — the stopping rule is the objective, not a schedule. What it does not supply is the hard part biologically: the slow store is symbolic and there is nothing to overwrite, so the loop never faces the interference problem consolidation exists to manage.

`PARTIAL` — the selection criterion is specified and computable, a transport loop exists in a linear model, and a full loop *with* a self-terminating regulator now runs in [[wiki/entities/dreamcoder.md]] over a symbolic slow store on crisp tasks. What remains open is the case the row was written for: transport into a *distributed* slow store, where consolidating is also overwriting
