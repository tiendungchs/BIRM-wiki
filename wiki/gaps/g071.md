# G71 — A generated inference is never tagged as one; transferred content becomes indistinguishable from observed content

**Status:** `OPEN`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Why it blocks the target

Every transfer mechanism in the wiki writes its output into the same store, in the same format, as the observations it was derived from: copy-with-substitution emits target propositions ([[wiki/concepts/analogical-mapping.md]]), schema assimilation writes the schema's expectations into the instance ([[wiki/concepts/schema-assimilation.md]]), replay writes edges the agent never traversed ([[wiki/concepts/offline-replay.md]]), pattern completion returns a filled-in pattern with no field saying which bits were cued and which were invented. Without a provenance bit, no later stage can weight a hypothesis differently from a fact, no acceptance test can be applied retroactively, and errors compound silently across transfers — which is the same failure mode as G6 (spurious edges) one level up, at the level of *episodes* rather than *weights*

## Best current answer

**Nothing, and the biology does not do it either — with a measured rate.** Blanchette & Dunbar 2002: subjects read a target text and then an analogous source, with no instruction to map and no correspondences stated; a week later they "recognise" never-presented copy-with-substitution inferences as having been in the target text **50%** of the time against a **25%** base rate, at both 15-minute and one-week delays (Perrott et al. 2005 replicate; Schustack & Anderson 1979 anticipate). So spontaneous transfer runs on mere juxtaposition, its products are integrated with prior knowledge of the target, and provenance is lost. Note this is exactly the property that makes analogy effective as *persuasion*, and exactly the retrieval-augmented-generation failure where a retrieved passage's content resurfaces as asserted fact. The only partial defence in the wiki is an acceptance test applied at generation time ([[wiki/concepts/external-verification.md]], G68) — which discards rejected candidates but still stores the survivors unmarked
