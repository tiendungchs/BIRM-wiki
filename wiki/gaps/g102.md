# G102 — No architecture has a state in which it holds a capability and declines to deploy it

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L1`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A system holds a capability and declines to deploy it under a settable disposition, so that a null result can be attributed to expression rather than to absent machinery.

## Why it blocks the target

Every wiki agent is scored on whether it *can* solve the task, so competence and expression are the same variable and a null is always read as an absence of machinery. The comparative record says that reading is wrong in the modal case: chimpanzees hold perspective taking and were recorded as lacking it for two decades because the paradigms were cooperative rather than competitive; the *same* chimpanzees succeed and fail at one cooperation task depending only on whether the reward is dispersed or monopolisable; and dyadic intolerance abolishes model–observer social learning outright, with the cognition held fixed in all three. What is missing is a scalar dispositional state, distinct from task reward, that gates whether a whole class of inferences is run at all — [[wiki/concepts/subjective-value.md]] and [[wiki/concepts/reward-prediction-error.md]] model the magnitude of a valuation at choice time, not a standing gate before it

## Best current answer

**None.** The nearest thing in the wiki is [[wiki/concepts/precision-weighting.md]]'s gain term, which modulates how strongly evidence is weighted rather than whether a competence is exercised, and [[wiki/concepts/neuromodulatory-metaparameters.md]], which has the right *type* (a slow scalar that reconfigures the whole system) and no candidate mapping to a social disposition. The evolutionary side supplies the driver but not the mechanism: prosociality across 15 primate species is best predicted by allomaternal care, i.e. by a population payoff structure, which is a training-signal specification no wiki architecture receives ([[wiki/concepts/objective-identifiability.md]]). The cheap first move is evaluative rather than architectural — the paired-frame protocol at `T291` — because it measures how large the competence/expression gap already is in models the wiki holds

**The one normative rule on offer, and why it does not close the row.** The expected-value-of-control criterion makes "hold a capability and decline to deploy it" the *default* case rather than a missing state: `signal* = argmax_signal [Σ Pr(outcome|signal,state)·Value(outcome) − Cost(signal)]`, so a competence goes unexercised whenever its control signal loses to the untaxed default — competence intact, expression withheld because the price exceeded the payoff (Shenhav et al. 2013, [[wiki/concepts/expected-value-of-control.md]]). This supplies the *form* the row asks for: a quantity distinct from task reward, evaluated before the inference is run, whose manipulation moves expression with cognition held fixed. Three things stop it from being the answer. (i) `Cost(signal)` is asserted monotonic in control intensity and never measured, so the gate has no settable parameter — the row needs a *dial*, and the theory supplies a term. (ii) The cost is indexed by the control signal, not by a class of inference, so it cannot express "run perspective taking in competitive contexts and not cooperative ones" without the identity dimension already carrying the distinction, which pushes the problem into the unexplained candidate set. (iii) It is a per-decision computation, not a standing disposition, so it re-derives the refusal each time rather than holding it — the opposite of the slow scalar [[wiki/concepts/neuromodulatory-metaparameters.md]] has the right type for.
