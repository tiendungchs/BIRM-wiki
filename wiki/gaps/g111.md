# G111 — Every predictor in the wiki compares its prediction with feedback in temporal register by fiat; none learns its own delay

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Spec:** `D256` ([[_brainstorm/birm-spec.md]] §11)  
**Closes when:** An architecture learns a model of its own sensory feedback latency *separately* from its forward dynamics model, uses it to align prediction with feedback before subtracting, and remains stable when the latency changes under it.

## Why it blocks the target

A prediction error is only an error if the two terms refer to the same moment. Every predictive architecture in the wiki — predictive coding ([[wiki/concepts/predictive-coding-free-energy.md]]), prediction-error neurons ([[wiki/concepts/prediction-error-neurons.md]]), world-model rollouts ([[wiki/concepts/learned-world-models.md]]), successor-representation TD errors — subtracts prediction from observation at a timestep index, which silently assumes the sensory consequence of an action arrives in the step the action was taken. In any embodied system it does not: visual feedback of a hand movement is delayed by ~100–200 ms, which is comparable to the movement itself. Without an explicit latency model the comparator is either subtracting mismatched pairs (error where there is none) or is forced to make the forward model absorb the delay, which conflates *what the world does* with *how late I hear about it* — and then a change in either one requires relearning both.

## Best current answer

**A named architecture and a measured way to train it, with no machine instance.** The Smith predictor (Miall et al. 1993, in Wolpert, Miall & Kawato 1998, [[wiki/entities/cerebellum.md]]) carries **two** forward models: a forward *dynamic* model producing an immediate state estimate inside a high-gain internal loop, and a forward *output* model that transforms and **delays** that estimate into an estimate of reafference, so the internal prediction can be held back into temporal register with the real feedback. Arbib's standing objection is that two models trained simultaneously from one error term face a structural credit-assignment problem. The answer offered is a **timescale separation**, and it is measured rather than assumed: human adaptation to an added 200–300 ms visual feedback delay in a tracking task takes **hours**, while adaptation to changed task dynamics takes minutes, and oculomotor delay adaptation is equally slow — so a slow delay model and a fast dynamics model can share one error signal without fighting over it. That gives a builder a concrete recipe (two heads, two learning rates two orders of magnitude apart, one error) and no implementation. The related *temporal* credit-assignment problem — the corrective signal arriving ~150 ms after the synapses that must be changed — is the eligibility-trace question of [[wiki/gaps/g020.md]], and is separate from this row: G20 asks how a late error reaches the right synapse, this row asks how the system knows *how late* the error is.
