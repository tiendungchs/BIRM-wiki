# G42 — No machine fast store has a capacity model, so nothing knows when it is full

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A machine fast store reports a capacity bound before it is exceeded, sized by fan-in per unit rather than by hyperparameter, and its measured breakdown point matches the bound.

## Why it blocks the target

Every memory architecture in the wiki — key-value stores, replay buffers, clone pools, Hopfield layers, attention over a cache — sizes itself by hyperparameter and reports no bound. Biology's version is closed form (`p_max ≈ k·C^RC/(a ln(1/a))`, `k ≈ 0.2–0.3`) and its overload behaviour is *catastrophic*: past capacity, most of what was stored stops being retrievable, not just the marginal item. A store with no capacity estimate therefore cannot decide when to forget, when to consolidate, or when to refuse a write — and its failure is silent

## Best current answer

**The equation itself, plus two design consequences and one missing piece.** (i) Capacity scales with *fan-in per unit*, not population size, so the move is more units at lower connection probability — diluted integrate-and-fire attractors are additionally measured to be *more* stable and more accurate than fully connected ones at matched fan-in, because duplicate synapses between a pair distort the basins. No machine memory exposes a connection-probability knob at all. (ii) Sparsity is the same parameter as the separation knob (G38), read from the capacity end. (iii) Missing: forgetting is asserted (heterosynaptic LTD plus random reallocation of cells to new episodes) with no rate, no schedule, and no account of what sets the retention window beyond "the acquisition rate of new episodes". **Now a built store with a derived capacity *and* a non-catastrophic overload** ([[wiki/entities/vector-hash.md]], Chandra et al. 2023): prestructure the fixed points from a frozen grid code randomly projected into the store, and all `∏_i K_i` states become attractors with store size growing only *logarithmically* in their number, basins provably convex, equal-sized and spurious-free. Past the perfect-recall point (`N_h` patterns) information per pattern falls as `1/N_patts` while saturating the same `#synapses/(2·#patts)` bound the cliff models hit only at a point — a **memory continuum**, so "full" stops being a binary state and becomes a detail-vs-count exchange rate the store can be queried for at any time. Three things it changes for a builder: capacity is set by the *address space* rather than by the plasticity rule, so it is chosen at design time and is exact; overload degrades resolution rather than identity (the retrieved item stays in the correct Voronoi cell), which is the failure mode a system can detect and act on; and recognition memory falls out of a two-threshold read of mean store activity. Still missing: no forgetting rate here either (nothing is ever evicted — the address space is simply large), no similarity structure across stored items (assignment to addresses is random), and the capacity is exponential in a code the model does not learn **A second bound, on the sequence side.** Replay of an embedded assembly chain in a spiking net with measured CA3 statistics succeeds iff `c · M ≳ const` — connection probability and assembly size are substitutes at fixed reliability, network size enters only weakly, and larger embedded weights lower the minimum assembly size (Sammons et al. 2023, [[wiki/concepts/offline-replay.md]]). So a store has *two* floors to report, not one: how many items it can hold (`p_max`) and how small an item may be before it can no longer be reactivated at all. The second is a pure wiring property and no machine buffer exposes it. Caveat: the connectivity `c` it is calibrated against is itself contested by 10× ([[wiki/empirical-tensions.md]] T49), so the constant is not yet a number a builder can use. **The earliest machine answer of all, and the only one with a per-retrieval confidence read-out** (Kanerva 1993, [[wiki/entities/sparse-distributed-memory.md]]): capacity `τ = T_max/M = 1/[Φ⁻¹(φ)]²` — ~10% of the location count at one wrong bit in a thousand — derived from signal `μ = pM` against noise `σ² ≈ pM[1 + pT(1 + p²M)]`, hence *independent of the pattern size* (Keeler 1988: the same capacity per storage element as a Hopfield net, but Hopfield's is capped by the word length while this one is not, so doubling the hardware doubles the words). Two things it adds to the row. (i) Overload is graded and its cause is named — cross-talk grows as `pT` because two cues' active sets overlap in `p²M` locations — so "full" is a signal-to-noise number the store can compute rather than a state it discovers. (ii) **Every read returns `|s_u|`, the distance of each output bit's vote from threshold**: an unlabelled, per-retrieval estimate of how much evidence the store holds for what it just said. That is the missing observable in this row's own statement of the problem — a store that cannot decide when to refuse a write or when to consolidate can at least report, per query, that it is guessing. CMAC (Albus 1971, same source) closes the loop crudely: write only when the retrieval error exceeds tolerance, `ΔC = g(p̂_u − s_u)/K` **And the row has been counting the wrong quantity for sequences** ([[wiki/entities/dense-sequence-memory.md]], Chaudhry et al. 2023): a store has an *item* capacity and a *sequence* capacity, and they scale differently — the number of chained transitions that survive before one bitflip derails the trajectory is smaller than the single-transition capacity by roughly a factor `P`, and for an exponential interaction function the gap **diverges with network size**, so a memory measured as excellent at one-step retrieval can be unusable for rollout. The same source relocates the capacity knob: with the code, the sparsity and the learning rule held fixed, sequence capacity goes from linear in `N` to polynomial (`f(x)=x^d`) or exponential (`f(x)=e^{(N−1)(x−1)}`) purely by steepening the nonlinearity applied to the state–pattern overlap at read-out — one scalar `d`, with a computable finite-`N` optimum `d_max` beyond which capacity *falls*. Two caveats it also supplies, both of which apply to every other entry in this row. (i) **The i.i.d.-pattern bounds fail qualitatively on correlated data**: 200,000 MovingMNIST frames well inside the predicted capacity are recalled *not at all* — not a partial image — by every polynomial network up to `d ≈ 50`, and the only fixes are an exponential `f` or a generalized pseudoinverse rule that is batch, non-local and numerically unstable. (ii) **The biologically plausible two-body form costs one hidden unit per stored pattern**, so total capacity is linear in the total neuron count; the exponential scaling is a statement about patterns per *visible* neuron only. **And a capacity number that is conditional on a control signal, plus the axis this row never named** ([[wiki/entities/context-modular-memory-network.md]], Podlaski et al. 2025): mask the same weight matrix per context — neurons (rows and columns) or synapses (entries) — and total capacity rises to ≈7× the Hopfield limit for random neuronal gating at 100 contexts and ≈30–40× (`α* ≈ 5`) for masks *refined* after learning by a per-synapse sign test `sgn(J_ij) = sgn(J_ij^(σ))`, with the refined gating ratio **derived rather than chosen** (`1−c → ½` as `s → ∞`, so the number of contexts can grow indefinitely without changing the usable synapse fraction). Four things it adds to this row. (i) Every number is *conditional on an externally imposed context*, which the authors flag as making comparison with classical bounds invalid — a store can be told what to be full of. (ii) A second quantity to report beside capacity: **accessibility**, `κ̄_acc/κ̄_inacc`, with `κ̄_inacc → 0` under refinement, i.e. hidden memories are not weakened but are *not attractors at all* — no other store here can withhold. (iii) **Information per synapse moves against capacity** under random gating (patterns get smaller, or overlap collapses), so a capacity multiplier is not a storage multiplier; only refinement raises both. (iv) The cost is priced and it is fatal for the strong version: a context-encoding network for per-synapse gating scales as `s·N`, dropping total capacity **below the Hopfield limit after a few contexts** — so the 30–40× is available only if the mask is free, and no forgetting rate appears here either. **And a route that raises the ceiling instead of reporting it** ([[wiki/entities/fcann.md]], Englert et al. 2026): if the stored states are mutually *orthogonal* the network is a Kanter–Sompolinsky projector — maximal capacity and error-free recall, with the attractors equal to the positive-eigenvalue eigenvectors of `J` — and the free-energy learning rule `ΔJ_ij ∝ σ_iσ_j − L(b_i + Σ_k J_ik σ_k)σ_j` is claimed to be the only known local, incremental, *single-phase* rule that approximates it (the unlearning/"dreaming" alternatives need two phases). Two things this changes for the row. (i) Every capacity number above is a random-i.i.d.-pattern number, i.e. the pessimistic case ([[wiki/empirical-tensions.md]] T61); the ceiling is a property of the write rule, not of the store. (ii) It supplies the row's missing *cheap* fullness test: attractor–eigenvector alignment and convergence time against a degree-preserving permutation of the same weights are both computable from the weight matrix alone, with no data, no labels and no probe — but neither is yet a capacity estimate, and this source measures the signature without ever running the rule. **And the row's sharpest consequence, because here the protection mechanism itself reverses** ([[wiki/entities/elastic-weight-consolidation.md]], Kirkpatrick et al. 2017): in the analytically tractable random-pattern case a Fisher-weighted quadratic penalty turns the stored-memory signal-to-noise decay from exponential to power-law *below* capacity and retains a **smaller** fraction than plain gradient descent *above* it, with Hopfield-style blackout catastrophe at saturation — neither retrieving old items nor storing new ones. The cause is structural and stated: the accumulated importance estimate can only ever make weights less plastic, so the method models retention with no forgetting operator and therefore has no steady state, unlike the cascade models it imports from. So a store with no capacity estimate is not merely unable to decide when to forget; it cannot detect that the thing protecting it has started doing harm.

## From

[[wiki/entities/rolls-treves-hippocampal-model.md]] (Rolls 2013); [[wiki/entities/vector-hash.md]] (Chandra et al. 2023); Sammons et al. 2023; the quantity [[wiki/concepts/complementary-learning-systems.md]] and [[wiki/concepts/pattern-separation-completion.md]] both assume without stating; [[wiki/entities/dense-sequence-memory.md]] (Chaudhry et al. 2023); [[wiki/entities/context-modular-memory-network.md]] (Podlaski et al. 2025)  **A second closed-form model, for the recognition side rather than the storage side, and it does not have the catastrophic overload** (Ahmad & Hawkins 2016, [[wiki/concepts/sparse-distributed-representations.md]]): for a detector holding a `s`-bit subsample of a sparse `n`-dimensional code, `P(false positive)` is a hypergeometric tail with `θ`, and `M` such detectors bound the population error by `M·P(match)` — so "how full is the store" becomes a number computable from `n`, `a`, `s`, `θ` and `M` alone, with no training and no measurement, and the degradation is a slowly rising false-positive rate rather than a cliff. The union variant gives the same statement per *slot* (4–16 patterns before mix-and-match errors), which is the closest thing the wiki has to a refuse-the-write criterion derived rather than tuned. **A third capacity model, for attention-based stores, and it is already computed on every read** (Gong & Zhang 2024, [[wiki/concepts/attention.md]]): a softmax row distributes one unit of mass over every candidate entry, so retrieval precision falls with *occupancy* rather than with a hyperparameter, and the summed row entropy `H_N = Σ_i H(A_{i,·})` of the attention matrix tracks that decline directly — in minimal causal transformers on the `N`-back task it rises with `N` exactly as accuracy falls, with the target item still well inside the context window. So an attention-based store has a free per-read confidence scalar and a free store-level fullness scalar, and no architecture in the wiki gates on either; the degradation is graded rather than catastrophic, and the measurement is on a deliberately crippled model (1 layer, 1 head, no feed-forward network) whose limit mostly disappears at 2 layers or 2–4 heads.  **And the first machine store that reports its occupancy *from its own contents at run time*, rather than from a formula fixed at design time** ([[wiki/entities/conceptor.md]], Jaeger 2014). Represent what each stored item claims as a soft subspace `C^j` (a positive semi-definite matrix with singular values in `[0,1]`), keep the union `A^j = C¹∨…∨C^j`, and read `q(A^j) = (Σ_i s_i(A^j))/N ∈ [0,1]` — the fraction of the shared space already spent. Four properties no other entry in this row has together. (i) The number is **derived from the same algebra used to write**, not instrumented separately: `∨` is the store's own union operator. (ii) It is **content-sensitive rather than count-based** — an exact replica of a stored item costs *zero* additional quota, and members 5–16 of a 2-parameter pattern family cost 0.26 where the first four cost 0.52, so the store prices redundancy without being told the items are related (this is G38's allocate-vs-reuse decision made by geometry: write only `C^{j+1} \\ A^j` into `¬A^j`). (iii) Overload is **bounded to the item being written**: at `q ≈ 0.99` the 16th pattern is recalled badly and the previous fifteen are untouched, which is neither the Hopfield cliff nor a graded resolution loss but a spill. (iv) It gives a **refuse-the-write criterion that is exact and free** — compare `q` against 1 before loading. What it does not give: no forgetting rate and no eviction (the row's standing hole, unmoved); it is demonstrated only for dynamical patterns in a reservoir at `N ≤ 500` with ≤16 items; and the construction needs the per-item spectra to be near-rectangular, which for arbitrary patterns must be forced by a hand-set thresholding step. See also [[wiki/empirical-tensions.md]] T194: in the same system, crossing the load threshold is what converts rote item storage into representation of the parametric class, so `q` may be a curriculum signal and not only an alarm. **A third bound, over a different quantity — fidelity rather than count** ([[wiki/entities/sigma-pi-reservoir.md]], Kleyko et al. 2025). For a superposition holding polynomial features of degree `p`, `D = O((pR/ε)²)` with `R = max(‖x‖₁,‖y‖₁)` suffices for every stored inner product to be within `ε` of the true kernel with high probability — the store is 'full' when the similarity it reports stops being accurate, not when items become unretrievable. Two things this adds: the bound is **quadratic in the structural complexity of what is stored** where the explicit representation is exponential, so richness is cheap and only precision is dear; and it is the wiki's only capacity statement that is a *continuous accuracy curve chosen by the designer* rather than a threshold discovered by overload. Its limit is the mirror of [[wiki/entities/vector-hash.md]]'s: nothing is ever decoded out of this store, so the bound says what can be *compared*, never what can be *recovered* — which is why it runs at `D = 28` where a decodable HRR needs thousands.
