# G15 — No control policy over simulation

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A policy sets rollout depth and branch choice from a quantity the agent computes for itself, and beats both always-on and hand-scheduled rollout on a task where the affordable depth varies across states.

## Why it blocks the target

Planning is path search, but nothing decides when to roll out, how deep, which branch, or when the answer is good enough. Without it, model-based reasoning is either always-on (unaffordable) or hand-scheduled (not general)

## Best current answer

Prefrontal control of hippocampal rollout, proposed biologically; controller-queries-model architectures implement the interface but not the policy. **Active inference supplies the *when* and the *switch*, not the *how deep*:** homeostatic divergence read as free energy both initiates the rollout and sets its target, the epistemic-vs-goal trade-off arbitrates exploration against exploitation on the same quantity, and dropping bottom-up gain (`γ → 0`) with strong biased competition (`β ≪ 0`) is the operational switch from perception into simulation. **A second candidate for the same half:** a rational *arbitration* between model-based and model-free control on a flexibility-vs-speed trade-off, supervised metacognitively, with habitization as the observed shift — which prices planning against its own cached output rather than against a homeostatic drive ([[wiki/concepts/amortized-inference.md]]). **A third supplies the *interface* in closed form and still no policy:** in an adaptive continuous attractor one scalar — adaptation gain `m` relative to input strength `α` — moves the same circuit continuously from locked-to-input, through oscillating around the current estimate, to running free through the state space, with both switching thresholds analytic (`m = τ/τ_v` and `m = τ/τ_v + α/A_u`), and a noisy gain parked at the boundary makes exploration breadth itself a formula (`α_Lévy = 1 + 2μ/γ²`) ([[wiki/entities/adaptive-cann.md]]). So "when to roll out" and "how broadly" become two continuous knobs rather than mode switches — but what *sets* the gain is exogenous in that model, so the row's missing piece is now sharply localised: a controller for one scalar. No computational account of the metacognitive estimator is given, and neither candidate answers *how deep*. **A fourth candidate dissolves the row instead of filling it**: if the planner is a spacetime attractor, there is no rollout to schedule — the whole trajectory is a fixed point, depth is the number of delay-subspaces (an anatomical constant), and the plan is done when the dynamics converge, so *when*, *which branch* and *when to stop* all disappear and only *how many subspaces to build* remains ([[wiki/entities/spacetime-attractor.md]], Jensen et al. 2026). The cost is that this works only where the structure is already embedded in the weights; novel environments still need the search this row is about. **The first candidate to remove a free parameter rather than add a knob:** written over occupancies the active-inference planning objective is `⟨ℓ,μ⟩ + Φ(μ)`, a linear preference cost plus one convex negative-entropy term, so the epistemic-vs-goal arbitration named above has **no mixing coefficient** — the balance is the objective's geometry (Milosevic et al. 2026). The same result sharpens what is still missing: the nonlinearity means no globally Bellman-optimal value function exists, so "which branch" cannot be read off a cached `V` and the planner must relinearise between iterations; and *how deep* is still unanswered, though now priced, since the mirror-descent smoothness constant is `L = ½T(T+1)` **The first candidate with a *stopping* rule rather than a starting one:** rewriting the same objective as a ρ-POMDP belief utility (`ρ_EFE(b,a) = I_a(b)` for information-gathering actions, `0` for terminal ones) makes *keep looking vs. commit* one scalar comparison — observe while `−c_k + I_k(b) + E_o[max_a V]` exceeds `max_i E_b[R_i]` — and the crossover appears without a tuned threshold, a confidence criterion or a metacognitive estimator (Cooper & Velasquez 2026). Measured against tuned additive bonuses this is exactly where the difference lives: at `w = 100` on Diagnosis a bonus agent takes 13.21 tests for 99.3% success and `−3.63` reward, the derived weight takes 9.73 for 97.1% and `−1.50`, and *planning depth amplifies the miscalibration* rather than damping it. Two limits on the row's progress: the rule holds only where information-gathering leaves the hidden state fixed (`Δ_T = 0`), i.e. for measurement and not for intervention; and it optimises expected reward, not accuracy — the success-maximising weight is 20–200× larger, so a controller that must be *right* is back where the row started  **The estimator the row has been calling missing now exists, and it is cheap:** run both controllers as approximate Bayesian learners and adopt, *per action*, the value estimate of whichever has the smaller posterior variance — no metacognitive module, no value-of-computation calculation, and the criterion is a quantity each learner already maintains (Daw et al. 2005, [[wiki/concepts/amortized-inference.md]]). The crossing points are derived rather than tuned: caching wins with overtraining, task simplicity and distance from reward; search wins early, near reward, under task complexity and under frequent contingency change; and fan-out topology favours the cache while fan-in or linear topology favours search, which is the row's only *structural* routing signal. What is still missing is entirely on the machine side — no deep planner reports the uncertainty its own truncation injects (`computational noise`), so the comparison cannot be instantiated even though it is specified. **The first *optimal* stopping rule, valid only inside a strong restriction:** where the candidates are already enumerated, commit when the normalised log-posterior over them, `y_i − ln Σ_j exp(y_j)`, crosses a threshold — asymptotically optimal for any `N`, decision time growing only as `ln N`, its one free gain parameter provably one-sided in cost, and its normaliser computed by a dedicated recurrent subcircuit rather than as a free arithmetic step (Bogacz & Gurney 2007, [[wiki/concepts/evidence-accumulation.md]]). This closes the *when is the answer good enough* clause for a fixed candidate set and sharpens what remains: the rule says nothing about depth or branch, and its enumeration requirement is precisely what an open-ended planner lacks — so the row's residue is now *constructing* the alternatives (G33), not scoring them. **The row's *which branch* clause has a deployed answer and its *how deep* clause has a constant** ([[wiki/entities/alphazero.md]], Silver et al. 2017): selection by low visit count / high learned prior / high mean value is a branch policy computed entirely from quantities the agent already maintains, and it buys equal-or-better play than the strongest alpha-beta engines while evaluating ~875× fewer positions per second — so the missing piece is demonstrably not branch choice. The budget is 800 simulations per move, in every position, in all three games; and the search reports visit counts and a mean value but never the uncertainty its own truncation injected, which is the one quantity the Daw et al. 2005 crossing rule above needs. The row is therefore now sharply split: *which branch* is answered on a known model, *how deep* is unaddressed by the field's strongest planner.
