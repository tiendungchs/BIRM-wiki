# G43 — Nothing arbitrates between concurrent reference frames

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** Two structural codes over the same space are shown to be independently oriented in one system — or the wiki records the single-frame finding as decisive and closes the row against it.

## Why it blocks the target

Every structural code in the wiki is singular: one `g`, one map, one integrator. Biology appears to run many at once — grid, place and head-direction cells in S1 and V2 alongside the entorhinal set, integrating different velocity signals (mEC grid cells follow physical motion while place cells follow visual input under decoupling) — and the columnar proposal makes this thousands of object-anchored frames rather than a handful. No architecture says how many frames to instantiate, how a frame is allocated to a new object, or how inconsistent frames are reconciled. "Coincidence voting" is asserted; the consensus rule, the tie-break and the failure mode are unspecified. The authors' own hedge (a *subset* of neurons recruited dynamically by task context — "dynamic resource allocation") makes even the *count* context-dependent

## Best current answer

None — and the biological case for the gap has weakened. Every abstract task in which more than one region's grid orientation has been estimated finds them **registered to a single angle**: entorhinal + ventromedial prefrontal over concept space (Constantinescu et al. 2016), and entorhinal + medial prefrontal + posterior cingulate + temporoparietal junction + superior temporal sulcus over a social decision space, stable across ~9 days (Park et al. 2021). If frames are shared-orientation by construction, arbitration reduces to weighting commensurate readouts, and the engineering problem is *how registration is maintained*, not how disagreement is settled. The nearest machine-side thing remains G40's factorise-or-entangle decision, which asks whether to split a code and not how to combine several once split; [[wiki/concepts/contextual-inference.md]] arbitrates over contexts but its nodes are scalars and share no structure. The theory that opened this gap supplies a *channel* but still no rule ([[wiki/entities/thousand-brains-theory.md]]): a second output from layer 2/3 sending votes laterally, with many hypotheses held simultaneously per column as sub-threshold dendritic priming and a rich-get-richer cascade plus lateral inhibition converging on the hypothesis in the intersection. What it does not supply is exactly what this row asks — no commensurability rule for two object-anchored frames (identity is voted on, matched pose is assumed), no stopping rule or null outcome when consensus fails, and no delimitation of the eligible voter set. **The primary adds a candidate *operator* while leaving the rule untouched** (Hawkins et al. 2019): displacement cells difference two grid states module by module, so relating two object-anchored frames is a subtraction returning a vector in the same modular format, and the serialisation is attentional — attend A, re-anchor into B's space, difference ([[wiki/concepts/displacement-codes.md]]). This converts the row's question from "how are frames reconciled" to "what makes two frames differenceable at all": the subtraction is only defined if both spaces share moduli, scale and orientation, and nothing allocates a module set to a new object or checks two spaces for comparability before differencing them. The re-anchoring step itself is named and never specified **The machine cost of having no frame at all is now measured** ([[wiki/entities/v-jepa-2.md]]): an action-conditioned world model that must infer the action coordinate axis from monocular pixels ends up with an inferred axis whose rotation error is close to *linear* in camera position over a 35°–85° sweep, systematic rather than noisy (~1.6 cm error against a ~5 cm ground-truth delta), and degrading downstream success. The repair is one 2×2 least-squares fit from self-generated random actions — unsupervised, reward-free, and the authors describe it and decline to run it. So at machine scale the row's residue is not "how do many frames vote" but "nothing ever fits the single frame it does have".

**The row now has its first positive biological case, and it is a lesion profile rather than a recording.** Retrosplenial cortex (`Rdg`/`Rga`/`Rgb`, areas 29/30; Vann et al. 2009, [[wiki/entities/retrosplenial-cortex.md]]) is anatomically placed between the frames — head-direction input from anterodorsal and laterodorsal thalamus to the granular subregions, visual input to the dysgranular subregion, reciprocal hippocampal and parietal connections — and its removal costs **little while one spatial mode suffices**. The full deficit appears only when modes must be switched or integrated: light → dark, local → distal cues, and most robustly when intra-maze cues are placed *in conflict* with extra-maze cues. The authors' summary is that rats with retrosplenial lesions cannot switch or integrate parallel modes of task performance. Three consequences for this row. (i) An arbitration module is **invisible to any task that presents one consistent frame**, which is why the abstract-task evidence above — all of it single-frame — kept finding registration and no arbitration; the two findings are compatible. (ii) It supplies an instrument requirement the wiki's evaluation inventory does not meet: *no benchmark in the wiki contains a cue-conflict design*, so nothing currently in the wiki could detect a frame-arbitration mechanism in a model even if one existed. (iii) It does not supply the rule. What is reported is that the arbitration fails, not how it succeeds — no consensus criterion, no tie-break, no report of what the animal does when the conflict is exact.

**And the same region's second review takes most of that back, while widening what the row has to arbitrate over** (Alexander et al. 2023, [[wiki/entities/retrosplenial-cortex.md]], `T383`). Three consequences, two of them costs. (i) The localised-arbitrator reading weakens: conjunctive egocentric–allocentric cells of the gain-field type are reported in **many** structures, and retrosplenial inactivation leaves boundary-anchored medial-entorhinal responses largely intact — so the cue-conflict lesion profile above survives as a *behavioural* signature of arbitration without licensing the claim that this region is where it happens. (ii) The number of frames to arbitrate goes up, not down: a third, **route-centered** frame is argued for, carried in retrosplenial ensembles that are split — some cells invariant to the route's allocentric placement, some drastically modulated by it — which is the only population in the wiki holding a route-relative coordinate and its allocentric embedding at once. (iii) The row inherits a definitional problem that sits under it: "transformation" has no operational criterion distinguishing a continuous active computation from the binding-and-recall of two co-occurring codes, so an arbitration or conversion mechanism cannot currently be certified as present even when the tuning is measured. The transferable version for a builder: **a frame-arbitration module needs both a cue-conflict task and a stated readout that separates converting from co-representing**, and the wiki's evaluation inventory has neither.


**And the one implemented architecture that holds two frames at once turns out to make their disagreement unrepresentable — which is this row's cleanest negative result** (Bicanski & Burgess 2018, [[wiki/entities/bb-model.md]]). The model runs an egocentric parietal code and an allocentric medial-temporal code simultaneously and converts between them continuously, so it is the strongest candidate the wiki has for an arbitration mechanism — and it contains none. There is one head-direction bump, one global interneuron gating the transformation bank, and therefore exactly one selected transform ([[wiki/concepts/reference-frame-transformation.md]]). Conflict is **architecturally denied**: the model cannot be in a state where two frames disagree, because the parameter that relates them is a single population with a single bump. Three things this settles for the row. (i) The failure mode of a single-parameter converter is not *error* but **undefined behaviour** — the gate thresholds total head-direction activity, so a two-bump parameter population has no specified outcome, and nothing in the model detects that case. (ii) It explains why the implementation never enters the regime the lesion literature finds the deficit in: every simulation is a *familiar* environment with a heading the agent trusts, and cue conflict is exactly what is not simulated. (iii) It prices the alternative — a `K`-element bank costs `K × |population|` units at *one* site, and the distributed reading needs one bank and one parameter feed per frame-holding module, so "how many frames" is a unit-count decision before it is an arbitration question. What it still does not supply is a rule, a tie-break or a detector for the disagreement it cannot represent.
