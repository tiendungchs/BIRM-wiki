# G43 — Nothing arbitrates between concurrent reference frames

**Status:** `OPEN`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Why it blocks the target

Every structural code in the wiki is singular: one `g`, one map, one integrator. Biology appears to run many at once — grid, place and head-direction cells in S1 and V2 alongside the entorhinal set, integrating different velocity signals (mEC grid cells follow physical motion while place cells follow visual input under decoupling) — and the columnar proposal makes this thousands of object-anchored frames rather than a handful. No architecture says how many frames to instantiate, how a frame is allocated to a new object, or how inconsistent frames are reconciled. "Coincidence voting" is asserted; the consensus rule, the tie-break and the failure mode are unspecified. The authors' own hedge (a *subset* of neurons recruited dynamically by task context — "dynamic resource allocation") makes even the *count* context-dependent

## Best current answer

None — and the biological case for the gap has weakened. Every abstract task in which more than one region's grid orientation has been estimated finds them **registered to a single angle**: entorhinal + ventromedial prefrontal over concept space (Constantinescu et al. 2016), and entorhinal + medial prefrontal + posterior cingulate + temporoparietal junction + superior temporal sulcus over a social decision space, stable across ~9 days (Park et al. 2021). If frames are shared-orientation by construction, arbitration reduces to weighting commensurate readouts, and the engineering problem is *how registration is maintained*, not how disagreement is settled. The nearest machine-side thing remains G40's factorise-or-entangle decision, which asks whether to split a code and not how to combine several once split; [[wiki/concepts/contextual-inference.md]] arbitrates over contexts but its nodes are scalars and share no structure. The theory that opened this gap supplies a *channel* but still no rule ([[wiki/entities/thousand-brains-theory.md]]): a second output from layer 2/3 sending votes laterally, with many hypotheses held simultaneously per column as sub-threshold dendritic priming and a rich-get-richer cascade plus lateral inhibition converging on the hypothesis in the intersection. What it does not supply is exactly what this row asks — no commensurability rule for two object-anchored frames (identity is voted on, matched pose is assumed), no stopping rule or null outcome when consensus fails, and no delimitation of the eligible voter set **The machine cost of having no frame at all is now measured** ([[wiki/entities/v-jepa-2.md]]): an action-conditioned world model that must infer the action coordinate axis from monocular pixels ends up with an inferred axis whose rotation error is close to *linear* in camera position over a 35°–85° sweep, systematic rather than noisy (~1.6 cm error against a ~5 cm ground-truth delta), and degrading downstream success. The repair is one 2×2 least-squares fit from self-generated random actions — unsupervised, reward-free, and the authors describe it and decline to run it. So at machine scale the row's residue is not "how do many frames vote" but "nothing ever fits the single frame it does have".
