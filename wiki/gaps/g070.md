# G70 — Every induced program in the wiki is a straight-line composition; nothing induces a loop, and the cost is that no program can extrapolate a count

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** An inducer emits a program containing a loop or recursion whose trip count is not fixed at synthesis time, and extrapolates a count beyond every training instance — the case unrolling cannot reach.

## Why it blocks the target

A transformation applied *until a condition holds* — translate the line across the grid until the border, repeat the motif to fill the space — has no fixed-length representation. Every inducer here emits a fixed sequence and must therefore *unroll*: `n` copies of the same clause, chosen from the training examples, which silently caps the test instance at `≤ n` repetitions. This is not a search-budget problem; the hypothesis class has no `Do Until`, `Repeat While` or recursion in it, so the correct program is not merely hard to find but inexpressible. It also makes the composition depth a *data* parameter rather than a program parameter, which is the opposite of what productivity requires

## Best current answer

**Nothing.** [[wiki/entities/ilp-arc-synthesizer.md]] names the hole explicitly and defers it to future work, after showing a task (`0a938d79`) that its unrolled program solves only because the test grid happens to need no more translations than the training grids did. [[wiki/entities/neo-neural-theorizer.md]] composes ≤8 codebook symbols by concatenation with no control flow at all; [[wiki/entities/bayesian-program-learning.md]]'s programs have a fixed part/sub-part structure sampled from the prior; [[wiki/entities/aixi.md]] has the whole computable class and no tractable search inside it. The host languages are Turing-complete in every case — Prolog, an executor network, a probabilistic λ-calculus — so this is a restriction on the *induced* class, imposed to keep the search finite. Note the biological side has the opposite shape: [[wiki/concepts/path-integration.md]] iterates an update rule an unbounded number of times by construction, but has no termination condition either **The end-to-end side of the same hole, measured** (Hupkes et al. 2020, [[wiki/entities/pcfg-set.md]]): where an inducer unrolls a fixed number of clauses, a trained seq2seq model holds a *length-indexed family of behaviours* in place of one operator. Trained on string arguments of length ≤5, LSTMS2S accuracy on every function drops to **exactly 0 at length 6** across all seeds; ConvS2S and Transformer decay smoothly to ~12 and ~9. A cliff at the training boundary is competence, not performance: `copy` was never acquired as a function of a variable-length argument. Productivity on held-out *sequence* lengths shows the same shape (0.30 / 0.31 / 0.50 against task accuracies of 0.79 / 0.85 / 0.92), and early end-of-sequence emission accounts for only 22 / 6 / 8% of it, so the cause is the missing iteration, not truncated decoding. **Now an authored eval axis rather than an incidental hole** ([[wiki/entities/arc-agi-2.md]]): *multi-step compositional reasoning* tasks are designed so the state after step `N` depends on the outcome of step `N−1`, with the paper's own statement that it is "virtually impossible to predict the position of object `N+1` without executing the previous `N` steps" (task `cbebaa4b`). A benchmark that deliberately populates itself with unrollable dependency chains is the first instrument in the wiki that would *score* this gap rather than merely exhibit it — except that it returns one exact-match number and no per-axis subscore, so the attribution is the authors' intuition.
