# G120 — No architecture regenerates its teaching signal from the memory that teaching signal created

**Status:** `OPEN`  
**Kind:** `arrangement`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** One system's learned predictor re-drives the channel that supplies its own teaching signal, with the return path independently ablatable, and the ablation is shown to leave first-recall behaviour intact while accelerating extinction — i.e. the loop is demonstrated to carry *persistence* and not *retrieval*.

## Why it blocks the target

In every architecture here the teaching signal originates outside the learner — from the environment's reward, from a critic's bootstrap, from a fixed cost. Nothing the learner has stored can put a signal back onto the teaching line. Two consequences a builder cannot express: a learned state that outlives the evidence for it, and an extinction rate that is a property of the *architecture* rather than of the disconfirming data.

Biology supplies both in one manipulation. Campos et al. 2018 ([[wiki/concepts/general-danger-channel.md]]) show that CGRP<sup>PBN</sup> neurons — the primary ascending relay for the footshock that *creates* a fear memory — are re-activated by the conditioned tone and by the conditioning context after learning. Silencing them with tetanus toxin **after** the memory is consolidated leaves freezing on the first extinction trial indistinguishable from controls, and then collapses the memory: minimal freezing by the second extinction session, matching never-conditioned animals, while controls keep freezing. So the conditioned stimulus re-supplies a fragment of the unconditioned signal, and it is that reafference, not the retrieval pathway, that resists updating.

```
learning:   US ──► danger channel ──► plasticity ──► memory
recall:     CS ──► [forebrain] ──► danger channel ──► plasticity ──► memory   ← the missing edge
```

The missing edge makes the system's own prediction a *source* of teaching signal. Whether that restrengthens the original association or blocks consolidation of a competing safe memory is not decided by the data, and both readings are architecturally interesting: one is a positive feedback loop on a weight, the other a veto on a second learner.

## Best current answer

**None built.** The nearest constructs each supply one half:

- [[wiki/entities/meta-rl-agent.md]] feeds `δ` back into the network as an **input**, which is `G57` — a teaching signal doubling as an observation. It does not let the network *emit* onto the teaching line.
- [[wiki/concepts/offline-replay.md]] and [[wiki/concepts/recall-gated-consolidation.md]] re-present stored experience to a learner, so stored content does drive plasticity again — but the replayed teaching signal is the *recorded* one, not one regenerated by the predictor at recall time, and replay is offline whereas this loop runs during behaviour.
- Eligibility traces and pessimistic value initialization both slow extinction, and neither is a loop: their rate is a hyperparameter, not a circuit that can be cut.

The cheap machine version: train a fear-conditioning agent in which the critic's own predicted negative value is added back to the reward channel with gain `α`. Sweep `α` and measure (i) first-recall response and (ii) extinction rate against the disconfirming evidence. The row's prediction is that `α` moves (ii) sharply while leaving (i) flat, reproducing the TetTox dissociation — and that large `α` yields a state that never extinguishes, which is the computational shape of a pathological fear memory and a candidate account of why some learned affect is not revisable by evidence.
