# G30 — The `g`/`x` factorization occupies only one slot of three

**Status:** `OPEN`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** An objective function is stated that is sensitive to path-consistency, and a system trained on it recovers a factorization that the same architecture trained on a code-length objective does not.

## Why it blocks the target

A design is specified by an objective function, a learning rule and an architecture. The wiki's central requirement — a content-invariant structural code `g` factored from content `x` — has been argued for **architecturally** (G1) and shown to be un-derivable from data (G16), but no page states a **quantity that is maximized when `g` is path-consistent and minimized when it is content-contaminated**. Without one there is nothing for a learning rule to ascend, so the factorization can be built but not *trained toward*, and no measurement says how far a given code is from it

## Best current answer

None. Candidate objectives exist for adjacent goals only (description length, reward-weighted log-probability, mutual information with the environment, empowerment), and none is sensitive to path-consistency. **(brainstorm)** The nearest shape is G26's constrained code length — price `g` and `x` on separate budgets — plus a commutativity residual: penalize disagreement between codes for the same node reached by different paths, which is an objective computable from trajectories alone. **One loss now has the right shape, from an unrelated direction** (Siméoni et al. 2025, [[wiki/entities/dinov3.md]]): `L_Gram = ‖X_S X_Sᵀ − X_G X_Gᵀ‖_F²` penalises *relations between elements* and nothing else — label-free, invariant to any transformation preserving inner products, so indifferent to the coordinates the content code happens to use — and it is measured doing the thing this row wants: an image-level content objective eroded the relational structure over 800k iterations while its own metric improved monotonically, and a term on the relations alone restored it **without costing the content code**. It is not the quantity (no path-consistency term; relations within one input, not across episodes; the target must come from a reference network), but it is the first demonstration in the wiki that a relational structure can be *held in place by gradient descent* while the code carrying it keeps changing. **One negative constraint now exists:** swapping the ELBO for a plain mean-squared-error loss in an otherwise identical spiking cognitive map drops grid emergence from 59.6% to 0.250%, so the *form* of the objective — not only which variables it ranges over — decides whether a structural code forms at all ([[wiki/entities/spiking-tem.md]]) **A second constraint, from the opposite direction:** in a predictive-coding network the objective is not designed at all — the ratio of the generative model's variance parameters `Σ^(l)` slides one architecture with one Hebbian rule between forward regression, the first principal component and inverse regression (Whittington & Bogacz 2017, [[wiki/concepts/predictive-coding-free-energy.md]]). So the slot may not need to be filled with a *formula*; it may be fillable with a **precision schedule** over an existing energy, which is learnable and physiologically ordinary. Nothing yet says which precision ratio makes `g` path-consistent — that is the gap restated, but now as a search over one scalar per layer rather than over the space of losses **(brainstorm)** **A third constraint, and it is an existence proof the gap should not ignore:** a plain next-token objective on Othello move sequences produced a *linear*, causally load-bearing, mover-relative state code with nothing in the loss asking for any of those properties ([[wiki/entities/othellogpt.md]]). Linear readability is currently a by-product, which is exactly why it is unreliable — no term defends it, and no one can say what would remove it ([[wiki/concepts/linear-representation-hypothesis.md]]). **A necessity/sufficiency ceiling on whatever objective is eventually written** (Locatello et al. 2019, [[wiki/concepts/disentanglement.md]]): a factorization penalty cannot by itself pick out the intended factorization, because for any factorized prior an infinite family of completely entangled latents yields the identical observation distribution — so the objective and the completely entangled solution have the same data term. An objective for this slot must therefore come **paired with a stated assumption about the data**, and the empirical half is worse than the theoretical half: across >12,000 models trained on six such penalties, the objective explains 37% of the resulting score's variance against ~41% for the random seed, and no unsupervised quantity ranks the runs (`G108`)
