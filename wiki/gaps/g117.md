# G117 — No architecture broadcasts one event on two differently-signed channels to different targets

**Status:** `OPEN`  
**Kind:** `arrangement`  
**Level:** `L2`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** One system emits, from the same outcome event, a signed value error and a rectified event-present magnitude on two channels with disjoint target sets, with each channel independently ablatable and each shown to be load-bearing for a different capability — learning what the outcome was versus deciding how hard to engage.

## Why it blocks the target

Every broadcast signal in the wiki is one scalar per quantity. Where several exist they are several *different* quantities on separate carriers — `δ`, `γ`, `β`, `α` in [[wiki/concepts/neuromodulatory-metaparameters.md]] — never one event split across channels that differ in sign convention and address space.

Midbrain dopamine is claimed to do exactly that ([[wiki/concepts/broadcast-channel-decomposition.md]], Bromberg-Martin et al. 2010). A ventromedial population carries a complete bidirectional value error, inhibited by aversive events and by reward omission. A dorsolateral population is excited by rewarding *and* aversive events and is **silent on omission** — a rectified, event-present magnitude that cannot be recovered from the signed error by any downstream post-processing, because the omission trials where the two differ are where the information lives. The two are claimed to reach different targets: nucleus accumbens shell versus core, orbitofrontal versus dorsolateral prefrontal cortex.

What this denies a wiki architecture is a *separately addressed engagement signal*. With one scalar, "the news was good" and "something important happened" are the same wire, so an agent cannot raise effort, working-memory engagement and orienting for a bad outcome without also assigning it positive value — and cannot assign an outcome value without also committing to engage. Both of the wiki's standing dopamine rows are conducted as if one signal had to be right: `T122` asks whether the scalar is an error or a gain when the split answer is that one population is each.

## Best current answer

**None built.** Two partial pieces exist and neither is the pairing:

- [[wiki/concepts/affective-opponency.md]] shows a two-population opponent code constrains only the *difference* of the activations, leaving the *sum* free for a second quantity — salience being the named candidate. That is a rival arrangement for the same requirement (one pair of wires rather than two channels), and no model here implements it either.
- [[wiki/entities/pbwm.md]] makes a broadcast scalar selective per module (`δ_j = snr_j · δ`), which addresses one channel rather than creating a second.

The machine-side experiment is cheap: give an agent two heads on one outcome — signed `δ` to the value learner, `max(0, |outcome|)·1[outcome occurred]` to a gain/effort controller with a disjoint target set — and ablate each. The prediction from the biology is a double dissociation: lose the signed channel and outcome learning fails while engagement survives; lose the rectified channel and the agent learns correct values but cannot mobilise effort for aversive outcomes.

## Status

`OPEN` — the biology is a review hypothesis with the pathway assignments inferred rather than traced, but the architectural question does not depend on the anatomy being right: the wiki has no system in which one event drives two channels at all. Adjacent rows: `G64` (one modulator setting a gain *and* a learning rate — the same signal at two timescales, where this row is two signals at one timescale), `T122` (what the scalar carries, which the split partly dissolves), `G116` (the designs the dopamine literature is adjudicated on do not cross valence with action).
