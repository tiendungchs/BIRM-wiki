# G90 — No architecture in the wiki has an internally generated mode that competes with the input-driven one, and none has an arbitrator

**Status:** `OPEN`  
**Kind:** `arrangement`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Why it blocks the target

Every system here is input-driven by construction: give it a prompt or an observation and it computes; give it nothing and it does nothing. Biology's arrangement is the opposite — the default mode is what runs when no input demands anything, it *deactivates* under nearly every externally directed task, the two modes are anticorrelated, the switch completes within seconds (event-related deactivation, not just blocked epochs), and the trade-off is paid in measurable sensory gain (individuals with the strongest intrinsic default coupling show the most attenuated sensory-evoked responses). Three things follow that no wiki architecture supplies: an **idle-time policy** (three literatures — consolidation via [[wiki/concepts/offline-replay.md]], competence updating via [[wiki/concepts/default-self-model.md]], and scenario construction here — all claim the same budget and none says how it is split), a **mode variable** that is not a function of the current input, and an **arbitrator** that assigns the network. Without the third, "internal mode" is either always-on rumination or never-on, and the boundary between simulated and perceived content has no maintainer

## Best current answer

Nothing here holds any of the three. The biological candidates are both unresolved in the source: local mutual inhibition between the two systems, or a separate frontoparietal system anatomically interposed between them (evidence preliminary at the time of writing). The clinical dissociation weakly favours a separate arbitrator — under-use and over-use of a network that may itself be intact are two settings of one control variable, and the autism data locate a frontoparietal abnormality alongside the default one, which a symmetric local competition would not predict. **The cheapest biological instance of the mode itself is now in the wiki, and it needs no arbitrator at all**: under a *constant* dichoptic input, macaque prefrontal content switches spontaneously on a gamma-distributed dwell time, and the switch is decodable at 95% single-trial with the strong feedforward transient that accompanies externally imposed switches **absent** (Kapoor et al. 2022, [[wiki/concepts/ignition.md]]). That is an internally generated content change competing successfully against an unchanged input, produced by competition-plus-adaptation-plus-noise and nothing else — which narrows this row usefully: an internal mode does not require a mode variable or a scheduler, only a landscape in which the incumbent's own adaptation makes it lose. What binocular rivalry does *not* supply is the arbitrator, since the alternatives it switches between are two readings of the same input rather than an internal and an external source. **A candidate arbitrator now exists in biology and still has no wiki instance** (Menon 2023, [[wiki/entities/salience-network.md]]): a third system — anterior insula plus dorsal anterior cingulate — whose bottom-up salience detection is claimed to disengage the default network and engage frontoparietal cortex by *one* mechanism, with the anterior insula as causal outflow hub and rodent optogenetics as the only interventional support. Three specifications it adds to this row: the arbitrator is a **detector**, not a scheduler (one relevance scalar, two opposed gains, no policy); its input is stimulus salience rather than goal relevance, which is what makes an internal mode interruptible by content the current task does not care about; and the mode has a **rebound** — the default is a state the system returns to once the salient event is handled, not the absence of a call. The row stays open on all three counts, and on a fourth: the same review reports the opposite directed gradient (default network with the largest net causal outflow of any network, at rest and during memory formation) without adjudicating it ([[wiki/empirical-tensions.md]] T257). The nearest wiki machinery is [[wiki/concepts/integration-segregation-balance.md]]'s demand-graded integration axis, which is a *measurement* on a task-driven system rather than a mode assignment, and [[wiki/concepts/cognitive-control.md]]'s task-set bias, which selects among externally directed tasks only. **A trigger and a second controlled variable** (Satpute et al. 2026, [[wiki/concepts/broadcast-hierarchy.md]]): the mode is not switched by salience alone but by whether *the immediate past still predicts the incoming input* — autopilot while it does, global reconstruction of the generative model from **endogenous priors** when it does not, with scene/goal/agent/affect changes as the named triggers. That supplies the row's missing input signal in a form an architecture can compute (a residual against the immediate-past prediction, not a salience detector's output), and adds a variable no wiki architecture has alongside the mode: the **scope** of the update — how many levels a revision reaches. It also says the internal mode is not idle-time filler but the *repair path*, which changes what the arbitrator is arbitrating: not internal-vs-external attention but local-adjustment-vs-global-revision. **The output is not a scalar and its address space is edges** (Gao et al. 2013): the rest→task reconfiguration is two separately controlled halves — release of the network's own periphery (precuneus, angular gyrus, vermis; core coupling `0.43 → 0.24`) and acquisition of outside regions (insula/inferior frontal, anterior and middle cingulate; `0.05 → 0.34`) — reversible to the rest set-point and demand-graded, with the first half predicting reaction time only and the second accuracy only. A single gain on the internal system's activity produces at most the first. **And the sign of the internal↔control coupling is itself the variable** (Tripathi et al. 2025): negative during sustained attention and during creative idea *generation*, positive during idea *evaluation*, goal-directed self-generated thought, semantic retrieval and scene construction — so the arbitrator sets *whether the control system is coupled to the internal one*, not only how hard the internal one is suppressed, and the same measurement makes this row and [[wiki/concepts/refinement-loop.md]]'s permanently-attached verifier the same missing scheduling variable. Six unrelated pathologies plus aging fail in one direction on it (reduced suppression, or lost anticorrelation), and meditation moves it back in adults **The generator now runs with the input removed** (Dwarakanath et al. 2023, [[wiki/concepts/cortical-state-bistability.md]]): the prefrontal oscillator that gates those spontaneous content switches — 1–9 Hz release bursts antagonising 20–40 Hz hold bursts — is present in **resting state**, with a gamma-distributed beta dwell of 1.2 ± 1.44 s against 1.54 ± 1.28 s for perceptual dominance. That is stronger than the rivalry result it extends: the internal mode is not a re-reading of an ambiguous input but a free-running clock the input is sampled by, and it hands this row a calibration identity that costs nothing to check in an implementation — **idle-mode alternation rate should equal task-mode alternation rate**, and any system where they differ has a stimulus-driven scheduler rather than an intrinsic one. It also splits the row's missing mode variable in two: a content-free hold/release state that is separately schedulable from *what* is held, which no architecture here has as an object.
