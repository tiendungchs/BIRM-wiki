# G35 — No model pays for its own parameters

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A model wins a two-part code against a general-purpose compressor with its parameters counted into the message, or prequential coding is actually evaluated and the accounting change is shown to be the whole of the effect.

## Why it blocks the target

A learner is supposed to be a compact description of a rich environment (the genome-bottleneck argument, [[wiki/concepts/three-component-framework.md]]). Measured as a two-part code — parameters counted into the compressed output — every neural model loses to gzip by two orders of magnitude: Chinchilla 70 B compresses enwik9 to 8.3% raw and **14008.3%** adjusted, against gzip's 32.3%. Parameters are themselves near-incompressible (92.2% under gzip). Every corpus therefore has an optimal model size past which scaling makes the total description *longer*, so "scale it up" stops being free the moment the model counts as part of the answer

## Best current answer

Prequential (online) coding charges the *training script* instead of the parameters and favours overparametrised networks — but requires training during both encoding and decoding, and was not evaluated. A second partial route attacks the parameter count directly rather than the accounting: a handcrafted dendritic connectivity mask matches a dense network's accuracy with 1–3 orders of magnitude fewer trainable parameters and no overfitting at any size tested, i.e. the description shortens without the outputs shrinking ([[wiki/entities/dendritic-ann.md]]) — demonstrated only on image classification, and the mask itself presupposes a spatial metric over the inputs. **(brainstorm)** The accounting the wiki actually wants is a third split: charge architecture + learning rule + objective, charge nothing for parameters, and measure code length on a held-out environment *family*. **The same gap has an inference-time twin, and it now has a price tag.** Once a method searches at test time, its score is bought rather than possessed: no number attaches to an approach, only to (approach, compute budget) — ~10⁸ programs per task is the estimate for reaching 85% on ARC-AGI-1 by one 2024 method, and ~$30,000 per task is the o3-high figure. Against which the 2024 competition's own 1,000× compute gap bought 0.1 points, so nobody knows the shape of the curve either ([[wiki/empirical-tensions.md]] T204). Neither the parameter charge nor the inference charge appears in any score the wiki holds **The row's first genuine near-miss, and it comes from the parameter side rather than the accounting side** (Chollet et al. 2026, [[wiki/concepts/refinement-loop.md]]): CompressARC reaches **20% on ARC-AGI-1 with 76K randomly-initialised parameters**, no pretraining, no dataset and no search, by minimizing the description length of a *single task* at test time; TRM reaches 45% on ARC-AGI-1 and 8% on ARC-AGI-2 with **7M** parameters. A two-part code that counts 76K parameters into the output is a rounding error against Chinchilla's 14008% adjusted rate, so for the first time the wiki holds a non-trivial score whose parameter charge it could actually pay. The catch is exactly the alternative this row names as unevaluated: the information has moved into the *training procedure* (architecture, loss, ~20 min of gradient descent per puzzle), which is prequential coding arriving as an empirical result rather than as a proposal — and nobody has charged it. **The efficiency twin also stops being hypothetical**: [[wiki/entities/arc-agi-2.md]] makes cost-per-task a mandatory reporting axis on every line, and supplies the wiki's first clean two-point curve — the same frozen Gemini 3 Pro scores 31% at $0.81/task and 54% at $31/task under a refinement harness. **And the charge has a training-side twin nobody levies**: ARC's competition rules cap inference compute (one P100, 12 h) and are silent on pretraining and on synthetic-task generation, so entrants trained on large volumes of generated ARC-like tasks at zero accounted cost — the unlimited-priors channel relocated into a line item the rules do not read (Pfister & Jud 2025).
