# G9 — W is flat; there is no third tier

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** _unset — see [[wiki/priority-tasks.md]]_

## Why it blocks the target

Two levels suffice only while the rewrite is expressible in the base vocabulary. Self-amendment that edits the rule-changing rules needs a distinct rewrite-graph level, and W itself would have to be a discoverable graph rather than a parameter blob

## Best current answer

**Self-referential meta-learning** — a network that recursively modifies *all* its parameters, so the learner can modify the meta-learner, in principle to arbitrary depth. The first named mechanism for this row. Not yet demonstrated on structure acquisition, and the reported cases restrict the search space until self-improvement is tractable. **The recursion now has a worked base case at level two**: a hand-written *meta-grammar* that samples the latent grammars defining each episode ([[wiki/entities/mlc.md]]) is the wiki's first concrete generator of `p(T)`, and any static corpus can be converted into one by within-class symbol permutation — which locates the missing tier precisely, since the meta-grammar itself is authored and nothing samples *it*. **And the tier now has a full design specification — which says the row was asking for the wrong object.** [[wiki/entities/nomic.md]] is a playable rule system in which the amendment rules, the conflict-precedence rule, the win condition and the rule requiring obedience are all inside the rewritable set, and it does *not* build a distinct rewrite-graph level: mutability is a **per-rule boolean** that a single extra operator (`transmute`, gated by unanimity) flips, so the tower of meta-levels exists implicitly — a rule-change can transmute the transmutation rule — and is never instantiated. Read as an architecture, that is one extra binary field per rule-node plus a gate on the operator that writes it, which is why the row's framing ("W itself would have to be a discoverable graph") is more expensive than the problem requires. Three further pieces come with it and are the parts a builder cannot skip: a **decidable precedence order** (immutable strictly dominates mutable and voids it entirely; within a tier, lowest ordinal wins, with a self-declaration escape hatch and a numeric cycle-breaker), an explicit **liveness invariant** in the dominant tier (at least one mutable rule must always exist; rule-change must never become completely impermissible), and a **defined outcome for undecidability** — self-reference is licensed outright rather than prohibited, and a state whose legality cannot be resolved is made *terminal and winning*, so the expressiveness is paid for with a halt-and-assign rule instead of a syntactic ban. It also shows what the tier costs: meta-stationarity and boundedness (two of G7's five clauses) are given up by construction, the rewrite vocabulary becomes open natural language so there is no generator left to learn, and the reward function moves *inside* `rule_config` — patched only by entrenching the objective's **form** while leaving its parameters mutable (G72). Nothing is implemented and nothing is measured, so the row stays `PARTIAL`: what changed is that the target is now specified operator-by-operator rather than named. Suber's own two open questions are the row's remaining content — can any rule be made truly immutable while an amendment power over everything else survives, and can the amendment power be completely and irrevocably repealed
