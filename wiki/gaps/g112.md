# G112 — Which carrier holds the fast store is not identifiable from behaviour: the synaptic and activity solutions to structured sequence memory are provably the same function

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A behavioural protocol — inputs and scored outputs only, no decoding, no neuron-budget sweep, no learning curve — separates a weight-stored from an activity-stored sequence memory; *or* the algebraic duality is shown to break outside the group-structured task family, with the boundary stated and a task on the far side of it exhibited.

## Why it blocks the target

The wiki grades memory architectures by what they can do: generalise to novel state–observation pairings, survive a delay, bridge 16,384 steps, hold a value against interference. Whittington et al. 2025 ([[wiki/concepts/activity-slots.md]]) prove that for the whole family of structured sequence-memory tasks, two architectures the wiki treats as rivals compute the **same function**. `H_v` is the transposed, expanded `G_v`; one solution is a rearrangement of the other; once trained, both generalise identically over novel pairings. Every separating measurement they report is *non-behavioural* — neuron-budget scaling (`O(\|states\|)` vs `O(\|states\|²)`), sample complexity, and linear decoding of position vs slot sequences.

This bites three ways. (i) The wiki's regional claims lose their evidence base: "hippocampus is a map / an index" (`T28`) and "working memory is prefrontal cortex's specialized function" (`T92`) are arguments about carriers being run on behavioural data that cannot see carriers. (ii) The short-term-synaptic-plasticity vs. persistent-activity dispute ([[wiki/entities/stsp-working-memory-rnn.md]], [[wiki/concepts/working-memory.md]]) is re-typed as a carrier question that its own delayed-match tasks cannot settle. (iii) A builder choosing between a fast-weight store ([[wiki/concepts/fast-weight-programming.md]]) and a recurrent activity store cannot use any benchmark in the wiki to make the choice — the decision is a neuron budget and a sample-complexity budget, and neither is reported.

## Best current answer

**Three non-behavioural instruments, all from the same source, and none of them cheap.**

1. **Scaling curve at matched neuron budget.** Sweep task size and read where accuracy breaks. The activity solution breaks first, by the ratio of `\|states\|`. Requires training many models and controlling for the memory module's own parameter count — which the source does.
2. **Cross-task linear decoding.** Train decoders across many tasks (not one) and ask whether *abstract position* or *slot sequences* are recovered. The discriminating control is that a slot sequence is **not** a lagged copy of the input whenever velocity varies, so "past sequences decodable" and "slots decodable" come apart on 1D/2D navigation and coincide on ISR and N-back — meaning the instrument only works on tasks with non-constant velocity.
3. **Slot algebra** as a task-free compositionality probe: substitution in one slot must be a fixed vector offset independent of the other slots' contents. This one is the closest to an instrument, since it needs no task performance at all — but it tests *whether the activity solution is clean*, not *which solution is in use*, and networks that fail it still solve the task.

**What is not yet available**: any of these applied to a biological recording as a carrier test rather than as a model-fitting exercise, and any statement of where the duality stops. The source is explicit that naive activity slots are *not* learned on some sequential WM tasks — which is the most likely place the equivalence breaks, and it is unexamined.

## Status

`OPEN` — the equivalence is a derivation, not a conjecture, and nothing in the wiki's evaluation layer ([[wiki/concepts/certification-instruments.md]], `G17`) proposes a behavioural test for a carrier. The three candidate instruments above are all representational or resource-based, so the honest position is that carrier questions must be demoted out of the behavioural benchmark suite entirely.
