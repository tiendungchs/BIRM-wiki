# G115 — Every geometric claim read off a fitted low-dimensional embedding is uncontrolled, because no one runs the arbitrary-target embedding that scores the same

**Status:** `OPEN`  
**Kind:** `part`  
**Level:** `L0-INSTR`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A geometry claim in the wiki's own literature — a manifold shape, a cluster arrangement, an antipodal or additive relation in a fitted subspace — is reported alongside the same statistic computed on an embedding fitted to an **arbitrary target shape** under the same fidelity objective, and the arbitrary one scores worse; or the control is shown to be inapplicable to a stated class of claims, with the class stated.

## Why it blocks the target

The wiki reads structure off fitted low-dimensional objects in at least three places: population manifolds and their learning-stage shape sequences ([[wiki/concepts/population-geometry.md]]), compositional and antipodal geometry in PCA subspaces of activation space ([[wiki/concepts/linear-representation-hypothesis.md]], `T159`), and cluster-distance arguments in probing reports ([[wiki/concepts/representation-probing.md]]). Each is offered as evidence about the *system*. None is accompanied by a control that could have come out negative.

The control exists and is cheap. Chari & Pachter 2023 fit an autoencoder that places points in an **arbitrary** 2-D shape — an elephant, a flower — while preserving ambient pairwise distances, and it matches t-SNE/UMAP on inter-type distance correlation and **beats both on intra-type correlation on every dataset tested**, including against density-preserving variants ([[wiki/concepts/projection-distortion.md]]). So the fidelity statistics conventionally offered in support of an embedding are satisfied by an embedding whose shape carries nothing. Any argument of the form "the representation has structure S, because the embedding shows S" is therefore unlicensed until S is shown to distinguish the real embedding from an arbitrary one.

This is `L0-INSTR` and not a methods footnote because the claims it gates are `L0` claims — whether a system acquired a structure at all.

## Best current answer

**None in the wiki's own literature; one worked instance outside it.** The Picasso construction is the only run of this control anywhere in the sources here, and it is on gene-expression data. Adjacent partial controls that exist:

- **Ambient-space statistics that bypass the projection entirely** — CCGP, parallelism score, shattering dimensionality, population-vector correlation matrices. These are the right answer where the claim can be reformulated in them, and the reason [[wiki/concepts/population-geometry.md]]'s exposure is partial rather than total. They do not cover claims whose content is a *shape* (a ring, a hub-and-spoke, a split shank).
- **Raw-versus-projected reporting** — the one paper in the activation-geometry literature that reports both columns (`T159`), which is a weaker control: it shows the projected number is not the raw number, without showing whether the projected number could have been obtained from nothing.
- **Behavioural prediction from the fitted object** — Sadtler et al. 2014 ([[wiki/concepts/manifold-constrained-learning.md]]), where a fitted manifold forecasts an unseen perturbation's outcome. This is a *stronger* standard than the control asks for and closes the question for that one result, but it needs an intervention and so is unavailable post hoc.
