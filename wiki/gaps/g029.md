# G29 — Exploration of the space of architectures is not algorithmic

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** An architecture-search procedure discovers a structural ingredient the wiki names as needed, at a cost a research group would actually pay — or the wiki records that hand-design is the answer and closes the row against that finding.

## Why it blocks the target

The wiki's control surface (G16) puts the heaviest lever in *architecture*, and that lever is currently pulled by researchers, not by a search procedure. Gradient descent optimises weights inside a fixed structure; the ingredients this wiki wants are structural. If the representations cannot be built from scratch in weight space regardless of data volume, then the scaling route is closed for reasons independent of the identifiability (G16) and compressibility (G26) arguments

## Best current answer

Genetic programming and structure-search algorithms are named as the direction, with the warning that their dynamics would resemble evolution's slow stochastic hill-climbing rather than the smooth progress of gradient descent — i.e. the cost profile machine-learning practice is least willing to accept. The stated alternative is to *stop searching* and build infant-like representations in by hand. **A third option is now demonstrated, in a restricted setting:** Hebbian Architecture Generation grows a recurrent connectivity matrix from an *empty* start by a purely local unsupervised rule — a neuron outside a homeostatic band on its own mean rate or activity variance grows one incoming edge from the off-band neuron it correlates with most over a randomly-resampled window — and the grown reservoirs beat every static and locally-tuned baseline on five classification benchmarks, at the cost of **one unsupervised pass**, no gradient and no candidate-network enumeration. The search step is a synapse rather than an architecture, which is why the cost profile is not evolution's ([[wiki/entities/hag-reservoir.md]], Cazalets et al. 2025). Restrictions: edge set only, within a fixed neuron pool; excitatory-only weights; the grown graph is symmetric (`r_ij = r_ji`), so no directed edge is expressible; growth is aimed but pruning is random; no objective is named that the growth ascends. **A fourth option exists where the target class is known, and it is not a search at all:** for time-invariant fading-memory filters, the architecture can be **written down in closed form** — Li, Fong & Tiňo 2024 give a constructive chain (Egerváry dilation → eigenvalue perturbation onto roots of unity → block-circulant lifting → sign-matrix quantisation of the input weights) that turns any linear reservoir system into an `ε`-close ring with a *single* recurrent parameter `λ`, read off the target rather than searched ([[wiki/entities/simple-cycle-reservoir.md]]). The same result narrows what the lever is worth: three visibly different constrained families are all universal over that class, so recurrent topology cannot be chosen on expressivity grounds there ([[wiki/empirical-tensions.md]] T174). Restrictions: linear state dynamics only; existential in the resulting dimension `n' ≈ (N+1)·n·k`, `k > nm`, with no lower bound; and it presupposes a *target system already in hand*, so it converts architecture search into architecture **compilation**, not discovery  **A fifth option, and the first that searches *at inference time* rather than at build time** ([[wiki/entities/autotom.md]], Zhang et al. 2025): enumerate the model space up front (30 configurations of a mental-variable Bayes net per timestep, `30^(t−ts+1)` over a window), then greedily hill-climb it per *question* against a closed-form objective — add the single variable that most raises `U(M,q) = −H(P(q|X)) − α|M|`, and when no variable helps, extend the context one timestep backwards. Cost: ~27 API calls and ~10K tokens per query, which is the wiki's first per-search price tag on structure discovery of any kind. What it does not do is enlarge the vocabulary: the four addable variable types and the local-conditional rewrite each addition performs are both authored tables, the search is greedy with no backtracking, and the recursion order — the choice with the steepest cost curve — is set by a single LLM call and never searched. The transferable part is the objective's *shape*: it is query-conditioned, so the criterion selects a different structure for a different question over identical observations, which no fit- or length-based criterion can do.
