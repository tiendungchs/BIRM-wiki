# G13 — No tractable system covers all six hardness sources

**Status:** `PARTIAL`  
**Kind:** `part`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A bounded architecture states a *principled* drop rule over the six hardness sources — which to abandon and why — rather than a compute budget, and its coverage is measured against that rule.

## Why it blocks the target

AIXI is the only known system that does, and it fails on computability. Every real architecture is a bounded-program approximation that drops whichever sources its search budget cannot reach — and there is no principled account of which to drop

## Best current answer

**AIXItl** is the one principled bounded approximation: enumerate every program of length `≤ l̃` with a proof that it never overrates its own expected credit, run them all, act on the highest self-certified value. It dominates every such policy at `O(2^l̃·t̃)` per cycle plus `O(l_P·2^l_P)` setup — so the drop rule is "whatever exceeds `l̃`", which is a budget, not a principle. The transferable part is the *selection criterion* (self-certified value), not the enumeration
