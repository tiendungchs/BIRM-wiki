# G78 — Nothing sets a slow variable's time constant, and memory span is that time constant

**Status:** `PARTIAL`  
**Kind:** `part`  
**Level:** `L3`  
**Registry:** [[wiki/architectural-gaps.md]]  
**Closes when:** A slow variable's time constant is set by the retention interval the task actually demands, discovered rather than swept — and the mapping from `τ` to span, which DEXAT shows is not the identity, is stated. Run-time form is `G94`.

## Why it blocks the target

Every store built from adaptation fixes its span at design time. A single-exponential ALIF needs `τ_a ≈ 1200 ms` to hold 1200 ms; DEXAT holds the same span from `τ_b1 = 30 ms` and `τ_b2 = 300 ms`, and raising `τ_b2` to 500 ms converges *faster* — so the mapping from constants to span is not even monotone in an obvious way, and it is found by grid search. The same constants simultaneously set inter-item interference (long adaptation → interference) and how much gradient flows through the adaptive threshold. This blocks the target because a task's required retention interval is discovered at run time, not at design time: an agent traversing a latent graph does not know in advance how long a partial path must survive

## Best current answer

Four partial moves, none a mechanism. (i) **Add timescales**: two coupled exponentials beat one, `L` kernels beat two (multi-timescale adaptive threshold) — buying range with parameters, which pushes the tuning problem up rather than solving it. (ii) **Distribute them by hand**: Yin et al. give each hidden layer a different adaptation constant and reach 92.1% Google Speech Commands, so heterogeneity works and is still authored. (iii) **Optimise them**: the review proposes Bayesian or gradient-based hyperparameter search over the adaptation parameters plus systematic ablation — offline, per task. (iv) **Make the device set it**: in NVM implementations the adaptation constant is tuned by programming current, which makes it *settable at run time* and is the only entry here that could close the row — nothing has used it as a learned or controlled signal. Compare G38, where the same shape of problem (a bias fixed at design time that should be dynamic) is stated for separation-vs-completion. **(v) Learn them, per unit, on a second loop** — the first entry that is a mechanism rather than a sweep (Wang et al. 2024, [[wiki/concepts/neuronal-parameter-heterogeneity.md]]): `α^k = [τ^k, γ^k, C^k, u_th^k, u_re^k]` per neuron, optimised by gradient descent on a held-out split in a bi-level program alternating with the weight loop, with the second-order term dropped to first order at no accuracy cost and a Laplacian penalty making the constants a smooth field over the network rather than i.i.d. draws. Three things this buys that (i)–(iv) do not: the sweep it replaces is *measured* to be replaced (accuracy holds across `τ` and `v_th` initialisations that break the homogeneous control); the loop is separable from the neuron model (the same procedure improves an SNU network); and the constants it finds match the recorded distributions for human middle temporal gyrus and mouse V1 layer 4, so the optimum is not arbitrary. What the row keeps: `α` is frozen at deployment, the loop is offline and per-task, and it needs a held-out split — so a retention interval discovered *during* a traversal is still unreachable, which was the row's actual claim
